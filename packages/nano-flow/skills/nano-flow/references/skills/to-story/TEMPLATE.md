# Story 模板

属于 epic 的故事使用四级标题；独立故事使用三级标题，不创建空壳 epic。

```markdown
# {工作名}

## 原始想法

{用户的最初表述，保留原话}

## 角色

- **{角色名}**：{是谁、处境与工作方式}

## 故事

### {Epic 标题}

{这组故事共同完成什么}

#### US-001 {故事标题}

作为 {角色}，我 {想要}，以便 {收益}。

- [ ] {可判定的验收结果}

### US-002 {独立故事标题}

作为 {角色}，我 {想要}，以便 {收益}。

- [ ] {可判定的验收结果}

## 迷雾

{尚未澄清的空白；澄清后迁移到权威章节}

## 上下文

{通过路径或 URL 引用生成故事时使用的现有产物；域内文档使用相对路径}
```

模板是最小集合。新增章节必须同时满足：内容无法归入现有章节；缺少它会使执行或验收丢失关键信息。章节标题使用中文。
