# Questing

根据任务与已有产物自行选择分支，复用仍成立的结论与确认：

| 分支     | 触发                   | 流程                                                                               |
| -------- | ---------------------- | ---------------------------------------------------------------------------------- |
| `story`  | 需要生成或打磨用户故事 | [用户逐轮澄清](STORY.md)，维护 `story.md`                                          |
| `domain` | 拷问计划、决策或设计   | [agent 自动回答](DESIGN.md)，形成审阅文件；涉及领域变更时同步[领域文档](DOMAIN.md) |

故事澄清完成后继续设计；已有故事直接从设计开始。任务涉及的分支及其产物与完成标准均成立时返回。确认后的结论写入各自唯一权威位置。
