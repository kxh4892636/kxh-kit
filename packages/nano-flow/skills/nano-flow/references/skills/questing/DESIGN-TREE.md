# Design tree

**Design tree** 按决策依赖展开：每个答案决定下游要回答的问题。**Frontier** 是前置已有答案、当前可回答的全部问题。

按 **rounds** 推进：

1. **取证**：事实由 agent 从代码与工具查明并保留来源；需进一步探索时委派 subagent，将探索作为未决前置，只暂停其下游，其余 frontier 继续推进。可检索事实查明后，才回答依赖它的决策；事实 blocker 保留现场与恢复条件。
2. **提问**：每轮覆盖整个 frontier，问题使用本次 quest 内唯一递增编号，并附推荐答案与理由；依赖本轮未决答案的问题留到下一轮。
3. **推进**：用本轮回答更新 tree，明列判断假设，记录已作选择、排除分支与新节点，再重算 frontier。上游变化使前置失效时，下游问题与答案失效。
4. **收敛**：每个可达分支均已访问、frontier 为空且没有静默假设时，拷问收敛。
