# 原型

原型是**回答一个问题的一次性代码**。按问题加载：

- 逻辑或状态模型 → [LOGIC.md](LOGIC.md)：单文件 HTML，自由操作与引导走查。
- UI 外观或局部交互 → [UI.md](UI.md)：同一路由比较多个变体。

问题含糊时询问；无法取得反馈时按周围代码选择分支，并在原型顶部声明假设。

## 共同规则

1. **问题**：动手前写明待验证问题与判断依据。
2. **隔离**：放在对应模块或页面旁并标记原型；默认内存状态，需要数据库时使用 scratch DB 或标记「PROTOTYPE，随手可删」的本地文件。
3. **取证**：逻辑 HTML 双击即开，UI 一条命令启动；手工走查，不写测试、不做抽象，错误处理以能跑为限；每次动作或切换后展示相关状态。
4. **收口**：约定场景或全部变体已走查，提供入口、观察与结论；需用户判断时标「待反馈」，证据支持且所需判断已确认后问题才算回答。
5. **保存**：完整原型提交到一次性分支，不进 main；在 issue 或 commit 记录问题、观察、结论或待反馈状态及入口。正式实现吸收已确认决策，逻辑模块可候选复用，均须通过项目规范、审查与测试。

## 设计中的写作

使用用户的领域语言与平实主动语态，符合品牌语域；控件说清动作结果，同一动作同名。错误说明修复入口，空态引导行动。标签标注、示例演示，每个元素只承担一个职责。
