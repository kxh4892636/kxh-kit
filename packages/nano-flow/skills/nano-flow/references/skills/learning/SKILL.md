# Learning

整理笔记执行下方流程；制作 Anki 卡片时读取 [ANKI.md](ANKI.md)，可独立执行。

## 1. 覆盖账本

完整读取材料，记录有意义的知识点，合并语义重复并保留全部来源位置；为每项记录产出位置或明确的排除理由。

## 2. 组织笔记

按概念体系与知识边界分组，每篇承载一个可独立学习的概念：

- 篇幅随知识密度，限 144 行；超过时按语义拆分;
- 目录结构最多三级，末级最多 13 个 Markdown 文件。
- 笔记整体以平均 55 行为指导目标，按知识密度调整。

## 3. 写入笔记

- 笔记风格使用 **费曼技巧**, 笔记格式使用 **电报体**;
- 每个 H2 使用问题形式, 正文完整回答问题, 不含标题未声称的内容；标题独立展现知识结构, 可完整讲解和主动复习;
- 每个知识点只有一处完整解释，其他 H2 需要时只作指向。
- 优先使用代码块、表格、公式或图示等富文本格式。

写入后逐项核对覆盖账本：范围内知识点均能定位到产出且无遗漏，UUID 无冲突、相对链接有效，并通过适用的文档格式与构建校验时完成。

````markdown
---
id: <uuid>
---

## 这个概念是什么？

- term: 最短完整解释;

## 如何用代码实现这个概念？

- term: 最短完整解释;

最小示例
```
````
