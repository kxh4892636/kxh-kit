# nano-mem

`nm` 是 agent 的长期记忆 CLI：记忆存进用户级记忆库（SQLite + FTS5，无向量模型），靠 FSRS 驱动的「检索 → 记使用 → 增强 → 闲置遗忘」闭环维持精炼——高频使用的记忆更牢固、排名更高，长期闲置的休眠、直至被 gc。按以下纪律读写。

## 契约

- 命令、选项、默认值以现场 `nm --help` 输出为事实来源；与本文冲突时以 `--help` 为准——skill 与 CLI 同版发布，冲突说明安装副本过期，`nm self skill update` 同步。
- `--json`：成功 JSON → stdout，错误 JSON → stderr；退出码 0 成功 / 1 运行时错误 / 2 用法错误；失败先按错误中的 `hint` 修正前置条件。
- `--db <path>` 覆盖库路径（默认 `$NANO_MEM_DB` → `~/.nano-mem/mem.db`）——用默认即可，仅在需要独立库时定制；首次运行自动建库，无需初始化。
- `--dry-run` 预演写命令（add/use/delete/gc），无副作用；delete、gc 先预演再执行。

## 写（add）

决策落地、获知用户偏好、踩坑、形成事实结论的**当轮**就写——「稍后补记」不会发生。

```sh
nm add "..." [--tag <t> ...] [--meta <k=v> ...]
```

- **写什么**：跨会话可复用、且无法从环境单点查到的内容——项目决策与原因、用户偏好、踩坑、事实结论。代码、文档、git 历史、`--help` 能回答的问题留给环境，不入库。
- **怎么写**：一条记忆一个结论，1-2 句自足（不依赖当次会话上下文），写清结论与原因。检索是关键词匹配：文本里没有的词搜不到，按「未来的自己会搜什么词」措辞，把关键术语直接写进文本。
- **标签**：用稳定的小集合（如 preference / decision / pitfall / fact），检索时按 `--tag` 收敛。
- 同 agent + run 分区内同文本去重（重复 add 返回既有 id）；文本为 `-` 时从 stdin 读取。

## 检索（search）

- **何时搜**：非平凡任务开始前先搜一次；做相似的工作（同类问题/改动/咨询）先检索；用户提到「记住」「记得」「之前」「上次」时先检索再回答。
- **怎么搜**：按「当初会怎么写」选关键词；查询中的多个词是 AND 关系，不命中先减词，再换同义词、缩写、中英文重搜。
- 结果按 score（0.65×相关性 + 0.35×强度）降序，只含 FTS 命中项。
- 命中默认自动记一次弱使用（Hard）；只为翻看而非取用时加 `--no-touch`，避免给无关记忆灌水。

```sh
nm search <关键词> [--tag <t> ...] [--no-touch] --json
```

**搜不到不代表没有**：目标可能在休眠、已删，或属于其他分区。逐层扩大后再下结论：`--include-dormant` → `nm list --state all` 盘点当前分区 → `--agent *` 跨分区。

## 记使用（use）

记忆真正用于回答或写进产物后，升级强使用——让记忆更牢固、检索排名更高：

```sh
nm use <id> [--grade again|hard|good|easy]   # 默认 good
```

- search 命中已自动记弱使用，不重复记账。
- 使用评级驱动 FSRS 调度：直接命中答案 → `easy`；被检索出来却没价值 → `again`，纠正自动记账、加速衰减。记忆本身错误或过期时走 delete——降级只会让它继续留在结果里误导。

## 遗忘（delete / gc）

三态「活跃 → 休眠 → 已删」惰性判定，无后台任务：R < 0.35 休眠（检索默认隐藏）；`gc` 标删 R < 0.10 或休眠超 180 天的记忆；已删超 30 天物理清除。

- **delete**：确认错误、过期、被取代的记忆当场 `nm delete <id>`（软删除）——记忆库的可信度靠主动维护，不靠等它自然衰减。
- **gc**：一轮大工作收尾或定期维护时 `nm gc --dry-run` 预览标删与清除清单，确认后 `nm gc` 执行。

## 分区（--agent / --run）

- **agent 分区**：默认当前目录名（如 kxh-kit），检索默认限定当前分区；写入用 `--agent` 显式归属，读取用 `--agent <name>` 覆盖或 `--agent *` 跨分区。
- **run 分区**：可选的任务/会话子分区（如 DSH sessionId）。只对本次任务有意义的记忆带 `--run` 写入；跨会话长期记忆不带。
- 盘点：`nm list --state all` 看当前分区全貌，`nm stats` 看记忆库健康度，`nm get <id>` 读单条全文与调度字段。
