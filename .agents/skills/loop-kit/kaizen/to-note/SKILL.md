# 知识笔记

以**覆盖账本**守住知识完整性, 以 **语义概念** 和 **知识密度** 组织笔记, 以 **费曼技巧** 提高学习效率, 以 **电报体** 提高信息效率, 根据用户输入制作 Markdown 知识笔记;

## 1. 建立覆盖账本

完整读取源材料, 将每个有意义的内容单元登记为独立知识点;
为每个知识点记录来源位置, 语义相同的重复项合并为一个知识点, 并保留其全部来源位置;

当每个源内容单元都已登记, 每个知识点都有来源位置, 且语义相同的知识点已合并时, 本步骤完成.

## 2. 构造笔记组织结构

一个笔记承载一个可独立学习的语义概念, 根据概念体系和知识边界进行分组;
基于原材料的知识密度, 决定笔记篇幅(与知识密度正比), 约束在 <= 144 行, 超过时按语义拆分, 无法再拆的连贯主题可以超出;
根据概念体系和知识边界, 可创建最多二级目录的树形结构, 保证末级目录的 markdown 文件数量 <= 13 个.
笔记的组织结构优先与工作区对齐;
为覆盖账本中的每个知识点记录目标文件和目标标题;

当覆盖账本中的每个知识点都恰好归入一个目标文件和标题, 且隶属于一个语义概念, 超出建议行数的文件均有不可再拆的理由时, 本步骤完成.

## 3. 写入笔记

笔记先使用 **费曼技巧** 保证内容清晰易懂, 再使用 **电报体** 压缩表达; 两者冲突时, **费曼技巧** 优先.
新建笔记必须使用 [`template.md`](template.md), 将 `<uuid>` 替换为新的唯一 UUID; 修改现有笔记时保留原 UUID;
笔记顶部具有若干问题, 覆盖笔记所有知识点, 可以通过回答问题进行完整讲解;

### 费曼技巧

- 简单教授: 以向初学者讲解为目的, 使用简单易懂的语言; 保留准确的专业术语, 并在首次出现时进行通俗解释;
- 修复盲点: 输出过程中, 不理解的地方, 需要反思/优化, 直至知识点清晰;
- 可以单纯根据笔记各级标题, 知道需要讲解的知识点内容;

### 电报体

- H1 仅用于文档主题; 正文按 H2 → ... 连续递进, 层级由知识关系决定;
- 普通文本使用电报体, 一个 bullet 承载一个独立知识点, 使用格式 `term: explanation;`, 富文本信息优先使用代码块\表格\公式等信息载体;

当覆盖账本中的所有目标文件均成功写入时, 本步骤完成.

## 4. 验证笔记

逐项核对覆盖账本, 确认每个源内容单元都映射到一个目标位置, 每个知识点只有一个主归属;
检查所有目标文件, 确认新建笔记的 UUID 均已替换且在工作区内唯一, 修改现有笔记的 UUID 保持不变, 各级标题可以独立展示笔记的知识结构;
执行工作区已有且适用的 Markdown 检查或文档构建命令;

当覆盖账本既无未映射项, 也无重复主归属, 文件与 UUID 检查通过, 且所有适用的工作区检查成功时, 本步骤完成.
