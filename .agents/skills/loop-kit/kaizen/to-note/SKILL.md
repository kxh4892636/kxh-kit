# 知识笔记

以**覆盖账本**守住知识完整性, 以 **语义概念** 和 **知识密度** 组织笔记, 以**电报体**提高信息效率, 根据用户输入制作 Markdown 知识笔记;

## 1. 建立覆盖账本

完整读取源材料, 将每个有意义的内容单元登记为独立知识点;
为每个知识点记录来源位置和目标位置, 语义相同的重复项进行合并;

当每个源内容单元都映射到一个目标位置, 且保证知识点无明显重复时, 本步骤完成.

## 2. 构造笔记组织结构

一个笔记承载一个可独立学习的语义概念, 根据概念体系和知识边界进行分组;
基于原材料的知识密度, 决定笔记篇幅(与知识密度正比), 约束在 13–144 行, 最佳范围为 34-89 行, 超过时按语义拆分, 无法再拆的连贯主题可以超出;
根据概念体系和知识边界, 可创建最多二级目录的树形结构, 保证末级目录的 markdown 文件数量 <= 13 个.
笔记的组织结构优先与工作区对齐;

当每个知识点都恰好归入一个文件, 且隶属于一个语义概念, 超出建议行数的文件均有不可再拆的理由时, 本步骤完成.

## 3. 写入笔记

笔记模板参考 `template.md`

- 笔记以 `id: <uuid>` 的 YAML frontmatter 开头, 并保证 `id` 唯一;
- H1 仅用于文档主题; 正文按 H2 → ... 连续递进, 层级由知识关系决定;
- 普通文本使用电报体, 一个 bullet 承载一个独立知识点, 使用格式 `term: explanation;`;
- 富文本信息优先使用代码块\表格\公式等信息载体;
- 专业名词保留原始描述, 不进行翻译;

当所有笔记成功写入, 且笔记内容和组织结构符合步骤 1 和步骤 2 的要求时, 本步骤完成.
