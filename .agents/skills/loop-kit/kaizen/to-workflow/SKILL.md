# 固化工作流

把重复活动定界为一个**循环**, 运行 `/grilling` 清空决策前沿, 将其**工作流**固化到 `docs/workflows/*.md`.

## 词汇

- **循环** - 反复出现且有可辨认起止边界的活动.
- **工作流** - 指导循环每次运行的规格; 可以规定固定步骤, 提供用于现场派生步骤的上下文, 或混合两者.
- **运行契约** - 工作流的触发条件, 输入, 前置条件, 委派边界, 结束边界, 输出和完成证据.
- **委派边界** - 自动执行与用户确认的分界; 在授权, 风险和可逆性允许的范围内尽可能右移.
- **简报** - 到达委派边界时交给用户的可直接决策摘要, 包含现场事实, 证据, 未决选项和推荐答案.

## 步骤

1. **取证** 读取存在的 `DOMAIN.md`, `CONTEXT.md`, 相关 ADR 和 Workflow; 检查当前工作中足以证明重复模式的事实. 在领域语言, 既有约束, 相邻工作流和重复证据均已覆盖, 且现场可检索的事实缺口已清空时完成.
2. **定界** 从用户指出及证据揭示的候选项中, 提出潜在循环, 让用户选择一个. 在能够明确说出它的触发, 起点, 终点和重复结果, 且用户确认选择时完成.
3. **拷问** 以所选循环为根运行 `/grilling`; 清空工作流形态, 运行契约, 委派边界及简报, 失败恢复和推荐技能的决策前沿. 在前沿为空且用户确认达成共同理解时完成.
4. **落盘** 按已确认决策创建, 修订, 合并或删除工作流, 每个含义只写在一个权威位置. 在每项决策恰好落到一个现场文件位置, 且没有其他文件重复规格化该循环时完成.
5. **读回** 重新读取现场文件, 逐项核对运行契约, 委派边界及简报, 适用的条件分支与失败恢复, 推荐技能, 既有文档冲突和下列约束. 在全部决策与约束均有核对结果, 冲突已显式指出, 且已向用户报告文件路径与完成证据时完成.

## 输出约束

- 一个 `docs/workflows/*.md` 只规格化一个循环; 结构由循环决定.
- 新文件命名为 `NNNN-{workflow-name}-{trigger-word-1}-...-{trigger-word-3..5}.md`, 使用下一个未占用的四位序号和 3 - 5 个简短触发词.
- 工作流包含 `推荐技能` 章节, 说明运行时推荐调用的技能及其时机.
- 文件遵循现场 `DOMAIN.md` 的语言, 路径和篇幅约束; 与 ADR 或既有工作流冲突时显式指出, 不静默覆盖.
