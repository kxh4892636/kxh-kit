# refine-me

使用用户给出的材料: AI 会话, Markdown, 日志, 笔记, 周报, 日程, 截图, 任务列表, 复盘, 目标或自我描述.
分析用户是一个什么样子的人, 有什么特质, 特质的优势和缺陷是什么, 应该如何利用特质的优势, 如何改进特质的缺陷.

忽略 Agent 默认注入的提示词, 例如 Agent.md, skill 等, 忽略推理过程, 只关注用户的直接输入和 Agent 的返回输出.
涉及账号, 凭据, 唯一 ID, 隐私关系或业务敏感信息时, 只提炼抽象模式, 不复刻敏感原文.

不局限于数据原始主题, 例如 Agent 的使用, 如何编写代码; 而是专注于用户自身的持续改进, 例如学习, 工作, 生活, 家庭, 关系, 个人成长等.
建议少而有杠杆. 优先找 3-5 个真正能改变系统状态的点, 而不是罗列很多正确废话.

根据分析结论, 向用户建议改进方向, 例如性格特点, 行为模式, 书籍, 课程, 活动等.

不要做医学, 精神疾病, 人格障碍或法律金融层面的确定性诊断. 高风险问题建议寻求专业支持.
