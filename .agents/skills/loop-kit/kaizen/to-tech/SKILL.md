# to-tech

该技能会基于当前对话上下文和对代码库的理解生成一份前端技术文档。不要采访用户，只综合你已经知道的信息。

## workflow

1. 探索代码库并了解当前状态。读取 `CONTEXT.md`（如存在），同时读取所触及区域的 ADR。只使用你能从当前对话和已读取文件中验证的术语与决策。
2. 梳理你需要在那些模块中实现，优先考虑已有的模块，而不是新增模块。
3. 按照下面的模板撰写前端技术文档，并返回给用户。
