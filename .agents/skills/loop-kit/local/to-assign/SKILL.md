# 分配子任务

将当前会话整理成**分工图**，并把每个子任务分配到独立会话。

## 1. 确认分工图

运行 `/grilling`，讨论范围仅限于如何拆分当前会话和用户参数中的工作。

分工图中的每个子任务只包含：

- 标题；
- 一句话职责；
- 与其他子任务的边界；
- 与其他子任务的依赖关系。

每个子任务应足够聚焦，可由一个独立会话承载。实现方案、技术选型、交付产物、验收标准和具体执行范围留给对应会话。

向用户展示完整分工图。用户明确确认所有子任务的上述四项信息后，本步骤完成。

## 2. 生成共享交接文档

用户确认分工图后运行 `/handoff`，交接目标是让所有子任务会话获得同一份已确认分工图和共享上下文。

完整读取生成的交接文档，确认其中包含：

- 已确认的完整分工图；
- 当前会话已有的共享上下文；
- 相关产物的路径或链接（如有）。

交接文档忠实记录已有上下文和本阶段确认的拆分；各子任务尚未确定的细节留给用户后续决定。分工图与共享上下文完整、相关引用无遗漏且文档可读取时，本步骤完成。

## 3. 分配独立会话

使用当前平台提供的会话创建能力，为每个已确认子任务创建恰好一个独立会话。初始提示可采用适合当前平台和任务语境的任意结构。

每个会话必须：

- 推理等级设置为「high」；
- 拥有独立上下文并能访问所需工作环境；
- 使用子任务标题作为会话标题；
- 获得该子任务的完整拆分信息和完整交接文档；
- 说明已准备好处理该子任务，正在等待用户下一步操作。

每次创建成功后立即记录子任务与会话的映射；重试时只处理创建失败的子任务。

向用户报告交接文档路径、完整的子任务与会话映射，以及仍未解决的创建失败。

每个已确认子任务都映射到唯一一个已创建且等待用户操作的会话时，本技能完成；存在创建失败时，以未完成状态交付失败清单。
