# E2E 框架测试

本 reference 在选用、创建、更新或执行代码驱动的 E2E 验收资产时读取。共同的验收主张、真实路径与结论以 [E2E 主流程](SKILL.md) 为唯一事实源；本文件只定义框架特有契约。

## 资产与 runner

按以下优先级确定代码资产位置、runner 与执行入口：

1. 用户指定的框架、目录或命令。
2. 仓库规范和 E2E 配置声明的 test root、project 与脚本。
3. 相邻可部署单元或同类消费者路径的既有约定。

完成标准：目标资产、runner、配置、可复现的选择与重跑命令以及诊断产物位置都有当前仓库事实来源。

## 框架契约

- 沿用项目已有配置、fixtures、身份与数据准备、等待机制和 reporter，使测试进入同一维护体系。
- 测试名称或 metadata 回链共同入口确定的验收主张与主执行路径。
- 项目命令为目标测试提供可复现的收集、选择与重跑入口；执行时记录 runner 退出状态以及 collected / executed / skipped 数量。
- 零收集、零执行或非预期 skip 记为 `blocked`；有意排除项在执行范围中记录依据。
