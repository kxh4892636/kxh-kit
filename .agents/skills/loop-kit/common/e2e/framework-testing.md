# E2E 框架测试

本 reference 仅在创建或更新代码驱动的 E2E 验收资产时读取。

## 工作流程

1. 定位项目已有 E2E runner、配置、测试目录、运行命令和相邻测试。完成标准：目标资产的位置与执行入口都有仓库事实来源。
2. 将验收主张映射为从消费者入口执行的测试。完成标准：每个范围内结果都有外部可观察断言。
3. 按项目约定实现测试及其前置。完成标准：项目声明的命令能够选择并重跑目标测试。
4. 执行受影响测试并保留结果。完成标准：目标测试已被实际收集和执行，结论与失败证据可复验。

## 位置与框架

按以下优先级确定代码资产位置与 runner：

1. 用户指定的框架、目录或命令。
2. 仓库规范和 E2E 配置声明的 test root、project 与脚本。
3. 相邻可部署单元或同类消费者路径的既有约定。
