# Reference Template

用于共享词汇、规则、审查维度或事实集合。Reference skill 可以没有流程，但必须用 application criterion 驱动完整 legwork。

```markdown
# <Reference Title>

在 `<适用范围>` 中统一使用下面的词汇和判断规则。

## 词汇

**<Canonical Term>** — <紧凑、精确的定义。>

_Avoid_: <会造成语义漂移的近义词>

**<Canonical Term>** — <定义。>

_Avoid_: <近义词>

## 原则

- **<原则名>** — <它如何改变实际判断或输出。>
- **<原则名>** — <它如何改变实际判断或输出。>

## 关系

- `<概念 A>` <约束、产生或依赖> `<概念 B>`。

## 拒绝的表述

- **<被拒绝的说法>** — <它为什么会导致错误行为。>

## 应用标准

使用本 skill 时，逐项应用所有与当前任务相关的规则；输出中的每个偏离都必须说明依据。
```

每个概念的定义、规则和例外放在同一处。只有某些调用分支需要的大段参考再外置。
