# compress-text

把目标文本压缩成一个物理行，只做格式压缩，不改写内容。

## 流程

1. **确定目标文本**

   若用户明确给出文本边界，只处理边界内文本；若用户给出代码块或引用块，默认只处理块内正文，不把包裹标记当作正文。完成条件：待压缩文本范围唯一。

2. **去空行和缩进**

   删除只包含空白字符的行；对保留的每一行，删除行首空格和 tab。保留行内字符、行内空格、标点、大小写和原有顺序。完成条件：每个保留行都没有行首缩进，且没有空行残留。

3. **替换换行**

   按原顺序用字面量 `\n` 连接所有保留行。输出必须是一个物理行，不能包含真实换行。完成条件：输出中每个分隔符都是两个字符 `\` 和 `n`，且没有额外说明、代码围栏或前后缀。

## 边界

- 若目标文本只有空行或缩进，输出空字符串。
- 除删除空行、删除行首缩进、把保留行之间的换行替换为字面量 `\n` 外，不做摘要、翻译、润色、转义或补全。
