# vp 统一入口 — monorepo 管理工作流

本工作流为 monorepo 操作提供上下文：本仓库用 vite-plus（`vp`）统一管理引导、依赖、运行时、测试、打包、格式化与任务运行。

## 循环

monorepo 日常操作反复出现：引导环境、增删更新依赖、管理 Node 运行时、跑测试、格式化与静态检查、构建打包、执行脚本与跨包任务。每次操作都要先决定「用什么命令、从哪个入口进」，本工作流把该决策固定下来：一律经 `vp`。

## 上下文

### 单一入口

一切 monorepo 操作经由 `vp`，禁止裸用 `pnpm`/`npm`/`npx`/`node`/`vite`/`vitest` 等底层命令；`vp` 依据 `packageManager` 字段与 lockfile 自动包装 pnpm。

### 仓库事实

- 包管理器 `pnpm@11.11.0`，Node `>=22.12.0`（由 `vp env` 管理）。
- 根 `package.json` 脚本：`ready` = 交付门禁（`vp check && vp run -r test && vp run -r build`）；`dev` = 起 wiki 站；`prepare` = `vp config`。
- 根 `vite.config.ts` 单点配置 dev/build/test/lint/fmt/run/staged：`staged` 对全部暂存文件跑 `vp check --fix`；fmt/lint 忽略 `AGENTS.md` 与 `.agents/**`；lint 开启 `typeAware` + `typeCheck`；`run.cache = true`。
- `.vite-hooks/pre-commit` 执行 `vp staged`，提交时自动检查暂存文件。

### 操作 → 入口映射

| 操作                         | 入口命令                                                       |
| ---------------------------- | -------------------------------------------------------------- |
| 安装依赖                     | `vp install`                                                   |
| 增 / 删 / 更新包             | `vp add` / `vp remove` / `vp update`                           |
| 管理 Node 运行时             | `vp env`                                                       |
| 跑测试                       | `vp test`；递归全部包 `vp run -r test`                         |
| 格式化 + lint + 类型检查     | `vp check`（自动修复 `vp check --fix`）                        |
| 构建应用 / 打包库            | `vp build` / `vp pack`                                         |
| 跑脚本 / monorepo 任务       | `vp run <script>`、`vp run -r <script>`、`vp run <pkg>#<task>` |
| 执行本地 bin / 脚本 / 临时包 | `vp exec` / `vp node` / `vp dlx`                               |
| 新建 / 迁移项目              | `vp create` / `vp migrate`                                     |

### 命令检索

具体子命令与参数以现场检索为准：`vp help`、`vp <cmd> --help`、官方文档 <https://viteplus.dev>。遵循检索式推理原则，不凭记忆拼写参数。

## 推荐技能

- `/verifying`：交付验证门禁，本地执行 `vp run ready`。
- `/tdd`：测试先行，测试统一经 `vp test` 执行。
