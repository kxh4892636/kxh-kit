# 逻辑原型

用自包含单文件 HTML 验证业务逻辑、状态转换或数据形状。

## 1. 模型

在页面顶部写明问题与状态模型。按问题选用纯 reducer、状态机、纯函数或有清晰接口的 class/module；逻辑独立于 DOM，页面通过接口调用。

## 2. 操作

HTML/CSS/JS 全部内联，无框架、打包器或服务器。页面依次提供：

- **说明与状态**：问题、模型及全部相关状态，每次操作刷新。
- **自由操作**：每个动作一个始终可用的按钮，允许任意顺序尝试。
- **引导走查**：每场景一个页签，说明处境与观察点；步骤按钮按序执行，开始时重置已知初态，支持重跑。

覆盖正常路径、难推理的边界与一次非法尝试。视觉保持克制，突出状态与操作；

## 3. 交付

提供文件或现场打开，按反馈补充动作与场景；保存完整 HTML、观察与结论。
