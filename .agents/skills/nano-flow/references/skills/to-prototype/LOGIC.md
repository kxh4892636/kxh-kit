# 逻辑原型

用自包含单文件 HTML 回答业务逻辑、状态转换或数据形状的问题，让非开发者自由操作并走查纸面上难以判断的场景。外观问题见 [UI.md](UI.md)。

## 1. 写明问题

编码前在 demo 顶部可见介绍区写明状态模型与待回答的问题，供用户随时核对。

## 2. 隔离逻辑

将逻辑放进单个 `<script>` 的小而纯的候选模块，按问题选择：

- 离散事件与单个状态值：纯 reducer `(state, action) => state`。
- 需要检验哪些动作合法：显式状态与转换的状态机。
- 只有数据转换、无隐式当前状态：一组纯函数。
- 拥有持续内部状态：有清晰方法面的 class/module。

选择最适合问题的形态，不以接入页面的便利决定。

逻辑独立于 DOM 和 `document`，页面通过接口调用它，handler 不进入内部。复用遵循 [捕获与交付规则](SKILL.md#共同规则)。

## 3. 构建 demo

所有 HTML/CSS/JS 内联，无框架、打包器或服务器，双击即开并可分享。标签使用领域语言，文案遵循 [共同写作规则](SKILL.md#设计中的写作)。

从上到下：

1. **标题与说明**：重述要探索的问题。
2. **当前状态**：用有标签的面板渲染全部相关状态，每次点击刷新；有帮助时标出变化。
3. **自由操作**：每个动作一个始终可用的按钮，支持任意顺序尝试；点击执行对应动作并刷新状态。
4. **引导走查**：每场景一个页签，平实说明处境与观察点；步骤按顺序排列为真按钮，点击执行并前进。开始走查重置已知初态，保证可重跑。

覆盖快乐路径、难推理的边界和一次理应非法的尝试。字体、间距与一个点缀色保持美观克制，不使用动画或噱头，任何装饰都不与状态和按钮争夺注意力。

## 4. 交付与反馈

提供文件或现场打开，供用户自由操作、走查并反馈不符合预期的行为；按反馈补充动作和场景。按 [证据收口与归档规则](SKILL.md#共同规则) 记录答案，保存完整 HTML 作为可重跑的实验依据。
