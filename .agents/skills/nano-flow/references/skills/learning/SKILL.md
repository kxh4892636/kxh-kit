# Learning

笔记执行第 1–3 步；制作 anki 卡片直接进入第 4 步;

## 1. 覆盖账本

完整读取材料，记录有意义的知识点，合并语义重复并保留全部来源位置。

## 2. 组织笔记

按概念体系与知识边界分组，每篇承载一个可独立学习的概念：

- 篇幅随知识密度，限 144 行；超过时按语义拆分;
- 目录结构最多三级，末级最多 13 个 Markdown 文件。
- 笔记整体篇幅平均 55 行。

## 3. 写入笔记

- 笔记风格使用 **费曼技巧**, 笔记格式使用 **电报体**;
- 每个 H2 使用问题形式, 正文完整回答问题, 不含标题未声称的内容；标题独立展现知识结构, 可完整讲解和主动复习;
- 每个知识点只有一处完整解释，其他 H2 需要时只作指向。
- 优先使用代码块、表格、公式或图示等富文本格式。

````markdown
---
id: <uuid>
---

## 这个概念是什么？

- term: 最短完整解释;

## 如何用代码实现这个概念？

- term: 最短完整解释;

```text
最小示例
```
````

## 4. Anki（可选）

### 1. 制卡准备

从工作区事实和用户输入进行默认推断, 卡点进行询问：

- anki 内容来源。
- anki 卡片/牌组配置;
- 使用 `nnf anki` / AnkiConnect 进行去重;

### 2. 解析材料

默认每文件一张卡, 子牌组取文件名去数字前缀与 `.md`, 复用 uuid frontmatter：

| 配置           | 默认值                                                      |
| -------------- | ----------------------------------------------------------- |
| 根牌组         | `<topic>`;                                                  |
| 笔记类型、字段 | `基础`；`正面` / `背面`                                     |
| 正面           | `根牌组-章节名-知识点`                                      |
| 背面           | `<a href="https://wiki.kongxiaohan.cn/<uuid>">跳转wiki</a>` |

### 3. 预览确认

预览确认录入的 anki 卡片;
每候选一行，展示唯一序号、来源、完整牌组路径及全部实际字段；列明排除及原因、假设、未验证项和冲突。
