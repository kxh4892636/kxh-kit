# Learning

笔记执行第 1–4 步，按需继续 Anki；仅制卡时从已有材料进入第 5 步。

## 1. 覆盖账本

完整读取材料，逐个登记有意义的知识点，合并语义重复并保留全部来源位置。所有源内容已登记、知识点有来源且去重时完成。

## 2. 组织笔记

按概念体系与知识边界分组，每篇承载一个可独立学习的概念：

- 篇幅随知识密度，限 144 行；超过时按语义拆分，无法再拆的连贯主题可超出并说明理由。
- 对齐已有笔记结构，目录最多二级，末级最多 13 个 Markdown 文件。

账本中每个知识点有唯一目标文件与标题，且上述约束满足时完成。

## 3. 写入笔记

新建时使用 [TEMPLATE.md](TEMPLATE.md)，以唯一 UUID 替换 `<uuid>`；修改时保留 UUID。

**费曼技巧优先于电报体**：先向初学者讲清，再压缩。准确术语首次通俗解释，发现理解盲点则反思修订。

- 顶部问题覆盖全部知识点，回答后可完整讲解和主动复习；标题独立展现知识结构。
- H1 仅作主题，正文从 H2 按知识关系连续递进。
- 普通文本每 bullet 一个知识点，使用 `term: explanation;`；富文本优先代码块、表格、公式或图示。
- 优先解释概念与权衡，精确记忆处补充说明。

账本中全部目标文件成功写入时完成。

## 4. 验证笔记

逐项核对源内容均有映射、知识点无重复主归属、新 UUID 已替换且工作区内唯一、旧 UUID 未变、标题可独立展现知识结构。

全部核对及工作区已有的适用 Markdown 检查/文档构建通过时，笔记完成。

## 5. Anki（可选）

需要制卡时读 [ANKI.md](ANKI.md)，以本轮笔记或指定材料执行其流程与完成标准；否则在笔记验证后结束。
