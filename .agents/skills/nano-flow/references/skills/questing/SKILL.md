# Questing

按任务与已有产物选择分支，复用仍成立的结论和确认：

| 分支     | 触发与流程                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| `story`  | 生成或打磨用户故事：按 [STORY.md](STORY.md) 由用户逐轮澄清，维护 `story.md`                                              |
| `design` | 拷问计划、决策或设计：按 [DESIGN.md](DESIGN.md) 由 agent 先回答、用户统一评价；涉及领域变更时同步 [DOMAIN.md](DOMAIN.md) |

故事澄清后继续设计；已有故事从设计开始。所涉及分支的产物与完成标准均成立、确认结论写入各自唯一权威位置时返回。
