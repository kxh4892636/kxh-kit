# Questing

持续拷问直到与用户达成共同理解。把讨论映射为 **design tree**：每个待定决策是一个节点，依赖它的决策位于下游；**frontier** 是前置已经确定、现在无需猜测即可回答的全部节点。

subagent 的选择先形成 **draft tree**；用户统一评价后，接受或修改的选择才进入 **confirmed tree**。事实由 agent 查明，决策最终由用户确认。

## 1. 建树与取证

从用户目标、已有答案和现场事实建立 design tree，区分事实节点与决策节点，并标明每个节点的前置依赖。通过文件和工具查找可获得的事实；需要继续探索的事实保持为未决前置，不转交用户回答。

所有当前可见分支都已进入 tree；每个已知事实都有可复核来源，每个未知事实都是正在进行的探索或带解除条件的 blocker，每个决策节点都有明确前置时，本步骤完成。

## 2. 收敛 draft tree

1. **Frontier**：计算当前整个 frontier。每个节点使用在本次 quest 内唯一且递增的编号，列出互斥选择和前置问题，说明下游边界，并给出 agent 的推荐答案及关键理由。同一轮问题互不依赖；依赖本轮答案的节点留在下一轮。每个 frontier 节点恰好对应一个问题，且没有前置未决的问题混入本轮时完成。
2. **Subagent**：整个 quest 固定一个 subagent，负责未决事实探索和全部轮次的选择；用户只评价审阅文件，不逐轮回答。首次启动时提供目标、事实来源、约束、未决事实以及本轮全部问题与选项；后续轮次通过 follow-up 只补充 tree 变化、新事实和新 frontier。未决事实只让依赖它的节点等待，其余 frontier 继续回答。当前轮每题都收到一项选择及关键理由、可检索事实均有结果或仍是显式未决前置，且 subagent 身份未改变时完成；原 subagent 无法继续时，以其可恢复为解除条件形成 blocker。
3. **记录**：首次写入前完整读取 [`template.md`](template.md)，在工作区根创建或续写 `.flow/quest/YYYY-MM-DD-中文工作名.md`。日期使用首次创建时的本地日期，中文工作名从目标提炼；同一 quest 始终续写同一文件，同名文件属于其他 quest 时改用更具体的工作名。按模板把本轮全部问题与答案插入最终的「补充说明」之前。所有模板占位符已替换、每题的推荐与选择可比较、且「补充说明」仍是最后一节时完成。
4. **推进**：用 subagent 的选择更新 draft tree，记录已确定决策、被排除分支与新节点，再计算 frontier。本轮每项选择都已应用且下一轮 frontier 已完整计算时完成。

重复本节；探索中的事实只暂停其下游，其他 frontier 继续推进。每个可达分支都有结论、frontier 为空、没有静默假设，且全部问题均已写入审阅文件时，draft tree 完成。此阶段只形成 draft。

## 3. 统一评价

draft tree 完成后，向用户提供审阅文件路径，请用户一次性评价全部问题，并把所有问题均未涉及的信息写入末尾的「补充说明」。等待用户说明评价完成，再重新读取所有轮次并按依赖顺序重放：

- 空白的「修改意见」确认 subagent 的选择，但只在该节点仍然可达且前置保持成立时生效。
- 非空的「修改意见」是用户的新答案或约束；能唯一确定答案时替换原选择，否则重新打开该节点。
- 上游修改使前置不成立时，其下游问题与答案退出 confirmed tree，即使修改意见为空。
- 非空的「补充说明」进入 design tree，按事实、约束或决策分类；HTML 注释不算内容。新事实沿用第 1 节的取证规则，只把 judgement 放入新 frontier。

每个问题均已评价、全部反馈已纳入或因依赖失效而排除、新事实已查明或成为 blocker，且新 frontier 已完整计算时，本步骤完成。修改意见与补充说明均为空时，draft tree 整体转为 confirmed tree；任一项非空且产生新 frontier 时，返回第 2 节，由同一 subagent 进行新一轮选择。

## 完成

只有以下条件全部成立时，本 skill 完成：

- design tree 的每个可达分支都已访问，frontier 为空，没有静默假设，未知事实均已查明。
- 审阅文件符合模板，包含全部问题、推荐答案、选择答案、双方关键理由、修改意见与补充说明，且「补充说明」位于末尾。
- agent 已复述 confirmed tree，用户明确确认已经达成共同理解。

`.flow/quest` 审阅文件是本 skill 唯一直接写入的产物；用户确认前不执行实现，其他权威文档仍由调用者负责。

仍有事实或 subagent blocker 时，保存现场与解除条件并暂停；该结果不满足本 skill 的完成条件。
