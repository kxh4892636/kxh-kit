# 003-内容搜索不再由本插件补丁启用

早期 dsh 插件曾把会话内容搜索交给上游 opt-in 包 `@deepseek-ai/dsh-tool-session-query`，并由插件 patch 将 `session-query-sqlite` 的 `openAt` 从 `never` 改为 `first-search`，启用部署级内容搜索索引。

当前 `@kxh4892636/dsh-toolkit` 的 bundle patch 只挂载插件入口，不再 patch `session-query`；内容搜索若需要，按上游 opt-in 方式独立配置，不再由本插件默认启用。

## Considered Options

- **上游 opt-in + 插件 patch（早期选定）**：五个只读工具直接可用，索引首次搜索时构建；但把部署级行为变更绑在 toolkit 上。
- **只保留上游 opt-in（当前）**：需要搜索时由部署方自行挂载；插件不扩大自己的职责。
- **插件自研扫描式搜索**：与现有 `session_read` 能力重复，成本随会话量上升；被拒绝。

## Consequences

- 当前 toolkit 不因安装而改变 Web GUI 内容搜索行为。
- 若重新启用，需要单独评估上游版本、索引持久化路径与部署级授权。
- 早期细节保留在本 ADR；当前实现以 `cordis.patch.yml` 与 `repos/dsh-toolkit/package.json` 为准。
