# 002 会话与提示词注入

## 范围

`session/`：`assets.ts`（77）、`limits.ts`（39）、`services.ts`（92）、`tool-runtime.ts`（122）、`workspace.ts`（17）、`config.ts`（15）、`mount-report.ts`（见 001）、`prompts/{system,user,limit}.md`。

## 资产定位

源码按能力分目录，发布包保持四个稳定入口。`assets.ts` 用一张表同时认两种布局，优先发布布局：

| 资产 | 发布布局 | 源码布局 |
| --- | --- | --- |
| 固定提示词 | `prompts/system.md` | `session/prompts/system.md` |
| 每轮 user 提示 | `prompts/user.md` | `session/prompts/user.md` |
| 篇幅模板 | `prompts/limit.md` | `session/prompts/limit.md` |
| dream 提示词 | `prompts/dream.md` | `dream/prompt.md` |
| 模板 | `templates/` | `documents/templates/` |
| skill | `skills/` | `skills/` |
| 校验脚本 | `scripts/check-domain.mjs` | `documents/check-domain.mjs` |

`locateAssetsRoot(start?)`：从模块所在目录起向上最多 8 层，第一个「`nano-flow/prompts/system.md` 或 `nano-flow/session/prompts/system.md` 存在」的目录即资产根；找不到抛「找不到包内资产目录」。

## 固定提示词段

一段（`nano-flow:system`，order 1，`interpolate: false`），正文三段拼接：

```text
prompts/system.md        ← 领域文档布局、YAML 头规则、共享域、Plan 生命周期、互链、运行时规则、维护循环
.agents/domains/GUIDE.md ← 会话启动快照（dream 维护）
prompts/limit.md + 具体值 ← 篇幅规则措辞 + buildLimitsValues(settings)
```

- `GUIDE.md` 按 agent 对象缓存（`WeakMap`），首轮读一次；文件缺失时该段为空字符串，不报错。
- 具体值固定八行：spec / note / description / CONTEXT / question / ADR / workflow / GUIDE，字节数按 KB 格式化（整数不补小数）。
- 上限来自 `createSettingsReader(services)`：每次调用都重新读 `toolkitNanoFlow.settings()`，服务缺席或抛错回落默认值——面板改设置下一轮就生效。

## 每轮 user 上下文

`nano-flow:input`（order 1）：正文是 `prompts/user.md` 全文（原则、打断条件、每轮首尾维护流程、plain language）。宿主支持 `systemPrompt.context` 才挂。

turn 标记：`services.on("agent/pre-step")` 在 `payload.step === 1` 时把 `payload.turn` 记进 `turnByAgent`（WeakMap，按 agent 对象）；已记到时正文追加 `<!-- nano-flow turn N -->`。第一轮 pre-step 之前取不到 turn，所以那条上下文没有标记。

## 工具运行期（tool-runtime.ts）

四个工具共享一个 `ToolRuntime`：`services` / `config` / `limits()` / `assetsRoot` / `templatesRoot` / `domainRoot` / `workspace(exec)` / `domainsDirectory(workspace)` / `rebind?`。

- `workspace(exec)`：`config.workspace` → `workingDirectory.ensure(agent, signal)` → `process.cwd()`；第二步抛错时 warn 并继续回落。
- `domainsDirectory(workspace)`：`domainRoot` 绝对则直接用，否则 `join(workspace, ".agents/domains")`。
- `rebind(exec, dir, workspace)`：从 `exec.agent.session.id` 取会话 id，缺 id 抛「无法确定当前会话」；回调由 assembly 注入到 `facade.rebindSession`。

参数处理四个纯函数，所有工具共用：`textBlocks`（统一渲染成单 text 块）、`asArguments`（非对象即抛）、`optionalString`/`requiredString`（`required` 同时拒空白）、`optionalBoolean`。

## 宿主服务契约（services.ts）

本包不依赖 `dsh-tools` / `dsh-system-prompt`，用结构化类型描述三个注册面：

| 类型 | 成员 | 用途 |
| --- | --- | --- |
| `ToolRegistry` | `register(definition) → dispose` | 注册工具 |
| `PromptRegistry` | `section`、可选 `context` | 系统提示词段与运行时上下文 |
| `ToolDefinitionLike` | name / description / parameters / output{schema, render} / execute | 工具定义形状 |
| `HostServices` | tools / systemPrompt / logger / get(name) / on(event) | 收窄后的 ctx |

`hostServices(ctx)` 是一次类型断言（`ctx as unknown as HostServices`），不做运行时包装。

## 配置

`session/config.ts` 只有两个字段：`workspace`（测试与「会话目录不可用」兜底）、`domainRoot`（缺省 `.agents/domains`）。预设行不传 workspace，宿主侧 `Config` 的 `workspace`/`domainRoot`/`nanoFlowOnly` 由根插件配置透传。

## 失败与降级

| 情形 | 行为 |
| --- | --- |
| GUIDE.md 不存在 | 该段为空，提示词只有固定段与篇幅段 |
| 设置服务缺席 | 每次读都回落默认值，不缓存错误 |
| `workingDirectory` 缺席 | 工具直接用 `process.cwd()` |
| 宿主不支持 `systemPrompt.context` | 只挂系统段，不追加每轮上下文 |
| 资产缺失 | 挂载阶段抛错（见 001），不留半套工具 |
