# 007 宿主路由与面板设置链路

## 共享契约（src/contract.ts）

宿主半与客户端半共用的形状与常量，客户端 bundle 直接内联本文件，因此它不引任何宿主依赖。

| 常量 | 值 | 用途 |
| --- | --- | --- |
| `TOOLKIT_NANO_FLOW_PATH` | `/api/toolkit/nano-flow` | 设置读写 |
| `TOOLKIT_NANO_FLOW_NOTES_PATH` | `/api/toolkit/nano-flow/notes` | 面板快照 |
| `TOOLKIT_NANO_FLOW_ROTATION_PATH` | `/api/toolkit/nano-flow/rotation` | 最近一次轮转 |
| `NANO_FLOW_NOTES_REFRESH_MS` | `5000` | 面板轮询 |
| `PANEL_STATUSES` | `pending / in_progress / blocked` | 面板可见状态（completed 不进面板） |
| `TOOL_IDS.nanoFlow` | `"nano-flow"` | 开关 id |

设置九个字段：`specMaxBytes 34KB`、`noteMaxBytes 13KB`、`noteDescriptionMaxChars 233`、`contextMaxBytes 89KB`、`questionMaxBytes 13KB`、`adrMaxBytes 8KB`、`workflowMaxBytes 34KB`、`guideMaxBytes 13KB`、`rotateAt 0.618`。

其余类型：`NotesSnapshot`（planName / planPath / notes[]）、`PanelNote`（name/status/description/reason?/nextStep?）、`NanoFlowRotation`（from/to/at）、`NanoFlowSettingsResponse`、`NanoFlowSettingsRequest`、`NanoFlowNotesResponse`、`NanoFlowRotationResponse`。

## 路由（host/toolkit-routes.ts）

六个路由一起注册、一起注销；nano-flow 占四个：

| 路由 | 方法 | 行为 |
| --- | --- | --- |
| `/api/toolkit/state` | GET/POST | 工具开关（四个开关共用） |
| `/api/toolkit/undo-turn` | GET/POST | 撤销（非本域） |
| `/api/toolkit/hidden` | GET | 已撤回会话 id |
| `/api/toolkit/nano-flow` | GET/POST | GET 返回当前设置；POST 读 `{patch}` 后合并落盘并回新值 |
| `/api/toolkit/nano-flow/notes` | GET | 必需 `?sessionId=`；返回 `{snapshot}`，未绑定/目录失效为 `null` |
| `/api/toolkit/nano-flow/rotation` | GET | 返回 `{rotation}`，本次运行未轮转为 `null` |

错误码：未接线 `501 unsupported-host`；请求体非 JSON / 缺字段 `400 invalid-body`；设置非法 `400 invalid-settings`；快照读取抛错 `500 internal`；撤销关闭 `409 tool-disabled`。响应统一带 `cache-control: no-store`。

接线时给的是回调而非对象：`nanoFlow: { get: () => runtime.nanoFlow.get(), update }`、`notes: { of: sessionId => runtime.notesOf(sessionId) }`、`rotation: () => runtime.lastRotation()`。缺哪个回调，对应路由返回 501 或 null，不影响其他路由。

## 设置存储（host/nano-flow-settings.ts）

`$DSH_HOME/toolkit/nano-flow.json`，`{ version: 1, …九个字段 }`。

- `parseNanoFlowSettings(raw, base)`：八个字节/字数键必须是正整数，`rotateAt` 必须落在 (0,1]；未知键忽略；任一已知键非法即抛（被路由转成 400）。
- 写用 `<file>.<pid>.tmp` + rename；`load` 遇到读失败 / 非 JSON / 校验失败一律 warn 并保留当前值（启动时即默认值），**不覆盖**坏文件。
- `update` 与 `load` 走同一条 promise 链串行化，避免两次写交叉。
- 只有一个实例写：预设半只读（通过 `toolkitNanoFlow`）。

## 服务（host/nano-flow-facade.ts）

`NANO_FLOW_SERVICE = "toolkitNanoFlow"`，六个方法见 001。约束：设置文件、绑定表、会话记账的写权都在根半，预设半只读与转发，避免两个实例同时写同一份状态。

## 客户端 Note 面板（client/notes-dock.ts）

- 只在 `preset === "nano-flow"` 的会话显示；其余会话直接不渲染。
- 每 5 s `setInterval` 拉一次 `/api/toolkit/nano-flow/notes?sessionId=…`；`snapshot === null` 视为无面板。
- 常驻、默认展开；标题行显示「Note」+ 状态计数（`n 阻塞 / n 进行中 / n 待办`），点标题行收起/展开，展开状态只在内存（重挂载回到展开）。
- 列表为空显示「全部完成」空态；每条显示中文状态名 + note 名称，hover 显示描述与有值时的「原因」「下一步」。
- 样式与 Todo 面板一致（`dshtk-notes` 前缀）。

## 客户端轮转跟随（client/rotation-follow.ts）

- 根上下文订阅导航选择 store；发现当前会话已被归档离开时读 `/api/toolkit/nano-flow/rotation` 拿 `{from,to}`。
- 按旧会话 id 记账（`followed`），同一轮转只切一次；打开新会话前重读选择，用户已自己切到第三个会话就不抢导航。
- 打开重试 `[0, 600, 1800] ms`，切成功后补刷目录 `[600, 1800] ms`（覆盖宿主 150 ms 删除窗口与落盘）。
- 根级跟随缺席时，dock 的 5 s 轮询兜底。

## 降级矩阵

| 缺失/异常 | 表现 |
| --- | --- |
| 宿主无 connection.fetch | 路由不注册，客户端面板发不出请求 |
| notes 回调缺席 | 501，面板不显示 |
| 设置文件损坏 | 用默认值继续，下一次面板保存才覆盖 |
| 客户端 preset 名不是 `nano-flow` | 面板不渲染 |
| 轮转路由返回 null | 客户端不切会话，只补刷目录 |
