# 027-索引链接恢复中文

## 取证

用户看到的行：

```md
| [007-转码上传与线上复验](007-%E8%BD%AC%E7%A0%81%E4%B8%8A%E4%BC%A0%E4%B8%8E%E7%BA%BF%E4%B8%8A%E5%A4%8D%E9%AA%8C.md) | ... |
```

- 根因：`check-domain.mjs` 的四个渲染点用 `encodeURI(fileName)` 生成链接目标；`encodeURI` 会把中文等非 ASCII 转成 UTF-8 百分号编码（`%E8…`）。
- 影响面：`questions/index.md`、`adr/index.md`、`workflows/index.md`、`notes_index.md`、spec 的 `## 追踪 Note`。
- 用户要求：链接目标显示为汉字。

## 决策

### 第 1 轮

#### Q1 — 全量去掉 encodeURI 还是只保留 ASCII 转义？

- 推荐答案及理由：保留「只转义 ASCII 不安全字符」——空格 → `%20`、`#` → `%23`、`?` → `%3F`、`%` → `%25`；其余（含中文）原样。直接去 `encodeURI` 会让带空格的标题链接失效。
- 修改意见：用户「希望是汉字」。
- 处理结论：新增 `linkTarget(fileName)`：先 `encodeURI`，再把连续的非 ASCII UTF-8 百分号序列解码回字符。中文原样、ASCII 不安全字符仍转义。

#### Q2 — 手写互链 `## 相关` 的校验会不会受影响？

- 推荐：validator 里的 `decodeURI` 对中文是 no-op；把非法 `%` 序列改为按原文处理（try/catch），避免抛错。
- 处理结论：已加 try/catch。

## 交付

- `check-domain.mjs`：新增 `linkTarget`，替换 4 处 `encodeURI`；`## 相关` 的 `decodeURI` 加容错。
- 测试：`check-domain.test.ts` 新增 2 例（中文原样、空格仍转义）。
- 版本 0.5.33，已装入 desktop / web profile；`nano_flow_check` 会重写全部索引为中文链接。
