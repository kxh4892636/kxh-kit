# 预设提示词评审

## US-001 评审提示词

作为 Nano Flow 预设的维护者，我希望知道 `packages/dsh-toolkit/src/nano-flow/prompt.md` 还有哪些优化空间，以便决定下一轮改什么。

## US-002 记录结论

作为下次会话的我，希望评审结论与修订清单落在 Plan 里，仅凭 Plan 就能判断目标、理由、进度与下一步。

## US-003 输入框上方的 ready 面板

作为 Nano Flow 用户，我希望在会话输入框上方看到当前 Plan 的未完成列表，按依赖关系分组，并能展开与折叠。

## US-004 恢复只读

作为恢复已有 Plan 的我，希望恢复时只读报告、不自动选 note 执行，以便先确认进度再决定是否开工。

## US-005 迁移 docs 全部业务域

作为仓库维护者，我希望 `docs/` 下的全部业务域（含旧 Plan）都迁到 `.agents/domains` 的统一布局，以便只有一套域根、旧记录也能被工具读取与校验。

## US-006 等待验证状态

作为推进 Plan 的我，希望 note 有「等待验证」状态，以便区分钟「代码完成、等真机确认」与「仍在改」。

## 非目标

- 迁移只覆盖 `docs/` 下的业务域资产，其它目录不动。
- ready 面板只读，不在界面里编辑 note。
