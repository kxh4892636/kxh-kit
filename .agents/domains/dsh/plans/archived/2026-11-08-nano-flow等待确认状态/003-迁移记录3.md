# 003-迁移记录3

> 迁移自旧 notes.json / story.md / spec.md；正文保留历史记录，旧工具、状态名与路径不再适用。

## 定案（参考 pi）

- `nano_flow_read op=inspect`：文档无法通过校验时给原始视图（id/title/description/content 与 index）。
- `nano_flow_write op=repair`：模型给出 `repairs`（按 id 的 title/description/content）与 `ids`（新 index），工具重新校验后落盘；不自动截断、不自动删索引项。
- repair 先于正常加载执行，所以坏文档也能修。

## 执行检查点（2026-11-08）

- `store.ts`：新增 `loadRawDocument`（读原始 JSON，不校验）。
- `tools/read.ts`：新增 `inspect` op 与工具描述。
- `tools/write.ts`：新增 `repair` op、`repairs` 参数与 schema；`repair` 在 `loadDocument` 之前路由。
- `prompt.md`：新增「修复校验失败」小节；README 记录用法与边界。
- 测试：`runtime.test` 覆盖「坏摘要 → resume 报错 → inspect 原始视图 → repair → resume 正常」；250 项通过。
