# 001-提示词与模板照搬pi

## 目标

dsh 的固定提示词与模板与 pi 对齐，消除 11-09 之后 pi 单方面迭代造成的分叉。用户已确认「完全照搬 pi」，包括删掉 dsh 独有的章节。

## 交付

- `prompts/system.md` ← pi 版（101 行，3.4 KB）：删「入口」「工具」「业务域」「Plan」细节、「恢复与轮转」「写入边界」；新增「更新优先级」「运行时规则」。dsh seed 已自带「先 bind 再只读恢复」，GUIDE 也保留只读与写入边界口径。
- `prompts/user.md` ← pi 版（16 行）：三条原则、plain language、每轮最多两次维护循环、note 按交付单元随时建；删除 `/ask` `/do` 路由与 `ask_user_question` 兜底。
- `prompts/limit.md` ← pi 版（8 行步骤式），语义不变。
- `templates/adr.md`、`context.md`、`question.md` ← 一行占位 `{根据工作内容, 自由发挥的正文}`；`note.md` 删除 `reason:` 行。
- 修正 pi 的一处笔误：`system.md` 目录注释写 `Domain-Indexs + Domains-Relationships`，实际生成物是 `## Contexts` / `## Relationships`（`scripts/lib/render.mjs`），照搬时改为 `Contexts + Relationships`。
- `prompts/dream.md` 不动：用户确认保留 dsh 版（游标、compact 轨迹、域并行与 pi 版耦合，不可移植）。

## 验收

## 风险

- 删除「恢复与轮转」「写入边界」后，行为定义只由工作区 `GUIDE.md` 与 dsh seed 承担；没有 GUIDE 的新工作区会缺少这两条规则。
- 模板退化后新建的 ADR/context/question 不再有固定结构，与 dsh 现有文档形态不一致（历史文档不改）。
