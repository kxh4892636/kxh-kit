# 003-校验脚本搬自动修复

## 目标

pi 的 `nano_flow_check` 会自动修 5 类可确定问题并输出「已自动修复 N 项」；dsh 目前只报错。用户选择全部搬。两包校验规则本身已逐项一致，本次只动「修复能力 + name 规则单点 + 写入安全」，不引入新规则。

## 交付

- 新增 `scripts/lib/fix.mjs`：`setFrontmatterScalar`、`removeFrontmatterKey`、`replaceNameToken`、`writeFixed`、`propagateRenames`。
- `lib/base.mjs`：新增 `addFixed`、`writeInsideWorkspace`（工作区边界 + 临时文件 rename + 内容相同不写）、`nameProblem`（name 规则单点，check 与 create 共用）。
- `lib/checks.mjs`：`SINGLE_LINE_FIELDS`、`applyFieldFixes`、`readDocument` 收 `expectedName`、篇幅按修复后内容判定。
- `scripts/check-domain.mjs`：三处 `expectedName`、note 改名传播到 `related_noted`、spec 状态按合法枚举改写、缺 `questions/` 建目录、结果新增 `fixed`；保留 dsh 独有的 CLI 入口（`--json` 输出带 `fixed`）。
- `check-domain.d.mts` 补 `fixed` 与新增导出；`tools/check.ts` 增加「已自动修复 N 项」与四数组形状守卫；`check-runner.ts` 透传 `fixed`。
- `tools/create.ts` 改用 `check-domain.mjs` 导出的名字规则，删除本地复制的 `KEBAB/PLAN_NAME/NUMBERED_NAME/HAN`。

## 验收

- 单测覆盖：spec 状态、name 对齐 + `related_noted` 联动、非 blocked 的 reason、多行头字段、缺 questions 目录；再跑一次修复数为 0（幂等）。
- 排除项仍只报错：篇幅超限、`## 相关` 目标缺失、大写 `INDEX.md`、真实编号缺口、blocked 缺 reason。
- 对 `.agents/domains` 全量跑一次应为「校验通过、已自动修复 0 项」。

## 说明

- dsh 的校验走子进程 JSON 契约，pi 是进程内 import；`fixed` 必须同时出现在脚本 stdout 与 `CheckResult`。
- pi 顺手把 `findTrackedRange` 返回形状改成 `{kind}`，行为等价，本次可不跟进以缩小改动面。
