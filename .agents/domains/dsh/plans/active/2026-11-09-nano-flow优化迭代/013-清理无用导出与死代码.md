# 013-清理无用导出与死代码

交付：删除没有任何引用的声明，内部符号不再导出。验收：`test` 337 项通过、`check` 无告警、导出面收敛且行为不变。

## 做法

扫描 `src` 92 个文件、301 个导出，按引用位置分三类处理：

| 类别 | 数量 | 处理 |
| --- | --- | --- |
| 完全无引用 | 5（+1 个连带孤儿） | 删除声明与注释 |
| 只在本文件用 | 57 | 去掉 `export`（仍存在，只是不再是模块 API） |
| 只有测试用 | 43 | **保留**（测试钩子，如 `resetRotationFollow` / `clearTombstones`） |

删掉的 6 个：`ClientSessions`、`ClientConversation`、`SessionScopeProps`（`client/contract.ts`），`UndoTurnRequest`（`contract.ts`），`TRACKED_HEADING`（`check-domain.mjs`），以及删除 `ClientConversation` 后变成孤儿的 `DraftInitializationOptions`。

## 结果

- 导出：**301 → 239**；扫描复跑：`dead 0 / selfOnly 0 / testOnly 43`。
- 改动面：30 个文件，`+60 / −93` 行。
- 门禁：`pnpm -C packages/dsh-toolkit test` 38 文件 337 项通过；`check` 格式 124 文件、lint/类型 96 文件无告警。

## 遗留

- 43 个只被测试引用的导出没有收拢；如果要彻底，应集中到 `*.test-support.ts`，但那会改动大量测试的 import，留到后续。
