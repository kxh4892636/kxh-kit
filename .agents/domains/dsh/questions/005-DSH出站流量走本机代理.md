# 005-DSH出站流量走本机代理

## 适用条件与现象

系统代理已启用（如 Clash `127.0.0.1:7890`），但 DSH 的 LLM / web 搜索 / web fetch / MCP 仍直连；`~/.dsh/.env` 不存在。

## 原因

DSH 只认**启动环境**与 `$DSH_HOME/.env` 里的 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`；它不读操作系统代理设置，且代理策略在进程启动时解析一次。

## 解决方法

在 `$DSH_HOME/.env`（默认 `~/.dsh/.env`）写 `HTTP_PROXY=http://127.0.0.1:7890`、`HTTPS_PROXY=http://127.0.0.1:7890`、`ALL_PROXY=http://127.0.0.1:7890`，再重启 DSH。代理名不能写进项目 `.env`，SOCKS 与 PAC 不被支持。

## 验证

重启后用一次需要代理的 web fetch 观察行为；`~/.dsh/.env` 会随 `~/.dsh` 重建或升级消失，重建后需重写。
