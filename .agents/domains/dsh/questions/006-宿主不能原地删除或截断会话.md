# 006-宿主不能原地删除或截断会话

## 适用条件与现象

想让某个会话回到上一轮结束的状态，并要求「同一个 session id 变短」（原地撤销）。

## 原因

会话日志是仅追加的事件源记录，删除/截断事件与会话的 API 都不存在；存活会话优先于磁盘；改文件后存活会话继续按旧游标追加，读取端会因 seq gap 判定损坏。

## 解决方法

用 `session/fork` 复制 `atSeq` 闭区间前缀得到等价历史，再归档原会话；需要「删除」时摘除记账、删除 `$DSH_HOME/sessions/<slug>/<sessionId>/`，最后去掉归档占位。会话仍存活时日志删除与撤销归档排队到下次启动。

## 验证

`packages/dsh-toolkit` 的 `undoTurn` 单测覆盖 fork 切点、归档、detach、立即删除与推迟删除两条路径、撤销归档；`purge` 单测覆盖队列的两阶段处理与孤儿归档清扫。
