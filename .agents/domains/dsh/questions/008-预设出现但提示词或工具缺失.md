# 008-预设出现但提示词或工具缺失

## 适用条件与现象

新会话选中 Nano Flow 后，预设选择器正常、无报错，但系统提示里没有固定提示词，工具目录里没有 `nano_flow_create` / `nano_flow_check`，随包 skill 也不出现。

## 原因

预设行的 standing mount 在宿主启动时建立；如果挂载过程中 `tools` / `systemPrompt` 服务未就位，或注册在启动后失败，子 fiber 失败只写宿主日志，预设注册表仍显示该预设可用。

## 解决方法

先读 `$DSH_HOME/toolkit/nano-flow-mount.json` 的 `stages`：没有文件说明 `apply` 未跑；只有 `apply` 说明 `tools` / `systemPrompt` 没就位；有 `ready` 才表示提示词、工具与 skill 注册完成。改完插件必须重打包、重装并重启宿主——standing mount 不会因磁盘文件变化而刷新。

## 验证

`stages` 同时出现 `entry`（`via: preset`）、`apply`、`ready` 与 `rotation`，且 `ready` 的 `services.tools` / `services.systemPrompt` / `services.skills` 为 true。
