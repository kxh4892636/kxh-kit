# 004-导图UIUX设计

## 交付

- 原型与截图曾放在 `packages/docusaurus-plugin-mindmap/design/`，2026-11-13 按用户要求删除；结论留在本 note。
- 主题 Cobalt（modern-minimal，deal 1/3）：冷白纸、蓝灰墨、发丝线；Familjen Grotesk 做标题，IBM Plex Sans 做正文，JetBrains Mono 只给节点 id 与机器值；电钴蓝是唯一信号色；面板切角、按钮是键帽。
- **实现以 Docusaurus 原生框架为准（2026-11-13 用户澄清：设计图只是示意图）**：页面套 `@theme/Layout`，导航栏、页脚、字体、深色模式、侧栏样式全部来自站点；导图区只做内容扩展——一个标题行 + 缩放工具 + 画布，左侧目录用 Infima `menu` 结构。原型里的自绘顶栏与 Cobalt 配色不再是实现目标。（用户 2026-11-13 要求去掉点阵网格），树左右双向：根居中，子节点前一半在右、后一半在左，两侧各自按叶子顺序堆叠、并与根垂直居中。
- 连线：三次贝塞尔曲线（控制点取水平方向 0.55 倍跨度），线宽随层级递减——根到一级 2.1、二级 1.65、三级 1.2，越靠近根越粗，层级一眼可读；连线颜色走 `--color-edge`（浅色 76% L，深色 44% L）。
- 节点是切角面板，写标题、等宽 `#id` 与引用条数。
- 签名：带 id 的节点本身，加上选中时拉出的钴蓝虚线引用边——结构和引用一眼分得开。
- 状态：满、选中、浮窗、空图（只有根节点）、引用目标缺失（`aria-disabled` + 错误色）、焦点环、明暗两套。没有加载态：数据随路由静态注入，不需要骨架屏。
- 交互规格：滚轮以指针为中心缩放到 0.35–2 倍；拖拽平移；`适应窗口` 回到全图；点节点出浮窗；`doc:` 引用开新标签页；`#` 引用关浮窗、把目标居中并短暂高亮；Esc 或点空白关闭；URL 带 `#节点id` 时首屏定位并打开浮窗。
- 默认视图：100% 打开、按内容水平居中（不整图缩小），纵向超出时靠平移；`适应窗口` 按钮才整图缩放（下限 0.55）。
- 浮窗：石墨底、切角，标题 + 概述行（纯文本，逐行）+ 引用列表。引用行两行式：标签在上，类型与目标在下（`文档` 或 `节点 #id`），目标是等宽字，便于对着 markdown 核对。
- 侧栏状态：当前导图条目用钴蓝淡底 + 深钴蓝文字（`aria-current="page"`），分类可折叠（`aria-expanded`），键盘可 Tab 进出。
- 响应式：≤60rem 侧栏收成抽屉（顶栏出现目录按钮 + 遮罩，Esc 关闭）、浮窗落成底部抽屉、顶部路径隐藏；≤40rem 再隐藏缩放读数、放宽引用目标换行。
- 实现约束（005 照抄）：节点宽 240、根 264，列间距 92，行距 22，内边距 12；标题按 12 字折行、最多 3 行；左右两侧子节点数按 `ceil(n/2)` 切分（先右后左）；顶部 bar 高 56px，工具键高 34px，命中区用 `::before` 撑到 44px。

## 决策

- **零依赖自绘**：节点 id、引用边、浮窗都由自己画，导图库给不了这套语义（见 spec「决策」）。
- **只读**：没有拖拽改结构、没有就地编辑；改内容只能改 markdown。
- **浮窗用浅色纸面**（2026-11-13 用户改定，原为石墨深色面板）：纸面 + 发丝线 + 一层阴影，深色模式下换成比画布亮一档的纸面，靠明度区分层级，不靠反色。
- **引用目标缺失不隐藏**：dev 期由 build 校验拦，运行期仍用禁用样式保留文案，避免节点「看着有引用、点了没反应」。
