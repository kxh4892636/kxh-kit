# 007-导图标题不进文档目录

## 交付

- `apps/wiki/docusaurus.config.ts`：`remarkMindmap` 从 `remarkPlugins` 移到 `beforeDefaultRemarkPlugins`。该选项先于默认的 `headings`/`toc` 插件执行，标签内的 heading 节点在 toc 收集之前就被替换成组件，`toc.length` 归零。
- 删掉 `styles.ts` 里两条 `:has(.mindmap-block) .table-of-contents { display: none }`（原先是重复的两条），并同步 `mindmap-block.css`。

## 为什么不 swizzle 主题

主题的 `DocItem/Layout` 用 `!hide_table_of_contents && toc.length > 0` 决定是否渲染 `col col--3`。让 toc 为空即可让整列（含移动端 `tocCollapsible`）不生成，不需要复制主题代码，升 Docusaurus 也不跟。

## 验收

- `pnpm --filter @kxh4892636/wiki build` 通过。
- 导图页产物（`build/docs/中转/思维导图示例/index.html`）：`col--3` 0 处、`table-of-contents` 0 处、`tocCollapsible` 0 处；导图块正常渲染。
- 对照普通文档 `build/docs/归档/计算机/编程语言/TypeScript/index.html`：`col--3` 仍为 1，目录没被误伤。
