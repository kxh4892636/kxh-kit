# 001-插件脚手架与站点接入

> 2026-11-14 更新：本条是「独立页面」时期的交付记录。2026-11-13 改成文档内 `<Mindmap>` 渲染块后，`apps/wiki/mindmaps/` 目录、路由注册与 `allContentLoaded` 校验都已删除，构建门禁改为 remark 直接抛错。当前形态见 [spec.md](spec.md)「决策」与 [001-在wiki文档里写一个导图块并验收](../../../workflows/001-在wiki文档里写一个导图块并验收/001-在wiki文档里写一个导图块并验收.md)。

## 交付

- 新包 `packages/docusaurus-plugin-mindmap`，照抄 `docusaurus-plugin-link` 的厂房约定：
  - `package.json`：名字 @kxh4892636/docusaurus-plugin-mindmap、`type: module`、`files: ["dist"]`；`exports` 含 `.`（`dist/index.mjs`）、`./client`（`dist/client.mjs`）、`./package.json`；`dependencies` 写显式版本：`@docusaurus/utils` 与 `@docusaurus/utils-validation` 均 3.10.1；`devDependencies` 的 typescript、types、vite-plus 用 `catalog:`；`peerDependencies` 写 @docusaurus/core ^3.10.1 与 react/react-dom。
  - `tsconfig.json` 与 `vite.config.ts` 复制样板的 pack 块（`dts: true`、`exports: true`、`neverBundle` 含 @docusaurus/Head、react、react/jsx-runtime），`entry` 与 `exports` 对齐。
- 插件骨架 `src/index.ts`：
  - 选项：`mindmapsPath`（默认 mindmaps）、`routeBasePath`（默认 /mindmaps）、`devWarnOnly`（默认 true），用 `validate` + schema 校验。
  - `loadContent`：递归读 `siteDir/mindmaps` 下的 md，用 `context.siteConfig.markdown.parseFrontMatter` 只取 id / title / mindmap；缺 id 或 mindmap 不为 true 记成错误项（完整校验交给 003）。
  - `contentLoaded`：每篇 `addRoute`，路径 = `routeBasePath` + 相对路径（剥数字前缀、README 作分类落地页，规则与 docs 相同），`component: "@kxh4892636/docusaurus-plugin-mindmap/client"`，`exact: true`、`priority: 100`，`props: { id, title, path, nav }`（`nav` 是侧栏树，按目录生成）。
  - 侧栏树：目录作分类（`aria-expanded` 可折叠）、文件作条目，顺序按数字前缀；每页都把整棵树传给客户端，供左侧栏渲染。`/mindmaps` 根路由给一张空态页（提示从左侧选一张）。
  - `getPathsToWatch`：返回导图目录下的 md glob（只影响 dev watcher）。
- 客户端占位页 `src/client.tsx`：`React.FC<{ id: string; title: string }>`，显示标题与「图渲染见 004」；SSR 安全（不碰 window）。
- 首篇示例导图 `apps/wiki/mindmaps/010-wiki站点结构.md`：id（UUID）+ `mindmap: true`，一个 H1、两三个 H2，正文写概述，引用块先留一条（等 003 的 `doc:<id>` 校验）。
- 站点三处接入：`apps/wiki/package.json` 加 `workspace:*` 依赖，`prebuild` 追加对该包的 build；`apps/wiki/docusaurus.config.ts` 的 plugins 数组追加一项；根 `tsconfig.json` 的 references 追加该包。
- link 插件纳入导图 id：`packages/docusaurus-plugin-link` 增加 `mindmapsPath` 选项（默认空），把 `mindmaps/` 一起索引、为每个导图生成 `/<id>` 短链，目标地址用导图插件算出的路径路由；同时把 `src/path.ts` 的「路径 → 路由」函数从 `./path` 子路径导出，mindmap 插件直接复用，保证两包剥离前缀的规则只有一份。wiki 的 `prebuild` 要同时构建两个包。
- 单测 `tests/scan.test.ts`：临时目录里放「有 id / 缺 id / mindmap 不是 true / 非 md 文件」四种，断言扫描结果与错误项。

## 风险

- `prebuild` 顺序：两个插件都要在 docusaurus build 前有 dist，用 && 串联，别用分号。
- 导图 id 与 docs id 共用 `/<id>` 命名空间，撞了就是重复路由；003 让 build 报错，001 先只查「缺 id」。
- link 插件改动会影响既有 1217 条文档短链，回归口径：`docs` 侧产物页数与改动前一致。
