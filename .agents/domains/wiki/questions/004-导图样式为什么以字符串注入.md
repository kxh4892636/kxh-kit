# 004-导图样式为什么以字符串注入

## 现象

客户端组件里 `import "./mindmap.css"` 时包构建（`vp pack`，tsdown）报解析失败，产物里没有 CSS 可挂。改成导出一个 `String.raw` 模板字符串，由组件渲染 `<style dangerouslySetInnerHTML={{ __html: mindmapStyles }} />`。

## 原因

这个包是以源码包方式被站点消费的（`workspace:*`，`exports` 只指 `dist/*.mjs`），构建器不跑 Docusaurus 的 CSS 管线；CSS 文件既不会被抽取进站点样式，也不会出现在 dist 里。用 `<style>` 注入绕开了整条 CSS 加载路径。

## 代价

- 每个导图块实例都插一份 `<style>`（内容相同，浏览器会重复解析），没有 source map，也无法被站点 CSS 压缩合并。
- 样式必须走 Infima 变量（`--ifm-*`）才跟得上明暗模式与站点主题；写死颜色会在深色模式下翻车。
- 两个文件内容必须一致：`mindmap-block.css`（正本，编辑器里写）与 `styles.ts`（副本，运行时用）。

## 防漂移

`remark-mindmap.test.ts` 的「injected styles」用例读磁盘上的 `client/mindmap-block.css`，断言与 `mindmapStyles` trim 后相等。只改 CSS 不改 `styles.ts`，`vp test` 直接红。

## 验证方法

`pnpm --filter @kxh4892636/docusaurus-plugin-mindmap test`；改样式后跑一次，用例通过才算两处同步。
