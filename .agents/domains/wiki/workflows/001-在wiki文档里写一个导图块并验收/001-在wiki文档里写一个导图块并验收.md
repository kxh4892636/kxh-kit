# 001-在wiki文档里写一个导图块并验收

适用：新增或改写一篇导图，或改动导图里某个节点的编号。触发场景是「想给某块知识画一张导航图」，不是「新建一个页面」——导图没有自己的路由（[001-导图是文档内渲染块而非独立路由](../../adr/001-导图是文档内渲染块而非独立路由.md)）。

## 前置

- 目标文档在 `apps/wiki/docs/` 下（插件只跑 docs 的 markdown；blog 已关闭）。
- 要引用的文档有 front matter `id`：站点里 370 篇没有（362 篇无 front matter + 8 篇脚本生成的八股文），引用它们点开必 404。
- 插件已构建：`apps/wiki` 的 `prebuild` 会先 build 该包，直接跑站点 build 即可。

## 步骤

1. **选文件**。导图块可以和普通正文共存，也可以独占一篇（示例：`apps/wiki/docs/000-中转/思维导图示例.md`）。整段包在 `<Mindmap>…</Mindmap>` 里；标签外的标题照常是正文标题、照常进文档目录。
2. **一个根**。标签内恰好一个 `# 1 <根标题>`，其余全是它的后代。
3. **编号写进标题**：`## 1.1 基础数据类型`、`### 1.1.1 如何为基础类型标注？`。编号同图唯一、标题层级不跳级（H2 不能直接挂 H4）；编号本身不要求连续。编号与标题之间留一个空格更好读（解析不强求）。
4. **概述**：标题下普通段落，一行一句（`常见标量: boolean、number、string`）。浮窗按纯文本逐行显示，不渲染粗体/代码块/公式。
5. **引用**（写在 `>` 引用块里，或直接写段落）：
   - 文档引用：`> - [基础数据类型](../../090-归档/…/010-基础数据类型.md) doc:07b40046-e58e-4b78-a552-928d99eb18fb`。链接后面的 `doc:<文档id>` 才是跳转依据；相对路径只给人看，写错不影响跳转也不报错。
   - 节点引用：`> - [接口](#1.2)`。锚点取编号，点了关浮窗并把图移到该节点。
6. **构建**：`pnpm --filter @kxh4892636/wiki build`。失败信息带文件路径与原因（缺编号 / 编号重复 / 层级跳级 / 多个或没有 H1 / 节点引用编号不存在 / 文档引用缺 `doc:` 后缀），按消息改，不要绕。
7. **本地起站**：`pnpm --filter @kxh4892636/wiki start --port 3000 --no-open`，浏览器开 `http://localhost:3000/...`（用 `localhost`，别用 `127.0.0.1`，见 [002-本地起wiki站验收的两个陷阱](../../questions/002-本地起wiki站验收的两个陷阱.md)）。

## 验收清单

- [ ] 块上方读数「N 个节点，M 条引用」与源文件的数量一致。
- [ ] 点节点出浮窗：概述逐行、引用分类正确（文档 / 节点 #编号）。
- [ ] 文档引用开新标签页、落到目标文档（不是 404，也不是回到导图页）。写错 id 不会在 build 期暴露，必须点（[003-doc引用写错为什么build不报错](../../questions/003-doc引用写错为什么build不报错.md)）。
- [ ] 节点引用关浮窗、目标节点居中并短暂高亮。
- [ ] Esc 或点浮窗外的遮罩能关闭；打开时页面不跟着滚动。
- [ ] 全屏按钮进全屏浮窗后仍能缩放平移，点遮罩或 Esc 退出。
- [ ] 含导图块的页面右侧目录整列消失；随便开一篇普通文档，目录还在（[002-导图解析挂在默认remark插件之前](../../adr/002-导图解析挂在默认remark插件之前.md)）。
- [ ] 深色模式下节点标题与工具条文字可读；窄屏下工具条不换行。
- [ ] 默认视图没把最左分支切掉；若复现，点「适应窗口」确认能恢复并记录一次。

## 容易踩的

- **改编号 = 改引用目标**：重排编号后全文件搜 `#旧编号`，否则节点引用会静默指向别的节点（只要编号还存在，build 不报错）。
- **把 `doc:<id>` 当链接目标**（`[说明](doc:<id>)`）：MDX 会把 `:id` 解析成指令节点，解析不到 id。
- **样式改了一处**：导图样式有 `mindmap-block.css`（正本）与 `styles.ts`（运行副本）两份，改完跑 `vp test`，包内有用例比对（[004-导图样式为什么以字符串注入](../../questions/004-导图样式为什么以字符串注入.md)）。
- **大图**：节点上千再考虑折叠/虚拟化，现在是一次性全量渲染。
