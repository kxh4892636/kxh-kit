# Wiki

`repos/wiki` 是个人知识站点：Docusaurus 直接把 `docs/` 下的 markdown 发布成站内文档，`sidebars.ts` 用 autogenerated，**目录结构与文件名就是站内结构**。内容按一级编号目录分栏目，编号决定侧栏顺序。

## Language

**栏目**：
`docs/` 下的一级编号目录（`010-记录`、`020-八股文梳理`、`090-归档`…），编号决定排序，栏目自带 `README.md` 作为落地页。
_Avoid_：分区、频道

**八股文梳理**：
`020-八股文梳理` 栏目，内容取自 osjobs Top K 面试题统计：面经高频题按知识 tag 归档，一个 tag 一个文件。
站点的「试题总数 1736」是「题目 × 公司」行数，唯一题目是 **849**；两个数字不要混用。
_Avoid_：题库、面经集合

**tag**：
站点 `api/category.json` 里的 `sub_category`，是唯一的知识维度（算法 / Java / 数据库 / 前端…），每个 tag 有稳定数字 id，如 Java=1、算法=8、Golang=29。
_Avoid_：分类、频道

**分组**：
tag 文件内部的知识体系统一分类（如算法下的「动态规划」「树与二叉树」）。由 `repos/wiki/scripts/topk-groups.mjs` 的关键词表决定：组顺序固定，首个命中的关键词胜出，没命中的进「其他」。
_Avoid_：子分类、章节

**次数**：
一道题在面经统计里被提及的次数，即站点字段 `vote`。排序与展示都以它为准。
_Avoid_：热度、票数

**快照**：
一次抓取得到的「tag → 题目 + 次数」原始数据，落成 JSON 提交进仓：既可离线重生成 markdown，也可与下次抓取 diff。
_Avoid_：缓存、dump

**思维导图**：
文档正文里 `<Mindmap>…</Mindmap>` 之间的 markdown 标题渲染成的只读图，由 `@kxh4892636/docusaurus-plugin-mindmap` 提供。它是正文里的一个块，不是页面：导航、搜索、面包屑仍走 docs 原生逻辑。只有标签内的标题算导图；标签外的标题照常是正文标题、照常进文档目录。
_Avoid_：导图页面、图文档、导图路由

**节点**：
思维导图里的一个 markdown 标题，父子关系即标题层级。节点 id 就是标题开头的编号（`## 1.2 接口` 的 `1.2`），同图唯一；标题层级不跳级（H2 不能直接挂 H4），编号本身不要求连续（`1.1` 之后可以直接 `1.3`）。
_Avoid_：卡片、条目

**概述**：
节点标题下、下一个同级或更高级标题之前的普通正文，浮窗里逐行显示。
_Avoid_：描述、备注

**引用**：
节点下的 markdown 链接，两种。文档引用 `[说明](相对路径.md) doc:<文档id>`：跳转依据是链接后面的 `doc:` 后缀，渲染时换成 `/<文档id>` 短链、新标签页打开。节点引用 `[说明](#<编号>)`：锚点取编号，点了关浮窗并把图移到该节点。链接写在 `>` 引用块或普通段落里都算引用；同一段落里不带链接的正文仍是概述。
_Avoid_：链接、关联

> 纠正（2026-11-13，seq 4594）：`doc:<id>` 是链接后面的普通文本、不是链接目标，节点引用锚点是编号（`#1.2`）而不是任意节点 id；原条目把前者写成了链接目标。
