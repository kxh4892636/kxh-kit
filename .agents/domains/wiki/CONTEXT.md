# Wiki

`apps/wiki` 是个人知识站点：Docusaurus 直接把 `docs/` 下的 markdown 发布成站内文档，`sidebars.ts` 用 autogenerated，**目录结构与文件名就是站内结构**。内容按一级编号目录分栏目，编号决定侧栏顺序。

## Language

**栏目**：
`docs/` 下的一级编号目录（`010-记录`、`020-八股文梳理`、`090-归档`…），编号决定排序，栏目自带 `README.md` 作为落地页。
_Avoid_：分区、频道

**八股文梳理**：
`020-八股文梳理` 栏目，内容取自 osjobs Top K 面试题统计：面经高频题按知识 tag 归档，一个 tag 一个文件。
站点的「试题总数 1736」是「题目 × 公司」行数，唯一题目是 **849**；两个数字不要混用。
_Avoid_：题库、面经集合

**tag**：
站点 `api/category.json` 里的 `sub_category`，是唯一的知识维度（算法 / Java / 数据库 / 前端…），每个 tag 有稳定数字 id，如 Java=1、算法=8、Golang=29。
_Avoid_：分类、频道

**分组**：
tag 文件内部的知识体系统一分类（如算法下的「动态规划」「树与二叉树」）。由 `apps/wiki/scripts/topk-groups.mjs` 的关键词表决定：组顺序固定，首个命中的关键词胜出，没命中的进「其他」。
_Avoid_：子分类、章节

**次数**：
一道题在面经统计里被提及的次数，即站点字段 `vote`。排序与展示都以它为准。
_Avoid_：热度、票数

**快照**：
一次抓取得到的「tag → 题目 + 次数」原始数据，落成 JSON 提交进仓：既可离线重生成 markdown，也可与下次抓取 diff。
_Avoid_：缓存、dump

**思维导图文档**：
`apps/wiki/mindmaps/` 下带 `id` 与 `mindmap: true` 的 markdown，由 `@kxh4892636/docusaurus-plugin-mindmap` 整页渲染。与 `docs/` 同级、不进 docs 侧栏；只读，编辑只改 markdown。
_Avoid_：导图页面、图文档

**导图目录**：
`/mindmaps` 页面的左侧栏，按 `mindmaps/` 的目录生成，规则与 docs 侧栏一致：目录是分类（可折叠）、文件是条目、数字前缀决定顺序、README 作分类落地页。
_Avoid_：导航、菜单

**导图路由**：
导图页按路径访问，如 `/mindmaps/010-计算机/031-TypeScript/知识地图`；同一篇导图还能用 `id` 走 `/<id>` 短链，与 docs 文档共用这套短链机制。
_Avoid_：永久链接、permalink

**节点**：
思维导图文档里的一个 markdown 标题，父子关系即标题层级。节点 id 由标题尾部 `{#id}` 显式给出，缺省按标题文本生成 slug。
_Avoid_：卡片、条目

**概述**：
节点标题下、下一个同级或更高级标题之前的普通正文，浮窗里逐行显示。
_Avoid_：描述、备注

**引用**：
节点下的 `>` 引用块，每条是一个链接：`doc:<文档id>` 跳到该 wiki 文档，`#<节点id>` 跳到本图节点。
_Avoid_：链接、关联
