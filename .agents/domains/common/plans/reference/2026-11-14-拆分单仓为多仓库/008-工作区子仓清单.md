# 008-工作区子仓清单

## 内容

工作区根新增 `workspace.yaml`，九个条目统一写成：

```yaml
repos:
  - name: wiki
    url: git@github.com:kxh4892636/wiki.git
    branch: main
    path: repos/wiki
```

- `name`：子仓名，与目录名、GitHub 仓名一致。
- `url`：SSH 远端（私有仓 clone 需要登录态，SSH 复用本机密钥）。
- `branch`：跟踪的分支，九个都是 `main`。
- `path`：相对工作区根的路径，统一 `repos/<name>`。

## 用法

- 新机器拉工作区后按此清单逐个 `git clone -b <branch> <url> <path>`。
- 新增子仓时同步追加条目；容器仓不再有 pnpm 工作区，这份 YAML 是唯一索引。
