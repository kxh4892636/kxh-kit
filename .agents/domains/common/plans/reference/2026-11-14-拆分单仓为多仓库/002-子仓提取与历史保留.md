- 容器仓两次提交后 `git status` 干净；`apps/`、`packages/` 已不存在。

## 实际做法（与计划的差异）

1. `git subtree split` 每个目录约 110–210 秒（1416 个提交全量遍历），九条串行跑了约 25 分钟，放后台任务执行。
2. **不能分两次搬**：`Move-Item` 遇到 `node_modules` 里的 dangling symlink 会中途失败，留下半搬状态（wiki 出现过 `repos/wiki/wiki` 嵌套）。最终顺序是：删该目录 `node_modules` → 整目录一次搬完 → `git init` 挂 split 历史 → `git reset`（mixed，不能用 `--hard`）。
3. `git subtree split` 只带 tracked 内容，`010-记录` / `000-中转` / `070-工作` / `etf/data` / `music/.env` 全靠整目录搬移保住，搬完仍被忽略。

## 回滚点

旧仓库里的 `split/<名>` 分支九条都还在；确认无误后可删。
