# 003-子仓独立化改造

## 做了什么

每个仓（由 `.tmp/split-independence.mjs` 一次性完成）：

1. `package.json` 里 `catalog:` 全部替换成根 `pnpm-workspace.yaml` 的真实版本（含 `vite: npm:@voidzero-dev/vite-plus-core@1.0.0`、`typescript: npm:@typescript/typescript6@~6.0.2` 这类别名）。
2. 补 `packageManager: pnpm@11.22.0`；可发布的包补 `repository.url = github.com/kxh4892636/<名>`。
3. 仓内自带 `.gitattributes`、`.node-version`、`tsconfig.base.json`，`tsconfig*.json` 的 `../../tsconfig.base.json` 改成 `./tsconfig.base.json`。
4. 仓内 `pnpm-workspace.yaml` 只留 `allowBuilds`、`overrides`（vite / vitest 固定）、`peerDependencyRules`、`minimumReleaseAgeExclude`，**没有 catalog**。
5. 补 `.gitignore`（node_modules / dist / coverage / tgz / tsbuildinfo / .vite-hooks …），app 沿用原有忽略项。
6. 逐个 `pnpm install` → `vp check --fix` → `check` → `test` → `build`，全绿后各仓单独提交。

## 实测结果

- link 7 测试；mindmap 15 文件 check 通过；dsh-infinite-story；dsh-toolkit 146 文件；nano-flow 850 测试；pi-toolkit 298 测试；etf 156 测试；music 63 测试——全部通过。
- wiki：`docusaurus build` 成功产出 `build/`。
- 根目录已无 `package.json` / `node_modules` / 锁文件 / `tsconfig*` / `vite.config.ts` / `.node-version` / `.vite-hooks`。

## 踩到的坑

- **wiki build 一开始全站失败**：MDX 报 `Could not parse style attribute on span`。根因是独立安装把 `hast-util-to-estree` 的传递依赖 `style-to-js` 解析到 `1.0.0`（根锁文件是 `1.1.21`），新版本解析 KaTeX 生成的 style 属性会抛错。修法：wiki 的 `pnpm-workspace.yaml` 加 `"hast-util-to-estree>style-to-js": "1.1.21"`。
- `vp check` 会挑 `package.json` 的 JSON 缩进，写完用 `vp check --fix` 收一遍再提交。
- `repos/etf/.gitignore` 需要额外加 `.vitest/`（以前靠根忽略项覆盖）。
