## 子仓骨架

以 `repos/docusaurus-plugin-link`（包）与 `repos/wiki`（app）为例，两者结构一致，差别只在业务目录：

```text
repos/<名>/
├── .git/                    # 独立历史（subtree split 出来的）
├── .gitattributes           # 从根复制（LF 策略）
├── .gitignore               # app 已有；包需要新补（node_modules / dist / coverage / *.tgz）
├── .node-version            # 从根复制
├── package.json             # catalog: 全部换成真实版本；补 packageManager / engines / repository
├── pnpm-workspace.yaml      # 只留 overrides、peerDependencyRules、minimumReleaseAgeExclude
├── pnpm-lock.yaml           # 本仓自己的锁文件
├── tsconfig.base.json       # 根基线副本（本地一份，不再指向根）
├── tsconfig.json            # extends "./tsconfig.base.json"
├── vite.config.ts           # 沿用各包已有；没有的按需补
├── vitest.config.ts / playwright.config.ts   # 沿用已有
├── README.md
└── src/ 或 docs/ scripts/ static/ server/ client/ shared/ ...   # 原样不动
```

- `catalog:` 固化示例：`react: ^19.2.5`、`vitest: 5.0.1`、`vite: npm:@voidzero-dev/vite-plus-core@1.0.0`、`hono: 4.13.7`。
- 各仓 `package.json` 加 `"ready": "vp check && vp test && vp build"` 这类只作用于本仓的脚本，根不再有全量脚本。
- `repository`、`docusaurus.config.ts` 的 `editUrl`、首页 GitHub 链接从 `kxh-kit` 改成各自的 `kxh4892636/<名>`。

## 被忽略的私有内容（不随 git 走）

| 位置 | 文件数 | tracked | 由哪条规则忽略 |
| --- | --- | --- | --- |
| `apps/wiki/docs/010-记录` | 86 | 0 | `*/*记录*` |
| `apps/wiki/docs/000-中转` | 2 | 0 | `*/*中转*` |
| `apps/wiki/docs/070-工作` | 6 | 0 | `*/*工作*` |
| `apps/etf/data` | SQLite 等 | 0 | etf 自己的 `.gitignore` |
| `apps/music/.env` | 1 | 0 | music 自己的 `.gitignore` |

- 这些文件的唯一副本在磁盘上：搬家时**必须整目录搬走**，且搬完仍被忽略。
- `apps/wiki/.gitignore` 是 tracked 文件，会随 split 历史一起进新仓，`*/*记录*` 这类规则在新仓继续生效，**不改写、不放宽**。
- 新补的包级 `.gitignore` 只覆盖 `node_modules` / `dist` / `coverage` / `*.tgz` 之类构建产物。

## wiki 的特例

- 两个 docusaurus 插件改成 GitHub Release 的 `.tgz` URL 依赖（不发 npm，见 [004](004-插件改走GitHub分发并切换wiki依赖.md)），`prebuild` 里 `pnpm --filter …` 两段删除。
- 前置条件：插件仓先打好 Release；在那之前 wiki 独立 build 会失败，属于预期。
- `scripts/backup-kxh.js` 里的 `apps/wiki/docs` 改成 `repos/wiki/docs`。

## 验收

- 根 `git status` 干净，且根目录没有 `package.json` / `node_modules` / 锁文件。
- `repos/` 下 9 个目录各有 `.git`，`git -C repos/<名> log --oneline | wc -l` 与拆分前该目录的提交数一致。
- 每个子仓单独 `pnpm install && pnpm ready` 能跑通（wiki 等 004 完成后）。
- `git -C repos/wiki ls-files docs/010-记录` 输出为空，`git -C repos/wiki status --ignored --porcelain docs/010-记录` 仍显示 ignored；`010-记录` 的文件数搬前搬后一致（86）。
