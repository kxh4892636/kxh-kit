# 002-覆盖率门槛在哪跑

## 适用条件与现象

验收要求「覆盖率达标」，但根 `vite.config.ts` 没有阈值，且不同包报出的门槛不一致。

## 原因

阈值写在各包自己的 `vitest.config.ts` 或 `vite.config.ts` 的 `test.coverage.thresholds`：`nano-flow` 为 90，`dsh-toolkit`（原 `dsh-nested-skill`，已并入）为 80；根配置只负责 fmt、lint 与提交钩子。

## 解决方法

在目标包内执行 `vp test --run --coverage`；全仓验收使用根 `vp run -r --no-cache test`。以目标包配置为准，不套用其他包的数字。

## 验证

coverage 报告不因阈值失败，且四项指标均达到该包配置值。
