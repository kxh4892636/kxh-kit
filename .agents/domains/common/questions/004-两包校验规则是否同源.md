# 004-两包校验规则是否同源

## 问题

`repos/pi-toolkit` 与 `repos/dsh-toolkit` 各带一份领域文档校验脚本。改一条规则时不确定改一处还是两处；两边入口行长不一样（17.8 KB vs 20.4 KB），看着像已经分叉。

## 答案

规则同源：`lib/base.mjs`、`lib/checks.mjs`、`lib/render.mjs` 逐字相同，`lib/fix.mjs` 只差模块注释里的包名。入口长度不同是因为「壳」不同——pi 在工具内进程 import 后直接跑；dsh 走子进程 JSON 契约、保留 CLI，输出多一个 `fixed` 字段。

所以：**改规则改 `lib/`，两包同步；只改入口壳时不必。**

## 验证

```bash
for f in base checks render fix; do
  diff -q repos/pi-toolkit/src/nano-flow/scripts/lib/$f.mjs \
          repos/dsh-toolkit/src/nano-flow/documents/lib/$f.mjs
done
```

无输出即一致（`fix.mjs` 会差一行模块注释）。跨包改动后两包各跑一次 `check-domain.mjs <repo>`，同一份 fixture 的输出应当一致。
