# 会话自动命名

## 做法

- `src/naming/register.ts` 只在「开关打开、非扩展注入、本会话尚未命名、分支里还没有用户消息」时启动一次后台命名，`input` 处理器立即返回，不阻塞发送。
- 命名输入先剔除 skill 调用：展开后的 `<skill name …>` 块与 `/skill:<name>` 命令都不进入标题；只有裸 skill 调用时用 skill 名兜底。
- `src/naming/name.ts` 负责纯文本清洗：取模型回复第一行非空文本，去掉标题标签、引号、markdown 标记与尾部标点，按 Unicode 码点截断（默认 21）。
- 模型不可用、无可用凭据、请求超时或回复无文本时，退化为清洗后的输入截断；期间用户若已手动命名，不再覆盖。
- `session_start` 重置「本会话已命名」并递增代次，迟到的模型回复不会写到新会话上。

## 证据

- 命名请求带 `maxTokens` 与 `timeoutMs`（默认 256 / 5000），并复用当前 session id。
- 单测覆盖：模型成功、无凭据、超时、空回复、手写名不被覆盖、skill 过滤与跨会话迟到回复。
