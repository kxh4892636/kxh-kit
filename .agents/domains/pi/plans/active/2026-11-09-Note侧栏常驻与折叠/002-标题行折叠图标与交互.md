# 标题行折叠图标与交互

## 交付

`packages/pi-toolkit/src/nano-flow/ui/sidebar.ts`：

- 标题行右端 2 列让给图标：展开态 `▾`、折叠态 `▸`；标题按剩余宽度 `truncateToWidth`，整行宽度仍等于 `SIDEBAR_WIDTH`。
- 列表 overlay 的 `handleMouse` 增判：`event.y === 1`（标题行）且 `event.x >= SIDEBAR_WIDTH - CLOSE_HIT_COLUMNS`（末 4 列）时切换折叠；其余坐标不误触。
- 折叠态 `render()` 只返回顶边、标题行、底边三行；展开态照旧渲染全部行。
- 折叠状态为 `let collapsed = false` 的内存变量：跨 `turn_end` 的 `refresh()` 保留，不写盘、不进配置；重启回到展开。折叠时若详情卡开着，一并关闭。
- 模块头 `@module` 描述补一句折叠行为。

`packages/pi-toolkit/src/nano-flow/ui.test.ts`：点击末 4 列后 `render()` 行数为 3 且含 `▸`；再点一次恢复列表行与 `▾`；点击标题行中间不切换折叠。

## 验收

- `pnpm --filter @kxh4892636/pi-toolkit check` 与 `test` 通过；新增用例覆盖折叠、展开、误触、行宽。
- 真机走查放到 003：点击图标即时收放，不遮挡正文、不引起整块 overlay 闪烁。

## 结果

按用户后续两条反馈定稿，与原计划不同：

1. **图标从标题行移出**：放在边框**之上**、与侧栏右缘对齐（`iconLine()` 把 `▤` 放在宽度 `SIDEBAR_WIDTH` 的第 40 列），标题行恢复为 `Note · {planName}`，不再带前缀图标。
2. **与边框同色**：只用 `theme.fg("border", …)`，不加 `bold`——加粗会破坏「与边框一致」的观感。
3. **折叠＝整块只剩图标**：`renderLines()` 在 `collapsed` 时只返回图标行，边框/标题/note 行全部让出 40 列。
4. 命中：`event.y === 0` 且 `event.x >= SIDEBAR_WIDTH - 3`（右端 3 列）切换；note 行索引随之从 `event.y - 1` 改为 `event.y - 2`。

`ui.test.ts`：新增 `collapses to the top-right icon and expands again`（6 行 → 1 行 → 6 行、点标题中间不折叠、折叠态点 note 行不出卡片、图标行 40 列）；首个用例补图标行断言并把 note 点击下移一行。

门禁：`test` 282 项全过，`check` 通过。
