# 配置与开关

## 交付

- `tools.nanoFlow`（默认 false）加入工具开关与 `/toolkit` 面板。
- `nanoFlow` 配置节：`always`、`domainRoot`、`specMaxBytes`、`noteMaxBytes`、`noteDescriptionMaxChars`、`contextMaxBytes`、`questionMaxBytes`、`adrMaxBytes`、`workflowMaxBytes`、`guideMaxBytes`、`rotateAt`。
- `/nano-flow` 命令：SelectList 只有「开 / 关」，Enter 只改当前会话，`Ctrl+S` 同时写 `nanoFlow.always`；非 TUI 退回 select + confirm。
- 会话状态写 `nano-flow-mode` 自定义条目；生效值 = 开关 ∧ (会话条目 ?? `always`)。

## 验收

只改 JSON 即可调整全部数值；`/nano-flow` 关闭后工具、提示词、侧栏立即失效；`Ctrl+S` 保存的默认值在新会话生效。


## 结果

- 已实现并通过 `pnpm --filter @kxh4892636/pi-toolkit test`（220 项）与 `check`。
- 真机冒烟：`nano_flow_create` 建 domain/plan、`nano_flow_bind` 写会话条目、rotateAt=0.0001 产生 `nano-flow-reset` 均已在 pi 1.5.0 验证。
- fullscreen 侧栏与 `/nano-flow` 选择器留待用户验收。
