# 002-命名规则只留一份

## 交付

- `lib/base.mjs` 新增 `nameProblem(value, kind)`，返回 `{ rule, message, blocking }` 或 `null`；「含中文标题」也并进这一处，删除 `checks.mjs` 的 `checkHanName` 与它在 `check-domain.mjs` 的 3 个调用点。
- `tools/create.ts` 的 note 名字改用 `nameProblem(name, "note")`；本地 `KEBAB` / `PLAN_NAME` / `NUMBERED_NAME` / `HAN` / `isValidDate` 全部删除，改为从 `check-domain.mjs` 转出的同一份常量（`check-domain.d.mts` 补上声明）。

## 验收

- `nano_flow_create(kind=note, name="001-setup")` 必须拒绝，且不落文件；create 与 check 对同一个名字给出同一个结论。

## 证据

- 新增测试（`tools.test.ts`）：旧实现下该调用「resolved 而不是 reject」，新实现抛出「名称必须包含中文标题」。
- `create.ts` 净减 28 行（删除的常量与日期校验由 base.mjs 提供）。
