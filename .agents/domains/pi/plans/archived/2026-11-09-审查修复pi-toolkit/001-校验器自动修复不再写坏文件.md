# 001-校验器自动修复不再写坏文件

## 交付

- `lib/render.mjs` 的 `findTrackedRange` 区分三种结果：`missing` / `invalid` / `found(start)`；`check-domain.mjs` 只在 `missing` 时追加追踪表，`invalid` 只报错不写文件。
- `lib/fix.mjs` 新增 `continuationEnd`，标量续行的范围从「缩进且非空」放宽到「缩进或空行」，直到下一个顶格行；`setFrontmatterScalar` 与 `removeFrontmatterKey` 共用。

## 验收

- 追踪 Note 位置不合法或重复时，连续校验不再改变 spec。
- 块标量里带空行的字段，一次折成单行后不再变。

## 证据

- 临时工作区复现（修复前）：章节不在末尾时连续 3 次校验，章节数 3、4、5，文件 664 → 919 → 1174 字节。
- 临时工作区复现（修复后）：同一场景 3 次校验后 spec 的 md5 恒定、章节数 1，错误仍然报出；块标量场景第一次运行 `fixed=3`，第二次 `fixed=0`、内容一字不变。
- 新增 3 条测试（`check-domain.test.ts` 末尾两个 describe）。用 `git checkout HEAD` 退回旧实现后 3 条全部失败，恢复后全绿。
