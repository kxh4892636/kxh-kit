# 侧栏常驻与空态渲染

## 交付

- `packages/pi-toolkit/src/nano-flow/register.ts`：`snapshotOf` 去掉 `notes.length === 0 ? null`，空数组也返回 `{ planName, notes }`；无绑定、目录失效仍返回 `null`。
- `packages/pi-toolkit/src/nano-flow/ui/sidebar.ts`：
  - `view()` 不再因 `notes.length === 0` 返回 `[]`；始终返回标题行，列表为空时追加一行 `全部完成`（dim），`Row.kind` 增加 `"empty"`（或等价方式），不参与点击命中。
  - `refresh()` 的关卡片判据从「`rows` 为空」改为「`detailNote` 已不在新的未完成列表里」——常驻后 `rows` 恒非空，旧判据会漏关。
  - 注释与模块头 `@module` 描述同步：原来写「无未完成 note 时不显示」，改为「已绑定 Plan 常驻」。
- `packages/pi-toolkit/src/nano-flow/ui.test.ts`：空列表仍渲染「顶边 / 标题行 / 空态行 / 底边」，行宽 == `SIDEBAR_WIDTH`；`snapshot === null` 仍渲染空数组。

## 验收

- `pnpm --filter @kxh4892636/pi-toolkit check` 与 `test` 通过，新增用例失败于实现前、通过于实现后。
- 单测断言：`snapshot = { planName, notes: [] }` 时 `render()` 非空且含 `全部完成`；空态行点击不产生详情卡 overlay。

## 结果

- `register.ts` `snapshotOf` 去掉空列表判断，空数组也返回快照；注释同步。
- `sidebar.ts`：`view()` 无绑定（`snapshot === null`）才返回空，否则恒有标题行，空列表追加 `kind: "empty"` 的 dim `全部完成` 行；`rowText` 分三支；`refresh()` 改为按「详情卡所指 note 是否还在新列表里」关卡片。
- `ui.test.ts` 新增 `keeps the frame when there are no unfinished notes`：空列表渲染 5 行（图标 / 上边框 / 标题 / 空态 / 下边框）、每行 40 列、点空态行不出卡片；保留 `renders nothing when there is no snapshot`。
- 门禁：`pnpm --filter @kxh4892636/pi-toolkit test` 282 项全过；`check` 通过（仅 provider 目录的既有 lint warning）。
