# 001-本地行情只覆盖最近1000根

## 适用条件与现象

看板/接口的日线起点明显晚于证券最早交易日，或历史长度固定在约 1000 根。

## 原因

上游红色火箭按 `count=-1000` 只返回最近 1000 根；已有缓存的最新日期是昨日时，增量刷新不会补更早历史。

## 解决方法

执行 `pnpm --filter @kxh4892636/etf run sync:market`（workflow 使用 `count=-10000` 全量请求并幂等 upsert）；详见 [行情全量同步](../workflows/001-行情全量同步/001-行情全量同步.md)。

## 验证

932315.CSI 3108 根（2013-12-31 起）、930955.CSI 5048 根（2005-12-30 起），截至 2026-10-16；接口 `meta.rows` 与 SQL 计数一致。2026-10-17 实测。
