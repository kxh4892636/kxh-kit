# 003-合并目录并回归验证（1-2）

> 迁移自旧 notes.json / story.md / spec.md；正文保留历史记录，旧工具、状态名与路径不再适用。
## 交付

`apps/etf` 成为唯一 ETF 应用：应用根直接分 `client`、`server`、`shared`，工具按 `libs`/`utils` 归位；后端业务域 `market` 内有 handler/service/repository 三层并以依赖注入装配；一条命令启动前后端，前端行为不变，API 仍以 Hono RPC 暴露；原有测试、覆盖率、构建与五组 E2E 通过。关联 US-001、US-002、US-003。

## 范围

- 用 `git mv` 合并：前端 `apps/etf-dashboard/src/*` → `apps/etf/client/*`，`index.html`、`public/` → `apps/etf/client/`，`e2e/` → `apps/etf/e2e/`；后端 `apps/etf-service/src/*` → `apps/etf/server/*`；`migrations/`、`drizzle.config.ts` → `apps/etf/`；删除旧目录与旧 workspace 包。
- 前端归位：`common/cn.ts` → `client/utils/cn.ts`；`features/market-dashboard/market-number-format.ts`（含测试）→ `client/utils/market-number-format.ts`，更新 chart 与看板的导入；`libs/api/` 保留 Hono RPC client 与 query hooks；`features/market-dashboard/chart/` 与 `pages/home/index.tsx` 路径不变。
- 后端按业务域重排：
  - `server/app.ts`（HTTP 装配、CORS、健康检查、错误映射、`AppType`）、`config.ts`、`main.ts`、`server.ts`（组合根）留在 server 根。
  - `market/daily-bars.ts` → `market/service/market-service.ts`：只保留用例、`MarketService`、`RemoteFetcher` 与输入类型；`dailyBarsRequest` 移到 handler，`DailyBarsMeta`/`DailyBarsResponse` 移到 shared。
  - `market/errors.ts` → `market/service/errors.ts`：`MarketError` 去掉 HTTP 状态，只保留业务码（`not_found`/`deadline_exceeded`/`upstream_unavailable`）与消息；新增 `market/handler/errors.ts` 负责业务码/Zod/取消 → HTTP 状态。
  - `storage/schema.ts` → `market/repository/sqlite/schema.ts`；`storage/market-store.ts` → `market/repository/sqlite/sqlite-market-repository.ts`（`MarketRepository` 接口移至 `market/repository/market-repository.ts`）；`storage/database.ts` 的连接/迁移 → `libs/sqlite/database.ts`；`market/securities.ts` 的种子数据 → `market/repository/securities.ts`，由 SQLite 实现幂等写入。
  - `integrations/{hongsehuojian,kline-response}.ts` → `libs/hongsehuojian/`。
  - `market/dates.ts` → `server/utils/dates.ts`（保留 Zod schema 与 `shanghaiDate`）。
  - `market/handler/routes.ts` 新增：`createMarketHandler(service)` 定义 `/securities`、`/daily-bars` 与 Zod 校验，由 `app.ts` 以 `.route("/api", ...)` 挂载。
- 数据库接口与实现解耦：`market/repository/market-repository.ts` 定义 `MarketRepository`/`TradingDay`（无 Hono/Drizzle 依赖），`repository/sqlite/sqlite-market-repository.ts` 是 SQLite 实现；`libs/sqlite/database.ts` 用 `better-sqlite3` + `drizzle-orm` + `drizzle-kit` 迁移实现连接与迁移。替换 MySQL/PG 时新增同接口实现并在组合根替换。
- 框架边界：`server/market/service` 与 `server/market/repository` 不导入 `hono`/`@hono/*`；只有 `market/handler`、`server/app.ts`、`server/server.ts`、`server/main.ts` 依赖 Hono。
- 依赖注入：`openSqliteDatabase(dsn)`、`createSqliteMarketRepository(db)`、`createMarketService({ repository, fetcher, now })`、`createMarketHandler(service)`、`createApp(service)`；`server.ts` 唯一组合根执行「选择数据库实现 → repository → service → app → serve」，测试可替换任一层。
- 共享抽取：`shared/market.ts` 放 `Security`、`DailyBar`、`DailyBarsMeta`、`DailyBarsResponse`；`shared/api.ts` 放 `ApiResponse<T>`/`ApiCode`/`apiCode`/`apiOk`/`apiFail`；`shared/utils/trade-date.ts` 放 `parseTradeDate`、`formatTradeDate`、`isValidTradeDate`、`addDays`、`dateRange`、`isWeekday` 与测试。服务端 `utils/dates.ts`/`market-service.ts` 与前端 `chart-data.ts`/`test-support/render.tsx` 复用；前端 `libs/api/client.ts` 复用共享契约类型。
- RPC 大型应用组织：`server/app.ts` 用单一链式 `routes` 组合 `CORS → 健康检查 → .route("/api", createMarketHandler(service)) → onError → notFound`，导出 `AppType = ApplyGlobalResponse<typeof routes, GlobalErrorResponses>`；移除原先逐请求 try/catch 中间件，只保留 `app.onError()`；404 使用 `c.json(..., 404)`。
- 统一响应结构：`shared/api.ts` 新增 `ApiResponse<T> { code: number; message: string; extra: Record<string, any>; data: T }`、`apiCode`（0 成功，1001–1007 错误，1007 为未匹配路由）、`apiOk`、`apiFail`。成功 handler 用 `apiOk(data)` 包装；错误映射用 `apiFail(code, message, extra = {})`，失败时 `data = null`；HTTP 状态由 Hono 按语义单独返回（200/400/404/408/500/502/504），与业务码分离。`ApplyGlobalResponse` 的全局错误类型使用 `ApiResponse<null>`。
- RPC 类型：`client/libs/api/client.ts` 成为唯一 `hc<AppType>` 实例化点，导出 `Client` 与 `hcWithType`（type-only `AppType`），`createEtfClient` 委托给 `hcWithType`；成功响应类型用 `InferResponseType<..., 200>["data"]`，全局错误可按状态收窄；前端在 `response.ok` 与 `body.code === apiCode.ok` 后解包 `data`。不改路由路径、请求参数与响应形状；不引入 OpenAPI/SDK 生成。handler 使用 `async/await` 且不拆断链式路由定义。
- 测试随层迁移：`service.test.ts` 拆为 `server/server.test.ts`（配置/入口/启停）、`market/handler/routes.test.ts`（HTTP 校验与错误映射）、`market/repository/sqlite/sqlite-market-repository.test.ts`（迁移、幂等 seed、事务、查询）；`daily-bars.test.ts` → `market/service/market-service.test.ts`（用假 repository/fetcher，证明不依赖 SQLite/Hono）；上游测试 → `libs/hongsehuojian/`；新增 `shared/utils/trade-date.test.ts`。
- 合并 `package.json`（依赖、`dev:server`/`dev:web`/`dev`/`build`/`start`/`test`/`test:coverage`/`test:e2e`/`db:generate`），更新锁文件；同步根 `dev:etf`。
- 配置：`vite.config.ts` 设 `root: "client"`、`outDir: "../dist/client"`、别名 `@` → `client`、`@shared` → `shared`；`tsconfig.json` 统一类型检查（client/server/shared + 配置，paths 同步）；`tsconfig.server.json`（`rootDir: "."`、`outDir: "dist"`、include `server`/`shared`、exclude 测试）；`vitest.config.ts` 两 project 共用别名，unit 覆盖三个源码根；`playwright.config.ts` webServer 改 `dev:web`；`drizzle.config.ts` schema 指向 `server/market/repository/sqlite/schema.ts`；合并 `.gitignore`。
