# 001-倒计时状态与播完行为

## 交付

- 新增 `apps/music/client/app/playback/sleep-timer.ts`：
  - `type SleepTimer = { kind: "off" } | { kind: "endless" } | { kind: "until"; endsAt: number; totalMs: number }`（`totalMs` 供尾线算剩余比例，2026-11-11 实现时补）
  - `isAutoPlayActive(timer, now = Date.now()): boolean`
  - `remainingMs(timer, now = Date.now()): number | null`（`off`/`endless` 返回 `null`，否则 `max(0, endsAt - now)`）
  - `MINUTES_MAX = 1440` 与 `parseMinutes(raw: string): number | null`（正整数校验，供面板复用）
- `apps/music/client/app/store/player.ts`：
  - 删 `autoPlay` / `setAutoPlay`；新增 `timer: SleepTimer`（默认 `{ kind: "off" }`）。
  - 新增 `startCountdown(minutes: number)` → `{ kind: "until", endsAt: Date.now() + minutes * 60_000 }`；`startEndless()` → `{ kind: "endless" }`；`expireTimer()` → `{ kind: "off" }`（仅在当前为 `until` 且已过期时生效，`endless` 不受影响）。
  - `persist` 的 `partialize` 只留 `{ history }`；`resetPlayer` 置 `timer: { kind: "off" }`。
- `apps/music/client/app/playback/use-playback.ts`：从 store 取 `timer`，`onEnded` 改为 `if (isAutoPlayActive(timer)) shouldPlayRef.current = true; advance(ids)`；`useEffect` 依赖换成 `timer`。
- 单测：新增 `sleep-timer.test.ts`（三态判定、边界 `now === endsAt` 为假、`parseMinutes` 合法/非法），`player.test.ts` 删旧开关用例、换成本条的三态与持久化断言。

## 验收

- [x] 未设倒计时：曲目自然播完切下一首且 `paused === true`、`currentTime < 1`（与 2026-11-05 行为一致）。

- [x] `vp check` 与 `apps/music` 单测全绿。

## 决策与验证

- **到期在 `onEnded` 时按墙钟判，而不是等控件把状态置回 `off`**：控件未挂载或标签页在后台时 `setInterval` 会被节流，靠 `endsAt` 判定才不会漏。
- **`parseMinutes` 放 sleep-timer.ts**：面板与单测共用一份校验，避免两处规则漂移。
- **不做 persist 版本迁移**：旧 `autoPlay` 字段被 zustand 忽略，`history` 结构未变，bump version 只会多写一次迁移代码。
- 验证证据：单测输出与本地实测记录追加在本 note 末尾。
