## 设计定稿

**控制条**：`播放 · 下一首 · 定时` 一行。未设置时只有一个 44px 的「定时」文字按钮（`--color-ink-2`，悬停转 `--color-ink` 加 `--color-paper-2` 底，聚焦 2px accent 轮廓）。生效后同一位置变成读数：`--font-code` 数字 + 下方 2px 尾线，`--color-rule` 轨、`--color-accent` 填充，宽度用 `transform: scaleX(var(--remain))`（不动 width）。读数 `min-inline-size: 4.75rem`，数字变化不抖。

**面板**（`inset-inline-end: 0`，向上弹，17rem，`--color-sheet` + `--radius-card` + `--shadow-lift`）：
1. 标签「自动播放分钟数」，40px 输入框（16px 字，`--radius-inner`，`inputmode=numeric`，min 1 / max 1440）+ 单位「分钟」；
2. hint 行「到期后，本轮播完就停。」（`min-block-size: 1lh`，错误时原位替换为红字「只能是 1 到 1440 之间的整数。」）；
3. 快选 5 / 10 / 15 / 30：**只填数字，不开始**（原草稿是点了就开始，改成填值，因为开始不可撤销）；
4. 「开始计时」整宽填充按钮（唯一主操作）+ 下方同宽的安静文字「不限时」（文案居中，宽度与主按钮一致）。

**八态**：默认、悬停、`:focus-visible`、按下各就绪；不可用 = 原生 disabled + 0.55 + not-allowed；错误 = 输入框红边 + hint 红字（不靠颜色单独表达）；成功 = 面板关闭、读数出现（就是运行态）；loading 无（无请求），已在预览末尾写明。

**动效**：面板 `opacity + translateY(4px)`，`--dur-short` / `--ease-out`；尾线 `transform` 过渡用 `linear`（进度允许）；`prefers-reduced-motion` 全部关闭。

## 决策与验证

- **样式放独立 `sleep-timer-control.css` 而不是追加到 `styles.css`**：Hallmark 要求 stamp 在 CSS 首行，追加会破这条；组件自己 import，Vite 处理。
- **读数不是禁用按钮，而是 `role="timer"` 的静态读数**：不可撤销时禁用按钮会被读成「坏掉了」，读数才表达「正在跑」；也不用 disabled 的 0.55 透明度去压时间。
- **快选改成只填值**：不可撤销的动作只留一个提交入口，误触代价从「几个小时静音」降为「改一个数字」。
- **不加「取消/续时」**：用户明确要求不可暂停不可取消，逃生口是刷新。
- **计数用 `--font-code` 且不补字体文件（用户 2026-11-11 决定）**：Geist Mono 不在 `client/public/fonts/`，渲染落到系统等宽；接受兜底，不新增资源。
- 证据：八态预览 1280/390 与 3x 读数特写（截图已删）；sloplint 两次（改前 WARN F23 已补 meta description，改后 clean）。
