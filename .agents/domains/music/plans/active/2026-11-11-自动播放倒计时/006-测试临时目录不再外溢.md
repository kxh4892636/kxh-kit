# 006-测试临时目录不再外溢

## 交付

- 新增 `apps/music/server/temp-dir.test-helper.ts`：`tempDir(prefix)` 在系统临时根下建目录并登记，`cleanupTempDirs()` 递归删掉本文件登记的全部目录并清空列表。
- `server/app.test.ts`、`server/config.test.ts`、`server/tracks.test.ts` 各加一行 `afterAll(cleanupTempDirs)`，把 `mkdtempSync(join(tmpdir(), …))` 换成 `tempDir(…)`（共 5 处）。
- `tsconfig.server.json` 的 `exclude` 增加 `**/*.test-helper.ts`，测试辅助不进 `dist/server`。

## 验收

- [x] 跑全套测试前后 `ls -d /tmp/music-{app,env,index}-*` 计数都是 0（修复前每跑一次多 3 个以上）。
- [x] `npx vp test run` 11 个文件 63 条全绿。
- [x] `tsc -p tsconfig.server.json` 后 `dist/server` 只有 app/config/main/media/server/tracks 六个文件，无 `test-helper`。
- [x] `vp check` 通过（46 文件 0 告警）。
- [x] 历史残留已清：878 个目录、198 MB（`/tmp` 下 485 个 `music-app-*`、258 个 `music-env-*`、135 个 `music-index-*`）。

## 决策与验证

- **共享一个 helper 而不是三个文件各写四行**：同一段清理逻辑出现三次会漂移；用一个文件放 `tempDir` 与清理入口，测试文件只多一行 `afterAll`。
- **不在 helper 里写模块级 `afterAll`**：hook 必须注册到发起文件所属的 suite，import 时注册依赖收集顺序；改成每个文件显式调用，行为可预期。
- **为 helper 改 `tsconfig.server.json` 是必要的**：`exclude` 原本只挡 `*.test.ts`，不加这一条，`.test-helper.ts` 会被编译进发布产物。
- 未处理：`/tmp` 里另有约 3 GB 的 `*.tmp`、`*.tmp.png`，是 agent 工具链的过程文件，不属于本仓库产物。
