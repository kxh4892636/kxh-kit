# 003-本地验收与测试

## 交付

- `apps/music/e2e/smoke.spec.ts`：删掉基于 `role=switch` 的旧用例，新增
  1. **未设倒计时**：自然播完 → 换曲、按钮回到「播放」、`currentTime < 1`（现有默认行为不回归）。
  2. **倒计时内**：设 1 分钟 → 立即把当前曲推到末尾 → 换曲且「暂停」按钮可见（自动播下一首）。
  3. **到期后**：设 1 分钟 → 让 `Date.now()` 前进 61 秒 → 再把当前曲推到末尾 → 换曲且停在 `paused`。
  4. **不限时**：点「不限时」→ 按钮显示「不限时」且被禁用；推进时间后仍自动连播。
  5. **刷新重置**：设 1 分钟 → reload → 按钮回到「定时」。
- 时间推进方案：优先 `page.addInitScript` 覆写 `Date.now`（暴露 `window.__musicNow = () => realNow() + offset`，用例里加 `offset`），只影响倒计时判定、不动音频计时；`page.clock` 备用，若与音频 `timeupdate` 冲突就放弃。
- 面板交互用例：点「定时」→ 焦点在输入框 → 填 30 → 点「开始」→ 按钮显示 `30:00` 且 `disabled`。
- 本地起服务实测（`pnpm dev` 或本地构建 + `node dist/server/main.js`，127.0.0.1:5210），按 1440 与 390 两档截图，列差异清单交用户确认。

## 决策与验证

- **不新增测试专用后门**：用假 `Date.now` 足以控制到期判定，避免为测试在 store 里留可写入口。
