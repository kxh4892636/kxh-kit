# 002-老曲库中文元数据与纠错

## 交付

- `apps/music/scripts/data/old-zh.json`：37 部作品的中文作曲家、中文作品名、原文作品名、作品号；145 条曲目的中文乐章/段落名。以老索引的 `work + movement` 与 track id 为键，不依赖曲目顺序。
- 修正两处原始错误：Haydn 弦乐四重奏 `Op. 645` → Op. 64 No. 5（Hob. III:63，Lark）；Rimsky-Korsakov `Russian Overture` → 《俄罗斯复活节序曲》Op. 36。
- 每条译名附依据（维基百科中文/英文条目、权威唱片目录或乐理通行译名），存进数据文件的 `evidence` 字段。

## 范围

- 作曲家 14 位、作品 37 部、曲目 145 条；只补中文字段与作品号，不改音频、不改老索引的英文原文。
- 乐章译名用通行中文术语（如 Allegro con brio → 有活力的快板；Marcia funebre → 葬礼进行曲），同一术语在全库保持一致。

## 验收

- [ ] 145/145 条曲目都有非空 `composerZh / workZh / movementZh`（无乐章的作品用空字符串，界面显示“单乐章/选段”）。
- [ ] 37 部作品都有标准中文名与作品号；Haydn、Rimsky 两处错误已改正。
- [ ] 抽查至少 10 条与权威来源一致；术语表内无同词异译。
- [ ] 数据文件可被构建脚本直接读取，无重复键。

## 下一步

先产出 37 部作品对照表（中文名、原文名、作品号、依据链接），再逐条补乐章译名。

## 交付记录

- 2026-11-08：生成 `apps/music/scripts/data/old-zh.json`（22,293 B），覆盖 37 部作品、145 条曲目。
- 结构：`works` 以老索引的 `work` 原字符串为键，含 `composerZh / workZh / workOriginal / catalog / evidence`；`tracks` 以 track id 为键，含 `movementZh`。
- 校验：145/145 条曲目有中文字段（无乐章作品为空字符串）；37/37 部作品有中文名与作品号；无缺失、无未用译名键；脚本打印 `missing movement zh []`。
- 已改正：Haydn `Op. 645 → Op. 64 No. 5, Hob. III:63`；Rimsky `Russian Overture → Russian Easter Festival Overture, Op. 36`。
- 抽查依据：哥德堡变奏曲（BWV 988）、在中亚细亚草原上、赫布里底群岛序曲（Op. 26）、海顿《云雀》四重奏（Op. 64 No. 5）、俄罗斯复活节序曲（Op. 36）、悲剧序曲（Op. 81）、《培尔·金特》第一组曲（Op. 46）、伏尔塔瓦河；其余采用中文维基百科通行译名与作品号核对。
- 乐章编号写进中文（第一乐章…），因为页面只显示 `movement`，同曲不同乐章不能靠编号区分。
- 限制：舒伯特奏鸣曲末乐章等个别条目的原作标记本身有笔误（如 D. 568 第四乐章标 Allegro moderato），按索引原文翻译，不擅自改动作曲家的标记；后续如听众发现可在数据文件单点修正。
