# 003-新曲库标准化与去重

## 交付

- `apps/music/scripts/data/new-catalog.json`：202 条，字段含 `id、relPath、composer、composerZh、work、workZh、catalog、movement、movementZh、kind、confidence、evidence、seconds、bytes、sampleRate、bits`。
- 四组并行整理：贝多芬+莫扎特 59、李斯特+舒曼 38、肖邦 39、克莱德曼 66。
- 元数据依据：文件名、时长、音频调性/末和弦分析、豆瓣/世界猫/IMSLP 等公开目录；每条 evidence 记录依据或疑点。

## 去重与显示重名

- 字节重复 2 对，删除 `(1)` 副本：`侏儒的轮舞(1).wav`、`夜曲16号降E大调慢板(1).wav`。
- `悲怆奏鸣曲.wav` 与 `绿袖子.wav` 字节数、时长相同但 PCM 相关性 ≈ 0，不是重复。
- 跨库重叠 3 部保留老库、删除新库副本：英雄交响曲（新库 6:20 选段）、科里奥兰序曲、爱格蒙特序曲。
- 显示重名不删音频，改加后缀：3 条肖邦同曲不同录音加“（另一录音）”；12 条克莱德曼琴动情怀版加“（琴动情怀版）”。最终 202 条无重复的「作曲家+作品+乐章」显示组合。
- 低置信度且无法定名的肖邦条目，display 名取用户文件名 + “（待考）”，不臆造作品号；候选作品保留在 evidence 与 work 字段。
- 单乐章作品被分轨的（李斯特 B 小调奏鸣曲 3 轨、舒曼幽默曲 4 轨），乐章显示为“第 N 段 · …”，避免同一作品在三行里看起来一样。

## 结论

- 新库保留 **202** 条；与老库 145 条合并后 **347** 条、196 部作品。
- 置信度：high 104 / medium 63 / low 35（新库）；低置信度集中在肖邦分辑，原因是文件名调性/序号与音频普遍不符。

## 验收

- [x] 202 条全部有 `composerZh + workZh`；作品号只在有依据时填写。
- [x] 每条有 `confidence` 与 `evidence`；low 条目在 evidence 写明疑点。
- [x] 去重后没有重复的「作曲家 + 作品 + 乐章/选段」显示组合。
- [x] `new-catalog.json` 的 `relPath` 与保留文件一一对应。

## 备注

- 肖邦 39 条中 35 条为 medium/low：文件名声称的调性与音频分析结果大量冲突，建议后续人耳复核 low 条目。
- 克莱德曼两辑的中文名有豆瓣条目逐一对应，置信度最高。
