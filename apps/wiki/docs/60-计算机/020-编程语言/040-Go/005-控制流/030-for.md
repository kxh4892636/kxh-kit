# for

## 三段式循环的 init、condition、post 如何书写？

- 三段式流程: init 只执行一次；每轮先检查 condition，执行循环体后运行 post，再检查下一轮条件;

```go
func main() {
	for i := 0; i < 3; i++ { // init; condition; post
		println(i)
	}
}
```

## 条件循环如何书写, 如何表达 while 语义？

- 条件循环: 只保留 bool 条件时，每轮开始前检查；循环体必须自行推进状态，否则条件可能一直成立;

```go
func main() {
	n := 3
	for n > 0 { // condition-only for; 表达类似 while 的循环
		println(n)
		n--
	}
}
```

## 无限循环如何书写, 如何退出？

- 无限循环: 省略全部控制部分后不断执行，通常通过 `break`、`return` 或取消信号结束；`break` 只退出它所针对的循环;

```go
func main() {
	for { // 无限循环
		println("once")
		break // 退出当前循环
	}
}
```
