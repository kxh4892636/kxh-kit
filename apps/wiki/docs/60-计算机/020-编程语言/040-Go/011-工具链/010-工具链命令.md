# 工具链命令

## Go 常用工具链命令有哪些？

- 工具链: `go` 根据当前包与模块上下文执行任务，`./...` 表示当前目录及其子目录的包模式，不表示任意系统文件;

| 命令       | 描述                    |
| ---------- | ----------------------- |
| `go run`   | 编译并运行              |
| `go build` | 编译 package 或源码文件 |
| `go test`  | 运行测试                |
| `go fmt`   | 格式化 Go 源码          |
| `go doc`   | 查看文档                |
| `go env`   | 查看环境变量            |
| `go mod`   | 管理 module             |

```bash
go test ./... # 测试当前模块的包
go doc fmt.Println # 查看特定符号文档
go env GOMOD # 查看当前模块配置位置
go run . # 编译并运行当前 main 包
```

## Go 代码如何格式化？

- 格式化入口: `go fmt ./...` 按包调用 gofmt 统一代码外观；它不会替代编译、静态检查或测试，也不会自动补齐缺失 import;

```bash
go fmt ./... # 格式化当前目录及子目录中的所有 Go package
```

## Go 代码如何编译与运行？

- 构建与运行: `go build` 生成程序但不执行，`go run` 临时编译并运行；显式传入 main.go 只包含列出的文件，构建当前完整包通常用 `go build .`;

```bash
go build -o hello main.go # 编译 main.go 并输出名为 hello 的可执行文件
./hello # 运行当前目录下的 hello
```

```bash
go build -o hello . # 将当前 main 包的全部适用源码一起构建
go run . # 直接执行同一个包，适合本地快速运行
```

- 平台差异: Windows 通常输出 hello.exe 并用 .\hello.exe 运行；文件名、后缀与启动方式应按当前终端调整;
