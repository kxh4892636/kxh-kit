# hz 自定义模板与插件

## layout 模板

- 定义生成代码的目录结构(与 IDL 无关);
- 使用 go template + yaml 格式, 模板渲染数据用 json;
- 全局渲染参数: `GoModule`, `ServiceName`, `UseApacheThrift`, `HandlerPkg`, `RouterPkg`;
- 文件渲染参数仅作用于所属文件, key 为相对路径文件名;
- `--customize_layout=template/layout.yaml --customize_layout_data_path=template/data.json` 启用;
- 不指定渲染数据时使用默认渲染参数, 自定义模板须保证参数在默认范围内;

## package 模板

- 与 IDL 相关的代码(handler, router, middleware, client);
- 内置模板: `handler.go`, `router.go`, `register.go`, `middleware.go`, `client.go`, `handler_single.go`, `middleware_single.go` 等;
- 同名模板覆盖默认, 新模板需给出基于 out_dir 的相对路径;
- 支持 `loop_method` / `loop_service` 循环渲染;
- `update_behavior.type`: skip / cover / append 控制更新行为;
- 已存在 handler 追加新 method 时使用默认 `handler_single` 模板;

## 第三方插件

- thrift: `hz new --idl=x.thrift --thrift-plugins=validator`(如 thrift-gen-validator 生成 `IsValid()`);
- protobuf: `hz new --protoc-plugins=openapi::./docs ...`(如 protoc-gen-openapi 生成文档);
- 插件格式: `{PLUGIN-NAME}:{OPTION1,OPTION2}:{OUT_DIR}`;
