# Hertz 日志

## 基本使用

- 日志实现在 `pkg/common/hlog`, 默认输出到标准输出;
- 全局函数: `hlog.Info`, `hlog.Errorf`, `hlog.CtxTracef`, `hlog.CtxDebugf` 等;
- `hlog.SetOutput(w)`: 重定向输出, 可用 `io.MultiWriter(f, os.Stdout)` 同时输出文件与终端;
- `hlog.SetLevel(hlog.LevelInfo)`: 设置日志等级, 高于该等级的才打印;
- 等级: `LevelTrace < LevelDebug < LevelInfo < LevelNotice < LevelWarn < LevelError < LevelFatal`;
- `hlog.SetSilentMode(true)`: 关闭框架层因客户端不规范行为产生的错误日志;
- 默认 logger 基于标准库 `log.Logger`, 封装会影响文件行号准确性;

## 日志扩展

- `hlog.SetLogger(yourFullLogger)`: 注入自定义 logger;
- 需实现 `FullLogger` 接口(`Logger + FormatLogger + CtxLogger + Control`);
- 第三方日志库扩展见 hertz-contrib/logger(zap, logrus, zerolog, slog);

## 示例

```go
func AccessLog() app.HandlerFunc {
	return func(ctx context.Context, c *app.RequestContext) {
		start := time.Now()
		c.Next(ctx)
		hlog.CtxTracef(ctx, "status=%d cost=%d method=%s full_path=%s client_ip=%s host=%s",
			c.Response.StatusCode(), time.Since(start).Microseconds(),
			c.Request.Header.Method(), c.Request.URI().PathOriginal(), c.ClientIP(), c.Request.Host())
	}
}
```
