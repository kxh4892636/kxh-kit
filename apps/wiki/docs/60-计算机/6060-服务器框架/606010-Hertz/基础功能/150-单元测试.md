# Hertz 单元测试

## 原理

- 类似 Go 标准库 httptest: 不经过网络, 直接执行 `ServeHTTP` 并返回响应;
- 工具包: `github.com/cloudwego/hertz/pkg/common/ut`;

## 创建请求上下文

- `ut.CreateUtRequestContext(method, url, body, headers...)`: 构造 `*app.RequestContext`;
- `ut.Body{Body: bytes.NewBufferString(...), Len: len(...)}`: 请求体;
- `ut.Header{Key, Value}`: 请求头;

## 发送请求

- `ut.PerformRequest(engine, method, url, body, headers...)`: 向 engine 发送请求;
- url 可为相对路径或绝对路径;
- 流式请求体: `server.WithStreamBody(true)` 或将 body Len 设为 -1;
- 返回 `*ResponseRecorder`;

## 响应断言

- `w.Result()`: 返回 `*protocol.Response`, 包含 StatusCode, Header, Body, Trailer;
- `ResponseRecorder` 提供 `Header/Write/WriteString/WriteHeader/Flush/Result`;
- handler 未调用 WriteHeader/Write 时 Code 可能为 0, 用 `Result()` 取隐式 200;

## 示例

```go
func TestPerformRequest(t *testing.T) {
	h := server.Default()
	h.GET("/ping", Ping)
	w := ut.PerformRequest(h.Engine, "GET", "/ping", &ut.Body{Body: bytes.NewBufferString("1"), Len: 1})
	resp := w.Result()
	assert.DeepEqual(t, 200, resp.StatusCode())
}
```
