# Hertz 概览与架构

## 核心类型

- `server.Hertz`: Hertz 核心类型, 由 `route.Engine` 与 `signalWaiter` 组成;
- `route.Engine`: 承载路由, 中间件注册与请求分发;
- Handler 签名: `func(ctx context.Context, c *app.RequestContext)`;
- `server.Default()`: 默认注册 Recovery 中间件, `server.New()` 不注册;
- `h.Spin()`: 运行服务并支持优雅退出; `Engine.Run()` 不支持优雅退出;

## 服务配置

- `server.WithHostPorts(":8888")`: 监听地址, 默认 `:8888`;
- `WithTransport`: 更换底层网络库, 受平台影响;
- `WithKeepAliveTimeout`(1min) / `WithIdleTimeout`(3min): 长连接保活与空闲超时;
- `WithMaxRequestBodySize`(4MB): 最大请求体大小;
- `WithRedirectTrailingSlash`(true): 自动重定向尾斜杠; GET 返回 301, 其他方法 307;
- `WithHandleMethodNotAllowed`(false): 开启后未匹配路径时检查其他方法并返回 405;
- `WithExitWaitTime`(5s): 优雅退出等待时间;
- `WithTLS` / `WithALPN` / `WithH2C`: TLS 与协议协商相关;
- `WithRegistry`: 设置服务注册中心;
- `WithTraceLevel`: 埋点粒度, 有 tracer 时默认 `LevelDetailed`;
- `WithGetOnly` / `WithKeepAlive` / `WithStreamBody`: 请求行为控制;
- `WithDisableHeaderNamesNormalizing`: 关闭 Header 名规范化;

## 运行与退出

### Spin

- `Spin` 启动服务并阻塞等待退出信号;
- 使用服务注册发现时, `Spin` 会先注册服务再监听信号;

### 信号处理

- 版本 >= v0.9.6: `SIGTERM|SIGHUP|SIGINT` 均触发优雅退出;
- `SetCustomSignalWaiter(f)` 可自定义信号处理; 返回 error 立即退出, 否则优雅退出;

## 其他内置能力

- `AddProtocol(protocol, factory)`: 注册自定义协议 server;
- `PanicHandler`: 设置 panic 处理函数, 设置后与 Recovery 同时存在时 Recovery 生效;
- `ContinueHandler`: 决定是否读取带 `Expect: 100-continue` 的请求体;
- `Routes()`: 返回已注册路由信息(方法, 路径, handler);
- `h.OnRun` / `h.OnShutdown`: 注入启动后 / 退出前钩子;

## 网络库选择

- linux 默认 `netpoll`, windows 只能使用 `go net`;
- `GetTransporterName()` 获取当前网络库名称;
- `route.SetTransporter(standard.NewTransporter)` 设置全局默认网络库;
- `WithTransport` 优先于 `SetTransporter`;
