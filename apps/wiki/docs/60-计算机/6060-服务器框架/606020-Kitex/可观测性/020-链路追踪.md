# Kitex 链路追踪

## Tracer 接口

```go
type Tracer interface {
	Start(ctx context.Context) context.Context
	Finish(ctx context.Context)
}
```

- 通过 `client.WithTracer(...)` / `server.WithTracer(...)` 注入;
- 可用于指标监控与链路追踪扩展;

## 自定义跟踪事件

- 内置事件见埋点笔记(RPCStart/RPCFinish 等);
- 可手动创建 span 增加追踪数据(如 OpenTelemetry 原生 API);

## 接入 OpenTelemetry

- `kitex-contrib/obs-opentelemetry` 提供 provider + tracing suite;
- Client: `client.WithSuite(tracing.NewClientSuite())` + `client.WithClientBasicInfo(...)`;
- Server: `server.WithSuite(tracing.NewServerSuite())` + `server.WithServerBasicInfo(...)`;
- `provider.NewOpenTelemetryProvider(...)` 持有 exporter client, 重复初始化需先 `Shutdown()` 前一个实例;
- 也支持 OpenTelemetry 编译时注入方案;

## 流式追踪

- 基本埋点: RPCStart / RPCFinish; Server/Bidirectional 流需 Recv 收到 non-nil error 才记录 RPCFinish, 提前结束用 `streaming.FinishStream`;
- Client Streaming 在 `CloseAndRecv()` 返回前自动记录;
- 细粒度: `StreamEventReporter` 报告 StreamSend/StreamRecv, 可读取 `LastSendSize` / `LastRecvSize`;
