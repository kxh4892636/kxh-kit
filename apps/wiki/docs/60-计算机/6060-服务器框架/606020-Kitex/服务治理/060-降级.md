# Kitex Fallback 降级

## 功能说明

- v0.5.0+; RPC 失败(超时/熔断/限流/协议等)后执行降级逻辑保证有效返回;
- 支持处理: RPC Error, 业务 Error(BizStatusError), Resp(BaseResp 中定义的错误);
- 只支持代码配置; streaming 请求不支持 fallback;

## Fallback Func

- 两种签名;
  - `Func`: `func(ctx, args utils.KitexArgs, result utils.KitexResult, err) (fbErr error)`, 必须 `result.SetSuccess(fbResp)` 替换返回值;
  - `RealReqRespFunc`: `func(ctx, req, resp, err) (fbResp, fbErr)`, 配合 `fallback.UnwrapHelper` 使用真实 RPC 类型;
- 构造: `fallback.NewFallbackPolicy(fn)`(Error 和 Resp 均触发);
- `fallback.ErrorFallback(fn)`: 只对 Error(含业务 Error);
- `fallback.TimeoutAndCBFallback(fn)`: 只对超时与熔断;

## 配置

```go
opts = append(opts, client.WithFallback(yourFallbackPolicy))
xxxCli.XXXMethod(ctx, req, callopt.WithFallback(yourFallbackPolicy)) // 调用级
```

## 监控上报

- 默认按原 RPC 结果上报(RPC 失败即 is_error=1);
- `policy.EnableReportAsFallback()`: 以 fallback 结果上报;
- 业务错误(Biz Err 或 BaseResp 非成功)默认 is_error=0, 且 fallback 返回 error 也不会改变;

## 特殊返回

- fbResp 与 fbErr 均为 nil: 返回原 resp 与 error;
- fbResp 与 fbErr 均非 nil: 不返回 resp 给用户;
- 允许 fallback 返回 error;
- Kitex Protobuf/gRPC Unary 支持 fallback, 需 >=v0.5.0 生成代码;
