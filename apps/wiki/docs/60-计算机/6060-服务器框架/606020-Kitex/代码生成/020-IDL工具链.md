# Kitex IDL 工具链

## Validator(thrift)

- thriftgo 插件 `thrift-gen-validator`, 注解 `vt.{ConstraintType}="Value"`;
- 生成 `IsValid() error` 到 `*_validator.go`;
- 数字: const/lt/le/gt/ge/in/not_in/not_nil;
- string/binary: const/min_size/max_size/pattern/prefix/suffix/contains/not_contains/in/not_in;
- enum: const/defined_only; set/list: min_size/max_size/elem; map: min_size/no_sparse/key/value;
- struct: skip(跳过递归校验), not_nil;
- 变量引用 `$x`(当前结构体作用域), 工具函数 `@len($x)`, `@sprintf(...)`;
- 使用: `kitex --thrift-plugin validator -service a.b.c hello.thrift`;

## Protoc Validator

- `protoc-gen-validator` 为 protobuf message 生成 `Validate() error`;
- 注解 `(api.vt).const/lt/le/gt/ge/pattern/min_size/...`; 支持 msg_vt.assert, 跨域引用, 内置函数(len/sprintf/now_unix_nano/equal/mod/add);
- 参数: `recurse`(递归生成依赖), `func=name=template`(自定义验证函数);

## Fastpb

- protobuf 增强插件, 规避反射, 性能优于官方库;
- Kitex 默认集成, 生成 `xx.pb.fast.go`; `-no-fast-api` 关闭;
- 删除 `xx.pb.fast.go` 后框架自动适配官方库编解码;

## Prutal

- v0.13.0+ 默认使用 Prutal 替代 protoc/protoc-gen-go 生成代码与序列化;
- 无需安装 protoc; 生成代码精简, 序列化性能优于官方;
- `--protobuf` / `--protobuf-plugin` 参数废弃; `KITEX_TOOL_USE_PROTOC=1` 回退;
- 生成的代码不实现 protoreflect.ProtoMessage, 需用 `github.com/cloudwego/prutal` 的 MarshalAppend/Unmarshal;

## Thrift Reflection

- thriftgo v0.3.0+ 提供 IDL 反射; 生成 `-thrift with_reflection` 产生 `*-reflection.go`;
- 运行时获取 Descriptor 与 IDL 元信息, 支持与 Go reflect 结合(GetGoType, SetInstanceValue);
- IDL 注册以文件路径为唯一 key, 重复注册 panic;
- 与公共结构体功能可共存;

## IDL Trimmer

- thriftgo v0.3.1+ 裁切未被 service 引用的 struct, 减小生成代码;
- `trimmer [options] file`: `-o` 输出, `-r` 递归, `-m service.method` 指定方法;
- `// @preserve` 注释保护结构; `-p false` 禁用;
- 集成: `kitex -thrift trim_idl xxx.thrift`; 可用 trim_config.yaml 配置;
- typedef, 枚举, 常数不裁切;

## 其他

- SkipDecoder: `-thrift no_default_serdes` 移除 Apache Thrift Codec 代码(可裁 36% 产物), 配合 `thrift.EnableSkipDecoder` 兼容 Buffered 协议(Kitex v1.16.0+);
- 自定义 struct tags: `go.tag = "..."` 注解; JSON tag 会被覆盖, 可用 `-thrift always_gen_json_tag` 保留;
- 引用结构体: `-thrift code_ref` + idl-ref.yml 生成远端公共结构体引用;
- 枚举检查: v0.15.1+ 拦截 int32 溢出枚举并报错;
