# Kitex 概览与快速开始

## 定位

- Kitex: 字节跳动开源的 Go 微服务 RPC 框架, 高性能, 强可扩展;
- 基于 IDL(thrift/protobuf)生成代码;
- 教程涵盖基本特性, 服务治理, 高级特性, 代码生成, 框架扩展与 Option;

## 快速开始

```shell
go install github.com/cloudwego/kitex/tool/cmd/kitex@latest
kitex -module demo -service demo-server api.thrift
```

- 生成 `kitex_gen/`(IDL 结构体 + service 桩代码)与 `main.go`, `handler.go` 脚手架;
- handler 实现 IDL 定义的方法后运行 `main.go` 启动 Server;
- Client: `xxxservice.NewClient("destService", client.WithHostPorts("0.0.0.0:8888"))`;
- 直接运行: `go run main.go`;

## 生成代码结构

```
kitex_gen/
└── echo
    ├── echo.go          # thriftgo/protoc 生成的结构体
    ├── k-echo.go        # kitex 额外序列化优化
    ├── k-consts.go      # 占位符
    └── echoservice
        ├── client.go    # NewClient
        ├── server.go    # NewServer
        ├── invoker.go   # SDK 化调用
        └── echoservice.go
```

## 依赖版本

- thrift IDL 依赖 `github.com/apache/thrift v0.13.0`(生成时自动 replace 固定);
- v0.14.0 起 API 不兼容, 勿用 `go get -u` 升级;
- protobuf IDL 依赖 `google.golang.org/protobuf`, 版本由 Kitex 决定;
- 已生成代码与 Kitex 版本强相关, 升级 Kitex 需重新生成代码;

## 消息类型与协议支持

- 消息类型: PingPong(请求-响应), Oneway(不等待响应), Streaming;
- PingPong 支持 Thrift/Protobuf, 传输协议 TTHeader/HTTP2(gRPC);
- Oneway 仅 Thrift + TTHeader;
- Streaming 支持 Thrift/Protobuf + HTTP2(gRPC);
