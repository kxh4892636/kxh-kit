# Kitex 传输协议与序列化协议

## 分层概念

- RPC 协议 = 消息协议(Payload 序列化)+ 应用层传输协议;
- 传输协议透传服务治理元信息(如链路追踪信息), 与 MetaHandler 搭配使用;
- 支持 TTHeader, HTTP2 两种传输协议;
- 可配置项: TTHeader, GRPC, Framed, TTHeaderFramed, PurePayload;

## 协议组合

- Thrift: TTHeader(建议), Framed, TTHeaderFramed;
- KitexProtobuf: TTHeader(建议), Framed, TTHeaderFramed;
- gRPC: HTTP2;
- Framed: 在 PurePayload 前增加 4 字节 Payload Size;
- PurePayload: 无任何头部;
- TTHeaderFramed = TTHeader | Framed;

## 配置

```go
// Client: TTHeader
cli := xxx.NewClient("service",
	client.WithTransportProtocol(transport.TTHeader),
	client.WithMetaHandler(transmeta.ClientTTHeaderHandler))

// Client: gRPC(IDL 无 streaming 方法时必须显式指定)
cli := xxx.NewClient("service",
	client.WithTransportProtocol(transport.GRPC),
	client.WithMetaHandler(transmeta.ClientHTTP2Handler))
```

- Server 支持协议自动探测, 无需配置传输协议, 但需配 MetaHandler;
- Thrift 默认 Framed(v0.13.0+), 旧版本默认 Buffered PurePayload;

## 序列化协议

- Thrift Binary: Thrift 默认序列化协议, 高性能紧凑, 支持跨语言;
- Protobuf: Kitex 封装的高性能自定义格式(fastpb 编解码), 不支持 streaming;
- Hessian2: 与 Dubbo 互通使用;
- 关闭 Thrift 编解码优化: 生成代码加 `-no-fast-api`;
