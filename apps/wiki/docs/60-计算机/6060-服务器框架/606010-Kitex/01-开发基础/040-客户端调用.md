# 客户端调用

## 创建与复用

- Client: 管理服务发现缓存、连接池、治理配置和后台 goroutine; 按目标 service 进程级复用;
- 禁止模式: 每个请求调用一次 `NewClient`; 会放大连接、CPU、配置拉取与 goroutine;
- service name: `NewClient` 第一个参数; 同时是发现与观测维度;

```go
func newUserClient() (userservice.Client, error) {
	cli, err := userservice.NewClient(
		"user",
		client.WithHostPorts("127.0.0.1:8888"),
		client.WithConnectTimeout(200*time.Millisecond),
		client.WithRPCTimeout(time.Second),
	)
	if err != nil {
		return nil, fmt.Errorf("create user client: %w", err)
	}
	return cli, nil
}
```

## 发起调用

```go
func getUser(ctx context.Context, cli userservice.Client, id int64) (*api.GetUserResponse, error) {
	resp, err := cli.GetUser(ctx, &api.GetUserRequest{ID: id})
	if err != nil {
		return nil, fmt.Errorf("get user %d: %w", id, err)
	}
	return resp, nil
}
```

- Client Option: 创建时生效，适合服务级配置;
- Call Option: 只对一次调用生效，优先级高于 Client Option;
- `callopt.WithRPCTimeout`: 单次覆盖 RPC timeout; 不应成为到处散落的常规配置;
- `callopt.WithHostPort`: 单次直连指定实例; 适合诊断，不适合普通生产流量;

## 寻址方式

- 本地开发: `client.WithHostPorts` 直接指定实例;
- 动态环境: `client.WithResolver` 获取实例列表，由 LoadBalancer 选择;
- URL/DNS: `callopt.WithURL` 或 HTTP Resolver; 解析结果仍需连接目标;
- 预热: 首次调用延迟敏感时初始化 Resolver 与连接池; 实例变化后不会自动重复完整预热;

## 错误处理

- 先处理 `err`, 再读取 response;
- 使用 `errors.Is`、`kerrors.IsTimeoutError` 或业务异常转换判断类别;
- 不因“读请求”就盲目重试; 必须确认接口幂等和总时间预算;
