# 从零构建 RPC 服务

## 目标

- 结果: 创建一个可运行的 Thrift PingPong 服务，Server 监听 `127.0.0.1:8888` 并原样返回消息;
- Client: 设置 1s timeout，发起一次调用并打印结果;

## 最终结构

- 根目录: `go.mod`、`go.sum`、`hello.thrift`、`handler.go`、`main.go`;
- `kitex_gen/`: kitex 生成，不手工修改;
- `client/main.go`: 独立调用端;

## 初始化

```powershell
New-Item -ItemType Directory -Path hello
Set-Location hello
go mod init example.com/hello
go install github.com/cloudwego/kitex/tool/cmd/kitex@latest
go install github.com/cloudwego/thriftgo@latest
kitex --version
```

- module path: 后续生成命令必须与 `go.mod` 一致;

## 定义 IDL

```thrift title="hello.thrift"
namespace go api

struct Request {
  1: required string message
}

struct Response {
  1: required string message
}

service Hello {
  Response Echo(1: Request req)
}
```

## 生成代码

```powershell
kitex -module example.com/hello -service hello hello.thrift
go mod tidy
```

- `kitex_gen`: request/response、编解码、Client、Server 与 service interface;
- `handler.go`: Handler 骨架; 可以修改;
- `main.go`: Server 启动骨架; 可以修改;

## 实现 Handler

```go title="handler.go"
package main

import (
	"context"

	"example.com/hello/kitex_gen/api"
	"github.com/cloudwego/kitex/pkg/kerrors"
)

type HelloImpl struct{}

func (s *HelloImpl) Echo(ctx context.Context, req *api.Request) (*api.Response, error) {
	if err := ctx.Err(); err != nil {
		return nil, err
	}
	if req == nil || req.Message == "" {
		return nil, kerrors.NewBizStatusError(400, "message is required")
	}
	return &api.Response{Message: req.Message}, nil
}
```

## 启动 Server

```go title="main.go"
package main

import (
	"log"
	"net"

	hello "example.com/hello/kitex_gen/api/hello"
	"github.com/cloudwego/kitex/server"
)

func main() {
	addr := &net.TCPAddr{IP: net.ParseIP("127.0.0.1"), Port: 8888}
	svr := hello.NewServer(new(HelloImpl), server.WithServiceAddr(addr))
	if err := svr.Run(); err != nil {
		log.Fatalf("run hello server: %v", err)
	}
}
```

## 创建 Client

```go title="client/main.go"
package main

import (
	"context"
	"log"
	"time"

	"example.com/hello/kitex_gen/api"
	hello "example.com/hello/kitex_gen/api/hello"
	"github.com/cloudwego/kitex/client"
)

func main() {
	cli, err := hello.NewClient("hello", client.WithHostPorts("127.0.0.1:8888"))
	if err != nil {
		log.Fatalf("create hello client: %v", err)
	}
	ctx, cancel := context.WithTimeout(context.Background(), time.Second)
	defer cancel()
	resp, err := cli.Echo(ctx, &api.Request{Message: "hello kitex"})
	if err != nil {
		log.Fatalf("call Echo: %v", err)
	}
	log.Printf("response=%q", resp.Message)
}
```

## 运行与验收

- Terminal 1: 在项目根目录执行 `go run .`;
- Terminal 2: 在项目根目录执行 `go run ./client`;
- 预期输出: `response="hello kitex"`;
- 失败排查: 检查 8888 端口、module path、生成代码与 Client 地址;
- 完成标准: 修改 IDL 后能重新生成、补 Handler，并由 Client 调用新方法;
