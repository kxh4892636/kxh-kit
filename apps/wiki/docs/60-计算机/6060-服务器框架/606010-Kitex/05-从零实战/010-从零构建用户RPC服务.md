## 完成目标

- RPC: 使用 Thrift 定义 `CreateUser` 与 `GetUser`;
- Server: Kitex Server 监听 `0.0.0.0:8888`;
- 分层: Handler → Service → Repository;
- 存储: GORM + MySQL，使用版本化 migration;
- Client: 复用 Kitex Client，并配置连接与 RPC timeout;
- 错误: 参数、冲突、不存在和内部错误具有稳定分类;

```text
Thrift IDL → kitex 生成 → Entity/Repository/Service
           → GORM 实现 → Handler → Server 组装
           → Client → 测试 → Docker Compose 冒烟
```

## 第一阶段：定义 IDL 并生成代码

### Thrift 契约

```thrift title="idl/user.thrift"
namespace go user

struct User {
  1: required i64 id
  2: required string email
  3: required string name
  4: required i64 created_at_unix
}

struct CreateUserRequest {
  1: required string email
  2: required string name
}

struct GetUserRequest {
  1: required i64 id
}

service UserService {
  User CreateUser(1: CreateUserRequest req)
  User GetUser(1: GetUserRequest req)
}
```

- 字段编号: 发布后不复用，不因删除字段而重新编号;
- `required`: 变更会影响兼容性; 新字段通常优先 optional;
- 时间: 契约明确使用 Unix 秒，避免语言相关时间类型;
- 数据库: IDL 是 RPC 契约，不直接复用 GORM Row;

### 生成

```powershell
kitex -module example.com/user-service idl/user.thrift
go mod tidy
go test ./...
```

- `kitex_gen/user`: 请求、响应和编解码类型;
- `kitex_gen/user/userservice`: Client、Server 桩和服务接口;
- Handler/Server: 手工放入 `internal/transport/kitex` 与 `cmd/server`，避免根目录生成骨架限制分层;
- 重新生成: 修改 IDL 后再次运行同一命令并审查 diff;

## 第二阶段：实现领域层

### Entity 与错误

```go title="internal/user/entity.go"
package user

var (
	ErrInvalidInput = errors.New("invalid user input")
	ErrEmailConflict = errors.New("email conflict")
	ErrNotFound = errors.New("user not found")
)

type User struct {
	ID        int64
	Email     string
	Name      string
	CreatedAt time.Time
}

type CreateInput struct {
	Email string
	Name  string
}
```

### Repository

```go title="internal/user/repository.go"
type Repository interface {
	Create(ctx context.Context, user *User) error
	FindByID(ctx context.Context, id int64) (*User, error)
}
```

- Repository 围绕领域用例设计，不暴露 `*gorm.DB`;
- Service 依赖接口，Handler 和 Client 不访问数据库;
- 所有方法接收 context，以传播 deadline 和取消;

### Service

```go title="internal/user/service.go"
type Service struct{ repo Repository }

func NewService(repo Repository) (*Service, error) {
	if repo == nil {
		return nil, errors.New("repository is required")
	}
	return &Service{repo: repo}, nil
}

func (s *Service) Create(ctx context.Context, in CreateInput) (*User, error) {
	in.Email = strings.ToLower(strings.TrimSpace(in.Email))
	in.Name = strings.TrimSpace(in.Name)
	if in.Email == "" || !strings.Contains(in.Email, "@") || in.Name == "" {
		return nil, ErrInvalidInput
	}
	entity := &User{Email: in.Email, Name: in.Name, CreatedAt: time.Now().UTC()}
	if err := s.repo.Create(ctx, entity); err != nil {
		return nil, fmt.Errorf("create user: %w", err)
	}
	return entity, nil
}

func (s *Service) Get(ctx context.Context, id int64) (*User, error) {
	if id <= 0 {
		return nil, ErrInvalidInput
	}
	entity, err := s.repo.FindByID(ctx, id)
	if err != nil {
		return nil, fmt.Errorf("get user %d: %w", id, err)
	}
	return entity, nil
}
```

- 结构校验: Handler 检查 nil 请求;
- 业务校验: Service 规范化 email/name 并验证规则;
- 错误链: `%w` 保留 Repository 根因，Handler 使用 `errors.Is` 分类;
- 时间注入: 严格单测可向 Service 注入 clock，避免依赖真实时间;

## 第三阶段：实现 MySQL Repository

### Migration

```sql title="migrations/001_create_users.sql"
CREATE TABLE users (
  id BIGINT NOT NULL AUTO_INCREMENT,
  email VARCHAR(254) NOT NULL,
  name VARCHAR(100) NOT NULL,
  created_at DATETIME(3) NOT NULL,
  PRIMARY KEY (id),
  UNIQUE KEY uk_users_email (email)
);
```

- email: 唯一索引是并发创建时的最终一致性防线;
- migration: 由独立命令执行，Server 启动不做无条件 AutoMigrate;
- 时间: MySQL 与应用统一使用 UTC;

### GORM Row

```go title="internal/user/repository_gorm.go"
type userRow struct {
	ID        int64     `gorm:"primaryKey"`
	Email     string    `gorm:"size:254;not null;uniqueIndex"`
	Name      string    `gorm:"size:100;not null"`
	CreatedAt time.Time `gorm:"not null"`
}

type GormRepository struct{ db *gorm.DB }

func NewGormRepository(db *gorm.DB) (*GormRepository, error) {
	if db == nil {
		return nil, errors.New("database is required")
	}
	return &GormRepository{db: db}, nil
}

func toEntity(row userRow) *User {
	return &User{ID: row.ID, Email: row.Email, Name: row.Name, CreatedAt: row.CreatedAt}
}
```

### Create 与 FindByID

```go
func (r *GormRepository) Create(ctx context.Context, entity *User) error {
	row := userRow{
		Email: entity.Email,
		Name: entity.Name,
		CreatedAt: entity.CreatedAt,
	}
	if err := r.db.WithContext(ctx).Create(&row).Error; err != nil {
		if isDuplicateKey(err) {
			return ErrEmailConflict
		}
		return fmt.Errorf("insert user: %w", err)
	}
	entity.ID = row.ID
	return nil
}

func (r *GormRepository) FindByID(ctx context.Context, id int64) (*User, error) {
	var row userRow
	err := r.db.WithContext(ctx).First(&row, id).Error
	if errors.Is(err, gorm.ErrRecordNotFound) {
		return nil, ErrNotFound
	}
	if err != nil {
		return nil, fmt.Errorf("select user %d: %w", id, err)
	}
	return toEntity(row), nil
}
```

- `isDuplicateKey`: 只解析当前 MySQL Driver 的重复键错误码;
- `WithContext`: DB 查询继承 RPC deadline;
- 连接池: 配置 max open、max idle 和 connection lifetime;
- 启动: 在注册服务前 Ping 数据库并打开 readiness;

```go title="internal/transport/kitex/handler.go"
	}

}
```

### 模型转换

```go
func toRPCUser(entity *userdomain.User) *user.User {
	return &user.User{
		ID:            entity.ID,
		Email:         entity.Email,
		Name:          entity.Name,
		CreatedAtUnix: entity.CreatedAt.Unix(),
	}
}
```

### CreateUser

```go
func (h *UserServiceImpl) CreateUser(
	ctx context.Context,
	req *user.CreateUserRequest,
) (*user.User, error) {
	if req == nil {
		return nil, kerrors.NewBizStatusError(40001, "request is required")
	}
	entity, err := h.service.Create(ctx, userdomain.CreateInput{
		Email: req.Email,
		Name:  req.Name,
	})
	switch {
	case errors.Is(err, userdomain.ErrInvalidInput):
		return nil, kerrors.NewBizStatusError(40001, "invalid user")
	case errors.Is(err, userdomain.ErrEmailConflict):
		return nil, kerrors.NewBizStatusError(40901, "email already exists")
	case err != nil:
		return nil, fmt.Errorf("create user: %w", err)
	default:
		return toRPCUser(entity), nil
	}
}
```

### GetUser

```go
func (h *UserServiceImpl) GetUser(
	ctx context.Context,
	req *user.GetUserRequest,
) (*user.User, error) {
	if req == nil {
		return nil, kerrors.NewBizStatusError(40001, "request is required")
	}
	entity, err := h.service.Get(ctx, req.ID)
	switch {
	case errors.Is(err, userdomain.ErrInvalidInput):
		return nil, kerrors.NewBizStatusError(40001, "invalid user id")
	case errors.Is(err, userdomain.ErrNotFound):
		return nil, kerrors.NewBizStatusError(40401, "user not found")
	case err != nil:
		return nil, fmt.Errorf("get user: %w", err)
	default:
		return toRPCUser(entity), nil
	}
}
```

- 业务异常: 稳定 BizStatus code，供 Client 分支;
- 系统异常: 保留 error chain，由 Server middleware 统一记录;
- 敏感信息: SQL、DSN 和堆栈不进入业务异常 message;
- Service: 不导入 `kitex_gen` 或 Kitex 包;

## 第五阶段：组装 Server

### 配置

```text
USER_SERVICE_ADDRESS=:8888
USER_DATABASE_DSN=user_service:user_dev@tcp(127.0.0.1:3306)/user_service?parseTime=true&loc=UTC
USER_RPC_TIMEOUT=1s
USER_EXIT_WAIT=10s
```

- 非敏感默认值可写入配置文件;
- DSN、密码和证书通过环境或 Secret Manager 注入;
- 启动时校验 address、timeout 和数据库连接池;

### main

```go title="cmd/server/main.go"
func main() {
	cfg := config.MustLoad()
	db := database.MustOpen(cfg.Database)
	repo, err := userdomain.NewGormRepository(db)
	if err != nil {
		log.Fatal(err)
	}
	service, err := userdomain.NewService(repo)
	if err != nil {
		log.Fatal(err)
	}
	handler, err := kitextransport.NewUserServiceImpl(service)
	if err != nil {
		log.Fatal(err)
	}

	addr, err := net.ResolveTCPAddr("tcp", cfg.Address)
	if err != nil {
		log.Fatal(err)
	}
	svr := userservice.NewServer(
		handler,
		server.WithServiceAddr(addr),
		server.WithExitWaitTime(cfg.ExitWait),
		server.WithMetaHandler(transmeta.ServerTTHeaderHandler),
	)
	if err := svr.Run(); err != nil {
		log.Fatalf("run user service: %v", err)
	}
}
```

### 生产组装顺序

```text
加载配置 → logger/tracer/metrics → DB → Repository → Service → Handler
        → Kitex middleware → Registry → readiness=true → Run
```

- 服务名: 与注册中心、Client 和指标维度保持一致;
- timeout: Server Handler 继续使用调用方 context，不替换为 Background;
- 退出: 先 readiness=false/注销实例，再等待 RPC，最后关闭 exporter 与 DB;
- `log.Fatal`: 只允许进程入口记录一次并退出，底层包返回 error;

## 第六阶段：创建并复用 Client

### Client 构造

```go title="cmd/client/main.go"
func main() {
	cli, err := userservice.NewClient(
		"user-service",
		client.WithHostPorts("127.0.0.1:8888"),
		client.WithConnectTimeout(300*time.Millisecond),
		client.WithRPCTimeout(time.Second),
		client.WithTransportProtocol(transport.TTHeader),
		client.WithMetaHandler(transmeta.ClientTTHeaderHandler),
	)
	if err != nil {
		log.Fatalf("create user client: %v", err)
	}

	createCtx, cancelCreate := context.WithTimeout(context.Background(), time.Second)
	created, err := cli.CreateUser(createCtx, &user.CreateUserRequest{
		Email: "alice@example.com",
		Name:  "Alice",
	})
	cancelCreate()
	if err != nil {
		if bizErr, ok := kerrors.FromBizStatusError(err); ok {
			log.Fatalf("create user rejected: code=%d message=%s", bizErr.BizStatusCode(), bizErr.BizMessage())
		}
		log.Fatalf("create user: %v", err)
	}
	getCtx, cancelGet := context.WithTimeout(context.Background(), time.Second)
	found, err := cli.GetUser(getCtx, &user.GetUserRequest{ID: created.ID})
	cancelGet()
	if err != nil {
		log.Fatalf("get user: %v", err)
	}
	log.Printf("user=%d %s %s", found.ID, found.Email, found.Name)
}
```

- Client 按目标服务与策略在进程级复用;
- TTHeader: Server/Client 两侧同时启用，用于透传 Thrift BizStatusError;
- `WithHostPorts`: 只适合本地或固定地址; 生产使用 Registry/Resolver;
- connect timeout: 限制建连;
- RPC timeout: 限制单次调用; 调用方 context 可以提供更短 deadline;
- 重试: 创建用户不是天然幂等，不默认自动重试;
