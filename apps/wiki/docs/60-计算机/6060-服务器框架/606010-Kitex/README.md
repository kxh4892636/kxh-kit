- 开发基础: [01-快速上手](./01-快速上手/README.md)，遇到具体 API 用法再回来查;
- 上线前: [02-服务端开发](./02-服务端开发/README.md)，按项目需要补超时、日志和退出;
- 可跳过: [协议与持续通信](./90-协议速查/README.md)、[特殊需求与排障](./91-特殊需求/README.md)，出现对应需求时再查;
