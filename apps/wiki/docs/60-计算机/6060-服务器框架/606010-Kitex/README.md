# Kitex

## 学习路径

- [01-开发基础](./01-开发基础/README.md): 从 IDL 到可调用的 Thrift RPC;
- [02-协议与通信](./02-协议与通信/README.md): 消息模型、连接、协议与 StreamX;
- [03-生产治理](./03-生产治理/README.md): 寻址、可靠性、流量保护、错误与观测;
- [04-进阶与生态](./04-进阶与生态/README.md): 泛化能力、生成器、扩展、第三方与排障;

## 使用顺序

- 首次使用: 依次完成开发基础与生产治理;
- 协议选型: 默认采用 Thrift unary; 需要 gRPC 互通或 streaming 时再进入协议与通信;
- 深入框架: 只有出现网关、代理、自定义协议或治理平台需求时才进入进阶与生态;
