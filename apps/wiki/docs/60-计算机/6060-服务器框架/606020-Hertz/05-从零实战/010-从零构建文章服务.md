# 从零构建文章服务

这篇实战最终要完成什么？应该按什么顺序完成这篇实战？项目如何初始化？最终目录如何划分职责？接口契约是什么？如何判断每一步已经完成？第一阶段：定义 IDL 并生成项目需要完成什么，如何验证？第二阶段：实现领域层与 MySQL 存储需要完成什么，如何验证？第三阶段：组装 Handler、鉴权与路由需要完成什么，如何验证？第四阶段：测试、运行与容器交付需要完成什么，如何验证？

## 完成目标

- API: 创建、分页查询、读取、更新和删除文章;
- 身份: 调用方通过 JWT 访问写接口，文章服务只负责验证 Token;
- 权限: 只有作者可以更新或删除自己的文章;
- 存储: GORM + MySQL，Repository 隔离数据库;
- 交付: 单元测试、HTTP 测试、Docker Compose 和健康检查;

## 开发顺序

```text
IDL 契约 → hz 生成 → 领域 Entity/Repository/Service
        → GORM 实现 → Handler 与错误映射 → JWT 中间件
        → main 组装 → 测试 → Docker Compose 冒烟
```

## 第一阶段：定义 IDL 并生成项目

### 文章契约

```thrift title="idl/article.thrift"
namespace go article

struct Article {
  1: i64 id
  2: i64 author_id
  3: string title
  4: string content
}

struct CreateArticleRequest {
  1: required string title   (api.body="title")
  2: required string content (api.body="content")
}

struct UpdateArticleRequest {
  1: required i64 id         (api.path="id")
  2: required string title   (api.body="title")
  3: required string content (api.body="content")
}

struct GetArticleRequest {
  1: required i64 id (api.path="id")
}

struct ListArticlesRequest {
  1: optional i32 page = 1       (api.query="page")
  2: optional i32 page_size = 20 (api.query="page_size")
}

struct ListArticlesResponse {
  1: list<Article> items
  2: i64 total
  3: i32 page
  4: i32 page_size
}

service ArticleService {
  Article Create(1: CreateArticleRequest req)
      (api.post="/api/v1/articles")
  ListArticlesResponse List(1: ListArticlesRequest req)
      (api.get="/api/v1/articles")
  Article Get(1: GetArticleRequest req)
      (api.get="/api/v1/articles/:id")
  Article Update(1: UpdateArticleRequest req)
      (api.put="/api/v1/articles/:id")
  void Delete(1: GetArticleRequest req)
      (api.delete="/api/v1/articles/:id")
}
```

## 第二阶段：实现领域层与 MySQL 存储

### Entity 与错误

```go title="internal/article/entity.go"
package article

var (
	ErrNotFound         = errors.New("article not found")
	ErrPermissionDenied = errors.New("permission denied")
	ErrInvalidInput     = errors.New("invalid article input")
)

type Article struct {
	ID       int64
	AuthorID int64
	Title    string
	Content  string
}

type CreateInput struct {
	AuthorID int64
	Title    string
	Content  string
}
```

- Entity: 不包含 JSON、Thrift 或 GORM tag;
- 领域错误: 供 Handler 使用 `errors.Is` 分类;
- CreateInput: 作者来自已经验证的认证身份;

### Repository 与 Service

```go title="internal/article/service.go"
type Repository interface {
	Create(ctx context.Context, a *Article) error
	FindByID(ctx context.Context, id int64) (*Article, error)
	List(ctx context.Context, offset, limit int) ([]Article, int64, error)
	Update(ctx context.Context, a *Article) error
	Delete(ctx context.Context, id int64) error
}

type Service struct{ repo Repository }

func NewService(repo Repository) (*Service, error) {
	if repo == nil {
		return nil, errors.New("repository is required")
	}
	return &Service{repo: repo}, nil
}

func (s *Service) Create(ctx context.Context, in CreateInput) (*Article, error) {
	in.Title = strings.TrimSpace(in.Title)
	if in.AuthorID <= 0 || in.Title == "" || len(in.Title) > 100 || in.Content == "" {
		return nil, ErrInvalidInput
	}
	a := &Article{AuthorID: in.AuthorID, Title: in.Title, Content: in.Content}
	if err := s.repo.Create(ctx, a); err != nil {
		return nil, fmt.Errorf("create article: %w", err)
	}
	return a, nil
}

func (s *Service) Delete(ctx context.Context, actorID, articleID int64) error {
	a, err := s.repo.FindByID(ctx, articleID)
	if err != nil {
		return err
	}
	if a.AuthorID != actorID {
		return ErrPermissionDenied
	}
	return s.repo.Delete(ctx, articleID)
}
```

- `Get`: 校验正数 ID，再调用 `FindByID`;
- `List`: 将 page/page_size 规范为 offset/limit，并限制 page_size;
- `Update`: 先查询文章、检查作者，再更新允许修改的字段;
- `Delete`: 只有作者可以删除，Repository 不负责业务授权;

### GORM Repository

```go title="internal/article/repository_gorm.go"
type articleRow struct {
	ID        int64 `gorm:"primaryKey"`
	AuthorID  int64 `gorm:"not null;index"`
	Title     string `gorm:"size:100;not null"`
	Content   string `gorm:"type:text;not null"`
	CreatedAt time.Time
	UpdatedAt time.Time
}

type GormRepository struct{ db *gorm.DB }

func NewGormRepository(db *gorm.DB) *GormRepository {
	return &GormRepository{db: db}
}

func (r *GormRepository) FindByID(ctx context.Context, id int64) (*Article, error) {
	var row articleRow
	err := r.db.WithContext(ctx).First(&row, id).Error
	if errors.Is(err, gorm.ErrRecordNotFound) {
		return nil, ErrNotFound
	}
	if err != nil {
		return nil, fmt.Errorf("find article %d: %w", id, err)
	}
	return &Article{ID: row.ID, AuthorID: row.AuthorID, Title: row.Title, Content: row.Content}, nil
}
```

- `Create`: 使用 `Create(&row)`，将数据库生成的 ID 回填 Entity;
- `List`: 固定排序，分别执行 count 与带 offset/limit 的查询;
- `Update/Delete`: 使用明确条件并检查 `RowsAffected`;
- migration: 由独立命令执行，应用启动不做无条件 AutoMigrate;

## 第三阶段：组装 Handler、鉴权与路由

### 注入 Service

`hz update` 会保留已存在的 Handler 函数并追加新函数。生成路由引用包级函数，因此 Handler 包提供一次性初始化入口：

```go title="biz/handler/article/article_service.go"
var articleService *article.Service

func Init(service *article.Service) error {
	if service == nil {
		return errors.New("article service is required")
	}
	if articleService != nil {
		return errors.New("article service already initialized")
	}
	articleService = service
	return nil
}
```

- 初始化发生在 `Spin` 前，之后只读;
- 不在每次请求中创建 Repository、Service 或 Client;
- 不需要生成路由时，可改用 Handler struct + 手工注册实现构造器注入;

### 创建文章 Handler

```go
func Create(ctx context.Context, c *app.RequestContext) {
	var req model.CreateArticleRequest
	if err := c.BindAndValidate(&req); err != nil {
		writeError(c, 400, "INVALID_ARGUMENT", "invalid request")
		return
	}
	actorID, ok := actorFrom(c)
	if !ok {
		writeError(c, 401, "UNAUTHENTICATED", "authentication required")
		return
	}
	a, err := articleService.Create(ctx, article.CreateInput{
		AuthorID: actorID,
		Title:    req.Title,
		Content:  req.Content,
	})
	if err != nil {
		writeDomainError(ctx, c, err)
		return
	}
	c.JSON(consts.StatusCreated, toModel(a))
}
```

### 统一错误映射

```go
func writeDomainError(ctx context.Context, c *app.RequestContext, err error) {
	switch {
	case errors.Is(err, article.ErrInvalidInput):
		writeError(c, 400, "INVALID_ARGUMENT", "invalid article")
	case errors.Is(err, article.ErrPermissionDenied):
		writeError(c, 403, "PERMISSION_DENIED", "permission denied")
	case errors.Is(err, article.ErrNotFound):
		writeError(c, 404, "ARTICLE_NOT_FOUND", "article not found")
	default:
		hlog.CtxErrorf(ctx, "article request failed: %v", err)
		writeError(c, 500, "INTERNAL", "internal server error")
	}
}
```

- 错误响应包含 `code`、`message` 和 `request_id`;
- 500 不返回原始 error、SQL 或堆栈;
- DELETE 成功设置 204，不再写 JSON body;

### JWT 身份

```go
func actorFrom(c *app.RequestContext) (int64, bool) {
	v, exists := c.Get("user_id")
	id, ok := v.(int64)
	return id, exists && ok && id > 0
}
```

- 中间件校验算法白名单、签名、issuer、audience 和 exp;
- 验证成功后将规范化 `user_id` 写入 RequestContext;
- 公开读路由不要求 JWT，写路由组安装 JWT;
- 更新和删除仍由 Service 校验资源所有权;

### main 组装

```go title="cmd/server/main.go"
func main() {
	cfg := config.MustLoad()
	db := database.MustOpen(cfg.Database)
	repo := article.NewGormRepository(db)
	service, err := article.NewService(repo)
	if err != nil {
		panic(err)
	}
	if err := articlehandler.Init(service); err != nil {
		panic(err)
	}

	h := server.Default(
		server.WithHostPorts(cfg.HTTP.Address),
		server.WithReadTimeout(cfg.HTTP.ReadTimeout),
		server.WithMaxRequestBodySize(cfg.HTTP.MaxBodyBytes),
		server.WithExitWaitTime(cfg.HTTP.ExitWait),
	)
	register(h) // 保留 hz 生成的 router_gen.go 注册链路。
	h.Spin()
}
```

```text
Recovery → Request ID → Access Log → CORS/Secure
         → 公开读路由 / JWT 写路由 → Handler
```

- `/livez`: 只检查进程;
- `/readyz`: 反映是否可以接收流量;
- `/metrics` 与 pprof: 使用独立受保护路由;
- 退出: 先关闭 readiness，再等待请求并关闭 DB/exporter;
