# Hertz

## 学习路径

- [01-开发基础](./01-开发基础/README.md): HTTP 服务、路由、上下文、绑定、响应和中间件;
- [02-hz与工程化](./02-hz与工程化/README.md): Thrift IDL、代码生成、分层 CRUD 与持久化;
- [03-生产治理](./03-生产治理/README.md): 错误、安全、生命周期、可观测性、测试与部署;
- [04-客户端与进阶](./04-客户端与进阶/README.md): Client、代理重试、流式能力、协议扩展与生态;
- [05-从零实战](./05-从零实战/README.md): 连续构建可测试、可容器运行的文章服务;

## 使用顺序

- 首次使用: 依次完成开发基础和 hz 与工程化，建立可运行的 HTTP API;
- 生产开发: 再完成生产治理，将安全、观测、测试和退出流程补齐;
- 按需深入: 只有出现出站 HTTP、实时推送、HTTP/2 或自定义扩展需求时进入客户端与进阶;
- 项目练习: 完成从零实战，将分散能力串成一个文章服务交付闭环;
