# DNS 记录与报文

## 资源记录 RR 有哪些类型?

- 资源记录（Resource Record，RR）: DNS 数据库中的一条记录，形式为 (Name, Value, Type, TTL);
- Name 和 Value: 它们的含义取决于 Type;
- TTL: RR 的缓存时间;

| Type  | Name             | Value                                                           |
| ----- | ---------------- | --------------------------------------------------------------- |
| A     | 主机名           | IP 地址                                                         |
| NS    | 域               | 知道该域对应 IP 地址的权威 DNS 服务器的主机名，如 `dns.foo.com` |
| CNAME | 主机的别名       | 规范主机名                                                      |
| MX    | 邮件服务器的别名 | 规范主机名                                                      |

## DNS 报文由哪些区域组成?

- 格式统一: 查询报文和回复报文具有相同格式;
- 首部区域: 报文的元数据;
- 问题区域: 查询信息;
- 回答区域: 回复信息;
- 权威区域: 其他权威服务器的记录;
- 附加区域: 其他有帮助的信息;

## DNS 有什么脆弱性?

- DDoS: 向每个 DNS 根服务器发送大量分组，使得大多数合法请求得不到回答;
