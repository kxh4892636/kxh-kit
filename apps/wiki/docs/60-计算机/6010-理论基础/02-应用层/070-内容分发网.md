# 内容分发网

## CDN 是什么，解决什么问题?

- CDN（Content Distribution Network，内容分发网）: 管理分布在多个地理位置的服务器，缓存源站点数据，将用户请求定向到最优的服务器上，加速访问速度;
- 要解决的问题: 用户离源站远、源站带宽有限时访问就慢; 把内容缓存到离用户更近的服务器上可以缓解;
- 三项工作: 管理分布在不同地理位置的服务器、缓存源站点数据、把用户请求定向到最优的服务器上;

## CDN 把服务器放在哪里?

- 两种服务器安置原则: 深入与邀请做客;

| 安置原则 | 做法                                                           |
| -------- | -------------------------------------------------------------- |
| 深入     | 在基于全球的 ISP 中部署服务器集群                              |
| 邀请做客 | 在少量关键位置建立服务器集群，邀请 ISP 访问，一般部署在 IXP 中 |

## 用户请求怎样被导向最合适的 CDN 服务器?

- 工作流程: 先确定适合该客户的 CDN 服务器集群，再把客户请求重定向到该集群; 重定向一般基于 DNS 实现;

| 步骤 | 动作                               |
| ---- | ---------------------------------- |
| 1    | 客户访问 URL 并发送 DNS 请求       |
| 2    | DNS 服务器返回 CDN 的主机名        |
| 3    | DNS 请求重定向到 CDN 的 DNS 服务中 |
| 4    | 返回 CDN 服务器的 IP 地址          |
| 5    | 客户与 CDN 建立 TCP 连接           |

## CDN 怎样挑出最合适的集群?

- 地理最邻近: 按地理位置挑最近的服务器集群; 局限是地理最邻近不一定是网络上的最邻近;
- 周期性实时测量: CDN 周期性地实时测量，用实际网络状况判断，而不是只看地图上的距离;

## CDN 上放哪些内容，带来什么好处?

- 存放内容: 静态资源文件与静态页面文件;
- 静态资源文件: 图片/视频/音频、第三方库 js 文件、字体文件;
- 优势一: 降低用户访问延迟;
- 优势二: 减少源站点带宽;
- 优势三: 增强安全性，CDN 服务商提供防御措施;
- 优势四: 提高可用性，某服务器出现故障时向其他服务器请求;
