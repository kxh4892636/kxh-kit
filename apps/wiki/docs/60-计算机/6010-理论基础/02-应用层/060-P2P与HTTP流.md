# P2P 与 HTTP 流

## P2P 文件分发与客户端-服务器结构有什么不同?

- P2P: 服务器具有最小的作用甚至没有作用; 客户端和客户端直接建立联系;
- 分发的主体: 拿到副本的对等方自己也在提供副本，不再依赖中心服务器逐份发送;
- 与客户端-服务器结构的差别: 后者把全部请求交给服务器处理，前者把服务能力分散到参与的主机上;

## 分发时间衡量的是什么?

- 分发时间: 所有 N 个对等方得到该副本需要的时间;
- 衡量的对象: 它不是某一个对等方的等待时间，而是全部 N 个对等方都拿到副本所花的时间;

## BitTorrent 是什么?

- BitTorrent: 用于文件分发的 P2P 协议; 使用 TCP 连接;
- 位置: 它属于 P2P 文件分发这一类应用，靠参与的主机互相提供文件;

## HTTP 流怎样播放视频?

- HTTP 流: 服务器发送视频文件; 客户端缓存接收到的字节，到达一定数量便播放视频并缓存下一段;
- 为什么先攒一段: 客户端不是收到一个字节就播一个字节，而是先缓存到一定数量再开始播放，播放的同时继续缓存下一段;

## DASH 为什么能自适应?

- DASH（Dynamic Adaptive Streaming over HTTP，HTTP 的动态适应流）: 一种让客户端自己挑视频版本的方式;
- 多版本编码: 视频编码为多个版本，具有不同的比特率;
- 自适应: 根据客户的网络质量自动选择不同的版本; 网络质量变化时，客户端换用另一个版本;
