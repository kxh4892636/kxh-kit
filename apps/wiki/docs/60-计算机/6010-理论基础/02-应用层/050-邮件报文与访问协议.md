# 邮件报文与访问协议

## 邮件报文长什么样?

- 组成: 报文首部、空白行、ASCII 表示的报文体;
- 报文首部: 写在最前面的若干行，说明这封邮件的基本信息;
- 空白行: 分隔报文首部与报文体，看到空行就说明首部结束;
- 报文体: 用 ASCII 表示邮件内容;

```text
From: test@test.test
To: tt@tt.tt
Subject: test
```

## 用户怎样把邮件从服务器取回来?

- 邮件访问协议: 用户代理从邮件服务器拉取邮件的协议; 它解决邮件已经到了服务器之后，用户怎样把它拿走的问题;
- POP3: 常见的邮件访问协议之一;
- IMAP: 常见的邮件访问协议之一;
- 基于 HTTP 的电子邮件: 除了邮件服务器之间使用 SMTP，其余过程使用 HTTP;
