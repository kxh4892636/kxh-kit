# HTTP 重定向与错误状态码

## 3XX 为什么要让客户端再跑一趟?

- 3XX: 重定向状态码，表示需要附加操作才能完成请求; 也就是说服务器没有直接把资源交出来，而是让客户端换个方式再要一次;

| 状态码                 | 含义                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 301 Moved Permanently  | 永久性重定向，永久使用新 URL                                 |
| 302 Found              | 临时性重定向，临时使用其他 URL，但希望用户依旧使用该 URL     |
| 303 See Other          | 同 302，但希望客户端使用单独的 GET 方法访问新 URL            |
| 304 Not Modified       | 客户端发送附带条件的请求，服务器端允许访问资源，但未满足条件 |
| 305 使用代理           | 用户需使用代理                                               |
| 307 Temporary Redirect | 同 302，但希望客户端保持请求方法类型不变访问新 URL           |

- 强制转换: 返回 301、302、303 时，几乎所有浏览器都会把 HTTP 方法转换为 GET; 于是原本带请求体的方法会被改写成一次 GET;
- 307 的用处: 它明确要求保持请求方法类型不变，正好避开上面这种被浏览器改写的情况;

## 4XX 到底是谁的错?

- 4XX: 客户端错误状态码，表示客户端发送请求错误; 服务器能收到请求，但认为这次请求本身有问题;

| 状态码           | 含义                       |
| ---------------- | -------------------------- |
| 400 Bad Request  | 请求报文存在语法错误       |
| 401 Unauthorized | 请求需要具有 HTTP 认证信息 |
| 403 Forbidden    | 服务器端拒绝请求           |
| 404 Not Found    | 服务器端未找到资源         |
| 405 方法禁用     | HTTP 方法禁用              |
| 408 请求超时     | 请求超时                   |
| 412              | 条件请求不满足条件         |

## 5XX 说明服务器出了什么问题?

- 5XX: 服务器错误状态码，表示服务器处理请求出错; 请求本身没毛病，是服务器这一侧没能把活干完;

| 状态码                    | 含义                         |
| ------------------------- | ---------------------------- |
| 500 Internal Server Error | 服务器端执行请求报错         |
| 502                       | 网关错误                     |
| 503 Service Unavailable   | 服务器端停机维护             |
| 504                       | 网关超时                     |
| 505                       | 服务器不支持请求的 HTTP 版本 |

- 502 与 504 的区别: 两者都跟网关有关，502 是网关错误，504 是网关超时; 前者是拿到的结果不对，后者是等不到结果;
