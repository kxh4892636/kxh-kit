# HTTP 方法与对比

## HTTP 有哪些方法?

| 方法    | 作用                                                                         |
| ------- | ---------------------------------------------------------------------------- |
| GET     | 请求资源                                                                     |
| POST    | 传输报文主体                                                                 |
| PUT     | 传输文件，不常用                                                             |
| DELETE  | 删除文件，不常用                                                             |
| HEAD    | 获得首部字段，不返回报文主体                                                 |
| OPTIONS | 查询支持的方法                                                               |
| TRACE   | 查询请求的通讯路径                                                           |
| CONNECT | 使用通道协议连接代理; 对应 SSL（安全套接字）与 TLS（传输层安全）这类加密通道 |

## GET 和 POST 有什么区别?

| 对比项   | GET                 | POST                         |
| -------- | ------------------- | ---------------------------- |
| 应用场景 | 幂等请求            | 非幂等请求                   |
| 缓存     | 会缓存              | 不会缓存                     |
| 传参方式 | 查询字符串          | 请求体                       |
| 安全性   | 明文                | 加密                         |
| 请求长度 | 浏览器限制 URL 长度 | 无限制                       |
| 参数类型 | ASCII 字符          | 更多的数据类型（二进制数据） |

## URL 的长度被谁限制?

- 限制来源: GET 把参数放在 URL 上，所以参数长度受浏览器 URL 长度限制; POST 把参数放在请求体里，没有这个限制; 各浏览器的上限见下表，单位是字节;

| 浏览器  | URL 长度上限 |
| ------- | ------------ |
| IE      | 2083 字节    |
| Firefox | 65535 字节   |
| Safari  | 80000 字节   |
| Opera   | 190000 字节  |
| Chrome  | 8182 字节    |

## 常见的 Content-Type 有哪些?

| Content-Type                        | 对应的数据                       |
| ----------------------------------- | -------------------------------- |
| `application/json`                  | JSON 数据                        |
| `application/x-www-form-urlencoded` | URL 编码的表单数据               |
| `multipart/form-data`               | 多部分表单数据，用于表单文件上传 |
| `text/plain`                        | 纯文本                           |
| `text/html`                         | HTML 文本                        |
| `image/jpeg`                        | JPEG 图片                        |
| `image/png`                         | PNG 图片                         |

## http/1.0 和 http/1.1 有什么区别?

| 区别     | http/1.0         | http/1.1                           |
| -------- | ---------------- | ---------------------------------- |
| 缓存机制 | 仅支持客户端缓存 | 客户端缓存 + 服务器缓存            |
| 持久连接 | 默认非持久连接   | 持久连接                           |
| 超时机制 | 无明确超时机制   | 连接超时 + 读取超时 + 空闲连接超时 |
| 管线化   | 不支持           | 支持                               |

- 状态码: http/1.1 提供更多的状态码;
- 带宽优化: http/1.1 支持分块传输与范围请求;
- Host 首部: http/1.1 引入了 `Host` 首部字段;
