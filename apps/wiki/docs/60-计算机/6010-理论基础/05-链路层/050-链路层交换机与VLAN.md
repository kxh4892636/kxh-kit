# 链路层交换机与 VLAN

## 链路层交换机为什么是即插即用的?

- 链路层交换机: 工作在链路层、按 MAC 地址转发帧的存储转发设备;
- 即插即用设备: 交换机不需要人工配置转发表，上电后自己把各接口对应哪些主机学出来;
- 即插即用的价值: 不需要管理员逐台配置转发表，交换机上电后自己把接口与主机的对应关系学出来;

## 交换机如何决定一个帧是转发还是丢弃?

- 过滤（filtering）: 决定帧是转发还是丢弃;
- 转发（forwarding）: 确定帧转发至哪个接口;
- 交换机表: 过滤和转发借助交换机表完成;
- 表中无对应接口: 交换机把帧广播出去;
- 对应接口就是帧的来源接口: 过滤丢弃，帧不需要再回到它来的地方;
- 对应接口不是来源接口: 转发至对应接口;

## 交换机表是怎么自动建立起来的?

- 自学习（self-learning）: 交换机的交换机表是自动、动态和自治建立的，不需要管理员配置;
- 第一步: 交换机表初始为空;
- 第二步: 对于每个接口接收的入帧，记录其源地址 MAC、到达的接口和当前时间;
- 第三步: 若一段时间后没有接收到以该地址作为源地址的帧，删除该表;
- 为什么有效: 一个帧从某个接口进来，说明发它的主机就在那个接口的方向上，源地址因此可以直接用来建表;

## 链路层交换机有哪些性质?

- 消除碰撞: 每个接口各占一条链路，不再全网争用同一段信道;
- 同时支持不同种类的链路: 不同接口可以接不同种类的链路;
- 具有管理功能: 交换机本身带有管理能力;

## 交换机和路由器的区别在哪里?

- 路由器: 使用 IP 地址转发分组的存储转发分组交换机;
- 链路层交换机: 使用 MAC 地址转发分组的存储转发分组交换机;
- 共同点: 两者都是存储转发分组交换机，差别在转发时依据的是哪一层地址;

![交换机和路由器的比较](../images/2023-09-11-20-36-13.png)

## 交换机毒化攻击是怎么得手的?

- 交换机毒化: 向交换机发送大量伪造的 MAC 地址，把交换机表填满;
- 后果: 表满之后交换机无法为大部分帧找到对应接口，被迫广播大多数帧;
- 攻击者的收益: 攻击者便可以嗅探到这些广播帧;

## VLAN 解决了什么问题?

- 虚拟局域网（VLAN）: 支持 VLAN 的交换机允许一个物理局域网建立多个虚拟局域网;
- 端口分组: 把交换机的多个端口划分为多个组，一个组对应一个虚拟局域网;
- 类比: 相当于在一台交换机上虚拟出多台互不相干的交换机;
