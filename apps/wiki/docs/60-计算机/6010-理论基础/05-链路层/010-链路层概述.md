# 链路层概述

## 链路层负责把数据搬过哪一段路?

- 链路层（link layer）: 负责将数据报通过通信链路从一个节点移动到另一个节点; 它只管相邻节点之间的这一跳，不管全程怎么走;
- 节点（node）: 运行链路层协议的任何设备，主机、路由器、交换机都算;
- 链路（link）: 沿着通信路径连接相邻节点的通信信道;
- 链路层帧（frame）: 链路层的分组; 数据报被封装在帧中，帧再带上自己的首部;
- 类比: 数据报是一封信，链路层是沿途每一段路上的运输车，车换了一辆又一辆，信始终是那封;

## 链路层为上层提供哪些服务?

- 成帧: 封装数据报为链路层帧;
- 链路接入: 多个节点共享同一条信道时，规定谁在什么时候可以把帧放上信道;
- 可靠交付: 在相邻节点之间把帧可靠地交到对端;
- 差错检测和纠正: 用额外的比特发现帧在传输中是否出了错，并尽可能把错纠正回来;
- 代价: 每项服务都要在帧里多带比特或做更多处理，链路层的可靠性是用带宽和计算换来的;

## 链路层的主体由什么硬件承担?

- 网络适配器（network adapter）: 又称网络接口卡（网卡），链路层功能的主体，一头接通信链路，一头接主机或路由器;
- 链路层控制器: 网络适配器的核心，真正执行成帧、链路接入、差错检测这些动作的部件;
