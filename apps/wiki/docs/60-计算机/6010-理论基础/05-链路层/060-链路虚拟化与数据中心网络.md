# 链路虚拟化与数据中心网络

## MPLS 为什么能加快转发?

- 多协议标签交换（MPLS）: 使用 MPLS 首部加快 IP 路由器转发速度;
- 所属位置: 它属于链路虚拟化技术;
- 代价: 帧里要多带一个 MPLS 首部，这部分开销同样占用链路容量;

![MPLS](../images/2023-09-11-20-45-12.png)

## 数据中心网络为什么要做负载均衡?

- 负载均衡: 平衡主机的工作负载;
- 目标: 把负载分散到多台主机上，避免一台主机独自承担全部工作;

## 数据中心的等级体系结构是什么样子的?

- 等级体系结构: 路由器和交换机按等级组织，不同等级之间的路由器是一对多的关系;
- 特点: 下级设备向上汇聚到数量更少的上级设备，逐级收敛;

## 数据中心网络的发展趋势是什么?

- 全连接拓扑: 不同等级之间的路由器变成多对多的连接;
- 模块化数据中心: 数据中心按模块组织和扩展;
