# Kitex 服务发现注册扩展

## 服务注册接口

```go
type Registry interface {
	Register(info *Info) error
	Deregister(info *Info) error
}
```

- `Info` 字段: `ServiceName`, `Addr`, `PayloadCodec`(框架默认填充), `Weight`, `StartTime`, `WarmUp`, `Tags`;
- 集成: `server.WithRegistry(yourRegistry)`, `server.WithRegistryInfo(info)`;
- 服务信息: `server.WithServerBasicInfo(&rpcinfo.EndpointBasicInfo{ServiceName, Tags})`;
- v0.10.0+ `SkipListenAddr`: 注册地址与监听地址不同(客户端无法访问 Listen Address 时);

## 服务发现接口

```go
type Resolver interface {
	Target(ctx, target rpcinfo.EndpointInfo) string
	Resolve(ctx, key string) (Result, error)
	Diff(key, prev, next Result) (Change, bool)
	Name() string
}
```

- `Resolve`: 核心方法, 从 target key 获取实例列表;
- `Target`: 生成唯一 target 并作为缓存 key;
- `Diff`: 计算变更, 通知负载均衡与熔断;
- `Name`: 唯一名称, 用于缓存复用; 实现必须并发安全;
- 集成: `client.WithResolver(yourResolver)`;
- `Result`: `Cacheable`, `CacheKey`, `Instances`;

## 负载均衡扩展

- 接口: `Loadbalancer { GetPicker(discovery.Result) Picker; Name() string }`;
- `Picker.Next(ctx, request)`: 选择实例; 无实例可重试时返回 nil;
- 有缓存时务必实现 `Rebalancer`(`Rebalance(Change)` / `Delete(Change)`), 否则服务发现变更无法通知;
- Proxy 场景不支持自定义 LoadBalancer;

## 已实现扩展

- 注册中心: etcd, consul, eureka, nacos, polaris, servicecomb, zookeeper;
- 服务发现: resolver-dns(Kubernetes), resolver-rule-based(自定义规则过滤);
- 配置中心扩展: config-consul/nacos/etcd/apollo/zookeeper/file;
