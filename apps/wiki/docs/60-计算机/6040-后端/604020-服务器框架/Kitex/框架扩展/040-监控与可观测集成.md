# Kitex 监控扩展与可观测集成

## Tracer 扩展

- `Tracer` 接口: `Start(ctx) / Finish(ctx)`;
- `WithTracer` 注入; 从 `rpcinfo.GetRPCInfo(ctx)` 获取 RPCInfo;
- 自定义打点: 从 `ri.Stats().GetEvent(stats.RPCStart/RPCFinish)` 计算耗时、包大小、错误;
- 链路追踪: 在 Start/Finish 中创建/结束 span（如集成 OpenTracing）;

## Prometheus

- `kitex-contrib/monitor-prometheus`;
- Client: `kClient.WithTracer(prometheus.NewClientTracer(":9091", "/kitexclient"))`;
- Server: `kServer.WithTracer(prometheus.NewServerTracer(":9092", "/kitexserver"))`;
- 指标: `kitex_client/server_throughput`、`kitex_client/server_latency_us`，tags: type/caller/callee/method/status;
- 支持 Go runtime metrics（WithGoCollectorRuntimeMetrics）;

## OpenTelemetry

- `kitex-contrib/obs-opentelemetry`，提供 provider + tracing + logging;
- Metrics: `rpc.server.duration` Histogram，可计算 R.E.D; 支持 Go runtime 指标;
- 日志扩展: logrus、zap、slog 实现（`klog.SetLogger`）;
- Provider 实例持有 exporter client，重复初始化需先 `Shutdown()`;
- 支持编译时注入方案;

## 诊断模块

- `diagnosis.Service`: `RegisterProbeFunc(name, func() interface{})` 注册诊断信息;
- Kitex 默认注册: events、service_info、options、dest_service、conn_pool、retry_policy;
- 注入: `server.WithDiagnosisService(...)` / `client.WithDiagnosisService(...)`;

## 已实现可观测扩展

- tracer-opentracing、monitor-prometheus、obs-opentelemetry;
- opensergo: 支持 OpenSergo 规范，快速集成 Sentinel 流量治理;
