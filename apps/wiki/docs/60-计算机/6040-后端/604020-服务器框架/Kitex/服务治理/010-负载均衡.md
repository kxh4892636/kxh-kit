# Kitex 负载均衡

## 内置策略

- `WeightedRoundRobin`: 加权轮询，默认策略; 权重相同退化为纯轮询;
- `InterleavedWeightedRoundRobin`(v0.7.0+): 空间复杂度 O(实例数)，权重总和很大时更省内存;
- `WeightedRandom`: 加权随机;
- `Alias Method`(v0.9.0+): O(n) 建表、O(1) 选取，比 WeightedRandom 更快;
- `ConsistentHash`: 一致性哈希;
- `Tagging Based`: 基于标签的子集划分（kitex-contrib/loadbalance-tagging）;

```go
cli, err := echo.NewClient("echo",
	client.WithLoadBalancer(loadbalance.NewWeightedRoundRobinBalancer()))
```

## 一致性哈希

- 适用场景: 依赖上下文（如本地缓存）的同 key 请求打同一实例;
- 不熟悉副作用时勿用;
- `NewConsistBalancer(NewConsistentHashOption(keyFunc))`; GetKey 或 VirtualFactor 为 0 会 panic;
- `Replica`: 请求失败（连接失败）后尝试 replica; 第一次失败后仍请求第一个实例;
- `VirtualFactor`: 每真实节点虚拟节点数，越大越均衡、代价越高; 建议总虚拟节点数 2000W 内;
- `Weighted`: 是否按实例权重生成虚拟节点，weight=0 不生成; 建议 true;
- `ExpireDuration`: key 缓存过期时间，建议设置且不小于 1 分钟;
- 下游节点变动可能改变哈希结果; 节点多时冷启动 build 可能耗时;

## Tagging Based

```go
cli, err := echo.NewClient("echo",
	client.WithLoadBalancer(tagging.New("tag",
		func(ctx context.Context, req interface{}) string { return "value" },
		loadbalance.NewWeightedRoundRobinBalancer())))
```

- 基于标签将集群划分为子集，适用于有状态/多租户服务;
- 支持自定义标签函数与嵌套 tag;
