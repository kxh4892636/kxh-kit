# Hertz 扩展：协议与网络库

## 协议扩展

- 分层设计支持自定义协议 server;
- `protocol.Server`: 字节流传输协议（HTTP1/HTTP2 类），底层网络库需实现 `network.Conn`;
- `protocol.StreamServer`: 流传输协议（HTTP3/QUIC 类），需实现 `network.StreamConn`;
- `ServerFactory.New(core Core)`: 创建协议 server 的工厂;
- `Core` 接口提供 `IsRunning`、`GetCtxPool`、`ServeHTTP`(引入业务逻辑)、`GetTracer`;
- 注册: `h.AddProtocol("http/1.1", &serverFactory{})`; key 与 ALPN 协商 key 对应;
- 覆盖默认 HTTP1 server 时直接注册同名 key "http/1.1";

## 网络库扩展

- Server 需实现 `network.Conn`（字节流）或 `network.StreamConn`（流式）;
- `network.Conn`: net.Conn + Reader(Peek/Skip/Release/Len/ReadByte/ReadBinary) + Writer(Malloc/WriteBinary/Flush) + SetReadTimeout;
- Client 需实现 `network.Dialer`（DialConnection/DialTimeout/AddTLS）;
- 注册: `server.WithTransport(YOUR_TRANSPORT)`、`client.WithDialer(YOUR_DIALER)`;

## 网络库接口要点

- `Peek` 返回的切片在 `Release` 后失效，使用需在 Release 前完成;
- `WriteBinary` 在 Flush 成功前调用方需保持 buffer 有效;
- StreamConn 提供 OpenStream/OpenUniStream、AcceptStream、CancelRead/CancelWrite 等 QUIC 流操作;
