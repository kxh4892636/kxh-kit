# Hertz 扩展：服务发现与负载均衡

## 服务注册扩展

- 接口: `type Registry interface { Register(info *Info) error; Deregister(info *Info) error }`;
- `Info` 字段: `ServiceName`、`Addr`、`Weight`、`Tags`;
- 集成: `server.WithRegistry(r, &registry.Info{...})`;

## 服务发现扩展

- 接口: `Resolver`，含 `Target`(生成缓存 key)、`Resolve`(返回实例列表)、`Name`(唯一名，用于复用);
- `TargetInfo`: Host + Tags; `Result`: CacheKey + Instances;
- 集成: `cli.Use(sd.Discovery(r))`;
- Resolver 会被复用，实现必须并发安全;

## 负载均衡扩展

- 默认 `WeightedRandom`; 接口: `Loadbalancer`，含 `Pick`、`Rebalance`、`Delete`、`Name`;
- 集成: `cli.Use(sd.Discovery(r, sd.WithLoadBalanceOptions(lb, opts)))`;
- 参数: `RefreshInterval`(默认 5s)、`ExpireInterval`(默认 15s);

## 客户端请求配置

- `config.WithSD(true)`: 本次请求走服务发现（必须）;
- `config.WithTag(k, v)`: 设置 Tag 信息;
- `sd.WithCustomizedAddrs("127.0.0.1:8088")`: 覆盖 Resolver 结果，直连指定地址;
