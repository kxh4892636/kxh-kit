# hz IDL 注解

## Field 注解（参数绑定）

- `api.query`: 生成 `query` tag; `api.header`: `header` tag; `api.cookie`: `cookie` tag;
- `api.body`: 生成 `json` tag（body 参数）;
- `api.path`: 生成 `path` tag; `api.form`: `form` tag;
- `api.raw_body`: 原始 body tag;
- `api.vd`: 生成 `vd` tag（校验）;
- `api.go_tag`(protobuf) / `go.tag`(thrift): 透传自定义 go tag;
- `api.none`: 生成 `-` tag，字段不参与绑定与序列化;

## Method 注解（路由）

- `api.get/post/put/delete/patch/options/head/any`: 定义 HTTP 方法与路由;
- protobuf 在 rpc 的 option 中声明，thrift 写在 service method 的括号中;

## Client 注解

- `api.base_domain`: 指定默认请求 domain（hz client 专用）;

## 示例

```thrift
struct Demo {
	1: string Demo (api.query="demo", api.path="demo");
	2: string Vd (api.vd="$!='your string'");
}

service Demo {
	Resp Method(1: Req request) (api.get="/route");
}(
	api.base_domain="http://127.0.0.1:8888";
)
```

```protobuf
message Demo {
	string Demo = 1[(api.query) = "demo", (api.path) = "demo"];
}

service Demo {
	rpc Method(Req) returns(Resp) {
		option (api.get) = "/route";
	}
}
```

## api.proto 扩展规则

- 自定义注解不要使用以 "5" 开头的序号，避免冲突;
- 官方扩展字段从 50101 开始，method 从 50201 开始;
