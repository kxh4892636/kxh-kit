# hz 命令

## 子命令

- `hz new`: 创建新项目;
- `hz update`: 更新已有项目;
- `hz model`: 只生成 model 代码;
- `hz client`: 基于 IDL 生成 client 侧代码（需指定 idl）;

## new 常用参数

- `--idl`: IDL 文件路径（.thrift / .proto）;
- `--service`: 服务名（为服务发现预留）;
- `--module/--mod`: go module 名，GOPATH 外必须指定;
- `--out_dir` / `--handler_dir` / `--model_dir` / `--router_dir`: 生成路径;
- `--client_dir`: client 代码路径，不指定则不生成;
- `-I/--proto_path`: protobuf IDL 搜索路径;
- `--force/-f`: 强制覆盖已生成文件;
- `--handler_by_method`: 每个方法生成独立 handler 文件;
- `--customize_layout` / `--customize_layout_data_path` / `--customize_package`: 自定义模板;
- `--protoc-plugins` / `--thrift-plugins`: 第三方生成代码插件;
- `--exclude_file/-E`: 不更新的文件;
- 其他: `--no_recurse`、`--enable_extends`、`--sort_router`、`--json_enumstr`、`--snake_tag`、`--rm_tag`、`--use` 等;

## update 注意事项

- 支持参数与 new 基本一致;
- `handler_dir/model_dir/client_dir` 必须与 new 相同，否则产生重复代码;
- 已存在 handler 文件按默认模板追加，不存在的按自定义模板生成;
- `--exclude_file` 可跳过部分文件更新;

## model 命令

- 仅生成 model，参数为 idl/module/out_dir/model_dir/proto_path 等;
- 适合先生成 model、后生成 handler 的场景（配合 `--use` 引用已有 model）;

## client 命令

- `hz client --mod=a/b/c --idl=../idl/psm.thrift --model_dir=model --client_dir=hertz_client`;
- 生成 RPC 风格一键调用代码，与 hz server 代码互通;
- `api.any` 注解在 client 中自动生成 POST 方法;
- 支持 `WithHertzClientOption`、`WithHeader`、`WithHertzClientMiddleware`、`WithHertzClient` 等高级设置;
