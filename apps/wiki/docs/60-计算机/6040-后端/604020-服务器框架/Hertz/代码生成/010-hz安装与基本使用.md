# hz 安装与基本使用

## 安装

```shell
go install github.com/cloudwego/hertz/cmd/hz@latest
hz -v
```

- 依赖 thriftgo / protoc 编译器;
- 确保 GOPATH/bin 在 PATH 中，且安装路径可写（hz 会创建软链接）;
- Windows 使用 hz 需开启开发者模式以支持 symlink;

## 生成原理

- thrift IDL: hz 调用 thriftgo，自身作为 `thrift-gen-hertz` 插件执行;
- protobuf IDL: hz 调用 protoc 的 `--hertz_out` 插件;
- 底层编译器生成结构体代码，hz 生成路由、method 等业务代码;

## 创建项目

```shell
# GOPATH 外必须指定 module
hz new -module hertz/demo
# GOPATH 下可不指定
hz new
go mod tidy
go build
./{{binary}}   # 默认 8888 端口
curl 127.0.0.1:8888/ping   # 返回 {"message":"pong"}
```

- `hz new` 只用于初始化，更新使用 `hz update`;
- 项目是否存在的标志是 `.hz` 文件; 存在时 `new` 报错，不存在时 `update` 报错;
- thrift 生成后需要 `go mod edit -replace github.com/apache/thrift=github.com/apache/thrift@v0.13.0`;

## 基于 IDL 创建

- thrift: `hz new -module example.com/m -idl idl/hello.thrift`;
- protobuf: `hz new -module example.com/m -I idl -idl idl/hello/hello.proto`（`-I` 为 IDL 搜索路径）;
- handler 通过 `c.BindAndValidate(&req)` 绑定参数，业务逻辑写在 `biz/handler` 下;
- `hz update -I idl -idl idl/hello/hello.proto`: thrift 只需指定主 service 文件，protobuf 需指定所有依赖文件;
