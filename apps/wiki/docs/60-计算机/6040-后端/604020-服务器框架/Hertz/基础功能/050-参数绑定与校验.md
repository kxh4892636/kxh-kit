# Hertz 参数绑定与校验

## 绑定 API

- `BindAndValidate`: 按 go tag 绑定并校验;
- `Bind`: 只绑定不校验;
- `BindQuery/BindHeader/BindPath/BindForm`: 绑定全部 query/header/path/form 参数;
- `BindJSON`: JSON body 反序列化; `BindProtobuf`: protobuf body;
- `BindByContentType`: 按 Content-Type 自动选择绑定方式;
- `Validate`: 配合校验 tag 使用;

## 支持的 tag

- `path`: 路由参数; `form`: form body; `query`: query 参数; `cookie` / `header`;
- `json`: JSON body; `raw_body`: 原始 body, 优先级最低;
- `default`: 默认值; tag 中 `required` 标记必传;
- 无 tag 时按 `path > form > query > cookie > header > json > raw_body` 优先级遍历绑定;
- IDL 生成代码默认添加 `form/json/query` tag, api 注解可覆盖;
- JSON 绑定默认使用 sonic, 可用 `UseStdJSONUnmarshaler` 或第三方库替换;
- `LooseZeroMode`: 允许只有 key 没有 value 的表单绑定数值类型;
- 文件绑定: 字段类型为 `*multipart.FileHeader`, 需 `multipart/form-data`;
- string 与 int 默认不互转, 可加 `json:",string"` 或换 JSON 库;

## 自定义扩展

- 实现 `binding.Binder` 接口, 通过 `server.WithCustomBinder` 注入;
- `server.WithCustomValidatorFunc`: 自定义校验函数, 如 go-playground/validator;
- `MustRegTypeUnmarshal`: 自定义类型解析;
- `validator.RegisterValidation`: 注册自定义校验规则;

## 示例

```go
type Test struct {
	A string `query:"a,required"`
}

r.GET("/hello", func(ctx context.Context, c *app.RequestContext) {
	var req Test
	if err := c.BindAndValidate(&req); err != nil {
		c.String(400, err.Error())
		return
	}
})
```
