# Hertz 重试

## 重试配置

- `client.WithRetryConfig(retry.WithXXX...)` 启用客户端重试 (v0.4.0+);
- `WithMaxAttemptTimes`: 最大尝试次数，默认 1（即不重试）;
- `WithInitDelay`(1ms) / `WithMaxDelay`(100ms) / `WithMaxJitter`(20ms): 延迟参数;
- `WithDelayPolicy`: 延迟策略，可组合;

## 延迟策略

- `FixedDelayPolicy`: 固定 `InitDelay` 延迟;
- `BackOffDelayPolicy`: 指数级延迟（`1<<n` 增长）;
- `RandomDelayPolicy`: 随机延迟，上限 `MaxJitter`;
- `DefaultDelayPolicy`: 返回 0，立即重试;
- `CombineDelay(...)`: 将多个策略结果加和;
- 所有策略结果受 `MaxDelay` 上限约束;

## 重试条件

- `cli.SetRetryIfFunc(func(req, resp, err) bool)`: 自定义重试条件;
- 默认条件: 请求体可重放（非 stream）且方法幂等（GET/HEAD/PUT/DELETE/OPTIONS/TRACE），或连接在响应前被关闭（io.EOF）;
- 非幂等请求（POST 等）默认不重试;

## 示例

```go
cli, err := client.NewClient(
	client.WithRetryConfig(
		retry.WithMaxAttemptTimes(3),
		retry.WithInitDelay(1*time.Millisecond),
		retry.WithDelayPolicy(retry.CombineDelay(retry.FixedDelayPolicy, retry.BackOffDelayPolicy)),
	),
)
```

## 注意事项

- 中间件可能执行多次，需考虑幂等性;
- HTTP2 客户端也有独立重试配置（`WithRetryConfig`、`WithMaxIdempotentCallAttempts`）;
