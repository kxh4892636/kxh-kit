# Hertz 错误处理与恢复

## 错误结构

- `Error` 结构: `Err`(标准错误) + `Type`(错误类型) + `Meta`(元数据);
- 错误类型: `ErrorTypeBind`(绑定)、`ErrorTypeRender`(渲染)、`ErrorTypePrivate`(内部)、`ErrorTypePublic`(外部可见)、`ErrorTypeAny`;
- `errors.NewPublic/NewPrivate/Newf/NewPublicf/NewPrivatef`: 快捷构造;
- `Error.SetType/SetMeta/IsType/JSON`: 类型设置、判断与 JSON 化;

## ErrorChain 错误链

- `c.Error(err)`: 将错误绑定到当前请求上下文;
- `c.Errors.Errors()`: 获取全部错误; `String()` / `JSON()` / `Last()` / `ByType(typ)`;
- 典型场景: 中间件统一收集并处理一次请求中的所有错误;

## Panic 恢复

- `server.Default()` 自动注册 Recovery 中间件;
- Recovery 默认打印 panic 时间、内容与堆栈，并返回 500;
- `recovery.WithRecoveryHandler(f)`: 自定义 panic 处理函数;
- `h.PanicHandler`: Engine 级 panic 处理; 与 Recovery 同时存在时 Recovery 覆盖;

## 其他错误行为

- `hlog.SetSilentMode(true)`: 关闭如 `error when reading request headers` 等客户端异常导致的日志;
- `WithMaxHeaderBytes`(1MB): Header 超限返回 431;
