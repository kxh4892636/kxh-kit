# Hertz SSE

## 概述

- SSE(Server-Sent Events) 是 HTML 标准，供浏览器 `EventSource` 使用，严格说不是 HTTP 协议;
- MCP、A2A 等协议部分基于 SSE;
- 实现位于 `github.com/cloudwego/hertz/pkg/protocol/sse`;

## 服务端

- `sse.NewWriter(c)` 创建 writer，`w.WriteEvent(id, type, data)` 发送事件;
- `w.Close()` 发送最后 chunk，可选; handler 返回后框架自动调用;
- writer 生命周期必须与 handler 一致，禁止异步后台使用;
- `sse.GetLastEventID(&c.Request)`: 读取客户端断点续传 ID;
- 报错 `connection has been closed when flush`: 客户端断开或响应间隔过长;

## 客户端

- 与普通 HTTP 请求一致，新版 Hertz 自动识别 SSE 流，无需显式 `WithResponseBodyStream(true)`;
- `sse.AddAcceptMIME(req)`: 显式加 `Accept: text/event-stream`;
- `sse.SetLastEventID(req, "id-123")`: 有状态服务断点续传;
- `sse.NewReader(resp)` + `r.ForEach(ctx, fn)`: 遍历事件; 正常断开时 err == nil;
- `r.LastEventID()`: 保存最后接收的 Event ID;

## Event 结构

- `ID`、`Type`(如 message)、`Data`([]byte)、`Retry`(浏览器重试策略);
- 多级 SSE/SSE Proxy: Server 启用 `WithSenseClientDisconnection`，将 context 传入下一跳 Reader 的 `ForEach`，客户端断开时自动中断整个流;
