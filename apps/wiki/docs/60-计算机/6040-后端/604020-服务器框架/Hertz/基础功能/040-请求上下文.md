# Hertz 请求上下文

## RequestContext 概述

- `*app.RequestContext`: 保存请求与响应对象的上下文，提供高频便捷 API;
- handler 同时收到标准 `context.Context` 与 `*RequestContext`;
- 协程安全: `RequestContext` 请求结束即回收复用，禁止传到后台异步协程;
- 异步使用需 `c.Copy()` 生成副本或调用 `Exile()` 标记不回收;
- 环境变量 `HERTZ_DISABLE_REQUEST_CONTEXT_POOL=1` 可关闭池化;
- v0.9.7+ Header 读方法并发安全，写方法仍不安全;

## 请求信息

- `Host()` / `Path()` / `FullPath()`: 主机、匹配后的路径、原始路由路径;
- `Param(key)`: 路由参数; `Query(key)` / `DefaultQuery` / `GetQuery`: query 参数;
- `Method()` / `ContentType()` / `UserAgent()` / `Cookie(key)` / `GetHeader(key)`;
- `IfModifiedSince(t)`: 与 `If-Modified-Since` 头比较，头缺失时返回 true;
- `Request.Header`: RequestHeader 对象，`Add` 支持多值、`Set` 单值覆盖;
- `Request.URI()`: URI 对象，可操作 path、query、hash、scheme 等;
- `Body()`: 请求体; `RequestBodyStream()`: 流式读取 body;
- `MultipartForm()` / `PostForm` / `PostArgs`: 表单参数;
- `FormValue(key)`: 按 QueryArgs → PostArgs → MultipartForm 顺序取值;
- `FormFile(name)` / `SaveUploadedFile`: 上传文件读取与保存;

## 元数据存储

- `c.Set(key, value)` 与 `c.Get(key)`: RequestContext 内轻量 KV 存储;
- 提供 `GetString/GetInt/GetBool/GetDuration/GetStringMap...` 类型化取值;
- 请求结束元数据置 nil，异步场景用 `Copy()`;
- `context.Context` 适合跨函数、协程安全的标准化参数传递;

## Handler 链控制

- `c.Next(ctx)`: 调用下一个 handler，通常在中间件中使用;
- `c.Handlers()` / `c.Handler()` / `c.HandlerName()`: 获取 handler 链信息;
- `c.GetIndex()`: 当前执行位置; `c.Abort()` / `c.IsAborted()`: 中止与状态查询;
- `c.SetHandlers(chain)`: 动态修改 handler 链;

## 响应控制

- `c.SetStatusCode/Status`、`NotFound()`、`NotModified()`、`Redirect(code, uri)`;
- `c.Header(key, value)`、`SetCookie(...)`、`SetConnectionClose()`;
- `c.AbortWithStatus(code)` / `AbortWithError(code, err)` / `AbortWithMsg` / `AbortWithStatusJSON`;
- `c.SetBodyString` / `Write` / `WriteString`: 写 body;
- `SetBodyStream(reader, size)`: 流式写，size=-1 表示 chunked;
- `c.File/FileAttachment/FileFromFS`: 文件响应;
- `c.Flush()`: 刷新被劫持的 Response Writer;

## ClientIP

- `ClientIP()` 默认优先读 `X-Forwarded-For`，其次 `X-Real-IP`，最后 remote address;
- `SetClientIPFunc` 自定义取 IP; `app.ClientIPOptions` 需自设 `TrustedCIDRs`，未设置则固定返回 remote address;

## 参数绑定

- `c.Bind(obj)` / `c.Validate(obj)` / `c.BindAndValidate(obj)`: 见参数绑定与校验笔记;
