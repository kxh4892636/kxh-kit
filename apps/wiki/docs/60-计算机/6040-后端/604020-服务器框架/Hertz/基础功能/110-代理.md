# Hertz 代理

## 正向代理

- 内置支持，`c.SetProxy(protocol.ProxyURI(parsedURL))` 设置固定代理;
- `Proxy` 类型: `func(*protocol.Request) (*protocol.URI, error)`，按请求选择代理;
- 代理 URL 支持 `http://user:pass@addr:port` 格式;
- 客户端默认网络库 netpoll 不支持 TLS，代理 HTTPS 需 `WithDialer(standard.NewDialer())` 并按需跳过证书验证;
- 同一客户端只能设置一个代理;

## 反向代理

- 第三方库 `github.com/hertz-contrib/reverseproxy`;
- `NewSingleHostReverseProxy(target, opts...)`: 转发到指定后端，路径拼接为 `target + requestPath`;
- `SetDirector`: 转换请求; `SetClient`: 指定转发客户端; `SetModifyResponse`: 修改响应; `SetErrorHandler`: 错误处理（默认 502）;
- 反向代理会重置响应头，请求前修改的响应头不生效;
- HTTPS 代理需在 `WithDialer` 中传 `standard.NewDialer()` 或设置使用标准库的 Client;
- WebSocket 反向代理: `NewWSReverseProxy("ws://example.com")`;
- 可在中间件中调用 `proxy.ServeHTTP(ctx, c)` 实现条件代理;

## 示例

```go
proxy, _ := reverseproxy.NewSingleHostReverseProxy("http://127.0.0.1:8000/proxy")
h.GET("/backend", proxy.ServeHTTP)
```
