# Hertz 优雅退出与钩子

## 优雅退出流程

1. 设置 engine 状态为 closed;
2. 非阻塞触发 `[]OnShutdown` 回调并等待完成或超时;
3. 注册中心注销服务;
4. 关闭网络库信号监听;
5. 对关闭中的请求响应统一带 `Connection: Close`;
6. 等待业务协程退出: netpoll 轮询 active conn 为 0，go net 直接关闭监听; 总超时默认 5s;

- `server.WithExitWaitTime(d)`: 修改退出等待时间;
- 信号处理: 版本 >= v0.9.6 时 `SIGTERM/SIGHUP/SIGINT` 均优雅退出;

## 钩子函数

- `h.OnRun`(StartHook): 启动后按声明顺序依次调用，全部完成后才开始监听端口; 出错立即终止服务;
- `h.OnShutdown`(ShutdownHook): 退出前并发调用，超时则立即终止;
- 签名: `type CtxErrCallback func(ctx context.Context) error` / `type CtxCallback func(ctx context.Context)`;

## 连接级钩子

- `WithOnAccept`: netpoll 中连接建立后、加入 epoll 前; go net 中 TLS 转换前;
- `WithOnConnect`: netpoll 中可读取连接数据; go net 中 TLS 转换后;

## 示例

```go
h := server.Default()
h.OnRun = append(h.OnRun, func(ctx context.Context) error {
	hlog.Info("start hook")
	return nil
})
h.OnShutdown = append(h.OnShutdown, func(ctx context.Context) {
	hlog.Info("shutdown hook")
})
h.Spin()
```
