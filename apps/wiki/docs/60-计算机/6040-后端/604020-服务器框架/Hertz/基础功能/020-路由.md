# Hertz 路由

## 路由注册

- 提供 `GET/POST/PUT/DELETE/PATCH/HEAD/OPTIONS` 方法注册路由;
- `h.Any`: 注册所有 HTTP 方法;
- `h.Handle(method, path, handler)`: 手动指定方法, 支持自定义 HTTP 方法;
- `h.StaticFile/Static/StaticFS`: 注册静态文件服务;

## 路由组

- `h.Group("/v1")` 返回路由组, 支持嵌套;
- 中间件可在 `Group` 参数中传入, 也可通过 `group.Use()` 注册;

## 路由类型与优先级

- 优先级: 静态路由 > 命名参数路由 > 通配参数路由;
- 命名参数 `:name`: 只匹配单个路径段, `/user/:name` 不匹配 `/user/gordon/profile`;
- 通配参数 `*path`: 匹配所有内容, `/src/*path` 可匹配 `/src/subdir/file.go`;
- 通过 `c.Param("name")` 获取参数值;

## 特殊处理

- `NoRoute` / `NoMethod`: 全局处理 404 / 405, `NoMethod` 需配合 `WithHandleMethodNotAllowed(true)`;
- 尾斜杠重定向: 默认开启, 可用 `WithRedirectTrailingSlash(false)` 关闭;
- `WithRemoveExtraSlash(true)`: 允许多余 `/` 匹配参数路由;
- `WithRedirectFixedPath(true)`: 修复路径后重定向, GET 返回 301, 其他返回 308;
- 匿名函数或装饰器注册路由时 `HandlerName()` 不准, 需用 `GETEX/POSTEX/...EX` 并手动传 handler 名;
- `h.Routes()`: 获取路由信息列表, 含 Method, Path, Handler 名;

## 示例

```go
h := server.Default(server.WithHostPorts("127.0.0.1:8080"))
h.GET("/hertz/:version", func(ctx context.Context, c *app.RequestContext) {
	version := c.Param("version")
	c.String(consts.StatusOK, "Hello %s", version)
})
h.Spin()
```
