# Hertz TLS

## 基本要求

- TLS 场景必须使用 go net 网络库; netpoll 尚未支持 TLS;
- `server.WithTLS(cfg)` 会自动将 Transporter 切换为标准库实现;
- 开启 TLS 后不接受非 TLS 请求;

## 服务端配置

- `tls.Config` 通用字段: `Certificates`, `VerifyPeerCertificate`, `VerifyConnection`, `NextProtos`, `CipherSuites`(TLS1.0-1.2), `MaxVersion`(最高 1.3);
- 服务端专属: `GetCertificate`(SNI), `ClientAuth`(默认 `NoClientCert`), `ClientCAs`, `GetConfigForClient`;
- 流程: 载入根证书 → 载入服务器证书 → 配置 `tls.Config` → `server.WithTLS(cfg)`;

## 客户端配置

- 客户端专属: `ServerName`(主机名校验), `InsecureSkipVerify`(跳过证书验证), `RootCAs`;
- 使用 `client.WithTLSConfig(cfg)` + `client.WithDialer(standard.NewDialer())`;
- 常见报错 `not support tls` 因默认 netpoll 不支持 TLS;

## 证书生成

```shell
openssl ecparam -genkey -name prime256v1 -out ca.key
openssl req -new -key ca.key -out ca.req
openssl x509 -req -in ca.req -signkey ca.key -out ca.crt -days 365
```

- 服务端/客户端证书由 CA 签名生成;

## Autotls 扩展

- `github.com/hertz-contrib/autotls` 适配 Let's Encrypt;
- `autotls.NewTlsConfig(domains...)`: 一行开启 HTTPS;
- `autotls.RunWithContext(ctx, h)`: 支持优雅退出;
- `NewServerWithManagerAndTlsConfig(m, tlsc, opts...)`: 自定义 `autocert.Manager` 证书管理;
