# Hertz 第三方中间件

## 认证与授权

- `jwt`: JSON Web Token 认证(hertz-contrib/jwt);
- `paseto`: JOSE 替代方案的 PASETO token;
- `keyauth`: token 鉴权; `casbin`: ACL/RBAC/ABAC 访问控制;
- `basic_auth`: 框架内置 Basic Auth;
- `csrf`: 防跨站请求伪造;

## 请求增强

- `cors`: 跨域; `gzip`: 压缩; `etag`: 缓存标识;
- `requestid`: X-Request-ID 关联请求; `accesslog`: 访问日志;
- `cache`: 响应缓存(memory 等 multi-backend);
- `i18n`: 国际化; `session`: 会话管理;
- `secure`: HTTP 安全头; `sentry`: 错误监控上报;
- `pprof`: 性能分析; `swagger`: 文档(已废弃, 改用 swaggo/swag + adaptor);

## 使用模式

```shell
go get github.com/hertz-contrib/cors
```

```go
h := server.Default()
h.Use(cors.Default())
```

## 废弃提示

- `hertz-contrib/websocket` 与 `hertz-contrib/swagger` 已废弃;
- 推荐迁移到官方 `gorilla/websocket` / `swaggo/swag`, 通过 `adaptor.HertzHandler` 接入;
