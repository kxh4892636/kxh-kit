# Hertz 第三方日志集成

## 概述

- hlog 支持 zap、logrus、zerolog、slog 扩展，均实现 `hlog.FullLogger`;
- 通过 `hlog.SetLogger(logger)` 注入;
- 扩展仓库: hertz-contrib/logger;

## zap

- `hertzzap.NewLogger(hertzzap.WithZapOptions(zap.Fields(zap.String("service", "logging"))))`;
- 指定日志 field 需手动添加 zap option;

## logrus

- `hertzlogrus.NewLogger()` 创建 Logger，可选 option 配置;

## zerolog

- `hertzZerolog.New(hertzZerolog.WithField("service", "logging"))`: 原生支持指定 field;
- `l.SetOutput(w)` 重定向输出;

## slog

- `hertzslog.NewLogger()` 创建 Logger;
- 只支持 `slog.NewJSONHandler()`，不支持 `slog.NewTextHandler()`;

## 使用示例

```go
hlog.SetLogger(hertzzap.NewLogger(hertzzap.WithZapOptions(zap.Fields(zap.String("service", "logging")))))
hlog.SetLevel(hlog.LevelInfo)
```

## 注意事项

- 各库实现 `var _ hlog.FullLogger = (*Logger)(nil)` 编译期断言;
- 默认 logger 基于标准库，封装会导致文件名/行号不准;
