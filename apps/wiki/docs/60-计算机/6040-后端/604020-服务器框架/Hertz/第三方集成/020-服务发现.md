# Hertz 第三方服务发现

## 支持的注册中心

- nacos、consul、etcd、eureka、polaris、servicecomb、zookeeper、redis;
- 扩展仓库: hertz-contrib/registry;

## 使用模式

```go
// server 注册
h := server.Default(
	server.WithHostPorts(addr),
	server.WithRegistry(r, &registry.Info{
		ServiceName: "hertz.test.demo",
		Addr:        utils.NewNetAddr("tcp", addr),
		Weight:      10,
	}))

// client 发现
cli, _ := client.NewClient()
cli.Use(sd.Discovery(nacosResolver))
status, body, err := cli.Get(context.Background(), nil,
	"http://hertz.test.demo/ping", config.WithSD(true))
```

## 各实现要点

- nacos: `hertz-contrib/registry/nacos`（v1）与 `/nacos/v2`（v2 SDK）;
- consul: `WithCheck` 配置 `AgentServiceCheck`，默认 Timeout/Interval 5s、Deregister 1min;
- etcd: `WithTLSOpt(certFile, keyFile, caFile)` 配置 TLS;
- eureka: `NewEurekaRegistry(servers, heatBeatInterval)`;
- polaris: `NewPolarisRegistry(configFile...)` 可传配置文件;
- zookeeper: `NewZookeeperRegistry(servers, sessionTimeout)`;
- servicecomb: `WithAppId` 配置 AppId，默认 "DEFAULT";
- redis: `WithExpireTime` 默认 60s，过期时间必须大于刷新间隔;

## 公共配置

- `WithSD(true)`: 本次请求走服务发现; `WithTag(k, v)`: tag 信息;
- `WithCustomizedAddrs`: 覆盖 Resolver 结果; `WithLoadBalanceOptions`: 负载均衡配置;
- 默认负载均衡为 WeightedRandom，RefreshInterval 5s、ExpireInterval 15s;
