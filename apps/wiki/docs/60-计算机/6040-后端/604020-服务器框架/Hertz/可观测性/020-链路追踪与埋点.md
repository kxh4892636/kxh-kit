# Hertz 链路追踪与埋点

## Tracer 接口

- `type Tracer interface { Start(ctx, c) context.Context; Finish(ctx, c) }`;
- `server.WithTracer(...)` 可注入多个 tracer;
- Start 在请求开始前（读包前）执行，此时 RequestContext 为空，拿不到请求信息;
- 需要在解包后取信息（如 traceID）时，用中间件注入 span;
- 中间件内对 context 的修改对 tracer 无效;

## 埋点粒度

- `LevelDisabled`: 禁用埋点; 无 tracer 时默认;
- `LevelBase`: 仅基本埋点（HTTPStart / HTTPFinish）;
- `LevelDetailed`: 基本 + 细粒度埋点; 有 tracer 时默认;
- 细粒度事件: ReadHeaderStart/Finish、ReadBodyStart/Finish、ServerHandleStart/Finish、WriteStart/Finish;
- `server.WithTraceLevel(stats.LevelBase)` 控制粒度;
- 节点禁用埋点会导致该节点 span/metrics 丢失并中断链路;

## HTTPStats

- `c.GetTraceInfo()` 获取 trace 信息;
- `ti.Stats()` 提供 `Record`、`GetEvent`、`SendSize`、`RecvSize`、`Error`、`Panicked`、`Level` 等;
- 自定义监控可在 `Finish` 中读取 `HTTPStart`/`HTTPFinish` 事件计算耗时;

## 接入方式

- Prometheus: `server.WithTracer(prometheus.NewServerTracer(":9091", "/hertz"))`;
- OpenTelemetry: hertz-contrib/obs-opentelemetry 的 `hertztracing.NewServerTracer()` + `ServerMiddleware(cfg)`;
- Client 侧没有 Tracer 接口，通过客户端中间件实现监控;
