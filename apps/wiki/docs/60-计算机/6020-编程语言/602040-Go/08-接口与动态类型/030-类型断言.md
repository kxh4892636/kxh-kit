# 类型断言

单值断言是什么？comma ok 断言是什么？type switch是什么？失败行为是什么？

## 单值断言

### 单值断言的写法

```go
func main() {
	var v any = "go"
	s := v.(string) // 断言动态类型为 string;失败时 panic
	println(s) // go
}
```

## comma ok 断言

### comma ok 断言的写法

```go
func main() {
	var v any = "go"
	s, ok := v.(string) // 失败时返回 string 零值和 false
	println(s, ok) // go true
}
```

## type switch

### type switch的写法

```go
package main

import "fmt"

func describe(v any) {
	switch x := v.(type) { // v.(type) 只能用于 type switch
	case int:
		fmt.Println("int", x) // x 为 int
	case string:
		fmt.Println("string", x) // x 为 string
	default:
		fmt.Println("other")
	}
}
```

## 失败行为

| 形式                 | 断言成功            | 断言失败           |
| -------------------- | ------------------- | ------------------ |
| `v.(T)`              | 返回动态值          | panic              |
| `value, ok := v.(T)` | 返回动态值和 `true` | 返回零值和 `false` |
| `switch v.(type)`    | 执行匹配的类型分支  | 执行 `default`     |
