# 方法集合

集合规则有哪些注意点？方法归属是什么？

## 集合规则

### 集合规则的核心规则

- method set: 一个类型可调用或可用于实现接口的方法集合;
- `T` 方法集合: 包含 receiver 为 `T` 的方法;
- `*T` 方法集合: 包含 receiver 为 `T` 和 `*T` 的方法;
- 接口实现: 类型的方法集合覆盖接口方法集合, 即实现接口;

### 集合规则的写法

```go
type N int

func (n N) Value() int {
	return int(n)
}

func (n *N) Inc() {
	*n = *n + 1
}
```

## 方法归属

| 方法      | `N` 的方法集合 | `*N` 的方法集合 |
| --------- | -------------- | --------------- |
| `Value()` | 包含           | 包含            |
| `Inc()`   | 不包含         | 包含            |
