# 函数声明

函数声明由哪些部分组成？相邻参数的类型何时可以简写？

## 函数声明如何声明或使用

- function: 一段可重复调用的代码，可以接收参数并返回结果;
- 声明结构: `func` 关键字后依次写函数名、参数列表、返回类型和函数体;
- 参数: 调用方传给函数的输入值，每个参数都具有确定类型;
- 返回值: 函数交回调用方的结果；没有返回值时省略返回类型;

```go
// add 接收两个 int 参数并返回一个 int
func add(a int, b int) int {
	return a + b
}
```

## 参数类型简写

- parameter type elision: 参数类型省略；相邻参数类型相同时，可只在最后一个参数后声明类型;

```go
// a, b int 表示 a 和 b 都是 int
func add(a, b int) int {
	return a + b
}
```
