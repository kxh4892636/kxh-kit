# if

## 基本条件

### 语法格式

```go
func main() {
	score := 80
	if score >= 60 { // if 条件必须是 bool; 条件不需要括号
		println("pass")
	} else { // else 必须跟在前一个右花括号同一行
		println("fail")
	}
}
```

## 初始化语句

### 语法格式

```go
func main() {
	if n := len("go"); n > 0 { // n 只在 if-else 内可见
		println(n)
	}
}
```

## 多分支

### 语法格式

```go
func main() {
	n := 0
	if n > 0 {
		println("positive")
	} else if n < 0 { // 从上到下匹配第一个 true 分支
		println("negative")
	} else {
		println("zero")
	}
}
```
