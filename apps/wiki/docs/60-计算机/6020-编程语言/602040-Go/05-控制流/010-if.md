# if

## if 的基本条件如何书写? 有哪些语法约束?

### 基本条件的写法

```go
func main() {
	score := 80
	if score >= 60 { // if 条件必须是 bool; 条件不需要括号
		println("pass")
	} else { // else 必须跟在前一个右花括号同一行
		println("fail")
	}
}
```

## if 的初始化语句如何书写? 变量作用域是什么?

### 初始化语句的写法

```go
func main() {
	if n := len("go"); n > 0 { // n 只在 if-else 内可见
		println(n)
	}
}
```

## if 多分支如何书写, 分支如何匹配?

### 多分支的写法

```go
func main() {
	n := 0
	if n > 0 {
		println("positive")
	} else if n < 0 { // 从上到下匹配第一个 true 分支
		println("negative")
	} else {
		println("zero")
	}
}
```
