# break 和 continue

break 和 continue如何使用？标签是什么？

## break 和 continue如何使用

### break 和 continue如何使用的写法

```go
func main() {
	for i := 0; i < 5; i++ {
		if i == 2 {
			continue // 跳过当前轮剩余代码
		}
		if i == 4 {
			break // 终止当前 for
		}
		println(i)
	}
}
```

## 标签

### 标签的核心规则

- label: 标记一条语句位置;
- 使用场景: 退出多层嵌套循环;

### 标签的写法

```go
func main() {
outer:
	for i := 0; i < 3; i++ {
		for j := 0; j < 3; j++ {
			if i*j > 2 {
				break outer // 跳出 outer 标签对应的外层循环
			}
		}
	}
}
```
