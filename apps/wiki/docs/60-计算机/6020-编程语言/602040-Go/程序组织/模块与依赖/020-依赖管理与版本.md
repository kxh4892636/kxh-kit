# 依赖管理与版本

## 依赖命令

```bash
go get github.com/google/uuid@latest # 添加或升级到最新版本
go get github.com/google/uuid@none   # 删除指定依赖
go mod tidy                          # 根据 import 补齐和清理依赖
```

## Module 主版本规则

### 概念

- `v0`: 初始阶段, 兼容性不稳定;
- `v1`: 默认稳定主版本, import path 不需要版本后缀;
- `v2+`: 主版本通常体现在 module path 中, 例如 `/v2`;

## Semantic Versioning

### 概念

- `X.Y.Z`: 主版本号, 次版本号, 修订版本号;
- major version: 不兼容变更, 例如新增大功能, 修改 API;
- minor version: 兼容功能新增, 例如新增小功能, 修复小问题;
- patch version: 兼容问题修复, 例如修复小问题, 优化性能;

## 版本维度

| 版本部分 | 变化性质     |
| -------- | ------------ |
| major    | 不兼容变更   |
| minor    | 兼容功能新增 |
| patch    | 兼容问题修复 |
