# array

array是什么？array如何初始化？数组等价是什么？多维数组是什么？

## array是什么

### array是什么的核心规则

- array: 固定长度, 元素类型相同的值序列;
- 长度: array 类型的一部分, `[3]int` 和 `[4]int` 是不同类型;
- 值语义: 赋值和传参会复制整个数组;

### array是什么的写法

```go
func main() {
	var nums [3]int       // 固定长度数组; 元素零值为 0
	nums[0] = 10          // 数组索引从 0 开始
	println(nums[0], len(nums))
}
```

## array如何初始化

### array如何初始化的写法

```go
func main() {
	a := [3]int{1, 2, 3}      // 显式长度数组字面量
	b := [...]int{1, 2, 3}    // 由元素数量推导数组长度
	c := [5]int{1: 10, 3: 30} // 指定索引初始化; 未指定元素为零值
	println(a[0], b[1], c[3])
}
```

## 数组等价

### 数组等价的核心规则

- array 可比较条件: 元素类型可比较;
- 数组相等: 长度相同, 元素类型相同, 每个元素相等;
- 类型差异: `[2]int` 和 `[3]int` 不是同一类型;

### 数组等价的写法

```go
func main() {
	a := [2]int{1, 2}
	b := [2]int{1, 2}
	println(a == b) // true
}
```

## 多维数组

### 多维数组的写法

```go
func main() {
	matrix := [2][3]int{{1, 2, 3}, {4, 5, 6}} // 2 行 3 列数组
	println(matrix[1][2])                     // 访问第 2 行第 3 列
}
```
