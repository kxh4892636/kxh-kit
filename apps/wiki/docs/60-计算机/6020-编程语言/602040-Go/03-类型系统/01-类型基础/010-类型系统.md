# 类型系统

## 基本概念

### 定义

- type: 值的模板, 决定存储形式和可用操作;
- value: 某个类型的具体数据;
- literal: 直接写在源码中的值表示;
- conversion: 显式类型转换, 语法为 `T(v)`;

## 值类型与引用类型

### 概念

- 值类型: 变量直接存储数据本体, 赋值即复制全部数据;
- 引用类型: 变量存储指向底层数据的描述头, 赋值只复制描述头, 共享底层数据;
- 赋值语义: `=`, 传参, 返回值永远只复制变量本身; 语言层面无自动深拷贝;

### 分类表

| 类别     | 类型                                              |
| -------- | ------------------------------------------------- |
| 值类型   | bool, 数值, string, array, struct                 |
| 引用类型 | pointer, slice, map, channel, function, interface |

- string: 底层引用语义, 但不可变, 可按值类型使用;
- array 与 slice 相反: `[3]int` 赋值全量拷贝, `[]int` 赋值共享底层数组;
