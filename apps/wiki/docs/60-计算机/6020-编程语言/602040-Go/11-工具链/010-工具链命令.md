# 工具链命令

常用命令是什么？格式化如何完成？编译/运行如何完成？

## 常用命令

### 常用命令包含的命令

| 命令       | 描述                    |
| ---------- | ----------------------- |
| `go run`   | 编译并运行              |
| `go build` | 编译 package 或源码文件 |
| `go test`  | 运行测试                |
| `go fmt`   | 格式化 Go 源码          |
| `go doc`   | 查看文档                |
| `go env`   | 查看环境变量            |
| `go mod`   | 管理 module             |

## 格式化

```bash
go fmt ./... # 格式化当前目录及子目录中的所有 Go package
```

## 编译/运行

```bash
go build -o hello main.go # 编译 main.go 并输出名为 hello 的可执行文件
./hello # 运行当前目录下的 hello
```
