# React 调用组件与 Hook

为什么不能直接调用组件函数？Hook 不能作为普通值传递？

## 声明式

- 你描述 UI, React 决定何时渲染;
- 组件只在 JSX 中使用;

```jsx
// 正确
<Page />;

// 错误
Page();
```

## 不要直接调用组件函数

- 直接调用会绕过 React 调度;
- 无法获得 Hooks 上下文和正确生命周期;

## 不要传递 Hook 为普通值

- Hook 只能在组件内调用;
- 不要传给其他函数、存进数组/对象;

```jsx
// 错误
const fn = useState;
fn(); // 不是合法 Hook 调用
```

## 不要动态修改 Hook

- 不动态创建、重命名、包装 Hook;
- 保持 Hook 调用静态可分析;

## 不要动态使用 Hook

- 不根据条件选择不同 Hook;
- 调用顺序必须稳定;
