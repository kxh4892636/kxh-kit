# 服务端函数

## 什么是 Server Functions?

- 在服务端执行的函数, 可从客户端调用;
- 适用于表单 action、数据变更;
- 旧称 Server Actions;

## Server Function 如何标记?

- 在 async 函数顶部或文件顶部加 `'use server'`;
- 文件顶部: 该文件所有导出均为 Server Function;

```js
"use server";

export async function updateName(name) {
  await db.users.update(name);
}
```

## 客户端如何导入并调用 Server Function?

- 客户端组件可导入 Server Function;
- 传入 `<form action>` 或 action props;

```jsx
import { updateName } from "./actions";

<form action={updateName}>
  <input name="name" />
</form>;
```

## Server Function 的参数与返回值有何要求?

- 必须可序列化;
- 不能传 DOM 节点、类实例等;

## Server Function 有哪些安全要求?

- 不要暴露敏感操作;
- 服务端始终校验输入和权限;

## Server Function 如何与 useActionState 配合?

- 可结合 `useActionState` 管理提交状态;
- 支持渐进增强;
