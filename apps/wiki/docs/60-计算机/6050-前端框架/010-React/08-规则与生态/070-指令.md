# 指令

RSC 指令 `'use client'` 和 `'use server'` 告诉打包器什么？

## 作用

- 给 React Server Components 兼容的打包器提供边界指令;
- 决定模块运行在客户端还是服务端;

## 'use client'

- 文件顶部声明;
- 标记该模块及其传递依赖为客户端代码;
- 可创建交互 UI;

## 'use server'

- 文件顶部或 async 函数顶部声明;
- 标记服务端可调用函数;
- 用于 Server Functions;

## 注意

- 指令必须是文件/函数的第一个语句（可位于注释后）;
- 不能动态导入或条件使用;
- 不是每个文件都需要;
