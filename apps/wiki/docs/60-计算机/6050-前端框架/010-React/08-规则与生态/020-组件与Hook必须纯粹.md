# 组件与 Hook 必须纯粹

## 组件与 Hook 的幂等指什么?

- 组件/Hook 对相同输入返回相同结果;
- 输入包括 props、state、context;

## 副作用为什么必须放在渲染之外?

- 渲染期间不能修改外部变量、发送请求、写 DOM;
- 副作用放在事件处理器或 Effect;

## props 和 state 为什么不可变?

- 单个渲染中 props/state 是快照;
- 不要直接修改它们;

## Hook 的参数和返回值为什么不可变?

- 传给 Hook 的值不可修改;
- Hook 返回的值也应视为不可变;

## 值用于 JSX 后为什么不可再修改?

- 值被用于 JSX 后不要修改;
- 修改应在创建 JSX 前完成;

## 哪些局部 mutation 是允许的?

- 渲染期间可修改“刚创建”的局部变量;
- 惰性初始化也允许;

## 组件与 Hook 纯粹为什么重要?

- 保证 React 可多次调用渲染而不出错;
- 支持自动优化和并发渲染;
