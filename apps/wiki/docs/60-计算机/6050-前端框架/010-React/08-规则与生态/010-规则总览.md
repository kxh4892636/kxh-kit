# 规则总览

## React 规则的性质是什么?

- 不只是风格指南, 违反会导致 bug;
- 帮助写出可预测、可组合、易维护的应用;

## React 的三大规则是什么?

1. 组件和 Hook 必须纯净;
2. React 调用组件和 Hook;
3. Hooks 规则: 顶层调用、只从 React 函数调用;

## React 规则有哪些工具支持?

- StrictMode 在开发中检查;
- ESLint 插件 `eslint-plugin-react-hooks` 自动检查;

## 遵循 React 规则会带来什么结果?

- 遵循规则后 React 可安全优化;
- 代码更容易理解、调试、协作;
