# 闭包与定时器最佳实践

React 中闭包问题如何产生？定时器/异步回调如何读取最新值？

## 问题

- `setTimeout` / `setInterval` / `Promise.then` 等回调捕获的是触发时的 state 快照;
- 若依赖数组为空, 回调里的 state 永远是首次渲染的值;

```jsx
const [count, setCount] = useState(0);

useEffect(() => {
  const id = setInterval(() => {
    setCount(count + 1); // count 永远是最初的 0
  }, 1000);
  return () => clearInterval(id);
}, []);
```

## 方案 1: updater function

- 只更新 state 本身时使用 `setCount(c => c + 1)`;
- 无需重新创建定时器;

```jsx
setInterval(() => {
  setCount((c) => c + 1);
}, 1000);
```

## 方案 2: ref 保存最新值

- 需要同时读取其他最新 props/state 时, 用 ref 同步;

```jsx
const countRef = useRef(count);
countRef.current = count;

useEffect(() => {
  const id = setInterval(() => {
    setCount(countRef.current + 1);
  }, 1000);
  return () => clearInterval(id);
}, []);
```

## 方案 3: Effect Event

- React 19 可用 `useEffectEvent` 在 Effect 中读取最新值且不触发重跑;

```jsx
const onTick = useEffectEvent(() => {
  setCount((c) => c + 1);
  console.log(latestProp);
});

useEffect(() => {
  const id = setInterval(onTick, 1000);
  return () => clearInterval(id);
}, []);
```

## 避免重复初始化

- 不要在渲染中重复创建昂贵对象;
- 惰性初始化 `useState(() => create())` 或 Effect 中初始化;

```jsx
const [player] = useState(() => new VideoPlayer());
```
