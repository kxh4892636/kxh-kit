# Zustand 中间件与持久化

Zustand 如何持久化状态？中间件怎么用？

## persist

- 用 `persist` 中间件把状态保存到 storage;
- `name` 必须唯一;
- 默认 `localStorage`, 可指定 `sessionStorage`、`AsyncStorage` 等;

```js
import { create } from "zustand";
import { persist, createJSONStorage } from "zustand/middleware";

export const useBearStore = create(
  persist(
    (set, get) => ({
      bears: 0,
      addABear: () => set({ bears: get().bears + 1 }),
    }),
    {
      name: "food-storage",
      storage: createJSONStorage(() => sessionStorage),
    },
  ),
);
```

## createJSONStorage

- 包装 storage 以支持 JSON 序列化;
- 用于 localStorage / sessionStorage / AsyncStorage;

## 其他中间件

- `immer`: 用可变风格更新;
- `devtools`: 接入 Redux DevTools;
- `subscribeWithSelector`: 增强订阅;

## 注意

- 持久化数据版本变化时需要迁移策略;
- 避免把不可序列化值放入持久化状态;
