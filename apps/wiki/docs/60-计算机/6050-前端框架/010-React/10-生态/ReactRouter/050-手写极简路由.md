# React Router 手写极简路由

## 手写极简路由的核心思路是什么?

- 监听 `popstate` 和 `pushState`;
- 用状态库保存当前 location 和 history 方法;
- 根据 location 匹配渲染组件;

## 手写路由的 location 与 history 如何存储?

```js
import { create } from "zustand";

const useRouterStore = create((set) => ({
  location: null,
  setLocation: (value) => set({ location: value }),
  history: null,
  setHistory: (value) => set({ history: value }),
}));
```

## 手写的 Router 组件需要做哪些事?

- 初始化时读取当前 pathname;
- 暴露 push / goBack;
- 监听 popstate;

```jsx
function Router({ children }) {
  const setLocation = useRouterStore((s) => s.setLocation);
  const setHistory = useRouterStore((s) => s.setHistory);

  useEffect(() => {
    setLocation(window.location.pathname || "/");
    setHistory({
      push: (to) => {
        setLocation(to);
        window.history.pushState({}, "", to);
      },
      goBack: () => window.history.go(-1),
    });
    const onPop = () => setLocation(window.location.pathname);
    window.addEventListener("popstate", onPop);
    return () => window.removeEventListener("popstate", onPop);
  }, []);

  return children;
}
```

## 手写的 Route 与 Link 如何实现?

```jsx
function Route({ path, component: Component }) {
  const location = useRouterStore((s) => s.location);
  return location === path ? <Component /> : null;
}

function Link({ to, children }) {
  const history = useRouterStore((s) => s.history);
  return (
    <a
      href={to}
      onClick={(e) => {
        e.preventDefault();
        history.push(to);
      }}
    >
      {children}
    </a>
  );
}
```

## 手写路由与生产环境的使用建议是什么?

- 生产环境使用 React Router 官方库;
- 手写实现仅用于理解路由原理;
