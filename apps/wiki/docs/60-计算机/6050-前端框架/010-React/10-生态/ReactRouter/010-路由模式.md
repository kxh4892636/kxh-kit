# React Router 路由模式

## 如何安装 React Router?

- v7 推荐使用 `react-router` 包;
- 旧项目常见 `react-router-dom`, v7 已合并;

```bash
npm install react-router
```

## BrowserRouter 的特点与使用要求是什么?

- 基于 History API;
- URL 路径干净, 推荐用于 Web 应用;
- 需要服务器支持回退到入口页;

```jsx
import { createRoot } from "react-dom/client";
import { BrowserRouter } from "react-router";

createRoot(document.getElementById("root")).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>,
);
```

## HashRouter 的特点是什么?

- 使用 URL hash 管理路由;
- 不需要服务器配置;
- 不推荐用于正式产品;

```jsx
import { HashRouter } from "react-router";
```

## MemoryRouter 适用于哪些场景?

- 路由状态保存在内存;
- 适合测试和非浏览器环境;

```jsx
import { MemoryRouter } from "react-router";
```

## StaticRouter 的用途是什么?

- 用于服务端渲染;
- 传入当前 location 生成静态 HTML;

```jsx
import { StaticRouter } from "react-router/server";
```
