# React Router 导航与链接

## Link 的作用是什么?

- 渲染为 `<a>`, 用于声明式跳转;
- `to` 指定目标路径;

```jsx
import { Link } from "react-router";

<Link to="/users">用户</Link>;
```

## Link 的常用选项有哪些?

- `relative="path"`: 基于当前路径解析相对路径;
- `preventScrollReset`: 跳转时保留滚动位置;
- `state`: 传递附加状态, 用 `useLocation` 读取;

```jsx
<Link to="?tab=one" preventScrollReset />
<Link to="/new" state={{ from: 'home' }} />
```

## NavLink 与 Link 有何区别?

- Link 的增强版;
- 提供 `isActive`, `isPending`, `isTransitioning` 状态;

```jsx
import { NavLink } from "react-router";

<NavLink to="/messages" className={({ isActive }) => (isActive ? "active" : "")}>
  Messages
</NavLink>;
```

## useNavigate 如何实现编程式导航?

- 编程式导航;

```jsx
import { useNavigate } from "react-router";

function LogoutButton() {
  const navigate = useNavigate();
  return <button onClick={() => navigate("/login")}>退出</button>;
}
```

## 导航方式的选用注意事项有哪些?

- 优先使用 Link 保持可访问性;
- 编程式导航适合事件回调、登录跳转等场景;
