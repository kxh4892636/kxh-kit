# 安装与工程搭建

## 如何试用 React?

- 无需安装: 用在线 sandbox 直接编辑;
- 本地开发: 需要 Node.js 和包管理器;

## 如何创建新的 React 应用?

- 推荐使用框架起步: 内置路由、数据获取、构建优化;
- 全栈框架: Next.js (App Router), React Router (v7), Expo (React Native);
- 从零搭建: 用 Vite 等构建工具 + `@vitejs/plugin-react`, 需要 `index.html`、`src/main.jsx`、`src/App.jsx`;
- Create React App 已不推荐用于新项目;

```bash
# 以 Vite 为例
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev
```

## 官方推荐框架有哪些特性?

- 官方推荐框架: 支持部署、缩放、最新 React 特性;
- 无服务器也可: 部分框架可导出静态站点;
- 框架选择取决于: Web/原生、路由需求、部署平台;

## 如何把 React 加入现有项目?

- 渐进式采用: 不必重写整个项目;
- 用构建工具支持 JSX, 再用 `createRoot` 在页面任意位置挂载 React;
- 从零搭建适合学习底层, 生产项目优先框架;

```jsx
import { createRoot } from "react-dom/client";

createRoot(document.getElementById("root")).render(<App />);
```
