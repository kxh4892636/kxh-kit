# 开发者工具

React Developer Tools 是什么？如何安装和使用？

## 作用

- 检查 React 组件树;
- 查看和编辑 props / state;
- 定位性能问题;

## 安装

- 浏览器扩展: Chrome, Firefox, Edge 等;
- React Native: 通过 DevTools 菜单连接;

## 核心能力

- Components 面板: 查看组件层级、props、state、hooks;
- Profiler 面板: 记录渲染耗时, 分析性能瓶颈;
- 高亮更新: 显示哪些组件发生了重渲染;

## 使用建议

- 开发环境默认启用;
- StrictMode 下额外检查可帮助发现不纯渲染;
- 生产构建需使用 profiling build 才能查看性能数据;
