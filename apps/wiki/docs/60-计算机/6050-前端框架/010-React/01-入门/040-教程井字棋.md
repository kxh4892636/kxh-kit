# 教程井字棋

## 井字棋教程的核心练习有哪些?

- 组件拆分: Board, Square;
- props 传值: 把点击位置和当前值传给子组件;
- state 提升: 把棋盘状态放到父组件 Board;
- 不可变性: 创建新数组而不是修改原数组;

```jsx
function Board() {
  const [squares, setSquares] = useState(Array(9).fill(null));
  function handleClick(i) {
    const next = squares.slice();
    next[i] = "X";
    setSquares(next);
  }
  // ...
}
```

## 井字棋如何保存历史并跳转步骤?

- 状态提升到顶层 Game 组件;
- 保存 `squares` 数组的历史: `history = [{squares}, ...]`;
- 当前步骤 `currentMove`, 点击历史可跳转;

```jsx
const [history, setHistory] = useState([Array(9).fill(null)]);
const [currentMove, setCurrentMove] = useState(0);
const currentSquares = history[currentMove];
```

## 时间旅行如何截断未来并渲染历史按钮?

- 用 `slice(0, currentMove + 1)` 截断未来;
- 渲染历史按钮列表, 点击 `setCurrentMove(move)`;
- 用 `key` 标识每一步;

## 胜负判定如何实现?

- 预先定义胜利线组合;
- 每步后检查当前棋盘是否满足任一组合;
- 显示获胜者或平局;
