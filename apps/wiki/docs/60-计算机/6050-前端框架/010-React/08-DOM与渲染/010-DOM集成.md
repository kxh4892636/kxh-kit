# React DOM 集成

## Portal 如何改变 DOM 位置而保留 React 关系？

- createPortal: `createPortal(children, domNode, key?)` 把内容放进指定已有 DOM 节点，适合弹窗、提示层等需要跳出裁剪容器的 UI;
- 树关系: Context 与事件仍按 React 树传播，Portal 内点击可能触发 React 祖先处理器，并非只沿 DOM 容器关系理解;
- 容器身份: 换用另一个 domNode 会重新创建 Portal 内容；弹窗仍需自行处理焦点、键盘与无障碍语义;

```jsx
import { createPortal } from "react-dom";

function Overlay({ children }) {
  return createPortal(children, document.body);
}
```

## 什么时候需要同步提交 DOM？

- flushSync: 包裹更新后，在下一行代码前让相关 DOM 同步更新，主要服务于必须即时观察 DOM 的浏览器或第三方集成;
- 成本: 可能冲刷回调外的待处理更新与 Effect，迫使 Suspense 显示 fallback，并损害吞吐，不作为日常更新默认方式;
- 调用限制: 不在 React 正在渲染或执行 Effect 时调用，避免试图嵌套提交;

```jsx
import { flushSync } from "react-dom";

function addAndScroll() {
  flushSync(() => setItems((items) => [...items, newItem]));
  listRef.current.lastElementChild?.scrollIntoView();
}
```

## 如何选择资源提示的准备程度？

| API           | 准备程度         | 典型用途               |
| ------------- | ---------------- | ---------------------- |
| prefetchDNS   | DNS 查询         | 很可能访问的域名       |
| preconnect    | 建立连接         | 即将获取跨域资源       |
| preload       | 获取资源但不执行 | 字体、图片、样式、脚本 |
| preloadModule | 获取模块但不执行 | 即将使用的 ESM         |
| preinit       | 获取并应用或执行 | 样式表、脚本           |
| preinitModule | 获取并执行模块   | 需要初始化的 ESM       |

## 资源提示怎样避免浪费与重复？

- 必需参数: preload 与 preinit 根据用途指定 as，字体等资源还需正确 crossOrigin，图片可提供 imageSrcSet/imageSizes;
- 去重边界: React 按对应 API 的等价规则去重，图片提示还涉及候选集；不要假定任意不同选项都生成新请求;
- 执行位置: 客户端可在事件等位置提示，服务端调用需属于组件渲染或由其发起的异步上下文才会生效;
- 预算意识: 提前加载会消耗带宽和连接，优先提示高概率资源，框架已经处理时不再盲目重复;
