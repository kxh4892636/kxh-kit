# 静态 API

## 静态 API 的用途是什么?

- 构建期预渲染静态 HTML;
- 比流式 SSR 功能有限, 但适合静态站点;

## prerender 如何在 Web Stream 环境生成静态 HTML?

- Web Stream 环境: `prerender(reactNode, options?)`;
- 返回静态 HTML 的流;

```jsx
import { prerender } from "react-dom/static";

const { result } = await prerender(<App />);
```

## prerenderToNodeStream 如何使用 Node.js 流?

- Node.js Stream 环境;
- 返回 Node.js 流;

## 何时使用静态 API?

- 需要静态 HTML 且无交互水合需求时使用;
- 框架通常会封装;
