# DOM 组件

## DOM 通用组件支持哪些 props? 属性命名有何要求?

- 所有内置 HTML/SVG 组件支持通用 props;
- React 特殊 props: `ref`, `dangerouslySetInnerHTML`;
- 属性使用 camelCase;

```jsx
<div ref={ref} className="box" />
```

## 表单组件有哪些? 受控与 action 如何工作?

- `<input>`, `<select>`, `<textarea>`, `<option>`, `<progress>`;
- 传 `value` 变为受控组件;
- `<form>` 支持 `action` 和 Server Function;

```jsx
<input value={text} onChange={e => setText(e.target.value)} />
<select value={selected} onChange={e => setSelected(e.target.value)}>
  <option value="a">A</option>
</select>
```

## 资源与元数据组件有哪些? 如何提升到 head 并支持 Suspense?

- `<link>`, `<meta>`, `<script>`, `<style>`, `<title>`;
- React 可提升到 document head;
- 支持资源加载 Suspense;

```jsx
<title>{pageTitle}</title>
<link rel="stylesheet" href="theme.css" />
```

## 自定义元素在 React 中如何处理?

- 带 `-` 的标签按 custom element 处理;
- 非字符串值默认序列化为属性;
- 类构造器上声明的属性会被识别为 property;

## 使用 DOM 组件有哪些注意事项?

- `dangerouslySetInnerHTML` 会绕过 React 转义, 慎用;
- 表单受控时 value 必须与 state 同步;
