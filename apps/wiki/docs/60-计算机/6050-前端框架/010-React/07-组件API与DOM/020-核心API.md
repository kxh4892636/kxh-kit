# 核心 API

createContext、lazy、memo、startTransition、act 的用途。

## createContext

- 创建 context 对象: `const Ctx = createContext(defaultValue)`;
- 配合 `<Ctx.Provider>` 和 `useContext` 使用;

```jsx
const ThemeContext = createContext("light");
```

## lazy

- 延迟加载组件: `const Lazy = lazy(() => import('./Comp'))`;
- 首次渲染时加载, 常与 Suspense 配合;

```jsx
const Markdown = lazy(() => import("./Markdown"));
<Suspense fallback={<Spinner />}>
  <Markdown />
</Suspense>;
```

## memo

- 缓存组件: `const Memo = memo(Component, arePropsEqual?)`;
- props 未变时跳过重渲染;

```jsx
const MemoButton = memo(Button);
```

## startTransition

- 标记非紧急更新: `startTransition(action)`;
- 让更新可中断, 不阻塞用户输入;
- 与 `useTransition` 的 `startTransition` 类似, 但可在组件外使用;

```jsx
startTransition(() => setPage("/comments"));
```

## act

- 测试助手: `await act(async () => { ... })`;
- 包裹渲染和交互, 确保更新已处理;

```jsx
await act(async () => {
  root.render(<App />);
});
```
