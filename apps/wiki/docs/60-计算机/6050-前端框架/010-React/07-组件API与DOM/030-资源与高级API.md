# 资源与高级 API

cache、cacheSignal、captureOwnerStack 是什么？

## cache

- 缓存函数结果, 仅用于 React Server Components;
- 相同参数返回缓存结果, 可缓存数据获取或计算;

```jsx
import { cache } from "react";

const getUser = cache(async (id) => {
  return await db.users.get(id);
});
```

## cacheSignal

- 获取 `AbortSignal`, 在 `cache()` 生命周期结束时中止;
- 用于取消不再需要的 in-flight 请求;

```jsx
const signal = cacheSignal();
const data = await fetch(url, { signal });
```

## captureOwnerStack

- 开发模式读取当前 Owner Stack 字符串;
- 用于增强自定义错误覆盖层;

```jsx
const stack = React.captureOwnerStack();
```

## 使用场景

- 都是偏底层/框架级 API;
- 应用代码通常不直接使用;
