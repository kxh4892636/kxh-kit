# 服务端 API

## 流式渲染有哪些 API?

- `renderToReadableStream`: Web Stream 环境;
- `renderToPipeableStream`: Node.js Stream;
- 支持 Suspense 流式输出;

```jsx
import { renderToPipeableStream } from "react-dom/server";

const stream = renderToPipeableStream(<App />, {
  onShellReady() {
    /* pipe */
  },
});
```

## 字符串渲染有哪些 API 与限制?

- `renderToString`: 渲染为 HTML 字符串;
- `renderToStaticMarkup`: 渲染为无交互 HTML;
- 不支持流式或等待数据, 功能有限;

```jsx
const html = renderToString(<App />);
```

## 恢复渲染有哪些 API?

- `resume`: Web Stream 环境恢复 prerender 结果;
- `resumeToPipeableStream`: Node.js 环境恢复;

## 服务端渲染 API 如何选择?

- 新应用优先流式 API;
- 简单/静态场景可用 `renderToString`;
- 大多数应用由框架处理 SSR;
