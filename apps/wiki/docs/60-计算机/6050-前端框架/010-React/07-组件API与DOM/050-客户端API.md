# 客户端 API

## createRoot 如何创建并接管 React root?

- 在浏览器 DOM 节点创建 React root;
- 接管该节点内的 DOM 管理;

```jsx
import { createRoot } from "react-dom/client";

const root = createRoot(document.getElementById("root"));
root.render(<App />);
```

## root.render 如何渲染并更新 React 树?

- 渲染 React 组件到 root;
- 再次调用会更新已有 UI;

## root.unmount 如何卸载整个 React 树?

- 卸载整个 React 树;

```jsx
root.unmount();
```

## hydrateRoot 如何水合服务端生成的 HTML?

- 把 React 附加到服务端生成的现有 HTML;
- 用于 SSR/SSG 水合;

```jsx
import { hydrateRoot } from "react-dom/client";

hydrateRoot(document.getElementById("root"), <App />);
```

## 客户端 API 的使用注意事项有哪些?

- 通常只在应用顶层调用;
- 框架会替你调用;
- React 19 移除旧的 `render` / `hydrate` API;
