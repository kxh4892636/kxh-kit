# 列表渲染

## 如何从数组渲染列表?

- 用 `map()` 把数组转为 JSX 列表;

```jsx
const people = ["凯", "林", "周"];
return (
  <ul>
    {people.map((name) => (
      <li key={name}>{name}</li>
    ))}
  </ul>
);
```

## 如何先过滤再渲染列表?

- 先用 `filter()` 得到子集, 再 `map()` 渲染;

```jsx
const chemists = people.filter((p) => p.profession === "化学家");
```

## 列表 key 的规则与作用是什么?

- key 必须唯一, 只在兄弟节点间区分;
- 帮助 React 识别哪些项改变、添加、删除, 没有稳定 key 会导致状态错位;
- key 不应使用数组索引（若顺序会变化）;
- key 不会传给组件, 不能当 prop 用;
- 列表项组件应接收 `item` 而不是索引;

```jsx
<li key={person.id}>{person.name}</li>
```

## 如何渲染多个 DOM 节点而不增加嵌套?

- 用 `<Fragment key={...}>` 包裹多个节点而不增加 DOM;

```jsx
import { Fragment } from "react";

{
  items.map((item) => (
    <Fragment key={item.id}>
      <h2>{item.title}</h2>
      <p>{item.body}</p>
    </Fragment>
  ));
}
```
