# 保持组件纯粹

## 什么是纯函数?

- 相同输入 → 相同输出;
- 不修改外部变量、不产生副作用;

```js
function double(x) {
  return x * 2; // 纯
}
```

## 组件作为公式的含义是什么?

- React 假设每个组件是纯函数;
- 同 props / state / context 应渲染相同结果;
- props / state 是渲染快照, 组件不应修改它们;

## 渲染期间哪些副作用不能做?

- 渲染期间不要修改已有变量、写 DOM、发请求;
- 副作用应放在事件处理器或 Effect 中;

```jsx
// 不纯: 渲染时修改外部变量
let count = 0;
function Bad() {
  count++; // 错误
  return <div>{count}</div>;
}
```

## 为什么允许局部 mutation?

- 在组件内创建新变量并修改是安全的;
- 只修改“刚创建”的局部值, 惰性初始化也允许;

```jsx
function Cup({ guest }) {
  const cups = [];
  for (let i = 0; i < guest; i++) {
    cups.push(i);
  }
  return <div>{cups.join(",")}</div>;
}
```

## Hook 的参数和返回值为什么不可变?

- 传给 Hook 的值不可修改;
- Hook 返回的值也应视为不可变;

## 值用于 JSX 后为什么不可再修改?

- 值被用于 JSX 后不要修改;
- 修改应在创建 JSX 前完成;

## StrictMode 如何检测不纯的渲染?

- 开发模式下 React 会双调用渲染函数;
- 帮助暴露不纯的渲染逻辑;

## 副作用应该放在哪里?

- 事件处理器: 用户交互引起的修改;
- Effect: 与外部系统同步;
- 两者都不在渲染过程中执行;

## 组件与 Hook 纯粹为什么重要?

- 保证 React 可多次调用渲染而不出错;
- 支持自动优化和并发渲染;
