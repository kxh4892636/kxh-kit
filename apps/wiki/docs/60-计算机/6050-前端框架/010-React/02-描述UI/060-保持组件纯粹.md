# 保持组件纯粹

什么是纯函数？为什么组件要纯？副作用应该放哪里？

## 纯函数

- 相同输入 → 相同输出;
- 不修改外部变量、不产生副作用;

```js
function double(x) {
  return x * 2; // 纯
}
```

## 组件作为公式

- React 假设每个组件是纯函数;
- 同 props / state / context 应渲染相同结果;

## 副作用

- 渲染期间不要修改已有变量、写 DOM、发请求;
- 副作用应放在事件处理器或 Effect 中;

```jsx
// 不纯: 渲染时修改外部变量
let count = 0;
function Bad() {
  count++; // 错误
  return <div>{count}</div>;
}
```

## 局部 mutation 允许

- 在组件内创建新变量并修改是安全的;
- 只修改“刚创建”的局部值;

```jsx
function Cup({ guest }) {
  const cups = [];
  for (let i = 0; i < guest; i++) {
    cups.push(i);
  }
  return <div>{cups.join(",")}</div>;
}
```

## StrictMode 检测

- 开发模式下 React 会双调用渲染函数;
- 帮助暴露不纯的渲染逻辑;

## 副作用的位置

- 事件处理器: 用户交互引起的修改;
- Effect: 与外部系统同步;
- 两者都不在渲染过程中执行;
