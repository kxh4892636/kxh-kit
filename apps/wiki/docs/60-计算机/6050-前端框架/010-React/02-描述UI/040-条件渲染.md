# 条件渲染

## 如何用 if 返回不同的 JSX?

- 用 `if` 语句在组件内分支返回;

```jsx
function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <AdminPanel />;
  }
  return <LoginForm />;
}
```

## 返回 null 会渲染什么, 有何影响?

- 返回 `null` 不渲染任何内容;
- 注意父组件布局可能受影响;

## 如何用三元运算符条件包含 JSX?

- 三元运算符 `? :` 适合紧凑表达;

```jsx
<div>{isLoggedIn ? <AdminPanel /> : <LoginForm />}</div>
```

## 逻辑与 `&&` 如何渲染, 有哪些注意点?

- `{isLoggedIn && <AdminPanel />}`;
- 左侧为 falsy 时不渲染右侧;
- 注意 `0` 会渲染成 "0", 判断时用布尔值;

## 复杂条件如何赋值给变量?

- 复杂条件先算到变量, 保持 JSX 可读;

```jsx
let content;
if (isLoggedIn) {
  content = <AdminPanel />;
} else {
  content = <LoginForm />;
}
return <div>{content}</div>;
```

## 条件渲染的原则有哪些?

- 没有特殊模板语法, 使用普通 JavaScript;
- 保持条件简单, 必要时抽成子组件;
