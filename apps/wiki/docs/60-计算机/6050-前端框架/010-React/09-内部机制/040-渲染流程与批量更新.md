# 渲染流程与批量更新

React 从触发更新到 DOM 变更经历了什么？批量更新如何工作？

## 渲染流程

1. 触发更新: 首次渲染或 state 更新;
2. 渲染: React 调用组件, 生成新的元素树;
3. 协调: 比较新旧树, 计算差异;
4. 提交: 将差异应用到 DOM;
5. 浏览器绘制;

## 批量更新

- React 将同一事件中的多个 setState 合并为一次渲染;
- 减少重复协调和 DOM 操作;

```jsx
function handleClick() {
  setCount((c) => c + 1);
  setFlag((f) => !f);
  // 只触发一次 re-render
}
```

## flushSync

- 强制同步刷新 state 更新到 DOM;
- 不常见, 可能影响性能;

```jsx
import { flushSync } from "react-dom";

flushSync(() => {
  setCount((c) => c + 1);
});
```

## 与并发

- 低优先级更新可被高优先级更新打断;
- 批量更新与可中断渲染共同提升响应性;
