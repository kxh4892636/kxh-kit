# 响应事件

如何添加事件处理器？事件如何传播？如何阻止默认行为？

## 添加事件处理器

- 给元素传函数 prop, 如 `onClick`;
- 传函数引用, 不是调用结果;

```jsx
function Button() {
  function handleClick() {
    alert("点击了");
  }
  return <button onClick={handleClick}>点击</button>;
}
```

## 读取 props 与传递

- 事件处理器可读取组件 props;
- 父组件可传自定义事件 prop 给子组件;

```jsx
function Toolbar({ onPlay, onUpload }) {
  return (
    <div>
      <Button onClick={onPlay}>播放</Button>
      <Button onClick={onUpload}>上传</Button>
    </div>
  );
}
```

## 事件传播

- 事件从触发元素冒泡到祖先;
- 调用 `e.stopPropagation()` 阻止继续传播;

```jsx
function handleClick(e) {
  e.stopPropagation();
  // ...
}
```

## 捕获阶段

- 用 `onClickCapture` 在捕获阶段处理;
- 适合在子元素处理前拦截;

## 阻止默认行为

- 用 `e.preventDefault()` 阻止浏览器默认动作（如表单提交）;

## 副作用

- 事件处理器适合产生副作用: 修改 state、发请求、弹窗;
- 与渲染函数不同, 不要求纯函数;
