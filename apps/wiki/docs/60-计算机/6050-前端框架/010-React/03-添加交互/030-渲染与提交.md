# 渲染与提交

React 更新界面的三个步骤是什么？渲染不一定提交 DOM？

## 三步流程

1. 触发一次渲染;
2. React 渲染组件;
3. React 提交 DOM 变更;

## 触发渲染

- 首次渲染: 调用 `createRoot().render()`;
- 后续渲染: state 更新;

```jsx
const root = createRoot(domNode);
root.render(<App />);
```

## 渲染阶段

- React 调用组件函数, 计算新的 UI;
- 组件应保持纯粹, 渲染可被多次调用;
- 初次渲染创建全部节点; 重渲染计算差异;

## 提交阶段

- React 将差异应用到 DOM;
- 初次渲染: 插入全部 DOM 节点;
- 重渲染: 只更新变化部分;

## 浏览器绘制

- React 提交后浏览器才 paint;
- 即使组件重渲染, DOM 未变化时用户无感知;

## 性能

- 不必要的渲染会浪费计算;
- 可用 memo、useMemo 等优化, 但先保证正确性;
