# 渲染与提交

## React 渲染与提交的三步流程是什么?

1. 触发一次渲染;
2. React 渲染组件;
3. React 提交 DOM 变更;

## 什么情况下会触发一次渲染?

- 首次渲染: 调用 `createRoot().render()`;
- 后续渲染: state 更新;

```jsx
const root = createRoot(domNode);
root.render(<App />);
```

## 渲染阶段做了什么, 组件为何要保持纯粹?

- React 调用组件函数, 计算新的 UI;
- 组件应保持纯粹, 渲染可被多次调用;
- 初次渲染创建全部节点; 重渲染计算差异;

## 提交阶段如何应用 DOM 变更?

- React 将差异应用到 DOM;
- 初次渲染: 插入全部 DOM 节点;
- 重渲染: 只更新变化部分;

## 浏览器绘制发生在何时, 用户为何无感知?

- React 提交后浏览器才 paint;
- 即使组件重渲染, DOM 未变化时用户无感知;

## 渲染性能如何优化, 优化的前提是什么?

- 不必要的渲染会浪费计算;
- 可用 memo、useMemo 等优化, 但先保证正确性;
