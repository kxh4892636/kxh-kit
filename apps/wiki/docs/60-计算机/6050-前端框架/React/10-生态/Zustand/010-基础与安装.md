# Zustand 基础与安装

Zustand 是什么？如何创建和使用全局状态？

## 安装

```bash
npm install zustand
```

## 创建 store

- `create((set, get) => ({ ... }))` 定义状态和操作;
- `set` 更新状态, `get` 读取最新状态;

```js
import { create } from "zustand";

const useBearStore = create((set) => ({
  bears: 0,
  increasePopulation: () => set((state) => ({ bears: state.bears + 1 })),
  removeAllBears: () => set({ bears: 0 }),
}));
```

## 在组件中使用

- 通过 selector 选择状态片段;
- 状态变化时只重渲染使用该状态的组件;

```jsx
function BearCounter() {
  const bears = useBearStore((state) => state.bears);
  return <h1>{bears} around here ...</h1>;
}
```

## get 访问内部状态

- 在 action 中可用 `get()` 获取最新值, 避免闭包问题;

```js
const useSoundStore = create((set, get) => ({
  sound: "grunt",
  action: () => {
    const sound = get().sound;
    // ...
  },
}));
```

## 渲染机制

- state 改变后, 所有选择该 state 的组件会重新渲染;
- 只选择 action 的组件不会因 state 变化而重渲染;
