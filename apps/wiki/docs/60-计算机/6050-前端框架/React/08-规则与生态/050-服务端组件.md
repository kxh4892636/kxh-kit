# 服务端组件

Server Components 是什么？`'use client'` 如何划分客户端代码？

## Server Components

- 在打包前于独立“服务器”环境渲染;
- 可读文件、访问数据层, 不进入客户端 bundle;
- 支持 async/await;

```jsx
async function Page() {
  const content = await readFile("post.md");
  return <div>{content}</div>;
}
```

## 好处

- 减少客户端下载体积;
- 首次加载更快;
- 数据获取与渲染同处;

## 客户端组件

- 需要 state、Effect、事件时使用客户端组件;
- 文件顶部加 `'use client'`, 标记该模块及其依赖在客户端运行;

```jsx
"use client";
import { useState } from "react";

export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
```

## 边界

- Server Component 可渲染 Client Component;
- Client Component 不能直接导入 Server Component;
- 可通过 children/props 传入;

## 没有“use server”组件指令

- Server Components 不需要 `'use server'`;
- 默认文件可以是服务端组件（取决于框架约定）;

## 适用

- 框架如 Next.js App Router 支持;
- RSC 是 React 19 稳定特性;
