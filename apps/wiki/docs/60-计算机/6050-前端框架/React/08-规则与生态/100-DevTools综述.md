# DevTools 综述

React DevTools 与 Performance tracks 的概览。

## 浏览器扩展

- 检查组件树、props、state;
- 分析重渲染与性能;

## Profiler

- 记录渲染耗时;
- 找出性能瓶颈;

## Performance tracks

- 浏览器 Performance 面板中的 React 专属时间线;
- 展示 Scheduler、Renders、Cascading updates、Components 等;

## 使用

- 开发构建默认可检视;
- 生产性能分析需要 profiling build;

## 结合

- 与 StrictMode、ESLint 一起发现并修复问题;
