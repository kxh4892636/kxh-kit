# 高阶组件 HOC

高阶组件是什么？如何用 HOC 复用组件逻辑？

## 定义

- HOC: 接收组件并返回新组件的函数;
- 用于横切关注点: 权限、日志、数据注入、样式包装;

```jsx
function withLoading(Component) {
  return function WithLoading(props) {
    if (props.loading) return <Spinner />;
    return <Component {...props} />;
  };
}

const UserListWithLoading = withLoading(UserList);
```

## 约定

- HOC 不修改原组件, 而是返回新组件;
- 透传与组件无关的 props;
- 显示名便于调试: `WithLoading(UserList)`;

```jsx
function withLoading(Component) {
  function WithLoading(props) {
    return props.loading ? <Spinner /> : <Component {...props} />;
  }
  WithLoading.displayName = `WithLoading(${Component.displayName || Component.name})`;
  return WithLoading;
}
```

## 注意

- 不要在 render 中创建 HOC, 否则每次渲染都会重建组件;
- 静态方法不会自动复制, 需要时手动拷贝;
- 多个 HOC 嵌套过多会降低可读性;

## 与 Hook 对比

- Hook 更适合共享有状态逻辑;
- HOC 适合包装式增强和遗留代码迁移;
- 新代码优先考虑 Hook 或普通组件组合;
