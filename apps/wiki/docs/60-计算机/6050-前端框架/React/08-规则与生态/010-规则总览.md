# 规则总览

Rules of React 是什么？有哪些核心规则？

## 规则性质

- 不只是风格指南, 违反会导致 bug;
- 帮助写出可预测、可组合、易维护的应用;

## 三大规则

1. 组件和 Hook 必须纯净;
2. React 调用组件和 Hook;
3. Hooks 规则: 顶层调用、只从 React 函数调用;

## 工具支持

- StrictMode 在开发中检查;
- ESLint 插件 `eslint-plugin-react-hooks` 自动检查;

## 结果

- 遵循规则后 React 可安全优化;
- 代码更容易理解、调试、协作;
