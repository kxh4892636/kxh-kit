# React 19 变更与废弃

React 19 新增了什么？哪些旧 API 已移除或不再推荐？

## 新增

- Actions: `useActionState`, `useOptimistic`, `useFormStatus`, `<form action>`;
- `use()`: 在组件中读取 Promise 或 context;
- `ref` 作为普通 prop 传给函数组件, `forwardRef` 不再是必需;
- `<Activity>`: 隐藏/恢复 UI 与内部状态;
- React Compiler: 自动 memoization;

## 移除/废弃

- `ReactDOM.render` / `hydrate` → 使用 `createRoot` / `hydrateRoot`;
- `findDOMNode` 移除;
- `unmountComponentAtNode` 移除;
- `renderToNodeStream` / `renderToStaticNodeStream` → 使用流式 API;
- 类组件 `propTypes` 等不再推荐;

## 仍兼容但可简化

- `forwardRef`: 仍可用, 但 React 19 可直接传 `ref` prop;
- `memo`, `useMemo`, `useCallback`: 仍可用, React Compiler 可自动处理;
- `Children`, `cloneElement` 等 legacy API 仍导出但不推荐用于新代码;

## 升级注意

- 检查第三方库对 React 19 的兼容;
- StrictMode 可能暴露更多问题;
- 使用官方 upgrade guide 逐步迁移;
