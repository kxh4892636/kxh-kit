# 组件与 Hook 必须纯粹

纯度规则具体包含哪些要求？

## 幂等

- 组件/Hook 对相同输入返回相同结果;
- 输入包括 props、state、context;

## 副作用必须在渲染外

- 渲染期间不能修改外部变量、发送请求、写 DOM;
- 副作用放在事件处理器或 Effect;

## props 和 state 不可变

- 单个渲染中 props/state 是快照;
- 不要直接修改它们;

## Hook 参数和返回值不可变

- 传给 Hook 的值不可修改;
- Hook 返回的值也应视为不可变;

## JSX 后不可变

- 值被用于 JSX 后不要修改;
- 修改应在创建 JSX 前完成;

## 允许局部 mutation

- 渲染期间可修改“刚创建”的局部变量;
- 惰性初始化也允许;

## 为什么重要

- 保证 React 可多次调用渲染而不出错;
- 支持自动优化和并发渲染;
