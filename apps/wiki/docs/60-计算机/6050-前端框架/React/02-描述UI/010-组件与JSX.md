# 组件与 JSX

组件如何定义和使用？JSX 规则是什么？与 HTML 有何不同？

## 组件

- 组件: 返回 markup 的 JavaScript 函数;
- 定义步骤: 导出组件 → 定义函数 → 返回 JSX;
- 使用: `<MyComponent />`, 组件名大写;

```jsx
export default function Profile() {
  return <img src="photo.png" alt="me" />;
}
```

## 嵌套与组织

- 组件可以渲染其他组件;
- 一个文件可导出多个组件, 推荐每个文件一个主要组件;
- 组件树层层嵌套, 构成 UI;

## 导入与导出

- 默认导出: `export default function App()`;
- 命名导出: `export function Header()`;
- 导入默认: `import App from './App'`;
- 导入命名: `import { Header } from './App'`;
- 一个文件通常只默认导出一个组件;

## JSX

- JSX: JavaScript 中写 HTML-like markup 的语法扩展;
- 不是 HTML: 最终被编译为 JavaScript;

## JSX 规则

1. 返回单个根元素: 用 `<div>` 或 `<>...</>` 包裹;
2. 所有标签必须闭合: `<br />`;
3. 属性使用 camelCase: `className`, `tabIndex`, `onClick`;

```jsx
export default function App() {
  return (
    <>
      <h1>Hello</h1>
      <img className="avatar" src="photo.png" alt="me" />
    </>
  );
}
```

## HTML 转 JSX

- 在线转换器可辅助;
- 注意 `class` → `className`, `for` → `htmlFor`, 自闭合标签;
