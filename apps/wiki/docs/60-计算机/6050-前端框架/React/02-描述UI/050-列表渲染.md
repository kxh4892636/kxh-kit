# 列表渲染

如何用数组渲染列表？`key` 的作用和规则是什么？

## 从数组渲染

- 用 `map()` 把数组转为 JSX 列表;

```jsx
const people = ["凯", "林", "周"];
return (
  <ul>
    {people.map((name) => (
      <li key={name}>{name}</li>
    ))}
  </ul>
);
```

## 过滤

- 先用 `filter()` 得到子集, 再 `map()` 渲染;

```jsx
const chemists = people.filter((p) => p.profession === "化学家");
```

## key 规则

- key 必须唯一, 用于兄弟节点间区分;
- key 不应使用数组索引（若顺序会变化）;
- key 不会传给组件, 不能当 prop 用;

```jsx
<li key={person.id}>{person.name}</li>
```

## 为什么需要 key

- 帮助 React 识别哪些项改变、添加、删除;
- 没有稳定 key 会导致状态错位;

## 显示多个 DOM 节点

- 用 `<Fragment key={...}>` 包裹多个节点而不增加 DOM;

```jsx
import { Fragment } from "react";

{
  items.map((item) => (
    <Fragment key={item.id}>
      <h2>{item.title}</h2>
      <p>{item.body}</p>
    </Fragment>
  ));
}
```

## 注意

- 列表项组件应接收 `item` 而不是索引;
- key 只需在兄弟中唯一;
