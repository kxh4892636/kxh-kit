# 条件渲染

React 如何按条件显示不同 UI？`if`、`? :`、`&&`、`null` 怎么用？

## 返回不同 JSX

- 用 `if` 语句在组件内分支返回;

```jsx
function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <AdminPanel />;
  }
  return <LoginForm />;
}
```

## 返回空

- 返回 `null` 不渲染任何内容;
- 注意父组件布局可能受影响;

## 条件包含 JSX

- 三元运算符 `? :` 适合紧凑表达;

```jsx
<div>{isLoggedIn ? <AdminPanel /> : <LoginForm />}</div>
```

## 逻辑与 `&&`

- `{isLoggedIn && <AdminPanel />}`;
- 左侧为 falsy 时不渲染右侧;
- 注意 `0` 会渲染成 "0", 判断时用布尔值;

## 赋值给变量

- 复杂条件先算到变量, 保持 JSX 可读;

```jsx
let content;
if (isLoggedIn) {
  content = <AdminPanel />;
} else {
  content = <LoginForm />;
}
return <div>{content}</div>;
```

## 原则

- 没有特殊模板语法, 使用普通 JavaScript;
- 保持条件简单, 必要时抽成子组件;
