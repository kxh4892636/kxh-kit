# 把 UI 看作树

React 如何用树理解 UI？渲染树和模块依赖树有什么区别？

## UI 是树

- React 将组件嵌套关系建模为树;
- 树结构帮助理解数据流、渲染和状态归属;

## 渲染树

- 由组件间的父子关系构成;
- 每次渲染可能变化（条件渲染、列表）;
- 不包括 HTML 标签, 只表示 React 组件;

```text
App
├── Header
└── ProductList
    └── ProductCard
```

## 模块依赖树

- 由文件的 import/export 关系构成;
- 决定打包体积和代码拆分;
- 与渲染树不同: 模块被引用不等于一定渲染;

## 使用价值

- 调试: 定位 state 所属组件;
- 性能: 分析哪些子树会重新渲染;
- 架构: 决定组件边界和复用方式;
