# 事件机制与合成事件

React 事件如何工作？合成事件和事件委托是什么？

## 合成事件

- React 对浏览器原生事件做跨浏览器封装;
- 事件对象提供统一 API: `stopPropagation`, `preventDefault`;
- 事件处理函数接收合成事件对象;

```jsx
function handleClick(e) {
  e.preventDefault();
  e.stopPropagation();
}
```

## 事件委托

- React 将事件委托到 root 容器统一处理;
- 减少直接绑定到每个 DOM 节点;
- React 17+ 挂载到 root container, 不再挂到 document;

## 与原生事件区别

- 合成事件在冒泡/捕获行为上模拟 DOM;
- 异步访问事件对象时可能需要 `e.persist()`（旧版本）; React 17+ 不再需要;
- 在原生事件监听器中可混用, 但注意顺序;

## 实践

- 日常使用 `onClick`, `onChange` 等即可;
- 需要捕获阶段用 `onClickCapture`;
- 需要阻止冒泡用 `e.stopPropagation()`;
