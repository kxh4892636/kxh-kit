# 虚拟 DOM 与协调

虚拟 DOM 是什么？React 如何比较并更新真实 DOM？

## 虚拟 DOM

- 概念: 用内存中的对象表示 UI, 再同步到真实 DOM;
- React 中通常指 React elements / Fiber 节点;
- 不是独立技术, 而是一种模式;

## 协调（Reconciliation）

- React 比较前后两棵元素树, 计算最小 DOM 变更;
- 该过程称为协调;
- 协调发生在 render 与 commit 之间;

## Diff 策略

- 同层比较: 只比较同一层级的节点;
- 不同类型元素: 直接替换旧子树;
- 同类型元素: 保留 DOM 节点, 更新属性;
- 列表: 使用 `key` 识别移动/新增/删除;

```jsx
// key 帮助 React 识别列表项身份
<li key={item.id}>{item.name}</li>
```

## 为什么需要 key

- 没有稳定 key 时, React 难以判断元素是否移动;
- 错误 key 会导致状态错位;

## 现状

- React 19 仍使用协调与 diff;
- 官方新文档不再强调这些实现细节;
- 开发者通常无需手动干预, 只需提供正确 key;
