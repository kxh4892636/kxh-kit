# ref 引用值

什么时候用 ref？ref 与 state 的区别？最佳实践？

## ref 作用

- 记住信息但不触发重新渲染;
- 适合 timeout ID、DOM 节点、不需要参与渲染的数据;

```jsx
import { useRef } from "react";

function Stopwatch() {
  const intervalRef = useRef(null);
  // ...
}
```

## 读取与修改

- 通过 `ref.current` 读取或修改;
- 修改 ref 不会触发渲染;

## ref vs state

| 对比         | ref               | state        |
| ------------ | ----------------- | ------------ |
| 更新触发渲染 | 否                | 是           |
| 可变         | 可修改 `.current` | 不可直接修改 |
| 渲染时可读   | 是                | 是           |
| 适合         | 外部/命令式值     | UI 状态      |

## 何时使用 ref

- 存储 timeout / interval ID;
- 保存上一次值;
- 访问 DOM 节点;
- 不希望引发重渲染的缓存;

## 最佳实践

- 不要把 ref 当作“紧急 state”;
- 不要在渲染期间读写 ref（除初始化）;
- 避免在渲染中依赖 ref.current 决定输出;

## 内部原理

- `useRef(init)` 可视为 `useState({ current: init })[0]`;
- React 在组件生命周期内保留同一对象;
