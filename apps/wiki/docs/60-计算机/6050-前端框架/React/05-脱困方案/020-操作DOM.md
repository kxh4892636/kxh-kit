# 操作 DOM

如何用 ref 获取 DOM 节点？如何访问子组件 DOM？ref 回调是什么？

## 获取 DOM 节点

- 给元素传 `ref` 属性, 之后通过 `ref.current` 访问;

```jsx
function Form() {
  const inputRef = useRef(null);
  function handleClick() {
    inputRef.current.focus();
  }
  return (
    <>
      <input ref={inputRef} />
      <button onClick={handleClick}>聚焦</button>
    </>
  );
}
```

## ref 回调

- 用函数 ref 管理多个节点或动态节点;

```jsx
<input
  ref={(node) => {
    if (node) node.focus();
  }}
/>
```

## 访问子组件 DOM

- 默认不能直接拿子组件内部 DOM;
- React 19: `ref` 可作为普通 prop 传给函数组件, 无需 `forwardRef`;
- 旧写法 `forwardRef` 仍可用, 但不再是必需;
- 需要限制暴露能力时用 `useImperativeHandle`;

```jsx
// React 19: ref 作为普通 prop
function MyInput({ ref, ...props }) {
  return <input ref={ref} {...props} />;
}

// 旧写法: forwardRef 仍兼容
const MyInput = forwardRef(function MyInput(props, ref) {
  return <input ref={ref} {...props} />;
});
```

## 挂载时机

- React 提交 DOM 后设置 `ref.current`;
- 卸载前清空为 `null`;

## 与 state 同步

- 在事件或 Effect 中操作 DOM;
- 需要强制同步刷新可用 `flushSync`;

## 最佳实践

- 不要用 ref 绕过 React 做常规 UI 更新;
- 适合焦点、滚动、测量、媒体播放等命令式操作;
