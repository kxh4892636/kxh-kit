# 快速开始

组件是什么？JSX 如何写？如何显示数据、条件渲染、列表渲染？如何响应事件和更新界面？如何在组件间共享数据？

## 组件

- component: 拥有自身逻辑和外观的 UI 片段;
- 定义: JavaScript 函数返回 markup;
- 组件名: 必须以大写字母开头, HTML 标签小写;
- 嵌套: 组件可以渲染其他组件;

```jsx
function MyButton() {
  return <button>I'm a button</button>;
}

export default function MyApp() {
  return (
    <div>
      <h1>Welcome</h1>
      <MyButton />
    </div>
  );
}
```

## JSX

- JSX: JavaScript 中写 HTML-like markup 的语法;
- 比 HTML 严格: 标签必须闭合, 多个顶层标签需包在父元素或 `<>...</>` 中;
- 样式: CSS class 用 `className`;
- 显示数据: 用 `{}` 嵌入 JavaScript 变量或表达式;

```jsx
const user = { name: "Hedy Lamarr" };
return <h1>{user.name}</h1>;
```

## 条件渲染与列表

- 条件: 用 JavaScript `if`、`? :`、`&&` 控制;
- 列表: 用 `map()` 渲染, 每项需要唯一 `key`;

```jsx
const items = ["Apple", "Banana"];
return (
  <ul>
    {items.map((item) => (
      <li key={item}>{item}</li>
    ))}
  </ul>
);
```

## 事件与 State

- 事件: 给 JSX 元素传 `onClick` 等事件处理函数;
- state: 用 `useState` 声明组件记忆; 更新 state 触发重新渲染;

```jsx
import { useState } from "react";

export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>Clicked {count} times</button>;
}
```

## 共享数据

- 状态提升: 把 state 移到共同父组件, 通过 props 传给子组件;
- props: 父传子的只读数据;

```jsx
function MyApp() {
  const [count, setCount] = useState(0);
  return <MyButton count={count} onClick={() => setCount(count + 1)} />;
}

function MyButton({ count, onClick }) {
  return <button onClick={onClick}>Clicked {count} times</button>;
}
```
