# 内置组件

React 内置组件有哪些？各自用途？

## Fragment

- 分组多个节点而不增加 DOM;
- 简写 `<>...</>`;

```jsx
<>
  <h1>标题</h1>
  <p>内容</p>
</>
```

## Profiler

- 测量渲染性能: `<Profiler id="..." onRender={...}>`;
- 生产环境需 profiling build;

```jsx
<Profiler id="list" onRender={log}>
  <List />
</Profiler>
```

## Suspense

- 显示 fallback 直到 children 加载完成;
- 配合 `lazy`、数据获取、Server Components;

```jsx
<Suspense fallback={<Spinner />}>
  <SlowComponent />
</Suspense>
```

## StrictMode

- 开发模式启用额外检查: 双调用渲染、重跑 Effect、重跑 ref 回调;
- 帮助发现不纯和清理遗漏;

```jsx
<StrictMode>
  <App />
</StrictMode>
```

## Activity

- 隐藏并恢复子组件 UI 与内部 state;
- 隐藏时销毁 Effects, 恢复时重建;
- 适合后台预渲染/保持状态;

```jsx
<Activity mode={visible ? "visible" : "hidden"}>
  <Sidebar />
</Activity>
```
