# 事件溯源

事件溯源与普通状态存储有何不同？与 EDA 有何区别？有什么优缺点？

## 定义

- Event Sourcing: 不存当前状态，而用 append-only 存储记录全部事件;
- 事件存储作为系统记录源，可物化出领域对象;

## 与 EDA 区别

- EDA: 用事件在服务边界间通信;
- Event Sourcing: 用事件作为状态存储方式，是实现 EDA 的模式之一;

## 优点

- 适合实时数据报告;
- 故障安全: 可从事件存储重建数据;
- 灵活: 可存任意类型消息;
- 高合规系统审计日志首选;

## 缺点

- 需要极高效的网络基础设施;
- 需要可靠的 schema registry 控制消息格式;
- 不同事件 payload 不同;
