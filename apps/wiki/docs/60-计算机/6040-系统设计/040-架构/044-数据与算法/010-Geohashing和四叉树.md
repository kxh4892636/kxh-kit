# Geohashing 和四叉树

Geohash 如何编码坐标？四叉树解决什么空间索引问题？各有什么用途？

## Geohashing

- 定义: 把经纬度编码为短字母数字字符串;
- 示例: 旧金山 `37.7564, -122.4016` → `9q8yy9mf`;
- 原理: Base-32 层次空间索引，世界递归划分成 32 个单元，每增加字符提高精度;
- 性质: 共享前缀越长，空间越近;
- 用途: 存储位置、URL 分享、基于字符串比较找最近邻、匿名化粗略位置;

## 四叉树

- 定义: 每个内部节点恰好有 4 个孩子的树，递归把二维空间分成四象限;
- 类型: Point quadtree、PR quadtree、PM quadtree、Compressed quadtree、Edge quadtree;
- 动机: 经纬度 + 欧氏距离在大数据集上 CPU 密集不可扩展;
- 作用: 高效二维范围搜索，可设置阈值再细分，配合 Hilbert curve 提升范围查询;
- 用例: 图像表示/压缩、空间索引、地图/打车、网格生成、稀疏数据存储;
