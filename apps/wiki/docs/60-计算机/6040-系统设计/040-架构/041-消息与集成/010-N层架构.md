# N 层架构

N 层架构如何分层与分 tier？3-Tier 是什么？有什么优缺点？

## 定义

- N-tier: 把应用分为逻辑层（layer）和物理层（tier）;
- 规则: 高层可使用低层服务，反向不可;
- Tier: 物理分离、运行在不同机器; 层可共用一个 tier;
- 物理分离收益: 提升可扩展性和韧性，但增加网络延迟;

## 层间调用

- 封闭层: 只能调用紧邻的下一层;
- 开放层: 可调用任意下层;
- 封闭层限制依赖但可能产生不必要的透传流量;

## 常见类型

- 3-Tier:
  - Presentation 表示层: 处理用户交互;
  - Business Logic 业务逻辑层: 校验并处理业务;
  - Data Access 数据访问层: 操作数据库;
- 2-Tier: 客户端直接访问数据存储，无中间业务层;
- 1-Tier: 所有组件在单机运行;

## 优点

- 提升可用性;
- 安全: 层可充当防火墙;
- 独立扩展各层;
- 维护分工清晰;

## 缺点

- 整体复杂度增加;
- 网络延迟随层数增加;
- 每层硬件成本;
- 网络安全难管理;
