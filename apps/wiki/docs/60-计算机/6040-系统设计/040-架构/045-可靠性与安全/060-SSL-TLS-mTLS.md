# SSL、TLS、mTLS

SSL 与 TLS 有什么关系？TLS 提供哪些安全保证？mTLS 用于什么场景？

## SSL

- SSL: 安全套接字层，1995 年出现，已被 TLS 取代;
- 命名残留: 证书提供商仍常称 SSL 证书;
- 价值: 加密 Web 数据，防止明文泄露和篡改;

## TLS

- TLS: 传输层安全，由 SSL 演化而来，广泛用于互联网通信加密;
- 三大组件:
  - Encryption 加密: 隐藏传输数据;
  - Authentication 认证: 确认通信双方身份;
  - Integrity 完整性: 验证数据未被篡改;

## mTLS

- mTLS: 双向 TLS，双方都验证对方证书和私钥;
- 用途: 保证客户端与服务器双向可信，适用于 IoT、微服务、零信任模型;
- 场景: 不适合交互登录的设备，以及服务间相互认证;
