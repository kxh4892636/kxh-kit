# 虚拟机和容器

VM 和容器分别是什么？Hypervisor 的作用？虚拟化与容器化有何区别？

## 虚拟机

- VM: 在物理硬件上创建的虚拟计算机，拥有自己的 CPU、内存、网络和存储;
- Hypervisor/VMM: 隔离并管理虚拟机资源，把硬件资源作为资源池分配;
- 用途: 服务器整合、隔离测试环境、单用途 VM;

## 容器

- 容器: 打包代码和所有依赖的标准单元，可在不同环境一致运行;
- 特点: 抽象应用与运行环境，逻辑隔离 OS 资源;
- 优势: 开发/运维职责分离、工作负载可移植、应用隔离、敏捷开发、高效运维;

## 虚拟化 vs 容器化

- VM: Hypervisor 虚拟化物理硬件，每个 VM 含 Guest OS、虚拟硬件、应用;
- 容器: 虚拟化操作系统，只含应用和依赖，共享 OS 内核，更轻量、内存占用少;
