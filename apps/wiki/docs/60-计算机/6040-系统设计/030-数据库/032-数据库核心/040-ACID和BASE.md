# ACID 和 BASE

ACID 四个性质是什么？BASE 三个性质是什么？如何权衡？

## ACID

- Atomic 原子性: 事务内所有操作要么全部成功，要么全部回滚;
- Consistent 一致性: 事务完成后数据库结构保持有效;
- Isolated 隔离性: 事务互不干扰，表现为顺序执行;
- Durable 持久性: 事务提交并落盘后，即使系统故障也保持不变;

## BASE

- Basic Availability 基本可用: 数据库大多数时间可用;
- Soft-state 软状态: 存储不要求随时写一致，副本间不必始终一致;
- Eventual consistency 最终一致: 数据可能暂时不一致，但最终会一致;

## 权衡

- ACID 适合数据可靠性和一致性要求高的场景;
- BASE 适合追求扩展与高可用、可接受最终一致的场景;
- 无绝对正确，需根据应用需求选择;
