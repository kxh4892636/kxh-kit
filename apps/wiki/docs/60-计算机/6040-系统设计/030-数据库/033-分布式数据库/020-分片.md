# 分片

数据分区有哪两种方式？分片如何工作？有哪些分区标准和优缺点？

## 数据分区

- 数据分区: 把数据库拆成更小部分，提升可管理性、性能和可用性;
- 水平分区: 按行拆分，即 Sharding;
- 垂直分区: 按列拆分，把表分成更小的表;

## 分片定义

- Sharding: 把一张表的行拆分到多个具有相同 Schema 的独立分区/分片;
- 理由: 数据量超过一定规模后，水平加机器比垂直升配更划算;
- 实现层级: 应用层或数据库层;

## 分区标准

- Hash-Based: 基于哈希算法分配行; 动态增删服务器成本高;
- List-Based: 基于列值列表选择分区;
- Range-Based: 基于分区键的连续范围，范围不重叠;
- Composite: 组合两种或多种分区技术;

## 优点

- 高可用与逻辑独立;
- 可扩展;
- 安全（敏感/非敏感分离）;
- 查询性能提升;
- 数据可管理性;

## 缺点

- 系统复杂度增加;
- 跨分片 Join 困难;
- 数据不均时需要重新平衡;
