# 一致性哈希

传统取模哈希有什么问题？一致性哈希如何工作？虚拟节点和数据复制解决什么？

## 问题

- 传统方式: Hash(key) mod N 决定节点;
- 缺点: 节点数 N 变化时，绝大多数 key 需要重新映射，成本高;

## 一致性哈希

- 思想: 把哈希输出范围映射为抽象环，节点和 key 都放到环上;
- 路由: 请求沿顺时针找最近节点;
- 效果: 增删节点只需重分布约 K/N 的数据;

## 虚拟节点

- 问题: 实际负载常不均匀，可能产生热点;
- VNode: 每个物理节点在环上映射多个位置，把环分成更小范围;
- 优点: 负载更均匀、减少热点、加快再平衡;

## 数据复制

- 为高可用和持久性，每个数据项复制到 N 个节点;
- N 为复制因子; 最终一致系统中通常异步复制;

## 优缺点

- 优点: 快速扩缩容可预测、利于分区和复制、可扩展高可用、减少热点;
- 缺点: 复杂度高、级联故障、负载仍可能不均、节点瞬断时 key 管理成本高;
