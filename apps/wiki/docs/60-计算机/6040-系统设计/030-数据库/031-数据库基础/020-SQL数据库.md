# SQL 数据库

关系数据库如何组织数据？物化视图解决什么？N+1 问题是什么？有什么优缺点？

## 定义

- SQL 数据库: 也叫关系数据库，数据以表、列、行组织，行间通过主外键关联;
- 主键: 唯一标识一行;
- 外键: 引用另一张表的主键;
- 一致性: 通常遵循 ACID;

## 物化视图

- 物化视图: 根据查询预计算并存储的数据集;
- 优点: 查询比直接查基表更快，适合高频或复杂查询;
- 用途: 性能优化、数据子集、复制;

## N+1 查询问题

- 现象: 数据访问层执行 1 次主查询后又执行 N 次附加 SQL 获取本可一次取回的数据;
- 常见: ORM、GraphQL;
- 解决: 优化 SQL 或使用 DataLoader 批量请求;

## 优点

- 简单准确;
- 易访问;
- 数据一致;
- 灵活;

## 缺点

- 维护成本高;
- Schema 演进困难;
- Join/反规范化有性能开销;
- 水平扩展困难;
