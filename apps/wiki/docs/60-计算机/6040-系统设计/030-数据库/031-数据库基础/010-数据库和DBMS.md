# 数据库和 DBMS

数据库与 DBMS 是什么关系？常见组件有哪些？数据库有哪些类型和规模化挑战？

## 基本概念

- 数据库: 有组织地存储结构化信息的集合，通常电子化存储;
- DBMS: 数据库管理系统，是数据库与用户/程序之间的接口;
- 数据库系统: 数据 + DBMS + 相关应用的总称;

## DBMS 职责

- 检索、更新、管理数据组织与优化;
- 管理运维: 性能监控、调优、备份恢复;

## 常见组件

- Schema: 定义数据结构形态，可严格、松散或不存在;
- Table: 类似电子表格，包含多列;
- Column: 一列保存特定类型的数据值;
- Row: 表中的一条记录，可有成千上万行;

## 类型

- SQL 数据库;
- NoSQL 数据库: Document、Key-value、Graph、Time series、Wide column、Multi-model;

## 规模化挑战

- 数据量爆炸式增长;
- 数据安全与合规;
- 实时访问需求;
- 数据库与基础设施维护成本;
- 可扩展性上限;
- 数据驻留、主权和延迟要求;
