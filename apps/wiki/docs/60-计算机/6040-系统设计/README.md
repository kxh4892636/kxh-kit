## 如何阅读这组笔记？

- 路径: 网络与基础设施 → 存储建模 → 分布式数据 → 架构通信 → 可靠性安全 → 方法与案例;
- 使用方式: 先尝试回答每个问题，再阅读正文，遇到前置概念时沿相对链接复习;
- 案例边界: 五篇案例是教学设计，数值沿用题设并重算，不代表真实公司的完整架构、实时规模或当前产品限制;
- 篇幅: 普通笔记最多 144 行，案例按用户要求允许超出，以保留容量、数据、请求与失败恢复的连续推理;
