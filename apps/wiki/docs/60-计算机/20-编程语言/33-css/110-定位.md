# 定位

## position 属性

### top/bottom/left/right 属性

- 用于定位元素位置;
- 见 [[040-类型-变量]];

```css
positioned {
  position: absolute;
  top: 40px;
  left: 40px;
}
```

### 定位样式

- position 属性;

```css
positioned {
  position: static;
  position: relative;
  position: absolute;
  position: fixed;
  position: sticky;
}
```

### static positioning

- static 属性;
- normal flow 默认值;
- top/right/bottom/left/z-index 无效;

```css
positioned {
  position: static;
  background: yellow;
}
```

### relative positioning

- relative 属性;
- 根据其 normal position 定位;
- 再根据 top/bottom/left/right 偏移;

```css
positioned {
  position: relative;
  background: yellow;
}
```

### absolute positioning

- absolute 属性;
- 脱离 normal flow, 与其隔离;
- 根据其 containing block 定位;

```css
positioned {
  position: absolute;
  background: yellow;
}
```

### fixed positioning

- fixed 属性;
- 根据 viewport 计算;

```css
positioned {
  position: fixed;
  background: yellow;
}
```

### sticky positioning

##### sticky positioning

- sticky 属性;
- 根据 containing block 计算;
  - 像是 relative 和 fixed 的混合体;
  - 默认根据 relative 定位;
  - 当其滚动到 fixed 定位生效的定位时, 转换成 fixed;

```css
positioned {
  position: sticky;
  background: yellow;
}
```

##### scrolling index 机制

- 当存在多个 position 属性值为 sticky 的元素时;
- 按照其次序一层层覆盖叠加;

##### 失效问题

- 父元素高度必须大于子元素;
- 父元素 overflow 不能设置为 hidden 或 auto;

## positioning context

##### containing block

- static/relative/sticky;
  - 最近的祖先元素, 且是 block container;
- absolute;
  - 最近的祖先元素, 且其 position 属性值不是 static;
- fixed:
  - viewport;

##### initial containing block

- 具有 viewport 的尺寸;
- 包含 html 标签;

##### 创建 positioning context

- position 属性值非 static 即可;
- 推荐使用 relative;

```css
.positioned {
  position: relative;
}
```

## z-index

- z-index 属性;
- 设置对应标签的 stack level;
- z-index 属性值越大, 其 stack level 越高;
- 当元素重叠时, stack level 高者优先被显示;

```css
dashed-box {
  position: relative;
  z-index: 1;
}
```
