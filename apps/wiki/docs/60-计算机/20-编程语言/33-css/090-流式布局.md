# flow layout

## 基础

##### flow layout

- 默认布局;

## 默认行为

### 块级标签

##### inline size

- 块级标签内容填满父标签 inline 方向;

##### 排列方向

- 依赖父标签的 wirting mode;
- 不同标签之间自动换行;
- 沿 block flow 方向依次排列;

### 内联标签

##### inline size

- 内联盒 inline size 见 [[070-盒子模型]];

##### 排列方向

- 依赖父标签的 wirting mode;
- 沿 inline flow 方向依次排列;
- 直至填满父标签空间才会换行;
- 内联盒换行和盒模型行为见 [[070-盒子模型]];

## margin collapsing

- margin collapsing 规则见 [[070-盒子模型]];
