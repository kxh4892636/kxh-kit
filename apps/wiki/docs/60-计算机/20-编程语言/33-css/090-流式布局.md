# flow layout

## flow layout 概念

### flow layout

- flow layout: 默认布局模式;

## 默认行为

### 块级标签

#### inline size

- 块级盒默认填满父元素 inline direction;

##### 排列方向

- 依赖父元素 writing-mode;
- 不同标签之间自动换行;
- 沿 block flow 方向依次排列;

### 内联标签

#### inline size

- 内联盒 inline size 见 [[070-盒子模型]];

##### 排列方向

- 依赖父元素 writing-mode;
- 沿 inline flow 方向依次排列;
- 直至填满父标签空间才会换行;
- 内联盒换行和盒模型行为见 [[070-盒子模型]];

## margin collapsing

- margin collapsing 规则见 [[070-盒子模型]];
