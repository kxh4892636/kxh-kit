# for

## 三段式循环

### 语法格式

```go
func main() {
	for i := 0; i < 3; i++ { // init; condition; post
		println(i)
	}
}
```

## 条件循环

### 语法格式

```go
func main() {
	n := 3
	for n > 0 { // condition-only for; 表达类似 while 的循环
		println(n)
		n--
	}
}
```

## 无限循环

### 语法格式

```go
func main() {
	for { // 无限循环
		println("once")
		break // 退出当前循环
	}
}
```
