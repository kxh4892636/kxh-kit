# 整数

## 整数类型

### 类型表

| 类型                             | 描述                   |
| -------------------------------- | ---------------------- |
| int                              | 平台相关有符号整数     |
| uint                             | 平台相关无符号整数     |
| int8 / int16 / int32 / int64     | 固定位宽有符号整数     |
| uint8 / uint16 / uint32 / uint64 | 固定位宽无符号整数     |
| byte                             | uint8 别名             |
| rune                             | int32 别名             |
| uintptr                          | 可保存指针位模式的整数 |

## 整数字面量

### 语法格式

```go
func main() {
	decimal := 42        // 十进制
	binary := 0b101010   // 二进制
	octal := 0o52        // 八进制
	hex := 0x2a          // 十六进制
	readable := 1_000_000 // 下划线仅提升可读性
	println(decimal, binary, octal, hex, readable)
}
```

## 整数溢出

### 语法格式

```go
package main

import "fmt"

func main() {
	var n uint8 = 255 // uint8 范围为 0..255
	n++              // 溢出后回绕为 0
	fmt.Println(n)
}
```
