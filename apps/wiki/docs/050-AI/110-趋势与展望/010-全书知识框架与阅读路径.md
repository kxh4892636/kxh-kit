# 全书知识框架与阅读路径

## 这本书要解决什么问题？

- 起点: 2025 年 8 月至 10 月图灵《AI Agent 实战营》的系列课程，本书以课程讲义与配套实验为基础重构而成;
- 核心问题: 如何以可解释、可验证、可复用的工程原则设计 AI Agent，而不是依赖经验和直觉反复试错;
- 终点定位: 不以跑通一个演示系统为终点，而要进一步分析 Agent 为何采用特定架构，以及每项设计决策对应的能力边界与工程取舍;
- 成书方式: 采用 **whisper coding**（口述式协作），与语音 Agent 共同完成资料整理与文本迭代;
- 迭代周期: 口述提纲 → Agent 调研并形成草稿 → 课程反馈 → 对论证、案例与实验反复核查修订;
- 附带意义: 本书既讨论 Agent，也记录了一种由 Agent 深度参与的知识生产方式;

## 本书处在怎样的技术与产品背景中？

- 时间分界: 2025 年初 DeepSeek R1 发布以来，AI 研究与产业实践的重心从基座模型能力扩展到 Agent 的系统化落地;
- 模型侧: 智能体强化学习（Agentic RL）开始把工具调用与环境交互能力内化到模型参数中;
- 通用能力: 编程、数学推理、图形界面操作（computer use）等领域表现出更强的通用能力;
- 产品侧: Manus、Claude Code、OpenClaw 等通用 Agent 推动了人机交互方式的变化;
- 架构范式: “代码生成 + 文件系统”成为重要的系统架构范式;
- 原则的稳定性: 模型与产品快速迭代，但课程中总结的架构原则仍具有稳定的解释力，见[实践在前，命名在后](./020-实践在前命名在后.md);

## 十章如何组织成两个部分？

| 章  | 主题                       | 核心内容                                                                                                    |
| --- | -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 一  | AI Agent 入门              | 从真实产品建立直观理解；核心公式的三层理解（实现/直觉/学术）与 ReAct 循环；编排设计模式                     |
| 二  | 上下文工程                 | 全书最关键的一章；API 消息结构与核心循环、KV Cache、提示工程与提示注入、Skills 按需加载、状态栏、上下文压缩 |
| 三  | 用户记忆和知识库           | 跨会话持久化；四类记忆策略、RAG 技术栈、知识组织、Agentic RAG、多模态记忆                                   |
| 四  | 工具                       | MCP 互操作标准与五类工具设计原则；多模态感知三条路线；执行工具的安全机制                                    |
| 五  | Coding Agent 与通用 Agent  | 论证“Coding Agent + 文件系统”是通用 Agent 的核心技术基础；代码生成在编程之外的广泛价值                      |
| 六  | 交互：观察与动作空间的扩展 | 从模态与时序两维展开：异步与事件驱动、语音交互、Computer Use、机器人操作                                    |
| 七  | Agent 的评估               | 评估环境、数据集设计、LLM-as-a-Judge、评估驱动选型、结果到改进的闭环                                        |
| 八  | 模型后训练                 | SFT 与 RL；“SFT 记忆、RL 泛化”与“数据与环境比算法更重要”；奖励信号设计与多轮强化学习                        |
| 九  | Agent 的持续进化           | 学习信号（环境结果、过程规则、LLM Rubric）；四种更新载体；新版本的验证、灰度、回滚与整理                    |
| 十  | 多 Agent 协作              | 多 Agent 协作分类框架；翻译、电话与电脑协同等案例；Agent 社会与 Agent 经济的展望                            |

- 第一部分“如何构建 Agent”: 第一至六章，从基本概念到上下文、记忆与知识、工具、Coding Agent、观察与动作空间扩展;
- 第二部分“如何提升 Agent 能力”: 第七至十章，从评估到模型后训练、持续进化与多 Agent 协作;
- 第二部分的三条线: 模型参数（第八章）、单体系统（第九章）、群体系统（第十章）分别扩展能力;
- 主线公式: 十章都在 `Agent = LLM + 上下文 + 工具` 三个词里展开，见[Agent 的核心公式](../010-Agent基础/010-Agent公式与边界.md);

## 三条阅读路径分别适合谁？

| 身份         | 路径               | 理由                                                                     |
| ------------ | ------------------ | ------------------------------------------------------------------------ |
| Agent 开发者 | 按顺序读全书       | 第一至六章建立完整构建方法，第七至十章给出四个方向的能力提升             |
| 时间有限     | 先读第一章与第二章 | 第一章建立全局认知，第二章是全书最关键、最核心的上下文工程               |
| 关注模型训练 | 直接读第八章       | 评估方法（第七章）是训练的前提，建议一并阅读；先读第一至二章建立整体认知 |

- 第二章的取舍: KV Cache 底层原理较为技术化，初次阅读可先跳过原理部分，只记住开头给出的三条核心结论;
- 各章关系: 各章节相对独立，可按需求跳读，但第九章依赖前文全部基础，是“构建”转向“长期变好”的汇合点，见[模型与 Agent 的共同演进](./060-模型与Agent的共同演进.md);

## 实验与配套代码如何使用？

- 编号格式: “实验 X-Y”，X 为章节号，Y 为章节内序号;
- 难度星级: ★ 入门级，适合所有读者；★★ 中等，需要一定工程实践基础；★★★ 进阶挑战，通常涉及开放性问题或复杂系统设计;
- 仓库地址: [github.com/bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book)，正文、配图与实验代码全部开源;

```bash
git clone https://github.com/bojieli/ai-agent-book.git
cd ai-agent-book
```

- 目录组织: 实验代码按 `chapter1/` 至 `chapter10/` 分章放置;
- 查找方式: 先打开对应 `chapterX/README.md`，按实验编号找到项目目录，再按该项目自身的 README 安装依赖并运行;
- 复现指南类实验: 依赖外部仓库，具体获取方式也在相应 README 中说明;
- 使用建议: 动手跑一遍实验——该领域实践性极强，很多设计直觉只有在调试过程中才能真正建立;

## 前置知识需要准备到什么程度？

| 层次 | 知识                 | 要求与理由                                                                                         |
| ---- | -------------------- | -------------------------------------------------------------------------------------------------- |
| 必需 | Python 编程          | 几乎所有实验基于 Python；能读懂并修改中等复杂度代码即可，不要求精通                                |
| 必需 | LLM 基本使用经验     | 理解“提示词 → 模型回复”的基本交互模式                                                              |
| 必需 | 一款 AI 辅助编程工具 | 提高实验开发效率；工具本身即成熟的 Coding Agent，使用中能直观体验 ReAct 循环、工具调用与上下文管理 |
| 必需 | 软件工程常识         | 命令行、Git、JSON、REST API 是运行实验与理解工具调用机制的基础                                     |
| 推荐 | 机器学习基础         | 训练与推理、损失函数、梯度下降、过拟合，用于第八章                                                 |
| 推荐 | 基础数学             | 线性代数直观理解嵌入与注意力；概率统计用于评估指标与期望奖励；书中不涉及复杂推导                   |
| 推荐 | Web 开发基础         | HTTP、WebSocket、前后端分离，用于第六章的异步与实时通信实验                                        |
| 推荐 | Transformer 基本了解 | 用书推荐《图解大模型》，与本书的 Agent 工程视角互补                                                |

- 兜底结论: 除第八章后训练以外，全书对数学与机器学习的要求很低，前置不足也可以本书为起点;
- 核心价值: 架构设计原则与工程实践的方法论，而非某个具体算法或技巧;
