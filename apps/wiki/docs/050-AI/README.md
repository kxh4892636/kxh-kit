## 如何阅读这组笔记？

- 来源: 《深入理解 AI Agent：设计原理与工程实践》开源书（bojieli/ai-agent-book），按章整理为独立概念笔记;
- 主线: `Agent = LLM + 上下文 + 工具`；第一至六章讲构建，第七至十章讲能力提升;
- 用法: 先尝试回答每个 H2 问题，再读正文；遇到前置概念沿相对链接复习;
- 篇幅: 普通笔记最多 144 行，超长内容按语义拆分到多篇;
