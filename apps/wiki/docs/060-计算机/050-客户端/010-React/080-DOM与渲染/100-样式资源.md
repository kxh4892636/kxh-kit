# 样式资源

## 样式表如何参与加载顺序？

- 分组标识: `precedence` 是任意字符串, React 用它排 head 里样式表的顺序;
- 澄清: 它不是浏览器原生的 CSS 优先级;
- 发现顺序: 第一次出现的不同值建立较低分组, 后续新值建立较高分组; 同值样式表回到同一组;

## precedence 用 high/low 有什么问题？

- 命名无语义: high、low 不会按字面比较, 若 high 先被发现, 它仍是较低分组;

```jsx
const stylesheets = (
  <>
    <link rel="stylesheet" href="/base.css" precedence="base" />
    <link rel="stylesheet" href="/theme.css" precedence="theme" />
    <link rel="stylesheet" href="/dialog.css" precedence="base" />
  </>
);
```

```html
<!-- 同分组放在一起；theme 分组仍排在后面 -->
<link rel="stylesheet" href="/base.css" />
<link rel="stylesheet" href="/dialog.css" />
<link rel="stylesheet" href="/theme.css" />
```

- 层叠边界: 排在后面只在来源、层、`important` 与选择器权重可比时更易覆盖;
- 边界: 它不替代 CSS 级联算法;

## 什么条件下样式表会与 Suspense 协调？

- 加载协调: React 托管的外部样式表未就绪时, 依赖组件保持最近的 fallback;
- 就绪后: 再揭示, 避免 FOUC;
- 基本条件: React 渲染的 link 要同时有 `rel="stylesheet"`、稳定 href 与 `precedence`;
- 不成立时: 普通 link 或缺 `precedence` 不假定会挂起;
- 手动管理: 传 `onLoad`、`onError` 或 `disabled` 表示应用自己管加载与启用状态;
- 后果: 不再依赖 React 的那套特殊处理;

```jsx
<Suspense fallback={<EditorSkeleton />}>
  <link rel="stylesheet" href="/editor.css" precedence="page" />
  <Editor />
</Suspense>
```

- 职责分工: 浏览器负责下载与应用 CSS, React 负责决定依赖内容何时显示;

## 如何声明可去重的内联样式？

- 资源三元组: `children` 是 CSS 字符串;
- `href`: 稳定且唯一的内联样式标识;
- `precedence`: 排序分组;
- href 语义: `style` 上的 `href` 不是下载 URL;
- 相同 href: React 当作同一份资源, 只保留一份;

## href 与生命周期有什么约束？

- 一致性: 相同 href 必须对应相同 CSS; 内容版本变化时同步更换标识或哈希;

```jsx
function Button({ color }) {
  return (
    <>
      <style href="button-styles-v1" precedence="components">
        {`.button { color: var(--button-color); }`}
      </style>
      <button className="button" style={{ "--button-color": color }}>
        按钮
      </button>
    </>
  );
}

<Button color="red" />;
<Button color="blue" />;
```

- 生命周期限制: 托管的 `href`、`precedence` 与 `children` 应视为不变;
- 风险: 渲染后更新可能被忽略, 卸载后样式也可能留在 DOM;
- 动态值: 频繁变化的尺寸或颜色用 `style` prop 或 CSS 变量;
- 反例: 不要用新 `href` 不断造全局样式资源;
