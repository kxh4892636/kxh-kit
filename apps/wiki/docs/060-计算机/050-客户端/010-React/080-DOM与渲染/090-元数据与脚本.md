# 元数据与脚本

## 如何在组件中声明页面标题与元信息？

- 元数据提升: 合适的 `title`、`meta` 与 `link` 可在组件附近声明;
- 结果: 由 React 放进 head;
- 边界: 不是任意标签与属性组合都有这种提升行为;
- 标题内容: `title` 只收单个字符串;
- 插值: 先拼成字符串, 避免多个子节点形成数组;
- 页面唯一性: 同时渲染多个冲突的 title 或描述会造成不确定结果;
- 做法: 由路由或页面层明确所有者;

```jsx
const metadata = (
  <>
    <title>{`商品 ${product.name}`}</title>
    <meta name="description" content={product.summary} />
  </>
);
```

## 异步脚本的提升与去重有哪些限制？

- 脚本条件: 外部脚本的 `src` 与 `async` 等决定是否进入特殊管理;
- 反例: 不能把所有 script 都当成同一种资源行为;
- 属性更新: 已执行或已插入的脚本不会因改 props 重新运行;
- 也不会: 因卸载组件而撤销已执行的效果;
- 加载选项: `crossOrigin`、`integrity`、`nonce`、`fetchPriority`;
- 前提: 要与资源发布与安全策略匹配, 不要随意复制;

```jsx
const script = <script async src="/analytics.js" />;
```
