# 最小代码示例

## 什么时候值得用这套结构？

- 适用: 两千行以上、多端或多宿主、测试要脱离浏览器的业务前端；活动页与一次性页面不用。

## 项目结构（最小可运行）

```text
src/
├── app/container.ts                 # 组装依赖，只做 wiring
├── domain/score/score-value.ts      # 值对象：判定 + 格式化
├── domain/gateway/overview-gateway.ts   # 接口，只有类型
├── application/service/load-score.ts    # 用例：调接口 + 调值对象
├── application/dto/score-view.ts        # 读模型：已判定的结论
├── infrastructure/gateway/overview-gateway.ts  # 实现，唯一碰后端
├── infrastructure/acl/to-snapshot.ts           # 后端字段 → 事实快照
└── presentation/score-card.tsx                 # 只渲染
```

## 值对象怎么写？

```ts
// domain/score/score-value.ts —— 规则唯一来源，零依赖
export class ScoreValue {
  private constructor(readonly raw: number) {}
  static of(raw: number) {
    return new ScoreValue(raw);
  }
  isValid() {
    return Number.isFinite(this.raw) && this.raw !== -9999;
  }
  formatSigned(kind: "plus" | "minus") {
    if (!this.isValid()) return "-";
    return this.raw === 0 ? "0" : kind === "plus" ? `+${this.raw}` : `-${Math.abs(this.raw)}`;
  }
}
```

## 接口与用例怎么写？

```ts
// domain/gateway/overview-gateway.ts —— 只有类型，编译后擦除
export interface OverviewGateway {
  fetchScore(nodeId: string): Promise<{ nodeId: string; score: number; masked: boolean }>;
}

// application/service/load-score.ts —— 编排，不写 HTTP 与 JSX
export const loadScore = async (deps: { gateway: OverviewGateway }, nodeId: string) => {
  const snap = await deps.gateway.fetchScore(nodeId);
  const score = ScoreValue.of(snap.score);
  return {
    nodeId,
    visible: !snap.masked,
    valid: score.isValid(),
    score: score.isValid() ? snap.score : null,
  };
};
```

## 实现与翻译怎么写？

```ts
// infrastructure/gateway/overview-gateway.ts
export const createOverviewGateway = (): OverviewGateway => ({
  async fetchScore(nodeId) {
    return toSnapshot(await GetScore({ sub_score_node: Number(nodeId) })); // 后端 SDK → acl
  },
});

// infrastructure/acl/to-snapshot.ts —— 唯一出现后端字段名的地方
export const toSnapshot = (res: { score?: number; is_mask_detail?: boolean }) => ({
  nodeId: String(res.sub_score_node ?? ""),
  score: Number(res.score ?? -9999),
  masked: res.is_mask_detail === true,
});
```

## 组装与视图怎么写？

```ts
// app/container.ts —— 唯一同时依赖全部层的地方
export const deps = { gateway: createOverviewGateway() };

// presentation/score-card.tsx —— 只消费结论，不做判定
export const ScoreCard = ({ view }: { view: ScoreView }) =>
  view.visible ? <span>{ScoreValue.of(view.score ?? -9999).formatSigned('plus')}</span> : null;
```

## 怎么验证这套是通的？

- 换实现: 写一个返回静态数据的 `gateway`，只改 `container`，其余零改动;
- 脱离浏览器: 用例与值对象能被脚本运行时直接执行，不需要 jsdom;
- 改后端字段: 只改 `acl`，`application` 与 `presentation` 不动。

分层与依赖的原理见 [分层结构与依赖关系](./010-分层结构与依赖关系.md)。
