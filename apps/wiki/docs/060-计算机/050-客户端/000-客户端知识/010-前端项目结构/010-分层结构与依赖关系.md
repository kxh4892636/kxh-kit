# 分层结构与依赖关系

## 前端的项目结构是什么？

```text
src/
├── app/                        # 组合根
│   ├── bootstrap.ts            #   启动入口
│   ├── routes.tsx              #   路由表
│   └── container.ts            #   依赖装配
├── ui/                         # 表现层 (UI 框架相关)
│   ├── pages/                  #   页面装配：只拼装模块，不写业务
│   ├── features/               #   页面级业务模块，对外只暴露 index
│   │   └── <模块>/{index.tsx, component/, hook/, model/}
│   ├── components/{base,biz}/  #   基础组件 / 跨模块业务组件
│   └── utils/                  #   无状态的工具函数
│   └── hooks/                  #   通用 hook，不装业务数据逻辑
├── core/                       # 领域层 (第三方框架无关)
│   ├── shared/                 #   跨子域基础类型（标识、无效值）
│   ├── <子域>/                 #   数据模型, 业务规则, 状态迁移, acl (DTO → model)
│   └── gateway/                #   后端接口声明，只有类型
└── libs/                       # 基础设施层 (第三方框架相关, 有副作用的工具函数)
    ├── request/                #   请求实例、重试、环境参数
    ├── gateway/                #   接口实现，唯一碰外部系统的地方
    └── runtime/                #   平台识别、时钟、构建期配置
```

各层的职责边界:

| 层         | 为什么需要它                 | 放什么                             | 不放什么             |
| ---------- | ---------------------------- | ---------------------------------- | -------------------- |
| 表现层     | 承载交互与视觉, 变化最快     | 页面、组件、交互、文案             | 业务判定、外部字段名 |
| 领域层     | 规则唯一来源, 可脱离环境执行 | 判定、计算、格式化口径、节点注册表 | 请求、框架、平台 SDK |
| 基础设施层 | 隔离外部系统, 可整体替换     | 请求、埋点、导航、翻译、环境参数   | 业务判定、用例签名   |

## 层与层之间是什么关系？

依赖是单向的: 外层可以依赖内层, 内层不能依赖外层; 表格里是「行可以导入列」:

| 从 ↓ 可依赖 → | ui  | libs | core |
| ------------- | --- | ---- | ---- |
| ui            | ✔   | ✔    | ✔    |
| libs          | ✘   | ✔    | ✔    |
| core          | ✘   | ✘    | ✔    |

## 数据在层间怎么流动？

| 形状     | 由谁生产   | 内容                           | 例子                                            |
| -------- | ---------- | ------------------------------ | ----------------------------------------------- |
| 事实快照 | 基础设施层 | 外部数据换成领域语言, 保留原值 | `{ nodeId: '101', score: -9999, masked: true }` |
| 值对象   | 领域层     | 判定与格式化能力               | `formatSigned('plus')` → `+3`                   |
| 读模型   | 应用层     | 已判定的结论、默认值           | `{ visible: false, valid: false, score: null }` |

链路:

```text
接口响应 → acl 翻译 → 事实快照 → 用例调用值对象 → 读模型 → 视图
```

两条边界:

- 外部字段名只允许出现在 `acl/`;
- 文案与格式化后的字符串只允许出现在视图;
