# 表达式与表达式构造器

## `Expression` 是什么？

- Kysely 的基本积木：任意一段 SQL 值或条件，带输出类型 `T`;
- 几乎一切都实现它——查询 builder、`sql` 模板、`fn()`、`eb()` 的返回值;
- 表达式可以互相嵌套，这是「抽公共查询片段」的基础。

## `eb` 怎么拿到，里面有什么？

- 通过回调拿到，回调参数同时带 `fn`、`ref`、`val`、`lit`、`and`、`or`、`not`、`exists`、`selectFrom`;
- 用回调而不是全局实例，才能让 Kysely 知道当前上下文有哪些表;

| 方法                                   | 作用                           | 示例                             |
| -------------------------------------- | ------------------------------ | -------------------------------- |
| `eb(左, 操作符, 右)`                   | 二元表达式                     | `eb('age', '>', 18)`             |
| `eb.fn(名, 参)`                        | 调任意函数，参数默认按列名解析 | `eb.fn('upper', ['first_name'])` |
| `eb.fn.count/countAll/avg/sum/min/max` | 常用聚合                       | `eb.fn.countAll<number>()`       |
| `eb.ref(列)`                           | 列引用                         | `eb.ref('person.id')`            |
| `eb.val(值)`                           | 参数化值（走占位符）           | `eb.val('Ms. ')`                 |
| `eb.lit(值)`                           | 字面量（直接拼进 SQL）         | `eb.lit(42)`                     |
| `eb.exists(子查询)`                    | `exists (...)`                 | `eb.exists(子查询)`              |

## 表达式能用在哪里？

- `select`、`where`、`having`、`on`、`orderBy`、`groupBy`、`set` 都接受表达式或表达式回调;
- `select` 里用表达式必须 `.as('名字')`，否则无法给结果字段命名（编译报错）;

```ts
const rows = await db
  .selectFrom("person")
  .select((eb) => [
    eb.fn("upper", ["first_name"]).as("upper_first_name"),
    eb.fn.countAll<number>().as("total"),
    eb.val("Some value").as("string_value"),
    eb.lit(42).as("literal_value"),
    eb("first_name", "=", "Jennifer").as("is_jennifer"),
  ])
  .groupBy("first_name")
  .execute();
```

## `sql` 模板和 `eb` 有什么区别？

- `sql` 里插入的普通值自动变成**参数**，列名要用 `sql.ref` 包;
- 用它兜住 Kysely 没有专门方法的语法，但混进去的列名不再受类型检查;

```ts
import { sql } from "kysely";

sql<string>`upper(first_name)`; // 参数化，但列名不受检查
sql<string>`upper(${sql.ref("first_name")})`; // 列引用交给 ref，保留检查
sql.join([sql.ref("a"), sql.ref("b")], sql`, `); // "a", "b"
sql`${sql.id("t", "c")}`; // "t"."c"
sql`select * from ${sql.table("person")}`; // 标识符自动加引号
```

## 为什么要用回调而不是自己造 `eb`？

- `expressionBuilder<DB>()` 造出的实例不带表上下文，适合写与调用方无关的 helper;
- 回调形式能把当前所有可见表带进上下文，写完就查、类型更安全;
- 需要跨查询复用时，见 [可复用查询函数](./050-可复用表达式函数.md)。
