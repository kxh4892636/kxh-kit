# 跑通一次增删改查

## 一次完整跑通要写什么？

```ts title="src/main.ts"
import { db } from "./db";
import { createSchema } from "./schema";

// 1. 建表（DDL 见 050-建表与索引，真实项目写进迁移）
await createSchema();

// 2. 插入并拿到整行
const person = await db
  .insertInto("person")
  .values({ first_name: "Jennifer", last_name: "Aniston", gender: "woman" })
  .returningAll()
  .executeTakeFirstOrThrow();

await db.insertInto("pet").values({ name: "Catto", owner_id: person.id }).execute();

// 3. 查询
const rows = await db
  .selectFrom("person")
  .innerJoin("pet", "pet.owner_id", "person.id")
  .select(["person.first_name", "pet.name as pet_name"])
  .execute();

// 4. 更新
const updated = await db
  .updateTable("person")
  .set({ last_name: "Aniston-Clark" })
  .where("id", "=", person.id)
  .executeTakeFirst();

// 5. 删除（pet 随外键级联删除）
const removed = await db.deleteFrom("person").where("id", "=", person.id).executeTakeFirst();

console.log(rows); // [ { first_name: 'Jennifer', pet_name: 'Catto' } ]
console.log(updated.numUpdatedRows, removed.numDeletedRows); // 1n 1n

await db.destroy();
```

```bash
npx tsx src/main.ts
```

## 每一步的关键点是什么？

| 步骤      | 关键点                                    | 细节                                                                              |
| --------- | ----------------------------------------- | --------------------------------------------------------------------------------- |
| 建表      | 每次 DDL 都要 `.execute()`                | [建表与索引](./050-建表与索引.md)                                                 |
| 插入      | `.returningAll()` 省掉再查一次            | [插入数据](../030-写入数据/010-插入数据.md)                                       |
| 查询      | `executeTakeFirst()` 可能返回 `undefined` | [选择列与别名](../020-查询数据/010-选择列与别名.md)                               |
| 更新/删除 | 别漏 `.where()`；影响行数是 `bigint`      | [更新](../030-写入数据/020-更新数据.md) / [删除](../030-写入数据/030-删除数据.md) |

## 跑完应该看到什么？

- 控制台打印一行查询结果，库文件 `dev.sqlite` 出现并有数据;
- 报 `no such table` 说明建表没执行，检查是否漏了 `.execute()`;
- 完整报错对照见 [常见报错与排障](../060-速查/010-常见报错与排障.md)。
