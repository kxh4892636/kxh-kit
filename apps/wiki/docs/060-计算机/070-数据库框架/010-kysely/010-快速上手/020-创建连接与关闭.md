# 创建连接与关闭

## 怎样创建 Kysely 实例？

- `Dialect` 负责「怎么和数据库说话」，`better-sqlite3` 负责「真正执行 SQL」;
- 整个进程只建一个实例：SQLite 驱动内部管理连接，无需按请求新建;

```ts title="src/db.ts"
import SQLite from "better-sqlite3";
import { Kysely, SqliteDialect } from "kysely";
import type { Database } from "./types";

const dialect = new SqliteDialect({
  database: new SQLite("dev.sqlite"), // 文件不存在会自动创建；测试可传 ':memory:'
});

export const db = new Kysely<Database>({ dialect });
```

## 实例上有哪些可配置项？

- `KyselyConfig` 只有三样东西：`dialect`、`plugins`、`log`;

```ts
export const db = new Kysely<Database>({
  dialect,
  plugins: [], // 见 050-进阶/010-插件与日志
  log: ["error"], // 'query' | 'error'，或自定义函数
});
```

- 连接参数（库路径、`timeout`、WAL）写在 `SqliteDialect` 与 `better-sqlite3` 构造函数里;
- 生产环境的路径用环境变量，别提交 `.env` 或凭据。

## 怎么确认连上了？

- 驱动是懒初始化的：第一次查询才真正打开数据库，所以「建实例成功」不代表连通;
- 执行任意一条查询即可验证;

```ts title="src/ping.ts"
import { sql } from "kysely";
import { db } from "./db";

const result = await sql<{ ok: number }>`select 1 as ok`.execute(db);
console.log(result.rows); // [ { ok: 1 } ]
```

## 用完为什么必须 `destroy()`？

- 释放文件句柄与 WAL，否则进程可能不退出、文件被锁;
- 显式事务未结束时，`destroy()` 会回滚;
- 长驻服务在退出信号里关闭，脚本在末尾关闭;

```ts
process.on("SIGTERM", async () => {
  await db.destroy();
  process.exit(0);
});
```

## 什么时候不该 `destroy()`？

- `better-sqlite3` 实例由外部（测试框架、其他模块）持有并负责关闭时跳过;
- 判断标准：谁创建、谁关闭，别两边都关;
- 换数据库只换 `Dialect` 与驱动，查询代码不变，见官方 [Dialects](https://kysely.dev/docs/dialects)。
