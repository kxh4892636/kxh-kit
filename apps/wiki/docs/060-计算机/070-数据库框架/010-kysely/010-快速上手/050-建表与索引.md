# 建表与索引

## 建一张表最少要写什么？

- `db.schema.createTable` 链式描述列，最后 `.execute()` 才真正执行;
- 省掉 `.execute()` 什么也不会发生——builder 只是意图;

```ts title="src/setup.ts"
export async function createPersonTable() {
  await db.schema
    .createTable("person")
    .addColumn("id", "integer", (col) => col.primaryKey().autoIncrement())
    .addColumn("first_name", "text", (col) => col.notNull())
    .addColumn("last_name", "text")
    .addColumn("gender", "text", (col) => col.notNull())
    .addColumn("created_at", "text", (col) => col.notNull().defaultTo(sql`CURRENT_TIMESTAMP`))
    .execute();
}
```

## 列约束怎么写？

| 约束   | 写法                                              | 说明                                      |
| ------ | ------------------------------------------------- | ----------------------------------------- |
| 非空   | `col.notNull()`                                   | 插入必须给值                              |
| 唯一   | `col.unique()`                                    | 与 `onConflict` 配合做 upsert             |
| 主键   | `col.primaryKey()`                                | SQLite 需配 `integer` + `autoIncrement()` |
| 默认值 | `col.defaultTo(值)` 或 `defaultTo(sql\`...\`)`    | SQLite 的时间默认用 `CURRENT_TIMESTAMP`   |
| 外键   | `col.references('person.id').onDelete('cascade')` | better-sqlite3 默认开启外键检查           |

```ts
await db.schema
  .createTable("pet")
  .addColumn("id", "integer", (col) => col.primaryKey().autoIncrement())
  .addColumn("name", "text", (col) => col.notNull().unique())
  .addColumn("owner_id", "integer", (col) =>
    col.references("person.id").onDelete("cascade").notNull(),
  )
  .addColumn("species", "text", (col) => col.notNull())
  .execute();
```

## 建表时要不要加 `ifNotExists`？

- 幂等脚本可以用 `.ifNotExists()`，重复执行不报错;
- 迁移文件里不需要：Kysely 保证每个迁移只执行一次，见 [编写迁移文件](../040-事务与迁移/030-编写迁移文件.md)。

```ts
await db.schema
  .createTable("pet")
  .ifNotExists()
  .addColumn("id", "integer", (c) => c.primaryKey())
  .execute();
```

## 索引怎么建和删？

```ts
await db.schema.createIndex("pet_owner_id_index").on("pet").column("owner_id").execute();
await db.schema.dropIndex("pet_owner_id_index").ifExists().execute();
```

- 外键列、常用过滤列、`orderBy` 列都建议建索引，否则 SQLite 全表扫描;
- 唯一索引用 `.createIndex('x').on('t').columns(['a', 'b']).unique()`。

- 一次性实验/测试: 直接调用上面的函数;
