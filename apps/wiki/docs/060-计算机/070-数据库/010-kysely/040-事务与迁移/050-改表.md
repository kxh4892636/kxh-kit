# 改表

## 改表有哪些常用操作？

| 操作      | 写法                                                        |
| --------- | ----------------------------------------------------------- |
| 加列      | `alterTable('t').addColumn('c', 'text', cb)`                |
| 改列名    | `alterTable('t').renameColumn('old', 'new')`                |
| 删列      | `alterTable('t').dropColumn('c')`                           |
| 改表名    | `alterTable('t').renameTo('t2')`                            |
| 加索引    | `createIndex('idx').on('t').column('c')`                    |
| 删索引/表 | `dropIndex('idx').ifExists()` / `dropTable('t').ifExists()` |

- 每个操作都要以 `.execute()` 结尾;
- 迁移里的 `up`/`down` 要成对写，`down` 把结构还原;

## 一次「加列 + 加索引」的迁移怎么写？

```ts title="migrations/2026-02-01T00-00-00-add-pet-age.ts"
import { Kysely } from "kysely";

export async function up(db: Kysely<any>): Promise<void> {
  await db.schema
    .alterTable("pet")
    .addColumn("age", "integer", (col) => col.defaultTo(0))
    .execute();
  await db.schema.createIndex("pet_age_index").on("pet").column("age").execute();
}

export async function down(db: Kysely<any>): Promise<void> {
  await db.schema.dropIndex("pet_age_index").ifExists().execute();
  await db.schema.alterTable("pet").dropColumn("age").execute();
}
```

- 加非空列时给 `defaultTo`，否则已有行会违反约束;
- 删列前先确认代码里没有引用，Kysely 的类型检查帮不了历史数据。

## SQLite 对改表有哪些限制？

| 能力              | SQLite                             |
| ----------------- | ---------------------------------- |
| 加列              | 支持（`NOT NULL` 需带默认值）      |
| 改列名            | 3.25+                              |
| 删列              | 3.35+                              |
| 改列类型 / 加约束 | 不支持，需「建新表 → 拷贝 → 改名」 |
| 加外键约束        | 不支持事后添加                     |

- 重建表的套路：`createTable('t_new')` → `sql\`insert into t_new select ... from t\``→`dropTable('t')`→`renameTo`;
- 重建期间要放在一个事务里，见 [事务与保存点](./010-事务.md)。

- 索引怎么建、怎么验证命中、视图怎么管，见 [索引与视图](./060-索引与视图.md)。
