# 删除数据

## 删除一行怎么写？

```ts
const result = await db.deleteFrom("person").where("id", "=", 1).executeTakeFirst();

console.log(result.numDeletedRows); // 1n（bigint）
```

- `.where()` 依旧必写，漏掉就是清库;
- 影响行数是 `bigint`，与更新一致。

## 想拿回被删的行怎么办？

- 加 `.returningAll()` / `.returning([...])`，结果是被删的行;
- 带 `returning` 时不再返回 `numDeletedRows`;

```ts
const deletedRows = await db.deleteFrom("pet").where("name", "=", "Catto").returningAll().execute();

const removeResult = await db
  .deleteFrom("pet")
  .where("name", "=", "Doggo")
  .executeTakeFirstOrThrow();

console.log(deletedRows); // [ { id: 1, name: 'Catto' } ]
console.log(removeResult.numDeletedRows); // 1n
```

## 子表数据会跟着删吗？

- 建表时写了 `onDelete('cascade')` 就会级联删除;
- better-sqlite3 默认开启 `PRAGMA foreign_keys = ON`，所以外键约束是生效的;

```ts
.addColumn('owner_id', 'integer', (col) => col.references('person.id').onDelete('cascade').notNull())
```

- 没有外键约束时只能手动按顺序删，或用 `where('owner_id', 'in', 子查询)`。

## 想清空整张表怎么办？

- SQLite 没有 `truncate`，用 `delete from`;
- `delete from` 不重置自增计数，需要重置就清掉 `sqlite_sequence` 里对应的行;

```ts
import { sql } from "kysely";

await sql`delete from ${sql.table("person")}`.execute(db);

// 让自增 id 从头开始（开发/测试环境才有意义）
await sql`delete from sqlite_sequence where name = ${sql.lit("person")}`.execute(db);
```

## 软删除该怎么做？

- Kysely 不提供软删除，自己在表里加 `deleted_at` 列，查询时过滤;
- 好处是可恢复、可审计；坏处是每个查询都要记得加条件，容易漏;

```ts
await db
  .updateTable("person")
  .set({ deleted_at: sql`CURRENT_TIMESTAMP` })
  .where("id", "=", 1)
  .execute();

const alive = await db.selectFrom("person").selectAll().where("deleted_at", "is", null).execute();
```

- 需要彻底清理时再物理删除，见 [冲突处理与批量写入](./040-冲突处理.md) 的批量写法。
