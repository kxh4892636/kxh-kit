# 更新数据

## 更新一行最少要写什么？

- `.set()` 只写要改的列，`Updateable` 让所有列可选;
- 一定要带 `.where()`，否则整表更新——Kysely 不会替你拦;

```ts
const result = await db
  .updateTable("person")
  .set({ last_name: "Aniston-Clark" })
  .where("id", "=", 1)
  .executeTakeFirst();

console.log(result.numUpdatedRows); // 1n（bigint）
```

## `set` 里能放表达式和子查询吗？

- 能。`set` 接受回调，可以基于当前值递增、引用其它列、塞子查询结果;

```ts
await db
  .updateTable("person")
  .set((eb) => ({
    age: eb("age", "+", 1),
    last_name: eb.selectFrom("pet").select("name").limit(1),
  }))
  .where("id", "=", 1)
  .execute();
```

## 更新时想拿到改后的行怎么办？

- 加 `.returningAll()` 或 `.returning([...])`；SQLite 3.35+ 支持 `returning`;
- 带 `returning` 时结果就是行对象，不再返回影响行数;

```ts
const updated = await db
  .updateTable("person")
  .set({ gender: "other" })
  .where("first_name", "=", "Arnold")
  .returning(["id", "gender"])
  .executeTakeFirstOrThrow();
```

## 影响行数是 `number` 还是 `bigint`？

| 字段                       | 类型     | 出现时机         |
| -------------------------- | -------- | ---------------- |
| `numUpdatedRows`           | `bigint` | 不带 `returning` |
| `numDeletedRows`           | `bigint` | 不带 `returning` |
| `numInsertedOrUpdatedRows` | `bigint` | 插入 / upsert    |

```ts
const changed = Number(result.numUpdatedRows); // 需要 number 时显式转换
```

## 更新时最容易犯什么错？

- 忘 `.where()`：整表被改，且没有任何提示;
- 用 `=` 与 `null` 比较永远不成立，要用 `is`;
- 显式事务里更新完忘 `commit()`，见 [事务](../040-事务与迁移/010-事务.md);
- 批量场景见 [批量写入](./060-批量写入.md)。
