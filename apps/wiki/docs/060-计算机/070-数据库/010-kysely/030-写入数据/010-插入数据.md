# 插入数据

## 插入一行最少要写什么？

- `.values({...})` 里只给必填列，`Generated` 列自动可选;
- `.values()` 是个赋值动作，调第二次会**覆盖**前一次，多行必须用数组;

```ts
const inserted = await db
  .insertInto("person")
  .values({ first_name: "Jennifer", last_name: "Aniston", gender: "woman" })
  .executeTakeFirst();

console.log(inserted.insertId); // 1n（bigint，SQLite/MySQL 才有；PostgreSQL 需 returning）
```

## 多行插入怎么写？

```ts
await db
  .insertInto("person")
  .values([
    { first_name: "Jennifer", last_name: "Aniston", gender: "woman" },
    { first_name: "Arnold", last_name: "Schwarzenegger", gender: "man" },
  ])
  .execute();
```

- 数组元素的列必须一致，缺列要显式写 `null`（不要指望 Kysely 帮你切列）;
- 想拿到插入后的整行，加 `.returningAll()`；只要部分列用 `.returning(['id'])`。

## 值可以是表达式或子查询吗？

- 可以。`values` 也接受回调，回调里拿 `ref`、`val`、`fn`、`selectFrom`;
- 典型场景：默认值引用别的列、插入时算一个聚合值;

```ts
const inserted = await db
  .insertInto("person")
  .values(({ ref, selectFrom, fn }) => ({
    first_name: "Jennifer",
    last_name: ref("first_name"), // 引用同一次插入的其它列
    gender: "woman",
    age: selectFrom("person").select(fn.avg<number>("age").as("avg_age")),
  }))
  .executeTakeFirst();
```

## 用 `select` 的结果批量插入怎么写？

- `.columns([...])` 声明目标列，`.expression(查询)` 给出数据来源，列顺序必须对齐;

```ts
await db
  .insertInto("person")
  .columns(["first_name", "last_name", "age"])
  .expression((eb) =>
    eb
      .selectFrom("pet")
      .select((eb) => ["pet.name", eb.val("Petson").as("last_name"), eb.lit(7).as("age")]),
  )
  .execute();
```

## 插入失败常见原因是什么？

| 报错                            | 原因               | 处理                                                |
| ------------------------------- | ------------------ | --------------------------------------------------- |
| `NOT NULL constraint failed`    | 必填列没给值       | 补值，或建表时加 `defaultTo`                        |
| `UNIQUE constraint failed`      | 主键/唯一索引冲突  | 改用 `onConflict`，见 [冲突处理](./040-冲突处理.md) |
| `FOREIGN KEY constraint failed` | 外键指向的行不存在 | 先插父表；better-sqlite3 默认开启外键               |
| `datatype mismatch`             | 类型与列声明不符   | 核对 `Database` 与运行时值                          |
