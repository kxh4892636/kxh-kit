# 冲突处理

## 主键冲突时除了报错还能做什么？

- 用 `.onConflict()` 声明冲突目标，再选三种收尾之一：忽略、更新、什么都不做;
- SQLite 与 PostgreSQL 支持 `on conflict`；MySQL 用 `ignore` / `onDuplicateKeyUpdate`;

| 收尾                      | 生成 SQL                              | 用途                 |
| ------------------------- | ------------------------------------- | -------------------- |
| `.doNothing()`            | `on conflict (col) do nothing`        | 幂等初始化、去重导入 |
| `.doUpdateSet({...})`     | `on conflict (col) do update set ...` | upsert               |
| `.doUpdateSet(eb => ...)` | 用 `excluded.列` 取待插入的值         | 增量累加、以新值覆盖 |

## 怎样写一个最简 upsert？

```ts
await db
  .insertInto("pet")
  .values({ name: "Catto", species: "cat", owner_id: 1 })
  .onConflict((oc) => oc.column("name").doUpdateSet({ species: "cat" }))
  .execute();
```

- `.column('name')` 要求该列有唯一索引或主键，否则 SQLite 直接报错;
- 复合唯一键用 `.columns(['a', 'b'])`，命名约束用 `.constraint('约束名')`。

## 冲突后怎么取值、怎么加条件？

- 用 `excluded` 引用「本来要插入的值」;
- 可以直接基于旧值累加，也能在 `doUpdateSet` 后加 `.where()` 决定是否更新;
- 三种套路与注意事项见 [upsert 的取值与条件](./050-upsert的取值与条件.md)。

## `onConflict` 之前要先有唯一约束吗？

- 必须有，否则数据库报「没有匹配的冲突目标」;
- 建表时用 `col.unique()` 或 `.createIndex('x').on('t').column('c').unique()`，见 [建表与索引](../010-快速上手/050-建表与索引.md);
- 上万行导入的批处理写法见 [批量写入](./060-批量写入.md)。
