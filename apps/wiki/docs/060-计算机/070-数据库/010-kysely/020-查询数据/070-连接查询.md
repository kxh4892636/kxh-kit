# 连接查询

## 有哪几种 join，SQLite 支持哪些？

| 方法        | 语义                      | SQLite |
| ----------- | ------------------------- | ------ |
| `innerJoin` | 两边都匹配才留            | 支持   |
| `leftJoin`  | 左表全留，右表缺失补 null | 支持   |
| `rightJoin` | 右表全留                  | 3.39+  |
| `fullJoin`  | 两边全留                  | 3.39+  |

```ts
const rows = await db
  .selectFrom("person")
  .leftJoin("pet", "pet.owner_id", "person.id")
  .select(["person.id", "pet.name as pet_name"]) // leftJoin 后 pet.name 自动带 null
  .execute();
```

## 连接条件复杂时怎么写？

- 简写 `join(表, 左列, 右列)` 只够等值连接;
- 多条件、含值条件、含 `or` 时用回调：`onRef` 比较两列，`on` 比较列与值;

```ts
const rows = await db
  .selectFrom("person")
  .innerJoin("pet", (join) =>
    join
      .onRef("pet.owner_id", "=", "person.id")
      .on("pet.species", "=", "dog")
      .on((eb) => eb.or([eb("person.age", ">", 18), eb("person.age", "<", 100)])),
  )
  .selectAll()
  .execute();
```
