# 选择列与别名

## 一次查询能选哪些形态的列？

| 写法                                   | 含义                                  | 结果字段            |
| -------------------------------------- | ------------------------------------- | ------------------- |
| `.select('id')`                        | 单列，列名唯一时可省略表名            | `id`                |
| `.select('person.id')`                 | 带表名，多表查询必写                  | `id`                |
| `.select(['person.id', 'first_name'])` | 多列，顺序即 SQL 顺序                 | 同名                |
| `.select('first_name as fn')`          | 别名用 SQL 风格字符串                 | `fn`                |
| `.selectFrom('person as p')`           | 表别名（写在 `selectFrom`/`join` 里） | 之后用 `p.xxx` 引用 |
| `.selectAll()`                         | 当前上下文所有列                      | 各列原名            |
| `.selectAll('person')`                 | 指定表的全部列                        | 各列原名            |

```ts
const rows = await db
  .selectFrom("person as p")
  .innerJoin("pet", "pet.owner_id", "p.id")
  .select(["p.id", "p.last_name as ln", "pet.name as pet_name"])
  .execute();
// 类型: { id: number; ln: string | null; pet_name: string }[]
```

## 结果类型会不会带出别名？

- 会。别名是类型的一部分，`as` 之后的字段名就是结果里的键;
- 别名不能省——`select` 里用表达式时不写 `as` 会编译报错，因为 Kysely 无法给结果字段命名;

```ts
// ✅ 表达式必须显式命名
.select((eb) => [eb.fn('upper', ['first_name']).as('upper_first_name')])

// ❌ 没有名字，类型系统无从生成字段
.select((eb) => [eb.fn('upper', ['first_name'])])
```

## 去重怎么写？

- `.distinct()` 作用于整行：所选列完全相同的行只留一条;
- `distinct on (...)` 是 PostgreSQL 专有写法，SQLite 不支持，需要时改用 `group by` 或窗口函数;

```ts
const firstNames = await db.selectFrom("person").select("first_name").distinct().execute();
```

## 可空列怎么变非空？

- `where('last_name', 'is not', null)` 只影响查询条件，**不会**改变结果类型;
- 明确知道不为空时，用 `$narrowType` 手动收窄;

```ts
const rows = await db
  .selectFrom("person")
  .select(["id", "last_name"])
  .where("last_name", "is not", null)
  .$narrowType<{ last_name: string }>()
  .execute();
```

- 更多类型收窄手段见 [生成与修正类型](../050-进阶/060-修正查询结果类型.md);
- 需要把子表作为嵌套字段返回时，见 [嵌套关联查询](../050-进阶/030-嵌套关联查询.md)。
