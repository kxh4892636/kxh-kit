# 子查询与 CTE

## `where in` 的子查询怎么写？

- `where('列', 'in', 子查询)` 直接嵌，不要先 `execute` 再塞数组;
- 子查询只选一列，列名要与左侧类型兼容;

```ts
const rows = await db
  .selectFrom("person")
  .selectAll()
  .where("id", "in", db.selectFrom("pet").select("pet.owner_id").where("pet.species", "=", "dog"))
  .execute();
```

## 子查询与外表有关联怎么办？

- 用 `whereRef` 引用外表的列，形成关联子查询;
- 这类查询每个外层行都会执行一次子查询，注意索引;

```ts
const rows = await db
  .selectFrom("person")
  .select((eb) => [
    "person.id",
    eb
      .selectFrom("pet")
      .whereRef("pet.owner_id", "=", "person.id")
      .select(eb.fn.countAll<number>())
      .as("pet_count"),
  ])
  .execute();
```

## CTE（`with`）怎么用？

- `with(名字, 查询)` 定义公共表达式，后面的 `selectFrom` 可以直接引用;
- 后面的 CTE 引用前面的 CTE 时，用回调形式 `with(名字, (db) => ...)` 才有正确上下文;

```ts
const rows = await db
  .with(
    "jennifers",
    db.selectFrom("person").where("first_name", "=", "Jennifer").select(["id", "age"]),
  )
  .with("adults", (db) => db.selectFrom("jennifers").where("age", ">", 18).selectAll())
  .selectFrom("adults")
  .where("age", "<", 60)
  .selectAll()
  .execute();
```

## CTE 里能写写入语句吗？

- PostgreSQL 支持 `with ... insert/update ... returning` 串起来一次完成;
- SQLite 的 CTE 只用于查询，写入要单独执行或在事务里串起来，见 [事务与保存点](../040-事务与迁移/010-事务.md)。

## `exists` 与 `in` 怎么选？

| 写法                       | 适合                         | 注意                 |
| -------------------------- | ---------------------------- | -------------------- |
| `where('x', 'in', 子查询)` | 子查询只返回一列、结果集不大 | 空结果集要防 `in ()` |
| `exists(子查询)`           | 只关心「有没有」             | 通常比 `in` 更快短路 |
| join                       | 需要取子表的列               | 会产生重复行         |

- `exists` 的表达式写法见 [可复用查询函数](./050-可复用表达式函数.md)；
- 空数组与 `in ()` 的处理见 [过滤条件](./020-过滤条件.md)。
