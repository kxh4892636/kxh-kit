# 动态表名与结果类型

## 表名要到运行时才知道怎么写？

- 用 `db.dynamic`：`table()` 包表名、`ref()` 包列名，类型换成运行时检查;

```ts
const { table, ref } = db.dynamic;

const row = await db
  .selectFrom(table(tableName).as("t"))
  .selectAll()
  .where(ref(column), "=", value)
  .executeTakeFirst();
```

- 拼出来的标识符会自动加引号，不用自己防注入;
- 代价：编译器不再校验表名、列名，写错只能运行时发现。

## 什么时候可以安全地用动态标识符？

| 场景                              | 可否不校验               |
| --------------------------------- | ------------------------ |
| 列名/表名来自代码常量表（白名单） | 可以                     |
| 来自用户输入                      | 必须查白名单，不能直接拼 |
| 值（非标识符）                    | 永远走参数，不用 dynamic |

```ts
const SORTABLE = ["created_at", "first_name"] as const;
const column = SORTABLE.includes(input as never) ? input : "created_at";

const rows = await db.selectFrom("person").selectAll().orderBy(db.dynamic.ref(column)).execute();
```

## 泛型查询怎么写？

- 用类型参数把「表 → 列 → 值」串起来，调用处仍然有检查;
- 内部依然要靠 `dynamic` 打破静态表名;

```ts
async function getRowByColumn<
  T extends keyof Database,
  C extends keyof Database[T] & string,
  V extends SelectType<Database[T][C]>,
>(t: T, c: C, v: V) {
  const { table, ref } = db.dynamic;
  return await db
    .selectFrom(table(t).as("t"))
    .selectAll()
    .where(ref(c), "=", v)
    .orderBy("t.id")
    .executeTakeFirstOrThrow();
}
```

## 怎样把查询的结果类型单独取出来？

- `InferResult<typeof query>` 可脱离链式上下文使用，适合函数签名或跨模块传递;

```ts
import type { InferResult } from "kysely";

const query = db.selectFrom("person").select("first_name");
type Row = InferResult<typeof query>; // { first_name: string }[]
```

- 也可以直接 `Awaited<ReturnType<typeof query.executeTakeFirst>>` 取单行类型。
