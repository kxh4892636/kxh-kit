# 生成数据库类型

## 表很多时还要手写 `Database` 吗？

- 不必。`kysely-codegen` 连库反向生成 `.d.ts`，业务里直接引用;
- 生成结果与库结构一致，改表后重跑一次即可;

```bash
npm i -D kysely-codegen typescript
npx kysely-codegen --dialect sqlite --url dev.sqlite --out-file src/db.d.ts
```

```ts
// 生成物示意
export interface Person {
  created_at: Generated<string>;
  first_name: string;
  id: Generated<number | null>;
  last_name: string | null;
}
export interface DB {
  person: Person;
}
```

## 常用参数有哪些？

| 参数                                      | 作用                                     |
| ----------------------------------------- | ---------------------------------------- |
| `--dialect sqlite`                        | 指定方言（PG / MySQL / MSSQL / SQLite…） |
| `--url dev.sqlite`                        | 库文件路径或连接串，也可指向环境变量     |
| `--out-file src/db.d.ts`                  | 输出路径，默认落到 `node_modules` 下     |
| `--print`                                 | 只打印不写文件                           |
| `--include-pattern` / `--exclude-pattern` | 只生成指定表 / 排除表                    |
| `--camel-case`                            | 生成驼峰字段，配套 `CamelCasePlugin`     |
| `--verify`                                | 校验生成物是否过期，可进 CI              |

## 装不上怎么办？

- `kysely-codegen` 的 peer 约束是 `better-sqlite3 >=7.6.2 <13`，与 13.x 冲突;
- 两条路：`npm i -D kysely-codegen --legacy-peer-deps`，或把驱动降到 `better-sqlite3@^12`;
- 它还依赖 `typescript`，缺失时报 `Cannot find module 'typescript'`，补装即可。

## 生成物能直接当 `Database` 用吗？

- 能，但注意两点：列顺序按字母排、命名按库里的实际大小写;
- `Generated<number | null>` 这类可疑类型来自库里的列定义（例如主键允许 null），必要时手动收紧;
- 想在业务层用驼峰，就配 `--camel-case` + `CamelCasePlugin`，两边必须一致，见 [内置插件](./010-内置插件.md)。

## 还有哪些生成器？

| 工具             | 特点                                      |
| ---------------- | ----------------------------------------- |
| `kysely-codegen` | CLI，支持 PG/MySQL/SQLite/MSSQL，最常用   |
| `kysely-typegen` | 代码内调用，支持进程内数据库（如 PGlite） |
| `prisma-kysely`  | 从 Prisma schema 生成，已有 Prisma 时省事 |
| `kanel-kysely`   | 基于 Kanel，仅 PostgreSQL                 |

- 生成器给的类型与运行时不一致时，先用 [SQLite 与 Kysely 的差异](../060-速查/020-SQLite类型与运行时差异.md) 核对驱动返回值。
