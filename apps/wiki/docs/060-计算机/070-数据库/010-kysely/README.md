# Kysely 使用手册（Node + SQLite）

- 学习目标: 能在 Node 项目里用 Kysely 连 SQLite，完成建表、增删改查、事务和迁移;
- 最快入口: [安装与连接 SQLite](./010-快速上手/010-安装与依赖.md)，按顺序做完全部四页，得到可运行的 CRUD;
- 环境约定: Node 20+、TypeScript 5.4+ (`strict`)、`kysely` 0.29、`better-sqlite3` 13、用 `tsx` 直接跑 `.ts`;
- 定位: Kysely 是类型安全的 SQL **构建器**，不是 ORM，没有模型、没有关系、没有懒加载;
- 来源: [kysely-org/kysely 仓库 site/docs](https://github.com/kysely-org/kysely/tree/c0d39311e0b024dc95497d2608c7c2747bdc916a/site/docs)（commit `c0d3931`）；README 所述内容按该目录文档整理，SQLite 代码在本地实测（kysely 0.29.7 + better-sqlite3 13.0.3 + SQLite 3.53.4）;

## 这份手册不覆盖什么？

- 不是 SQL 教程: 假定你会 `select`、`join`、`group by`;
- 不覆盖 PostgreSQL/MySQL 专属能力（`jsonb` 运算符、`distinct on`、`merge into`）: 需要时看官方 [Examples](https://kysely.dev/docs/category/examples);
- 不覆盖框架集成与浏览器端编译: 见官方 [Dialects](https://kysely.dev/docs/dialects)、[Browser](https://kysely.dev/docs/runtimes/browser);
