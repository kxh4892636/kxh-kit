# 流式选型

## SSE、WebSocket 与流式 body 怎么选？

- 先看方向：只需要服务端推送用 SSE；需要双向低延迟用 WebSocket；大文件或持续生成用流式 body;

| 能力          | 方向            | 协议形态      | 适用               |
| ------------- | --------------- | ------------- | ------------------ |
| 普通 HTTP     | 请求后单响应    | 有界 body     | CRUD、查询         |
| SSE           | 服务端 → 客户端 | 文本事件流    | 通知、进度、订阅   |
| WebSocket     | 双向            | message/frame | 协作、聊天、控制   |
| 流式 body     | 单向或上传      | 字节流        | 大文件、生成式内容 |
| RPC streaming | 单向/双向       | 框架流        | 内部服务间持续传输 |

- 适用: 需要服务端推送、双向通信或持续生成内容的服务。
