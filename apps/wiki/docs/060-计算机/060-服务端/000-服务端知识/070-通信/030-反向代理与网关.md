# 反向代理与网关

## 正向代理、反向代理与网关有什么区别？

- 正向代理: 客户端使用代理;
- 反向代理: 服务端使用代理;
- 网关: 反向代理 + 路由(内外网/端口/协议) + 治理(TLS\路由\限流\熔断);

## 代理链路里哪些头不能原样转发？

- 逐跳头（`Connection`、`Keep-Alive`、`Transfer-Encoding`、`Upgrade` 等）不能原样转发;
- 转发头（`X-Forwarded-For`、`X-Forwarded-Proto`、`X-Forwarded-Host`）只能由可信代理追加;

## 客户端到下游的代理链路怎么分层？

```text
客户端 → CDN/WAF → 负载均衡 → 网关（TLS、路由、限流）
      → 应用（业务、鉴权）→ 下游服务
```
