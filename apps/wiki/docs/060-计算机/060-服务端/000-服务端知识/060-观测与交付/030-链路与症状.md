# 链路与症状

## 一次请求的链路长什么样？

- 每个 span 记录开始/结束、状态、关键属性;
- 每个 span 传递/注入 trace 上下文（HTTP Header 或 RPC 元信息）;

```text
trace_id: 4b8e...
  span: HTTP POST /articles        12ms
    span: auth.verify               1ms
    span: db.insert                8ms
    span: mq.publish               2ms
```

## 什么是采样策略? 其作用是什么？

- 采样策略: 决定哪些 span 被记录;
- 决定点: 在入口决定, 下游继承;
- 比例: 正常请求按比例, 错误请求强制采样;
- 频繁的采样: 会增加存储成本, 影响性能;
