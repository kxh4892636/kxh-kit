# 链路与症状

## 一次请求的链路长什么样？

```text
trace_id: 4b8e...
  span: HTTP POST /articles        12ms
    span: auth.verify               1ms
    span: db.insert                8ms
    span: mq.publish               2ms
```

```go
ctx, span := tracer.Start(ctx, "db.find_article")
defer span.End()
// 出站调用继续使用 ctx，trace 上下文随之传播
```

- 每个 span 记录开始/结束、状态、关键属性;
- 出站调用注入 trace 上下文（HTTP Header 或 RPC 元信息）;
- 采样策略在入口决定，下游继承；正常请求按比例，错误请求强制采样;
- Trace 上下文要跨进程传播，否则链路在第一次出站调用就断;
- exporter/provider 有生命周期，退出前要 flush，重复初始化前要关闭。

## 指标与链路写错会看到什么症状？

| 症状                 | 原因                         |
| -------------------- | ---------------------------- |
| 监控存储暴涨         | 标签里放了用户 ID / 原始 URL |
| 告警总在故障后才触发 | 只看平均值，没有分位与错误率 |
| 链路只有一段         | 出站调用没注入 Trace 上下文  |
| 退出后丢最后一段数据 | exporter 没 flush            |
| 指标口径不一致       | 各服务自定义 status 含义     |
