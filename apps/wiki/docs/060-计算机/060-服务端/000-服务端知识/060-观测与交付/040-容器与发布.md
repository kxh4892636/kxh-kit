# 容器与发布

## 容器运行镜像里只放什么？

- 多阶段构建，构建工具与源码留在 builder：体积小、攻击面小;
- 用非 root 用户运行；root 进程逃逸后权限更大;
- 基础镜像尽量小（distroless / alpine）;
- 配置与 Secret 全部来自环境变量或挂载，不烤进镜像;
- 监听 `0.0.0.0`，端口来自环境变量；日志写 stdout/stderr，不写容器内文件;
- 适用: 需要容器化部署的服务。

```dockerfile
FROM golang:1.26 AS builder
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -trimpath -o /out/server ./cmd/server

FROM gcr.io/distroless/static-debian12:nonroot
COPY --from=builder /out/server /server
USER nonroot:nonroot
ENTRYPOINT ["/server"]
```

## Node 服务镜像怎么写？

```dockerfile
FROM node:22-alpine AS builder
WORKDIR /app
COPY package*.json tsconfig.json ./
COPY src ./src
RUN npm ci && npm run build && npm prune --production

FROM node:22-alpine AS runner
WORKDIR /app
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/package.json .
USER node
CMD ["node", "dist/index.js"]
```

## 平台终止宽限期为什么必须大于退出预算？

- 平台终止宽限期必须大于「摘流 + 在途等待 + 资源清理」的总预算;
- 宽限期小于退出预算，进程会被 SIGKILL，在途请求丢失。

## 发布前清单要核对哪几项？

- [ ] readiness / liveness 分开，探针不套鉴权;
- [ ] `terminationGracePeriodSeconds` > 退出预算;
- [ ] Secret 缺失时启动失败，而不是用空值;
- [ ] 镜像固定 digest 或不可变 tag（不用 `latest`），`.dockerignore` 排除 `.git`、`.env`、`node_modules`;
- [ ] 日志到 stdout，时区与 locale 显式设置。

## 容器配置写错会看到什么症状？

| 症状                     | 原因                                |
| ------------------------ | ----------------------------------- |
| 容器外连不上             | 监听 `127.0.0.1`                    |
| 发布时请求被切断         | 宽限期短于退出预算                  |
| 镜像里能翻到密钥         | Secret 写进 `Dockerfile` 或构建参数 |
| 镜像几百 MB              | 没用多阶段构建                      |
| 平台注入的 `PORT` 不生效 | 代码里写死端口                      |
