# GORM 建模与查询

## GORM 模型与查询怎么写？

- Row 与领域对象分离: 数据库 tag、可空字段、时间格式只属于 Row;
- 查询一律 `WithContext`，让请求取消与超时生效;
- 打开 `TranslateError`，把唯一键冲突翻译成 `gorm.ErrDuplicatedKey`，再转领域错误;
- 时间统一存 UTC，展示层再按契约格式化；不用 UTC 会在跨时区与夏令时出错;
- 适用: 使用 GORM 访问 MySQL 的 Go 服务。

```go
type UserRow struct {
	ID        int64     `gorm:"primaryKey"`
	Email     string    `gorm:"size:254;not null;uniqueIndex"`
	Name      string    `gorm:"size:100;not null"`
	CreatedAt time.Time
}

func (UserRow) TableName() string { return "users" } // 避免被推导成 user_rows
```

```go
func (r *GormUserRepository) FindByID(ctx context.Context, id int64) (*User, error) {
	var row UserRow
	err := r.db.WithContext(ctx).First(&row, id).Error
	if errors.Is(err, gorm.ErrRecordNotFound) {
		return nil, ErrUserNotFound
	}
	if err != nil {
		return nil, fmt.Errorf("find user %d: %w", id, err)
	}
	return toEntity(row), nil
}
```

## GORM 与 MySQL 配错会看到什么症状？

| 症状                   | 原因                              |
| ---------------------- | --------------------------------- |
| 请求取消后 SQL 还在跑  | 没用 `WithContext`                |
| 多实例发布时锁表       | 启动时 `AutoMigrate`              |
| 唯一键冲突返回 500     | 没开 `TranslateError`，没转业务码 |
| 数据库连接被打满       | 连接池上限 × 实例数超过数据库上限 |
| 时间差 8 小时          | 存了本地时间，或 DSN 没设时区     |
| 迁移「成功」但版本没写 | MySQL DDL 不回滚，未核对版本表    |
