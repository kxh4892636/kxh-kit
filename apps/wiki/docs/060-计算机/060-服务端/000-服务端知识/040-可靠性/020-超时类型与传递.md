# 超时类型与传递

## 四类超时各管什么？

- 连接、读写、空闲、业务四类语义不同，不能互相代替;

| 类型     | 管什么                    | 常见值   |
| -------- | ------------------------- | -------- |
| 连接超时 | 建立新连接                | 50–300ms |
| 读写超时 | 单次网络读写等待          | 3–10s    |
| 空闲超时 | keep-alive 连接的空闲回收 | 30–90s   |
| 业务超时 | 一次业务处理的总时间      | 按接口定 |
