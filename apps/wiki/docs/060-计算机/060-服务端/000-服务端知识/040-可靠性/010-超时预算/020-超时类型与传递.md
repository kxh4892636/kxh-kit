# 超时类型与传递

## 四类超时各管什么？

- 连接、读写、空闲、业务四类语义不同，不能互相代替;

| 类型     | 管什么                    | 常见值   |
| -------- | ------------------------- | -------- |
| 连接超时 | 建立新连接                | 50–300ms |
| 读写超时 | 单次网络读写等待          | 3–10s    |
| 空闲超时 | keep-alive 连接的空闲回收 | 30–90s   |
| 业务超时 | 一次业务处理的总时间      | 按接口定 |

- 读写超时不限制业务执行，业务超时要自己派生带 deadline 的上下文。

## Go 里怎么把 deadline 传给下游？

```go
ctx, cancel := context.WithTimeout(ctx, 800*time.Millisecond)
defer cancel()

resp, err := downstream.Call(ctx, req) // 下游实现必须使用这个 ctx
if errors.Is(err, context.DeadlineExceeded) {
	return ErrUpstreamTimeout
}
```

- 下游客户端不要自己再设一个更长的超时覆盖入口预算;
- 超时后要停止后续工作，不要继续写库或发消息。
