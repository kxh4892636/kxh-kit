# 目录与拆分

## 分层目录和接口示例长什么样？

```text
# Go
cmd/server/main.go          # 读取配置、创建依赖、启动、退出
internal/user/
  handler.go                # 传输适配：请求 → 领域调用 → 响应
  service.go                # 业务规则与事务
  repository.go             # 存储接口
  repository_sql.go         # SQL / ORM 实现

# TypeScript
src/index.ts                # 只启动服务
src/app.ts                  # 组装路由与中间件
src/routes/users.ts         # 路由 + 参数解析
src/services/user.ts        # 纯业务函数
src/repositories/user.ts    # SQL / ORM
```

```go
// Service 定义自己需要的存储接口，实现放在外层。
type UserRepository interface {
	FindByID(ctx context.Context, id int64) (*User, error)
}

type UserService struct{ repo UserRepository }

func (s *UserService) Get(ctx context.Context, id int64) (*User, error) {
	if id <= 0 {
		return nil, ErrInvalidID
	}
	return s.repo.FindByID(ctx, id)
}
```

```ts
// 业务函数不接收请求对象，方便在任务与测试中复用。
export const getUser = (repo: UserRepository) => async (id: string) => {
  if (!id) throw new Error("invalid id");
  return repo.findById(id);
};
```

## 分层什么时候该拆分？

- 拆分信号: 单文件超过约 300 行，或一个 Handler 里出现多段重复的参数解析；Handler 里出现 SQL、第三方 SDK、事务;
- 共性下沉: 多个路由共用鉴权、限流、日志，下沉为中间件；同一份错误响应代码出现两次以上，收进统一错误映射。
