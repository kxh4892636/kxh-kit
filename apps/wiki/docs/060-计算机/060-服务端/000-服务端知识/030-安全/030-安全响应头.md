# 安全响应头

## 常见的安全响应头有哪些?

| 头                                    | 作用                                                                                           | 注意                                                        |
| ------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| `Strict-Transport-Security`           | 强制 HTTPS                                                                                     | 先确认全站 HTTPS，再逐步加 `max-age`                        |
| `X-Content-Type-Options: nosniff`     | 禁止 MIME 嗅探, 严格按照 Content-Type 处理响应                                                 | 常开                                                        |
| `Content-Security-Policy`             | 限制脚本/样式等资源的来源, 防止 XSS 攻击                                                       | 先 Report-Only                                              |
| `X-Frame-Options` / `frame-ancestors` | 告诉浏览器，这个文档能否被放进 `<frame>`、`<iframe>`、`<embed>`、`<object>` 中渲染, 防点击劫持 | 二选一，别冲突                                              |
| `Referrer-Policy`                     | 控制 Referer 对外暴露的信息量                                                                  | 跨站默认 `no-referrer` 或 `strict-origin-when-cross-origin` |
| `Permissions-Policy`                  | 限制浏览器能力的使用                                                                           | 按需                                                        |
