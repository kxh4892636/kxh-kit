# 契约不变量与形状

## 接口契约发布后哪些东西不能动？

- 冻结字段编号、字段名、类型、语义；契约先行，跨进程/跨团队调用按契约编程，不按实现猜;

- 契约文件进仓库、可 review、有版本;
- 生成代码是派生产物，不手改；手改会被下次生成覆盖，且与契约永久不一致；生成器版本固定，升级单独评估。

## 接口契约长什么样？

- 谁调用、传什么、返回什么、失败是什么: 契约要能回答这四件事;
- IDL、OpenAPI、JSON Schema 都是契约的载体，规则相同。

```text
struct GetUserRequest {
  1: i64 id        // 字段编号 1，发布后不可复用
  2: optional string trace_id
}
```

```json
{
  "type": "object",
  "required": ["name"],
  "properties": { "name": { "type": "string" } }
}
```
