# 契约不变量与形状

## 什么是接口契约? 常见的标准有哪些?

- 谁调用、传什么、返回什么、失败是什么;
- IDL、OpenAPI、JSON Schema 都是契约的载体，规则相同。

```text
struct GetUserRequest {
  1: i64 id        // 字段编号 1，发布后不可复用
  2: optional string trace_id
}
```

```json
{
  "type": "object",
  "required": ["name"],
  "properties": { "name": { "type": "string" } }
}
```

## 接口字段怎么演进才不破坏兼容？

| 变更         | 兼容性 | 做法                   |
| ------------ | ------ | ---------------------- |
| 新增可选字段 | 兼容   | 直接发                 |
| 新增必填字段 | 不兼容 | 先给默认值，再逐步强制 |
| 改字段类型   | 不兼容 | 新增字段，双写过渡     |
| 复用字段编号 | 不兼容 | 禁止                   |
| 删除字段     | 需过渡 | 先停读写、观察，再删   |
| 改方法语义   | 不兼容 | 新增方法，旧方法保留   |
