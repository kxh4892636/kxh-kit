# 错误分层与响应

## 接口错误为什么先分三层？对应的状态码是什么？

- 三层: 传输层错误（没到）、业务拒绝（到了但不满足规则）、系统故障（到了但处理失败）; ;
- 4xx 通常为传输层错误, 5xx 为系统故障; 业务拒绝为特定业务错误码;

## 三层接口错误的重试策略？

- 4xx 通常不重试, 5xx 才可能重试;
- 业务拒绝不是故障: 不报 5xx、不触发告警、不盲目重试;

## 错误响应至少包括什么字段？

- 至少包括协议层状态（HTTP 状态或 RPC 状态）、业务状态、安全 message;
  - 堆栈、SQL、DSN、内部主机名只进服务端日志;
- 可选包括结构化校验数据, request_id 等;

```json
{
  "status": 400,
  "code": "ARTICLE_NOT_FOUND",
  "message": "article not found",
  "request_id": "9f2c1e7a5b",
  "details": { "field": "id" }
}
```
