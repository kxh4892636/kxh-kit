# 客户端调用

## Client 怎么建，为什么要复用？

```go
func newUserClient() (userservice.Client, error) {
	return userservice.NewClient(
		"user-service", // service name：服务发现与观测的维度
		client.WithHostPorts("127.0.0.1:8888"),
		client.WithConnectTimeout(200*time.Millisecond),
		client.WithRPCTimeout(time.Second),
	)
}
```

- 进程内建一次，调用只传 `ctx` 与请求对象；每请求新建会重复建连、拉配置、起 goroutine;
- 默认值: `ConnectTimeout` 50ms、`RPCTimeout` 0（不限时）；生产必须显式设 `RPCTimeout`。

## 寻址有哪几种写法？

| 写法                             | 场景                 |
| -------------------------------- | -------------------- |
| `client.WithHostPorts`           | 本地直连、测试       |
| `client.WithResolver` + 负载均衡 | 动态实例列表         |
| `callopt.WithURL`                | URL / DNS 形态的地址 |
| `callopt.WithHostPort`           | 单次直连，只适合诊断 |

- 一次调用只传 `ctx` 与请求对象:

```go
func getUser(ctx context.Context, cli userservice.Client, id int64) (*api.GetUserResponse, error) {
	resp, err := cli.GetUser(ctx, &api.GetUserRequest{Id: id})
	if err != nil {
		return nil, fmt.Errorf("get user %d: %w", id, err)
	}
	return resp, nil
}
```

- Call Option 走方法尾参，只对单次生效，一般覆盖同类 Client Option;
- `ctx` 只约束本地取消与 deadline；跨进程传播要 TTHeader 与 MetaHandler，见 [006-协议与连接](./006-协议与连接.md)。

## 调用失败怎么判断？

- 先判 `err` 再读 response，失败时不假设 response 可用;
- 分类入口: `errors.Is` 判包装、`kerrors.IsTimeoutError` 判超时、`kerrors.FromBizStatusError` 取业务码;
- 框架错误: `ErrServiceDiscovery`、`ErrGetConnection`、`ErrRPCTimeout`、`ErrCircuitBreak`、`ErrOverlimit`，症状对照见 [008-扩展与排障](./008-扩展与排障.md)。

```go
if biz := kerrors.FromBizStatusError(err); biz != nil {
	log.Printf("biz code=%d msg=%s", biz.BizStatusCode(), biz.BizMessage())
}
```

## 重试与熔断的装配在哪里？

- `retry` 包、`client.WithFailureRetry`、`client.WithCircuitBreaker` 的代码与默认阈值见 [009-超时重试与熔断限流](./009-超时重试与熔断限流.md);
- 什么能重试、重试会放大什么见 [重试与幂等](../000-服务端知识/040-可靠性/030-重试与幂等.md)。

## Client 侧有哪些常用选项？

| 选项                                     | 用途                                        |
| ---------------------------------------- | ------------------------------------------- |
| `WithResolver` / `WithHostPorts`         | 服务发现 / 固定地址                         |
| `WithConnectTimeout`                     | 建连上限，默认 50ms                         |
| `WithRPCTimeout`                         | 单次 RPC 上限，默认 0（不限时）             |
| `WithFailureRetry` / `WithBackupRequest` | 重试策略                                    |
| `WithCircuitBreaker`                     | 熔断实现，默认不启用                        |
| `WithTransportProtocol`                  | 传输协议常量，见 [006](./006-协议与连接.md) |
| `WithMetaHandler`                        | `transmeta.ClientTTHeaderHandler`           |
