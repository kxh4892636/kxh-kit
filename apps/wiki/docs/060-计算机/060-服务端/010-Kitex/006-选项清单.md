# Server 与 Client 选项

## Server 侧有哪些常用选项？

| 选项                                        | 用途                                               |
| ------------------------------------------- | -------------------------------------------------- |
| `WithServiceAddr`                           | 监听地址，缺省 `:8888`                             |
| `WithServerBasicInfo`                       | 服务身份，注册、日志与链路标签都依赖               |
| `WithRegistry`                              | 启动时注册、退出时注销                             |
| `WithMiddleware`                            | 先注册者包裹后注册者                               |
| `WithReadWriteTimeout`                      | 传输读写等待，默认 5s，不是业务超时                |
| `WithExitWaitTime`                          | 退出等在途请求，默认 5s                            |
| `WithEnableContextTimeout`                  | v0.9.0+，把上游 deadline 写进 Server context       |
| `WithLimit`                                 | 内置 QPS 与连接数限制                              |
| `WithQPSLimiter` / `WithConcurrencyLimiter` | 换成自定义限流实现                                 |
| `WithMetaHandler`                           | TTHeader 元信息，`transmeta.ServerTTHeaderHandler` |
| `WithListener` / `WithExitSignal`           | 测试用临时端口与退出注入                           |

## Client 侧有哪些常用选项？

| 选项                                     | 用途                                        |
| ---------------------------------------- | ------------------------------------------- |
| `WithResolver` / `WithHostPorts`         | 服务发现 / 固定地址                         |
| `WithConnectTimeout`                     | 建连上限，默认 50ms                         |
| `WithRPCTimeout`                         | 单次 RPC 上限，默认 0（不限时）             |
| `WithFailureRetry` / `WithBackupRequest` | 重试策略                                    |
| `WithCircuitBreaker`                     | 熔断实现，默认不启用                        |
| `WithTransportProtocol`                  | 传输协议常量，见 [007](./007-协议与连接.md) |
| `WithMetaHandler`                        | `transmeta.ClientTTHeaderHandler`           |

## 观测选项怎么注入？

- `klog.SetLogger` 注入组织 logger；`WithTracer` 注入 tracer；`WithStatsLevel` 控制埋点粒度;
- 无 tracer 默认 Disabled，有 tracer 默认 Detailed；装配例见 [011](./011-发现与观测接入.md);
- 连接池、gRPC 窗口、buffer、keepalive 只在测量证明默认值不合适时调整。
