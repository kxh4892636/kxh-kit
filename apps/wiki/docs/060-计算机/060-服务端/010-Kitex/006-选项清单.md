# Server 与 Client 选项

## Server 侧选项各自管什么？

| 选项                       | 用途                                                                                      |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| `WithServiceAddr`          | 监听地址，缺省 `:8888`                                                                    |
| `WithServerBasicInfo`      | 服务身份                                                                                  |
| `WithRegistry`             | 服务注册与注销                                                                            |
| `WithMiddleware`           | 先注册者包裹后注册者                                                                      |
| `WithReadWriteTimeout`     | 传输读写等待（默认 5s），不是业务超时                                                     |
| `WithExitWaitTime`         | 退出等待（默认 5s）                                                                       |
| `WithLimit`                | 内置 QPS 与连接数限制; 自定义用 `server.WithQPSLimiter` / `server.WithConcurrencyLimiter` |
| `WithEnableContextTimeout` | v0.9.0+，配合 TTHeader 传递上游 deadline                                                  |

## Client 侧选项各自管什么？

| 选项                                     | 用途                                                  |
| ---------------------------------------- | ----------------------------------------------------- |
| `WithResolver` / `WithHostPorts`         | 服务发现 / 固定地址                                   |
| `WithConnectTimeout`                     | 建连上限，默认 50ms                                   |
| `WithRPCTimeout`                         | 单次 RPC 上限，默认 0（不限时）                       |
| `WithFailureRetry` / `WithBackupRequest` | 重试策略                                              |
| `WithCircuitBreaker`                     | 熔断实现; 默认不启用，阈值见 [004](004-客户端调用.md) |
| `WithTransportProtocol`                  | 传输协议常量，见 [006-协议与连接](007-协议与连接.md)  |

- 观测: `klog.SetLogger` 注入组织 logger; `WithTracer` 注入 tracer，`WithStatsLevel` 控制埋点粒度; 无 tracer 默认 Disabled、有 tracer 默认 Detailed; 装配例见 [009](010-超时重试与熔断限流.md);
- 调参: 连接池参数与 gRPC 窗口、buffer、keepalive 只在测量证明默认值不适合时调整;
