# Kitex 服务端开发

Kitex 是 CloudWeGo 的 Go RPC 框架: IDL 生成桩、Client 与 Server 两端装配、内置服务治理。对外 HTTP 服务用 [Hertz](../020-Hertz/README.md)。

本目录只写「这个框架怎么接」; 原理、超时预算、错误分层、优雅退出、分层与测试策略都在 [000-服务端知识](../000-服务端知识/README.md)。

## 阅读顺序

1. [001-心智模型](./001-心智模型.md): 一次 RPC 的路径、对象分工、开发五步;
2. [002-IDL与代码生成](./002-IDL与代码生成.md): 写 IDL、跑 `kitex`、生成物归属;
3. [003-服务端开发](./003-服务端开发.md): `NewServer`、Handler、`kerrors`;
4. [004-客户端调用](./004-客户端调用.md): 复用 Client、默认超时、重试与失败判断;
5. [作用域与 Suite](./005-Option配置体系/010-作用域与Suite.md) / [选项清单](./005-Option配置体系/020-选项清单.md): 三层作用域、Suite 复用与常用选项表;
6. [006-协议与连接](./006-协议与连接.md): 消息类型、五个传输常量、连接池;
7. [007-StreamX流式](./007-StreamX流式.md): `-streamx` 门槛与三种流的关闭语义;
8. [008-扩展与排障](./008-扩展与排障.md): 特殊能力、注册与配置中心、`kitexcall`、错误入口;
9. [超时重试与熔断限流](./009-治理与观测接入/010-超时重试与熔断限流.md) / [发现与观测接入](./009-治理与观测接入/020-发现与观测接入.md) / [运行与测试接入](./009-治理与观测接入/030-运行与测试接入.md): 治理、观测、退出与 RPC 测试钩子。

## 按需回查

- 只有多实例、容量治理、可观测性、灰度等生产需求时才需要看 005、006、008、009;
- 治理类默认值（`ConnectTimeout` 50ms、`RPCTimeout` 0、`ReadWriteTimeout` 5s、`ExitWaitTime` 5s）与装配代码集中在 009;
- Kitex 的退出参数与平台终止窗口的关系见 [优雅退出](../000-服务端知识/040-可靠性/040-优雅退出/010-退出顺序.md);
- 错误分类、重试幂等、熔断三态机等判断规则见 000，本目录只给对应选项与代码。

## 版本

- 示例按 Kitex tool `v0.16.3`、thriftgo `v0.4.5` 编写; 升级前按官方文档核对选项与默认值;
- 框架用法依据 CloudWeGo 官方文档; 示例代码只演示接入，不代表推荐的项目结构。
