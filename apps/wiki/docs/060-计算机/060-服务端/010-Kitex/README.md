# Kitex 服务端开发

Kitex 是 CloudWeGo 的 Go RPC 框架: IDL 生成桩、Client 与 Server 两端装配、内置服务治理。对外 HTTP 服务用 [Hertz](../020-Hertz/README.md)。

本目录只写「术」: 生成命令、选项名与默认值、协议常量、关闭语义、框架错误入口。原理与判断规则在 [000-服务端知识](../000-服务端知识/README.md)，需要时只留一句指向，不重复解释。

## 阅读顺序

1. [001-心智模型](./001-心智模型.md): 对象分工、开发五步、两端各建几次;
2. [002-IDL与代码生成](./002-IDL与代码生成.md): IDL 形状、`kitex` flag、Protobuf 何时走 gRPC;
3. [003-服务端开发](./003-服务端开发.md): `NewServer`、Handler、`kerrors`、上游 deadline 的四个条件;
4. [004-客户端调用](./004-客户端调用.md): 复用 Client、默认超时、寻址写法、失败分类;
5. [005-作用域与Suite](./005-作用域与Suite.md) / [006-选项清单](./006-选项清单.md): 三层作用域、Suite 打包、选项总表;
6. [007-协议与连接](./007-协议与连接.md): 消息类型、五个传输常量、连接池参数;
7. [008-StreamX流式](./008-StreamX流式.md): `-streamx` 门槛与三种流的关闭语义;
8. [009-扩展与排障](./009-扩展与排障.md): 扩展能力、注册与配置中心、`kitexcall`、错误入口、RPCInfo 冻结;
9. [010](./010-超时重试与熔断限流.md) / [011](./011-发现与观测接入.md) / [012](./012-运行与测试接入.md): 治理装配、观测注入、退出与 RPC 测试。

## 按需回查

- 治理类默认值（`ConnectTimeout` 50ms、`RPCTimeout` 0、`ReadWriteTimeout` 5s、`ExitWaitTime` 5s）集中在 010;
- 选项名与作用域在 006，装配代码在 003 与 010，两处不重复;
- 超时预算、重试幂等、熔断三态、错误分层、分层依赖、退出顺序: 只查 000。

## 版本

- 示例按 Kitex tool `v0.16.3`、thriftgo `v0.4.5` 编写，本机与 CI 用同一组版本;
- 框架用法依据 CloudWeGo 官方文档; 示例只演示接入，不代表推荐的项目结构。
