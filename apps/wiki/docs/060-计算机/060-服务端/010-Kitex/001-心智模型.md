# Kitex 心智模型

## Kitex 里有哪些对象，各管什么？

| 对象             | 职责                               |
| ---------------- | ---------------------------------- |
| IDL / 生成代码   | 定义契约，生成类型、编解码与调用桩 |
| Handler / Server | 实现方法，接收 RPC                 |
| Client           | 按契约调用远端方法                 |
| Option / Suite   | 在明确作用域配置行为               |
| Middleware       | 在业务前后执行公共逻辑             |

- 生成布局: `kitex_gen/user` 放类型与编解码，`kitex_gen/user/userservice` 放 Server、Client 与 Handler 接口;
- 横切逻辑放哪一层与框架无关，见 [请求生命周期](../000-服务端知识/010-基础模型/010-请求生命周期.md)。

## 从 IDL 到上线分哪五步？

1. 写 Thrift 或 proto3 的 IDL: service、method、请求、响应;
2. `kitex` 生成 `kitex_gen` 桩;
3. 实现 Handler，`NewServer` 启动;
4. `NewClient` 建可复用 Client 再调用;
5. 按生产需要补寻址、超时、重试、熔断、可观测性。
