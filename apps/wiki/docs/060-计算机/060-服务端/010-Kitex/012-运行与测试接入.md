# 运行与测试接入

## 优雅退出怎么接？

```go
func main() {
	svr := userservice.NewServer(new(UserServiceImpl), server.WithExitWaitTime(5*time.Second)) // 须小于平台终止窗口
	if err := svr.Run(); err != nil { // Run 阻塞，收到信号后等在途请求
		log.Fatal(err)
	}
}
```

- 顺序: Run 返回后再关数据库与 exporter; 自定义信号用 `server.WithExitSignal`; 摘流、排空、关资源的顺序见 [优雅退出](../000-服务端知识/040-可靠性/050-退出顺序.md);

## RPC 集成测试怎么起？

```go
func startTestServer(h userservice.UserService, lis net.Listener) chan<- error {
	exit := make(chan error, 1)
	svr := userservice.NewServer(h, server.WithListener(lis), server.WithExitSignal(func() <-chan error { return exit }))
	go svr.Run()
	return exit
}
```

```go
cli := userservice.MustNewClient("user-service",
	client.WithHostPorts(lis.Addr().String()),
	client.WithShortConnection(),
)
resp, err := cli.GetUser(context.Background(), &api.GetUserRequest{Id: 1})
if err != nil || resp.Name == nil {
	t.Fatalf("unexpected: resp=%v err=%v", resp, err)
}
defer func() { exit <- nil }() // 让测试 Server 退出
```

- 覆盖与分层: 临时端口 + 真实 Client 覆盖生成代码、传输与错误码，结束时向 `exit` 发 nil 让 `Run` 返回; 不依赖网络的 Service/Handler 单测与测试分层见 [测试策略](../000-服务端知识/060-观测与交付/040-测试策略.md);
