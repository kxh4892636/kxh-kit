# 发现与观测接入

## 服务注册怎么写？

```go
func newRegisteredServer(h userservice.UserService) (server.Server, error) {
	registry, err := etcd.NewEtcdRegistry([]string{"127.0.0.1:2379"})
	if err != nil {
		return nil, err
	}
	return userservice.NewServer(h, server.WithRegistry(registry),
		server.WithServerBasicInfo(&rpcinfo.EndpointBasicInfo{ServiceName: "user-service"})), nil
}
```

- 配对: Client 用 `client.WithResolver`, service name 两端一致;
- ClusterIP 只暴露一个地址时做不了 Pod 级均衡;
- 算法取舍见 [服务发现与负载均衡](../000-服务端知识/070-通信/040-服务发现与负载均衡.md);

## 有哪些负载均衡算法可选？

| 算法                       | 用途                                |
| -------------------------- | ----------------------------------- |
| WeightedRoundRobin（默认） | 按权重轮询                          |
| WeightedRandom             | 按权重随机, 大样本下趋于均衡        |
| ConsistentHash             | 相同 key 命中同一实例, 适合缓存亲和 |
| Tagging Based              | 按标签筛选实例                      |

## 日志与追踪怎么接？

```go
func newTracedServer(h userservice.UserService, l klog.FullLogger, t stats.Tracer) server.Server {
	klog.SetLogger(l) // l 实现 klog.FullLogger
	return userservice.NewServer(h, server.WithTracer(t), server.WithStatsLevel(stats.LevelDetailed))
}
```

- `Tracer`: 在 Start/Finish 收 RPCInfo;
- 默认级别: 无 tracer 为 Disabled, 有 tracer 为 Detailed;
- 指标基数与采样纪律见 [信号与指标](../000-服务端知识/060-观测与交付/020-信号与指标.md);

## 观测选项怎么注入？

- 注入 logger: `klog.SetLogger`; 注入 tracer: `WithTracer`;
- 埋点粒度: `WithStatsLevel` 控制;
- 连接池、gRPC 窗口、buffer、keepalive 只在测量证明默认值不合适时调整;
