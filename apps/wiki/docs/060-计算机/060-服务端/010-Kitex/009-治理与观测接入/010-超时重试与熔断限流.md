# 超时重试与熔断限流

## 超时与重试的默认值是多少？

| 配置               | 默认值    | 控制对象            |
| ------------------ | --------- | ------------------- |
| `ConnectTimeout`   | 50ms      | 建立新连接          |
| `RPCTimeout`       | 0，不限时 | Client 等待一次 RPC |
| `ReadWriteTimeout` | 5s        | Server 网络读写等待 |
| `ExitWaitTime`     | 5s        | Server 退出等待     |

```go
func newRetryClient() (userservice.Client, error) {
	policy := retry.NewFailurePolicy()
	policy.WithMaxRetryTimes(2)   // 重试 2 次
	policy.WithMaxDurationMS(800) // 总预算上限
	return userservice.NewClient("user-service", client.WithRPCTimeout(300*time.Millisecond), client.WithFailureRetry(policy))
}
```

- 口径: 默认值按 Kitex v0.16.3 源码校对; 超时默认不重试; streaming 不支持常规重试; 预算分层与幂等前提见 [超时预算](../../000-服务端知识/040-可靠性/010-超时预算/010-预算模型.md)、[重试与幂等](../../000-服务端知识/040-可靠性/020-重试与幂等.md);

## 熔断与限流怎么配？

```go
func newCBClient() (userservice.Client, error) {
	cb := circuitbreak.NewCBSuite(circuitbreak.RPCInfo2Key)
	return userservice.NewClient("user-service", client.WithCircuitBreaker(cb)) // 默认不启用
}
```

- 熔断阈值: 错误率 50%、最小样本 200、OPEN 冷却 10s; service breaker 按 caller/callee/method 统计，instance breaker 在负载均衡之后; 三态机与降级条件见 [熔断降级与限流](../../000-服务端知识/040-可靠性/030-熔断降级与限流.md);

```go
func newLimitedServer(h userservice.UserService) server.Server {
	return userservice.NewServer(h, server.WithLimit(&limit.Option{MaxConnections: 2000, MaxQPS: 1000}))
}
```

- 限流实现: QPS limiter 默认令牌桶，connection limiter 限制并发连接; 自定义用 `server.WithQPSLimiter` / `server.WithConcurrencyLimiter`; 维度与组合顺序见 [熔断降级与限流](../../000-服务端知识/040-可靠性/030-熔断降级与限流.md);
