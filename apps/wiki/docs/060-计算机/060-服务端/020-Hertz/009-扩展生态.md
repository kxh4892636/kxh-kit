# 扩展生态

## 每个能力对应哪个 hertz-contrib 包？

| 需求              | 组件                                                                 |
| ----------------- | -------------------------------------------------------------------- |
| 登录与身份        | `hertz-contrib/jwt`、KeyAuth、Paseto                                 |
| Cookie 登录与跨域 | `hertz-contrib/sessions`、`hertz-contrib/csrf`、`hertz-contrib/cors` |
| 安全响应头        | `hertz-contrib/secure`                                               |
| 协议扩展          | `hertz-contrib/http2`（HTTP/2 与 H2C）                               |
| 日志              | Zap、Logrus、Zerolog、Slog、RequestID、Access Log                    |
| 指标与链路        | Prometheus、OpenTelemetry                                            |
| 限流              | Sentinel                                                             |
| 注册发现          | Nacos、Consul、etcd、Eureka、Polaris、ZooKeeper                      |
| 压缩与缓存        | Gzip、ETag、Cache                                                    |
| 权限与文档        | Casbin、Swagger、i18n                                                |
| 诊断              | pprof、Sentry                                                        |

- 一次只加一个依赖，加完验证失败响应、中间件顺序与退出行为。
