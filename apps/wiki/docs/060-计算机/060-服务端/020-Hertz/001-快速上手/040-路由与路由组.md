# 路由与路由组

## 如何注册一组资源路由？如何定义路由组

- method: GET、POST、PUT、PATCH、DELETE 等 HTTP 方法;
- path: 静态片段、命名参数和通配参数组成的匹配规则;
- Handler chain: 路由组与路由中间件加上最终 Handler;

```go
api := h.Group("/api/v1")
api.GET("/articles", listArticles)
api.POST("/articles", createArticle)
api.GET("/articles/:id", getArticle)
api.PUT("/articles/:id", updateArticle)
api.DELETE("/articles/:id", deleteArticle)
```

## 路由定义的约束有哪些?

- 固定路径优先: 避免参数路由遮蔽特殊动作;
- 方法明确: 不用 `Any` 代替清晰的资源语义;
- 404: 没有路径匹配;
- 405: 路径存在但方法不允许; 是否返回 405 取决于 Engine 配置;
