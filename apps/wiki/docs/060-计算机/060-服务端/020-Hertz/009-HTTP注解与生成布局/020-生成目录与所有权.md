# 生成目录与所有权

## hz 生成的目录里哪些能改、哪些不能？

- 能改: Handler 实现写在 `biz/handler`，入口在根 `main.go`；`biz/model`、`biz/router`、`router_gen.go` 是生成物，看 diff 但不写业务;

```text
article-api/
├─ idl/article.thrift
├─ biz/handler/article/   # Handler 骨架与实现的交界
├─ biz/model/article/     # IDL 生成的请求/响应模型
├─ biz/router/article/    # 生成的路由注册
├─ router_gen.go          # 汇总生成路由，可追加自定义注册
├─ router.go              # 用户自定义路由
└─ main.go                # Engine 组装与进程入口
```

- 入口不能搬到 `cmd/` 后继续调根包的 `register`：

```go
func main() {
	h := server.Default()
	register(h) // router_gen.go 生成的注册入口
	h.Spin()
}
```

- `hz update` 不记住 `new` 时传的 `model_dir`/`handler_dir`，每次带相同参数，否则目录会重排;
