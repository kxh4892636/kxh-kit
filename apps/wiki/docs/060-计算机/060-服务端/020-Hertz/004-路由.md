# 路由

## 一组资源路由怎么挂到同一个前缀下？

- 一个前缀一个组: `h.Group(prefix)` 建组，组内逐条挂方法与路径;

```go
api := h.Group("/api/v1")
api.GET("/articles", listArticles)
api.POST("/articles", createArticle)
api.GET("/articles/:id", getArticle)
api.PUT("/articles/:id", updateArticle)
api.DELETE("/articles/:id", deleteArticle)
```

- 组上的 `Use` 只作用于组内路由;
- `:id` 是命名参数，Handler 用 `c.Param("id")` 读;
- 一次请求的 Handler 链 = 全局中间件 + 组中间件 + 最终 Handler;

## 固定路径和命名参数冲突时谁先命中？

- 固定段优先: `/articles/search` 与 `/articles/:id` 并存时固定段先命中，不靠注册顺序;

- 路径没匹配上 = 404;
- 路径匹配但方法不对，默认也走 404;
- 要 405 必须显式开：`server.Default(server.WithHandleMethodNotAllowed(true))`;
- 不用 `Any` 代替资源语义：方法本身就是契约的一部分;

## 路由注册完用哪几条 curl 验证？

- 两条 curl: 一条查资源，一条发 DELETE;

```bash
curl -i http://127.0.0.1:8888/api/v1/articles/7
curl -i -X DELETE http://127.0.0.1:8888/api/v1/articles/7
```

- 参数怎么取见 [005-Handler与RequestContext](./005-Handler与RequestContext.md);
- 404/405 的契约语义归 [请求生命周期](../000-服务端知识/010-基础模型/010-请求生命周期.md);
- 生成的路由注册在 `biz/router`，见 [009-HTTP注解与生成布局](./009-HTTP注解.md);
