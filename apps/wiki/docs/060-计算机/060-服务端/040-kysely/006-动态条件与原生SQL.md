# 动态条件与原生 SQL

## 条件按需拼接怎么写？

```ts
let query = db.selectFrom("person").selectAll();
if (firstName) query = query.where("first_name", "=", firstName);
const rows = await query.execute();
```

- 每个方法都返回**新** builder: 不赋回变量，条件就被丢掉;
- `where`、`orderBy`、`limit` 用 `if` 没问题;
- `select`、`innerJoin`、`returning` 会改结果类型，要用 `$if`:

```ts
const one = await db
  .selectFrom("person")
  .select("first_name")
  .$if(!!withLastName, (qb) => qb.select("last_name"))
  .where("id", "=", id)
  .executeTakeFirstOrThrow();
```

- 空数组别直接 `in`: 用 `$if` 判空，否则 SQL 是 `in ()` 语法错误;

## 原生 `sql` 怎么嵌？

```ts
import { sql } from "kysely";

await db
  .selectFrom("person")
  .select(["id", sql<string>`upper(${sql.ref("first_name")})`.as("upper_name")])
  .execute();

await sql<{ total: number }>`select count(*) as total from person`.execute(db);
```

- 值自动变参数; 列名用 `sql.ref("a.b")`，标识符用 `sql.id("t","c")` / `sql.table("person")`;
- 只有排序方向这类常量才用 `sql.lit`;
- SQLite 没有 `concat`、`now()`: 用 `||`、`CURRENT_TIMESTAMP` 代替;

## 只想看 SQL 怎么办？

```ts
const q = db.selectFrom("person").select("first_name").where("id", "=", 1).compile();
console.log(q.sql, q.parameters);
// select "first_name" from "person" where "id" = ? [ 1 ]
```

- `.compile()` 不连库; 参数当成列名、少写条件一眼可见;
- 确认索引用 `explain query plan`，`SCAN` 即全表扫描;
- 排查顺序见 [排障](./015-排障与SQLite差异.md)。
