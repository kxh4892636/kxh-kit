# 迁移

## 迁移文件怎么写？

```ts title="migrations/2026-01-01T00-00-00-init.ts"
import { Kysely, sql } from "kysely";

export async function up(db: Kysely<any>): Promise<void> {
  await db.schema
    .createTable("person")
    .addColumn("id", "integer", (col) => col.primaryKey().autoIncrement())
    .addColumn("first_name", "text", (col) => col.notNull())
    .addColumn("created_at", "text", (col) => col.notNull().defaultTo(sql`CURRENT_TIMESTAMP`))
    .execute();
}

export async function down(db: Kysely<any>): Promise<void> {
  await db.schema.dropTable("person").execute();
}
```

- 参数必须是 `Kysely<any>`: 迁移要冻在时间里，不跟业务类型走;
- `up` 必需、`down` 可选; 文件名用 ISO 时间戳前缀，按字母序执行;
- 合入主干后不再改内容，只追加新迁移;

## 改表怎么写？

| 操作      | 写法                                                    |
| --------- | ------------------------------------------------------- |
| 加列      | `alterTable('t').addColumn('c', 'text', cb)`            |
| 改列名    | `alterTable('t').renameColumn('old', 'new')`            |
| 删列      | `alterTable('t').dropColumn('c')`                       |
| 加/删索引 | `createIndex(...)` / `dropIndex('i').ifExists()`        |
| 建/删视图 | `createView('v').as(查询)` / `dropView('v').ifExists()` |

```ts
export async function up(db: Kysely<any>) {
  await db.schema
    .alterTable("pet")
    .addColumn("age", "integer", (col) => col.defaultTo(0))
    .execute();
  await db.schema.createIndex("pet_age_index").on("pet").column("age").execute();
}
```

- 加非空列必须带 `defaultTo`，否则已有行违反约束;
- SQLite 不支持改列类型、加外键: 建新表 → `insert ... select` → 删旧表 → 改名，整段放一个事务;

## 迁移里能改数据吗？

- 能，迁移文件里的 `db` 就是普通连接: `await sql` + `update ... where ...` 即可;
- 数据量大用一条 `sql` 或分批，别在迁移里写业务逻辑;
- 条件写死在当时的数据形态上，不要引用当前业务类型;

## 为什么迁移只会跑一次？

- Kysely 建 `kysely_migration`、`kysely_migration_lock` 并加库级锁，多进程并发也串行;
- 表已存在说明迁移被手工跑过: 不要改历史迁移，追加新迁移; 怎么跑见 [运行迁移与上线](./013-运行迁移与上线.md)。
