# 查询与过滤

## 列怎么选、别名怎么写？

```ts
const rows = await db
  .selectFrom("person as p")
  .innerJoin("pet", "pet.owner_id", "p.id")
  .select(["p.id", "p.last_name as ln", "pet.name as pet_name"])
  .execute();
// 类型: { id: number; ln: string | null; pet_name: string }[]
```

- 表达式必须 `.as('名字')`，否则编译报错; 去重 `.distinct()`;
- 排序分页: `.orderBy("created_at", "desc").limit(20).offset(40)`;

## `where` 能用哪些操作符？

| 类别 | 操作符                                         |
| ---- | ---------------------------------------------- |
| 比较 | `=`、`!=`、`>`、`>=`、`<`、`<=`                |
| 集合 | `in`、`not in`                                 |
| 空值 | `is`、`is not`（`= null` 永远不成立）          |
| 模式 | `like`、`ilike`                                |
| 区间 | 没有 `between`，用 `eb.between('age', 18, 60)` |

```ts
const rows = await db
  .selectFrom("person")
  .selectAll()
  .where("first_name", "like", "%a%")
  .where("last_name", "is not", null)
  .where("id", "in", [1, 2, 3])
  .execute();
```

## 多个条件、或、非怎么组合？

- 链式多个 `where` 之间是 `and`; 要 `or`、`not`、`exists` 就用回调:

```ts
.where(({ eb, or }) => or([eb("first_name", "=", "Jennifer"), eb("age", "<", 60)]))
```

## 列与列比较怎么写？

```ts
.whereRef("pet.owner_id", "=", "person.id") // ✅ 两列比较
.where("pet.owner_id", "=", "person.id")    // ❌ 字符串当值，永远不匹配
```

- 口诀: 右边是**列**用 `whereRef`，是**值**用 `where`;
- 条件按需拼接、SQL 写不出来时见 [动态条件与原生 SQL](./006-动态条件与原生SQL.md)。
