# 连接与聚合

## 表怎么连？

```ts
const rows = await db
  .selectFrom("person")
  .leftJoin("pet", "pet.owner_id", "person.id")
  .select(["person.id", "pet.name as pet_name"]) // leftJoin 后 pet.name 带 null
  .execute();
```

| 方法        | 语义                      | SQLite |
| ----------- | ------------------------- | ------ |
| `innerJoin` | 两边都匹配才留            | 支持   |
| `leftJoin`  | 左表全留，右表缺失补 null | 支持   |
| `rightJoin` | 右表全留                  | 3.39+  |

- `.select()` 必须写在 join 之后，否则引用的表还不在上下文里;
- 多条件用回调 `onRef`（比两列）与 `on`（比列与值）:

```ts
.innerJoin("pet", (join) =>
  join.onRef("pet.owner_id", "=", "person.id").on("pet.species", "=", "dog"),
)
```

## 只查「有没有」怎么写？

```ts
.where((eb) =>
  eb.exists(eb.selectFrom("pet").select("pet.id").whereRef("pet.owner_id", "=", "person.id")),
)
```

- `exists` 只关心有没有，通常比 `in` 先短路;
- `where('id', 'in', 子查询)` 也能用: 子查询只选一列，别先 `execute` 再塞数组;

## 聚合与分组怎么写？

```ts
const rows = await db
  .selectFrom("person")
  .innerJoin("pet", "pet.owner_id", "person.id")
  .select((eb) => ["person.id", eb.fn.count<number>("pet.id").as("pet_count")])
  .groupBy("person.id")
  .having((eb) => eb.fn.count("pet.id"), ">", 1)
  .execute();
```

- 聚合函数: `eb.fn.count / countAll / avg / sum / max`，泛型参数决定结果类型;
- 非聚合列必须出现在 `groupBy` 里; `count(列)` 不数 null，数行用 `countAll()`;
- join 后行会重复，要数人就用 `count(distinct 列)` 的 `sql` 片段;
- 每行要带子表列表时，见 [嵌套关联结果](./008-嵌套关联结果.md)。
