# 安装与连接

## 装什么包？

```bash
npm init -y && npm pkg set type=module
npm i kysely better-sqlite3
npm i -D typescript tsx @types/node @types/better-sqlite3
```

## db 实例怎么写？

```ts title="src/db.ts"
import SQLite from "better-sqlite3";
import { Kysely, ParseJSONResultsPlugin, SqliteDialect } from "kysely";
import type { Database } from "./types";

const sqlite = new SQLite("dev.sqlite", { timeout: 5000 });
sqlite.pragma("journal_mode = WAL");

export const db = new Kysely<Database>({
  dialect: new SqliteDialect({ database: sqlite }),
  plugins: [new ParseJSONResultsPlugin()],
});
```

## 怎么确认连上、怎么关库？

```ts
const { rows } = await sql<{ ok: number }>`select 1 as ok`.execute(db);

process.on("SIGTERM", async () => {
  await db.destroy();
  process.exit(0);
});
```

- 驱动是懒初始化; 建实例成功不等于连通, 必须真跑一条查询; 连不上就在启动阶段退出;
- 不关库会占着文件句柄, 进程退不掉; 谁创建谁关闭, 别两边都关;
