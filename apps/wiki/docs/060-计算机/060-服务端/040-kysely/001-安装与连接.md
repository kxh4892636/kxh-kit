# 安装与连接

## 要装哪些包？

```bash
npm init -y && npm pkg set type=module
npm i kysely better-sqlite3
npm i -D typescript tsx @types/node @types/better-sqlite3
```

- Kysely 不带驱动: SQLite 用 `better-sqlite3`，Postgres 用 `pg`;
- `tsconfig` 必须 `strict: true` + `module: "Preserve"` + `moduleResolution: "Bundler"`，否则类型推导失效、`tsx` 解析不了;

## db 实例怎么写？

```ts title="src/db.ts"
import SQLite from "better-sqlite3";
import { Kysely, SqliteDialect } from "kysely";
import type { Database } from "./types";

export const db = new Kysely<Database>({
  dialect: new SqliteDialect({ database: new SQLite("dev.sqlite") }),
});
```

- 全进程一个实例，按请求新建没有意义;
- 配置项只有三个: `dialect`、`plugins`、`log`;
- 库路径走环境变量，`*.sqlite*` 进 `.gitignore`;

## 怎么确认连上了？

```ts
import { sql } from "kysely";
const { rows } = await sql<{ ok: number }>`select 1 as ok`.execute(db);
```

- 驱动懒初始化: 建实例成功 ≠ 连通，必须真跑一条查询;

## 怎么关库？

```ts
process.on("SIGTERM", async () => {
  await db.destroy();
  process.exit(0);
});
```

- 不关会占着文件句柄，进程可能退不掉; 谁创建谁关闭，别两边都关;
- 跑代码: `npx tsx src/main.ts`; 只查类型: `npx tsc --noEmit`;
- 分层与事务边界见 [Repository 与事务](../000-服务端知识/050-数据访问/010-Repository与事务.md)。
