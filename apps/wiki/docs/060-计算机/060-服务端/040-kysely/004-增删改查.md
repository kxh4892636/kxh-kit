# 增删改查

## 一屏跑通要写什么？

```ts title="src/main.ts"
import { db } from "./db";

await db.schema
  .createTable("person")
  .ifNotExists()
  .addColumn("id", "integer", (col) => col.primaryKey().autoIncrement())
  .addColumn("first_name", "text", (col) => col.notNull())
  .addColumn("last_name", "text")
  .execute();

const person = await db
  .insertInto("person")
  .values({ first_name: "Jennifer", last_name: "Aniston" })
  .returningAll()
  .executeTakeFirstOrThrow();

const rows = await db
  .selectFrom("person")
  .select(["id", "first_name as fn"])
  .where("id", "=", person.id)
  .execute();

const updated = await db
  .updateTable("person")
  .set({ last_name: "Aniston-Clark" })
  .where("id", "=", person.id)
  .executeTakeFirst();

const deleted = await db.deleteFrom("person").where("id", "=", person.id).executeTakeFirst();

console.log(rows); // [ { id: 1, fn: 'Jennifer' } ]
console.log(Number(updated.numUpdatedRows), Number(deleted.numDeletedRows)); // 1 1

await db.destroy();
```

## 每一步的坑是哪几个？

| 步骤 | 查什么                                  | 展开                              |
| ---- | --------------------------------------- | --------------------------------- |
| 建表 | 结尾有 `.execute()`                     | [建表与索引](./003-建表与索引.md) |
| 插入 | `.values()` 调两次是覆盖，不是追加      | [写入](./009-写入.md)             |
| 查询 | `executeTakeFirst()` 可能回 `undefined` | [查询与过滤](./005-查询与过滤.md) |
| 更新 | 漏 `.where()` 就是全表改，且不报错      | [写入](./009-写入.md)             |
| 删除 | 漏 `.where()` 就是清库                  | [写入](./009-写入.md)             |

- 跑通的标准: 打印出查询结果、`dev.sqlite` 里有数据;
- 报 `no such table` 说明建表没执行，检查是否漏了 `.execute()`; 其他报错见 [排障](./015-排障与SQLite差异.md)。
