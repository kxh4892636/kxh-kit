# 事务

## 最简单的事务怎么写？

```ts
const pet = await db.transaction().execute(async (trx) => {
  const person = await trx
    .insertInto("person")
    .values({ first_name: "Jennifer", last_name: "Aniston" })
    .returning("id")
    .executeTakeFirstOrThrow();

  return await trx
    .insertInto("pet")
    .values({ owner_id: person.id, name: "Catto", species: "cat" })
    .returningAll()
    .executeTakeFirstOrThrow();
});
```

- 回调抛错自动回滚，正常返回自动提交; 返回值就是事务返回值;
- 事务内的读写全部用 `trx`，用外层 `db` 会脱离事务，SQLite 下抢写锁;

## 要自己控制提交时机怎么办？

```ts
const trx = await db.startTransaction().execute();

try {
  await trx.insertInto("person").values({ first_name: "A", last_name: null }).execute();
  await trx.commit().execute();
} catch (error) {
  await trx.rollback().execute();
  throw error;
}
```

- 忘 `commit()` 时连接释放会回滚，症状是「写成功了但查不到」;

## 事务里哪些事不能做？

- 用外层 `db` 写: 不在事务内，SQLite 下等锁超时;
- 事务里做慢外部调用: 写锁不释放，其他写入全排队;
- 嵌套 `db.transaction()`: 直接抛错，部分回滚改用保存点;
- 事务里 `db.destroy()`: 回滚，后续语句全部失败;

## 部分回滚怎么做？

- 需要「某段失败只撤销这一段」时用保存点，且只在 `startTransaction()` 的受控事务上可用:

```ts
const sp = await trx.savepoint("after_audit").execute();
await sp.rollbackToSavepoint("after_audit").execute();
```

## 出错怎么查？

- `SQLITE_BUSY: database is locked` 是抢不到写锁: 缩短事务、开 WAL、加 `timeout`;
- 想看实际执行的语句，配 `log` 回调，见 [插件与日志](./014-插件与日志.md)。
