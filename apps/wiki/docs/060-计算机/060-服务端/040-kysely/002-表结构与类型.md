# 表结构与类型

## `Database` 接口怎么写？

- 键是表名, 值是列定义; 只描述列, 不描述关系;
- 可空列写 `string | null`, 不写可选属性 `?`;

```ts title="src/types.ts"
import type { ColumnType, Generated, JSONColumnType } from "kysely";

export interface Database {
  person: {
    id: Generated<number>;
    first_name: string;
    last_name: string | null;
    updated_at: ColumnType<string, string | undefined, never>;
    metadata: JSONColumnType<{ plan: "free" | "premium" }>;
  };
}
```

| 需求               | 写法                                             | 效果                  |
| ------------------ | ------------------------------------------------ | --------------------- |
| 库生成 / 有默认值  | `Generated<number>`                              | 插入、更新时自动可选  |
| 读写类型不同       | `ColumnType<读, 插入, 更新>`                     | 三个动作各用各的类型  |
| 插入可省、永不更新 | `ColumnType<string, string \| undefined, never>` | `Updateable` 里被剔除 |
| JSON 列            | `JSONColumnType<T>`                              | 读 `T`, 写 JSON 文本  |

- `never` 表示这一列在这个动作里不能出现; 想禁止更新就用它;

## 业务层对外用什么类型？

```ts
import type { Insertable, Selectable, Updateable } from "kysely";

type PersonTable = Database["person"];
type Person = Selectable<PersonTable>; // 全列必填
type NewPerson = Insertable<PersonTable>; // Generated 列可选
type PersonUpdate = Updateable<PersonTable>; // 全列可选，never 列消失

export async function createPerson(person: NewPerson): Promise<Person> {
  return await db.insertInto("person").values(person).returningAll().executeTakeFirstOrThrow();
}
```

- 函数签名只出现这三个, 别把 `Generated`、`ColumnType` 漏到业务层;

## 类型怎么生成、怎么收窄？

- 表多时反向生成: `kysely-codegen --dialect sqlite --url dev.sqlite --out-file src/db.d.ts`; 先跑迁移再生成, 空库生成的是空类型; 用 `CamelCasePlugin` 就加 `--camel-case`;

| 症状                            | 写法                                                                  |
| ------------------------------- | --------------------------------------------------------------------- |
| 结果 `X \| null` 但业务上不为空 | `.$narrowType<{ 列: NotNull }>()`                                     |
| 子查询当标量用                  | `.$asScalar()`, 确定非空再 `.$notNull()`                              |
| 关联对象要判空                  | `jsonObjectFrom(q).$notNull()`, 见 [005](./005-连接聚合与嵌套结果.md) |
| `Property 'xxx' does not exist` | 列名拼错, 或 `select` 写在了 join 之前                                |
