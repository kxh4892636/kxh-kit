# 写入

## 插入怎么写？

```ts
const inserted = await db
  .insertInto("person")
  .values({ first_name: "Jennifer", last_name: "Aniston" })
  .executeTakeFirst();
Number(inserted.insertId); // 1（bigint）
```

- 多行用数组 `.values([...])`: 调两次 `.values()` 是覆盖，不是追加;
- 要插入后的整行加 `.returningAll()`，只要部分列用 `.returning([...])`;

## 更新怎么写？

```ts
const result = await db
  .updateTable("person")
  .set({ last_name: "Aniston-Clark" })
  .where("id", "=", 1)
  .executeTakeFirst();

Number(result.numUpdatedRows); // 1
```

- `.where()` 必写，漏了就是整表更新，Kysely 不拦;
- `set` 里可以放表达式: `.set((eb) => ({ age: eb("age", "+", 1) }))`;
- 要改后的行就 `.returning([...])`，此时不再返回影响行数;

## 删除怎么写？

```ts
const result = await db.deleteFrom("person").where("id", "=", 1).executeTakeFirst();
Number(result.numDeletedRows); // 1

// 拿回被删的行
await db.deleteFrom("pet").where("name", "=", "Catto").returningAll().execute();
```

- 建表写了 `onDelete('cascade')` 才会级联删子行;
- 软删除自己加 `deleted_at`，查询永远带 `.where("deleted_at", "is", null)`;
- SQLite 没有 `truncate`: 清空整表用 `sql` 模板执行 `delete from`;

## 一次写很多行怎么办？

- 切成几十~几百行一批，整批包进一个事务:

```ts
await db.transaction().execute(async (trx) => {
  for (let i = 0; i < rows.length; i += 500) {
    await trx
      .insertInto("person")
      .values(rows.slice(i, i + 500))
      .execute();
  }
});
```

- 单语句参数上限 32766，按「列数 × 行数 < 3 万」切批，超了报 `too many SQL variables`;
- 冲突与 upsert 见 [冲突与 upsert](./010-冲突与upsert.md)。
