# 建表与索引

## 建一张表怎么写？

```ts
import { sql } from "kysely";
import { db } from "./db";

await db.schema
  .createTable("person")
  .addColumn("id", "integer", (col) => col.primaryKey().autoIncrement())
  .addColumn("first_name", "text", (col) => col.notNull())
  .addColumn("owner_id", "integer", (col) => col.references("person.id").onDelete("cascade"))
  .addColumn("created_at", "text", (col) => col.notNull().defaultTo(sql`CURRENT_TIMESTAMP`))
  .execute();
```

- 链式描述列，最后 `.execute()` 才真正执行；漏了它什么也不会发生;
- 幂等脚本加 `.ifNotExists()`；迁移里不需要，每个迁移只跑一次。

## 列约束怎么写？

| 约束   | 写法                                                        |
| ------ | ----------------------------------------------------------- |
| 非空   | `col.notNull()`                                             |
| 唯一   | `col.unique()`（做 upsert 的前提）                          |
| 主键   | `col.primaryKey()`，SQLite 配 `integer` + `autoIncrement()` |
| 默认值 | `col.defaultTo(v)` / `defaultTo(sql\`...\`)`                |
| 外键   | `col.references('person.id').onDelete('cascade')`           |

## 索引怎么建和删？

```ts
await db.schema.createIndex("pet_owner_id_index").on("pet").column("owner_id").execute();
await db.schema.createIndex("pet_name_unique").on("pet").column("name").unique().execute();
await db.schema.dropIndex("pet_owner_id_index").ifExists().execute();
```

- 索引建在 `on(表).column(列)` 上，多列继续 `.column()`；唯一索引用 `.unique()`;
- 命名约定 `<表>_<列>_index`；删索引带 `ifExists()`，换环境才不炸;
- 实验/测试里直接调用，真实项目写进迁移，见 [012-迁移](./012-迁移.md)。
