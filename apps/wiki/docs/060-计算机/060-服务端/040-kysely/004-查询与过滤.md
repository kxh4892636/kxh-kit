# 查询与过滤

## 列怎么选、别名怎么写？

```ts
const rows = await db
  .selectFrom("person as p")
  .innerJoin("pet", "pet.owner_id", "p.id")
  .select(["p.id", "p.last_name as ln", "pet.name as pet_name"])
  .orderBy("p.id", "desc")
  .limit(20)
  .offset(40)
  .execute();
// 类型: { id: number; ln: string | null; pet_name: string }[]
```

- 表达式必须 `.as('名字')`, 否则编译报错; 去重加 `.distinct()`;

## `where` 能用哪些操作符？

| 类别 | 操作符                                         |
| ---- | ---------------------------------------------- |
| 比较 | `=`、`!=`、`>`、`>=`、`<`、`<=`                |
| 集合 | `in`、`not in`                                 |
| 空值 | `is`、`is not`（`= null` 永远不成立）          |
| 模式 | `like`、`ilike`                                |
| 区间 | 没有 `between`, 用 `eb.between('age', 18, 60)` |

```ts
const rows = await db
  .selectFrom("person")
  .selectAll()
  .where("last_name", "is not", null)
  .where("id", "in", [1, 2, 3])
  .where(({ eb, or }) => or([eb("age", "<", 60), eb("vip", "=", 1)])) // or / not / exists 用回调
  .whereRef("pet.owner_id", "=", "person.id") // ✅ 列比列
  .execute();
```

- 链式 `where`: 彼此是 `and`;
- 需要 `or`、`not`、`exists`: 改用回调;
- 右边是列: 用 `whereRef`; 右边是值: 用 `where`;
- 反例: `where("a", "=", "b")` 永远不匹配;

## 条件按需拼接怎么写？

```ts
let query = db.selectFrom("person").selectAll();
if (firstName) query = query.where("first_name", "=", firstName);
const rows = await query.execute();

// 改结果类型的条件用 $if；空数组也要 $if 判空，否则 SQL 是 in ()
const one = await db
  .selectFrom("person")
  .select("first_name")
  .$if(!!withLastName, (qb) => qb.select("last_name"))
  .$if(ids.length > 0, (qb) => qb.where("id", "in", ids))
  .executeTakeFirstOrThrow();
```

- 每个方法: 返回新 builder, 不赋回变量就会丢掉条件;
- 可用 `if`: `where`、`orderBy`、`limit`;
- 必须用 `$if`: `select`、`innerJoin`、`returning` 会改结果类型;

## 原生 `sql` 和 `compile()` 怎么用？

```ts
import { sql } from "kysely";

await db
  .selectFrom("person")
  .select(["id", sql<string>`upper(${sql.ref("first_name")})`.as("up")])
  .execute();
await sql<{ total: number }>`select count(*) as total from person`.execute(db);

const q = db.selectFrom("person").select("first_name").where("id", "=", 1).compile();
console.log(q.sql, q.parameters); // select "first_name" from "person" where "id" = ? [ 1 ]
```

- 插值: 自动变成参数, 这是防注入的唯一正确做法;
- 理由: 见 [查询与访问路径](../000-服务端知识/050-数据访问/030-查询与访问路径.md);
- 列名: 用 `sql.ref("a.b")`;
- 标识符: 用 `sql.id("t","c")`;
- 常量: 只有排序方向这类才用 `sql.lit`;
- SQLite 没有 `concat` 与 `now()`;
- 替代: 用 `||` 与 `CURRENT_TIMESTAMP`;
- `.compile()` 不连库; 参数当成列名、少写条件一眼可见;
