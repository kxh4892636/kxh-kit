# 060-服务端

这里按「道 / 术」分两层：

- [000-服务端知识](./000-服务端知识/README.md) 是「道」：框架无关的服务端原理、判断规则与失败模式，值得记住；
- [010-Kitex](./010-Kitex/README.md)、[020-Hertz](./020-Hertz/README.md)、[030-hono](./030-hono/README.md)、[040-kysely](./040-kysely/README.md) 是「术」：只写各框架怎么接，用时查，不用背。

## 怎么用

1. 先读 `000` 的相关篇，建立模型：这件事为什么必须做对、做错是什么症状；
2. 再进对应框架目录，查最小接入代码与关键 API/选项；
3. 换框架时只重读接入代码，原理不用重学。

## 维护约定

- 通用原理只写在 `000`，框架目录只保留接入代码与框架 API，不重复解释「为什么」；
- 新增框架时，`000` 不动，只新增一个框架目录；
- 每篇至少一个最小示例，示例要能直接复制运行。
