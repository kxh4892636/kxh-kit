# 最小服务与心智模型

## 在 Node.js 上起一个 Hono 服务最少要什么？

- 依赖: `hono` + `@hono/node-server`；Node 20 及以上;
- 脚手架: `npm create hono@latest my-app -- --template nodejs`（`--` 必须带，参数才透传）;
- 三份文件: `package.json`、`tsconfig.json`、`src/index.ts`;

```json title="package.json"
{
  "type": "module",
  "scripts": { "dev": "tsx watch src/index.ts", "build": "tsc", "start": "node dist/index.js" },
  "dependencies": { "hono": "^4", "@hono/node-server": "^2" },
  "devDependencies": { "typescript": "^5", "tsx": "^4", "@types/node": "^22" }
}
```

```ts title="src/index.ts"
import { serve } from "@hono/node-server";
import { Hono } from "hono";

const app = new Hono();
app.get("/", (c) => c.text("Hello Node.js!"));

serve({ fetch: app.fetch, port: Number(process.env.PORT ?? 3000) }, (info) => {
  console.log(`http://localhost:${info.port}`);
});
```

- 两处不能省: `"type": "module"` + `"module": "NodeNext"`（产物按 CJS 跑时 `import` 直接报错）；`strict: true`（否则 `c.req.param()` 的字面量类型退化）;
- 验证: `npm run dev` 后 `curl -i http://localhost:3000/`，期望 200、`text/plain; charset=UTF-8`。

## serve() 接哪些参数？

- 基本: `serve({ fetch: app.fetch, port, hostname })`；`port` 默认 `3000`，`serve(app)` 是简写;
- 返回原生 `node:http` server，关闭由应用负责，见 [009](./009-运维接入.md);
- 其他选项: `createServer`（换 `node:https`/`node:http2`）、`serverOptions`、`websocket`;
- 容器里 `hostname: "0.0.0.0"`，端口走环境变量。

## 常用名词指什么？

| 名词   | 含义                                                   |
| ------ | ------------------------------------------------------ |
| `app`  | `Hono` 实例，一个应用或一个子路由                      |
| `c`    | 每请求一份的 Context，读写请求、设响应、存取请求级变量 |
| `Env`  | `Bindings` + `Variables`，决定 `c.env`/`c.var` 的类型  |
| Helper | 中间件，如 `hono/cookie`、`hono/streaming`             |
| Router | 匹配算法，默认 `SmartRouter(RegExp + Trie)`            |

- Handler 是唯一返回 `Response` 的一层；中间件签名 `(c, next) => Promise<void | Response>`，提前返回即短路;
- Hono 不带 ORM、DI、模块系统与 session 存储，全部自己选。
