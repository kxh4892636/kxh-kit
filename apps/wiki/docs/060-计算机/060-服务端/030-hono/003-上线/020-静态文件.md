# 静态文件

## serveStatic 适合什么流量，命中与未命中怎么走？

- 小流量、内网、单体服务: 用 `serveStatic` 让 Node 直接读盘返回，够用;
- 大流量: 交 Nginx/CDN，应用不碰静态字节;

```ts
import { serveStatic } from "@hono/node-server/serve-static";

app.use("/static/*", serveStatic({ root: "./" })); // ./static/hello.txt
app.use("/hello.txt", serveStatic({ root: "./static" })); // ./static/hello.txt
app.use("/favicon.ico", serveStatic({ path: "./favicon.ico" }));
```

- 命中: 直接返回 `Response`; 未命中: 调 `next()`，不短路，后面还能挂兜底 Handler;
- 绕过: 静态中间件挂在不带鉴权的路径上时，访问控制要覆盖同一路径模式;

## root 为什么会在容器里 404？

- 基准: `root` 相对**进程工作目录**（`process.cwd()`），不是源码位置; 容器、systemd、IDE 换目录启动就错位;
- 锚定: 用 `import.meta.url` 锁住模块目录，换启动目录不 404;

```ts
import { fileURLToPath } from "node:url";
import { serveStatic } from "@hono/node-server/serve-static";

app.use("/static/*", serveStatic({ root: fileURLToPath(new URL("./", import.meta.url)) }));
```

## URL 前缀和磁盘目录不一致怎么办？

- 改写: `rewriteRequestPath` 把 URL 前缀映射到真实目录;
- 缓存头: `onFound` 是加 `Cache-Control` 的正位;

```ts
app.use(
  "/static/*",
  serveStatic({
    root: "./",
    rewriteRequestPath: (p) => p.replace(/^\/static/, "/statics"),
    onFound: (_path, c) => {
      c.header("Cache-Control", "public, max-age=31536000, immutable");
    },
  }),
);
```

## 静态资源该由谁加缓存头？

- 小流量、内网: Node 自己服务并配 ETag;
- 大流量: Nginx/CDN 服务，静态资源带内容哈希文件名;
