# 静态文件

## serveStatic 怎么挂，未命中怎么办？

- 用途: 小流量、内网、单体服务让 Node 直接读盘返回；大流量交 Nginx/CDN，应用不碰静态字节;
- 命中直接返回 `Response`，未命中调 `next()` 不短路，后面还能挂兜底 Handler;

```ts
import { serveStatic } from "@hono/node-server/serve-static";

app.use("/static/*", serveStatic({ root: "./" })); // ./static/hello.txt
app.use("/favicon.ico", serveStatic({ path: "./favicon.ico" }));
```

## root 为什么在容器里 404？

- 基准: `root` 相对**进程工作目录**（`process.cwd()`），不是源码位置；容器、systemd、IDE 换目录启动就错位;
- 锚定: 用 `import.meta.url` 锁住模块目录，换启动目录也不会 404;

```ts
app.use("/static/*", serveStatic({ root: fileURLToPath(new URL("./", import.meta.url)) }));
```

## 前缀不一致与缓存头怎么处理？

```ts
app.use(
  "/static/*",
  serveStatic({
    root: "./",
    rewriteRequestPath: (p) => p.replace(/^\/static/, "/statics"),
    onFound: (_p, c) => c.header("Cache-Control", "public, max-age=31536000, immutable"),
  }),
);
```

- `immutable` 只给带内容哈希的文件名；其余用短 `max-age` 或 `etag()`，见 [HTTP 缓存与 ETag](../../000-服务端知识/020-契约与错误/030-HTTP缓存与ETag.md);
- 静态中间件挂在不带鉴权的路径上时，访问控制要覆盖同一路径模式;
