# 构建与运行产物

## 从 tsx watch 到 dist 的产物链怎么搭？

- 产物链: `tsx watch` → `tsc` → `node dist/index.js` → 反向代理 → 探针与日志; 开发热重载，生产只跑 `dist/*.js`;
- 脚本: `dev` = `tsx watch src/index.ts`; `build` = `tsc`; `start` = `node dist/index.js`;
- 入口: 只做 `serve`，端口与地址来自环境变量;

```ts
import { serve } from "@hono/node-server";
import { app } from "./app.js";

serve({
  fetch: app.fetch,
  port: Number(process.env.PORT ?? 3000),
  hostname: process.env.HOST ?? "0.0.0.0",
});
```

- `hostname`: 默认已是 `0.0.0.0`; 写 `127.0.0.1` 容器外连不上; `PORT` 从环境读，不写死;

## tsc 产物为什么必须声明 ESM？

- `package.json` 缺 `"type": "module"`: `dist/*.js` 被当 CJS 执行，直接报错;
- `NodeNext`: 相对导入带扩展名，写 `./app.js`;

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "rootDir": "./src",
    "outDir": "./dist",
    "types": ["node"]
  }
}
```

## 镜像为什么要分 builder 与 runner 两段？

- 分段: builder 里 `npm ci && npm run build` 再 `npm prune --production`; runner 只带 `dist`、`package.json` 与生产依赖，`tsx`、`typescript` 不进镜像;
- 非 root: `adduser --system` + `USER hono`; `.dockerignore` 排除 `node_modules`、`dist`、`.env`;
- 排障: 日志到 stdout/stderr; 本地时间在镜像里设 `TZ`; 原生模块（如 sharp）架构与运行环境一致; 敏感配置全来自环境变量，启动时校验;

```dockerfile title="Dockerfile"
FROM node:22-alpine AS builder
WORKDIR /app
COPY . .
RUN npm ci && npm run build && npm prune --production

FROM node:22-alpine AS runner
WORKDIR /app
RUN addgroup --system --gid 1001 nodejs && adduser --system --uid 1001 hono
COPY --from=builder --chown=hono:nodejs /app/node_modules ./node_modules
COPY --from=builder --chown=hono:nodejs /app/dist ./dist
COPY --from=builder --chown=hono:nodejs /app/package.json ./package.json
USER hono
CMD ["node", "dist/index.js"]
```

## HTTP/2 该由应用还是网关终结？

- 网关: 前面有网关时通常由网关终结 HTTP/2，应用仍跑 HTTP/1.1; 直连客户端才让 Node 开 secure server，证书由 Node 管理; `@hono/node-server` 2.x 可换 `createSecureServer`;
- H2C（明文）不提供加密与认证，只在受控网络用;

```ts
import { serve } from "@hono/node-server";
import { createSecureServer } from "node:http2";

serve({
  fetch: app.fetch,
  createServer: createSecureServer,
  serverOptions: { key, cert }, // PEM
});
```
