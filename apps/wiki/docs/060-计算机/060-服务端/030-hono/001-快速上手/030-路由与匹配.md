# 路由与匹配

## 路由怎么注册？

- 职责: 把「URL + 方法」映射到一个返回 `Response` 的 Handler；子路由再把大应用拆成按资源划分的小文件挂到前缀下;

```ts
import { Hono } from "hono";

const app = new Hono();

app.get("/", (c) => c.text("GET /"));
app.post("/", (c) => c.text("POST /"));
app.all("/any", (c) => c.text("任意方法"));
app.on("PURGE", "/cache", (c) => c.text("自定义方法"));
app.on(["PUT", "DELETE"], "/post", (c) => c.text("两种方法"));
app.on("GET", ["/hello", "/ja/hello"], (c) => c.text("两条路径"));
app.get("/wild/*/card", (c) => c.text("通配符"));
```

- 覆盖范围: `app.get/post/put/delete` 管标准方法，`app.on(method, path, ...)` 管自定义方法与多方法/多路径;
- 匹配顺序: 一条路由可挂多个处理函数，按注册顺序执行，最后一个返回 `Response`；注册顺序即匹配顺序，`app.get("*")` 写在前面会吞掉后续所有路由，兜底放最后;
- 链式写法: `.get(...).post(...)` 后续 Handler 可省略路径；只有链式注册能让 `AppType` 完整推理，RPC 与 `testClient` 依赖它，见 [不写控制器与 factory](../002-服务端开发/010-不写控制器与factory.md);

## 路径参数和通配符怎么匹配？

| 写法                         | 匹配                             | 读取                  |
| ---------------------------- | -------------------------------- | --------------------- |
| `/user/:name`                | `/user/张三`                     | `c.req.param("name")` |
| `/api/animal/:type?`         | `/api/animal`、`/api/animal/dog` | 可能为 `undefined`    |
| `/post/:date{[0-9]+}`        | 只匹配数字                       | 同上                  |
| `/posts/:filename{.+\\.png}` | 允许多段与点号                   | 同上                  |
| `*`                          | 任意路径                         | —                     |

```ts
app.get("/posts/:id/comment/:commentId", (c) => c.json(c.req.param())); // 一次取全部参数
```

- 正则段: 写在 `{}` 里，必须匹配整段，否则路由不命中；参数段默认不含斜杠，要吞斜杠用 `:id{.+}`;
- 严格模式: 默认开启，`/hello` 不等于 `/hello/`，用 `new Hono({ strict: false })` 关闭;
- 匹配范围: `getPath` 可把 hostname 等纳入匹配，但多租户/灰度更推荐在网关层做；尾斜杠自动重定向用 `appendTrailingSlash` / `trimTrailingSlash`，见 [内置中间件速查](../090-按需查阅/010-内置中间件速查.md);
- HEAD: 匹配前按 GET 处理并丢弃响应体，不要单独依赖 `app.head()`；测试时同时断言 GET 与 HEAD;

## 子路由怎么挂？

```ts
// routes/book.ts
const book = new Hono();
book.get("/", (c) => c.text("List Books"));
book.get("/:id", (c) => c.text(c.req.param("id")));

// app.ts
const app = new Hono();
app.route("/book", book); // GET /book、GET /book/:id
```

- 两种挂法: `app.route(prefix, app)` 把子应用整棵路由树挂到前缀下，子应用内部写相对路径；`new Hono().basePath("/api")` 把前缀写在子应用上，适合自带固定前缀、要独立运行/测试的子应用，挂载时 `app.route("/", api)`;
- 陷阱: `route()` 拷贝的是「当时已有」的路由，之后往子应用加路由不会同步；必须「先装配，最后挂载」，否则表现为 404 且不报错;
- 路由器选型: [路由器与预设](../003-上线/050-路由器与预设.md)；命中后取值: [读取请求](./040-读取请求.md);
