# 启动与验证

## `serve()` 有哪些启动参数？

| 选项                    | 作用                                        | 默认             |
| ----------------------- | ------------------------------------------- | ---------------- |
| `fetch`                 | 应用入口，传 `app.fetch`                    | —                |
| `port`                  | 监听端口                                    | `3000`           |
| `hostname`              | 监听地址                                    | 取决于 Node 默认 |
| `createServer`          | 换成 `node:https` / `node:http2` 的创建函数 | `node:http`      |
| `serverOptions`         | 传给 `createServer` 的 TLS 等参数           | —                |
| `websocket`             | 提供 WebSocket 服务端                       | —                |
| `overrideGlobalObjects` | 用轻量 Request/Response 覆盖全局对象提性能  | `true`           |
| `autoCleanupIncoming`   | 未读完请求体时主动销毁连接                  | `true`           |

```ts
serve({
  fetch: app.fetch,
  port: Number(process.env.PORT ?? 3000),
  hostname: "0.0.0.0", // 容器内必须监听 0.0.0.0，否则宿主机连不上
});
```

- `serve(app)` 是简写，等价于 `serve({ fetch: app.fetch })`;
- `serve()` 返回 `node:http` 的 server 实例，关闭由你负责，见 [优雅退出](../003-上线/030-优雅退出.md);

## 怎么验证服务真的跑起来了？

```sh
npm run dev
curl -i http://localhost:3000/
# 期望: HTTP/1.1 200 OK + Content-Type: text/plain; charset=UTF-8 + Hello Node.js!
```

- 先看端口是否被占用：`lsof -i :3000` 或 `ss -ltnp | grep 3000`;
- 改了代码没生效，多半是 `dev` 脚本没跑 `watch`，或进程启动目录不对;

## 怎么访问 Node 原生对象？

```ts
import { serve, type HttpBindings } from "@hono/node-server";

type Bindings = HttpBindings;

const app = new Hono<{ Bindings: Bindings }>();

app.get("/ip", (c) => c.json({ ip: c.env.incoming.socket.remoteAddress }));
```

- `c.env.incoming` / `c.env.outgoing` 是 `node:http` 的 `IncomingMessage` / `ServerResponse`;
- HTTP/2 下类型是 `Http2Bindings`;
- 拿到原生对象通常意味着要写平台相关逻辑，能不用就不用;
