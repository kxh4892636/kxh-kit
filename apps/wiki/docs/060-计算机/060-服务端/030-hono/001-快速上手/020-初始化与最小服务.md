# 初始化与最小服务

## 在 Node.js 上跑一个 Hono 服务要准备什么？

- 最小工程: `package.json`、`tsconfig.json`、`src/index.ts` 三份文件，加 `hono` 与 `@hono/node-server` 两个运行时依赖;
- Node: 官方适配器要求 20 及以上；网站兼容矩阵为 18.14.1+ / 19.7+ / 20+;
- 开发依赖: `typescript`、`tsx`、`@types/node`;
- 模块格式: `package.json` 加 `"type": "module"`，`tsconfig` 用 `"module": "NodeNext"`;

```sh
# npm 必须带 -- 才能把参数透传给 create-hono
npm create hono@latest my-app -- --template nodejs
cd my-app && npm i && npm run dev
```

- 模板参数: `--install`、`--pm pnpm`、`--offline`;

## 三份文件各写什么？

```json title="package.json"
{
  "type": "module",
  "scripts": { "dev": "tsx watch src/index.ts", "build": "tsc", "start": "node dist/index.js" },
  "dependencies": { "hono": "^4", "@hono/node-server": "^2" },
  "devDependencies": { "typescript": "^5", "tsx": "^4", "@types/node": "^22" }
}
```

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "NodeNext",
    "strict": true,
    "rootDir": "./src",
    "outDir": "./dist",
    "types": ["node"]
  }
}
```

```ts title="src/index.ts"
import { serve } from "@hono/node-server";
import { Hono } from "hono";
const app = new Hono();
app.get("/", (c) => c.text("Hello Node.js!"));
serve({ fetch: app.fetch, port: Number(process.env.PORT ?? 3000) }, (info) => {
  console.log(`Server is running on http://localhost:${info.port}`);
});
```

- `strict: true` 不能省: 非严格模式下 Hono 的字面量类型推导会退化（如 `c.req.param()`）;
- `module: NodeNext` + `"type": "module"` 不能省: 否则产物按 CJS 执行，`import` 直接报错;
- `rootDir` / `outDir` 保证 `dist/index.js` 与源码同层级，静态文件与 `import.meta.url` 不会错位;

## serve() 的启动参数与验证怎么做？

- 基本: `serve({ fetch: app.fetch, port, hostname })`；`port` 默认 `3000`，`hostname` 默认随 Node；`serve(app)` 是 `serve({ fetch: app.fetch })` 的简写;
- 其他选项: `createServer`（默认 `node:http`，可换 `node:https` / `node:http2`）、`serverOptions`（TLS 等透传）、`websocket`、`overrideGlobalObjects`（默认 `true`）、`autoCleanupIncoming`（默认 `true`）;
- 返回原生 `node:http` server，关闭由应用负责，见 [优雅退出](../../000-服务端知识/040-可靠性/040-优雅退出/010-退出顺序.md)；容器内监听 `hostname: "0.0.0.0"`，端口与主机名来自环境变量，见 [配置与启动顺序](../../000-服务端知识/010-基础模型/030-配置与启动顺序.md);
- 验证: `npm run dev` 后 `curl -i http://localhost:3000/`，期望 `HTTP/1.1 200 OK`、`Content-Type: text/plain; charset=UTF-8`、`Hello Node.js!`;

## 版本怎么对齐？

- 版本: `hono` 4.x、`@hono/node-server` 2.x、`@hono/zod-validator` 与 `hono` 大版本对齐；RPC 前后端 `hono` 版本必须一致;
- 目录与分层: [分层与依赖方向](../../000-服务端知识/010-基础模型/020-分层与依赖方向/010-依赖方向.md)；下一步: [路由与匹配](./030-路由与匹配.md);
