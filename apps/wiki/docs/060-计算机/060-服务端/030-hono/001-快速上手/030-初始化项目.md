# 初始化项目

## 需要什么环境和依赖？

- Node.js: 官方适配器要求 20 及以上；网站文档兼容矩阵为 18.14.1+ / 19.7+ / 20+;
- 运行时依赖: `hono` + `@hono/node-server`;
- 开发依赖: `typescript`、`tsx`（热重载）、`@types/node`;
- 模块格式: `package.json` 加 `"type": "module"`，`tsconfig` 用 `"module": "NodeNext"`;

## 怎么用脚手架生成 Node 项目？

```sh
# npm 需要 `--` 才能把参数透传给 create-hono
npm create hono@latest my-app -- --template nodejs

cd my-app && npm i && npm run dev
```

- 其他包管理器: `pnpm create hono@latest my-app --template nodejs`、`yarn create hono my-app --template nodejs`;
- 常用参数: `--template`、`--install`、`--pm pnpm`、`--offline`;
- 生成的脚本: `dev` = `tsx watch src/index.ts`、`build` = `tsc`、`start` = `node dist/index.js`;
- 模板里已经带好 `tsconfig`、`src/index.ts` 与 `.gitignore`，改业务直接写 `src/` 即可;

## 不想用脚手架时怎么手工起步？

```sh
npm init -y
npm i hono @hono/node-server
npm i -D typescript tsx @types/node
npx tsc --init
```

- 然后按 [最小可运行代码](./035-最小可运行代码.md) 补齐三个文件;
- 手工起步的好处: 依赖版本自己控，不引入模板里用不到的东西;

## 版本怎么选？

| 包                    | 说明                 |
| --------------------- | -------------------- |
| `hono`                | 4.x，与官方文档一致  |
| `@hono/node-server`   | 2.x，Node 适配器     |
| `@hono/zod-validator` | 与 `hono` 大版本对齐 |

- 前后端共享类型（RPC）时，两端 `hono` 版本必须一致，否则会出现类型推导报错;
- 升级前先看官方迁移说明，中间件与适配器可能同时要求升版;
