# 自定义响应与改写

## 如何返回一个完全自定义的 Response？

```ts
app.get("/raw", () => new Response("Good morning!"));

app.get("/file", (c) => {
  const bytes = new Uint8Array([0x48, 0x69]);
  return c.body(bytes, 200, { "Content-Type": "application/octet-stream" });
});

app.get("/go", (c) => c.redirect("/", 301));
```

- 直接 `new Response(...)` 时 Hono 不再插手，状态码/头都要自己写;
- `c.body()` 只帮你补 `Content-Type` 与状态码，body 可以是字符串、字节数组或可读流;
- 想返回流式内容不要用 `c.body`，用 `stream`/`streamSSE`，见 [流式响应](../090-按需查阅/110-流式响应.md);

## 响应已经发出后还能改吗？

```ts
app.use(async (c, next) => {
  await next();
  c.res.headers.append("X-Debug", "1"); // 改已生成的 Response
});
```

- `c.res` 首次访问前不存在；读取时返回一个 body 为 `null` 的占位 `Response`，`await next()` 之后才是真实响应;
- 给 `c.res` 赋新值会保留旧响应的头（除 `content-type`），想完全换掉就先 `c.res = undefined` 再赋值：

```ts
app.use(async (c, next) => {
  await next();
  c.res = undefined;
  c.res = new Response("masked", { status: 200 });
});
```

- 适合脱敏、统一错误页、加调试头；不适合改流式响应;
