# 路由与请求

## 路由怎么注册、按什么顺序匹配？

- 职责: 把「方法 + 路径」映射到返回 `Response` 的 Handler；子路由把大应用拆成按资源划分的文件;
- 覆盖范围: `app.get/post/put/delete` 管标准方法；`app.on(method, path, ...)` 管自定义方法、多方法与多路径;
- 顺序: 按注册顺序匹配，`app.get("*")` 写在前面会吞掉后面所有路由，兜底放最后;

```ts
const app = new Hono();

app.get("/", (c) => c.text("GET /"));
app.all("/any", (c) => c.text("任意方法"));
app.on("GET", ["/hello", "/ja/hello"], (c) => c.text("两条路径"));
app.get("/wild/*/card", (c) => c.text("通配符"));
```

- 链式写法: 只有 `.get(...).post(...)` 这样链式注册，`AppType` 才能完整推理，RPC 与 `testClient` 依赖它，见 [校验与类型](../002-服务端开发/010-校验与类型.md);

## 路径参数与通配符怎么匹配？

| 写法                  | 匹配           | 读取                  |
| --------------------- | -------------- | --------------------- |
| `/user/:name`         | `/user/张三`   | `c.req.param("name")` |
| `/api/animal/:type?`  | 可省略该段     | 可能是 `undefined`    |
| `/post/:date{[0-9]+}` | 只匹配数字     | 同上                  |
| `/p/:f{.+\.png}`      | 允许多段与点号 | 同上                  |
| `*`                   | 任意路径       | —                     |

- 正则段写在 `{}` 里且必须匹配整段；参数默认不含斜杠，要吞斜杠写 `:id{.+}`;
- 严格模式默认开，`/hello` ≠ `/hello/`，`new Hono({ strict: false })` 关闭；HEAD 按 GET 匹配后丢弃响应体;

## 子路由怎么挂？

```ts
// routes/book.ts
const book = new Hono()
  .get("/", (c) => c.text("List Books"))
  .get("/:id", (c) => c.text(c.req.param("id")));

// app.ts
const app = new Hono().route("/book", book); // GET /book、GET /book/:id
```

- 两种挂法: `app.route(prefix, sub)` 把子应用挂到前缀下，子应用里写相对路径；`new Hono().basePath("/api")` 把前缀写在子应用上，适合要独立运行/测试的子应用，挂载用 `app.route("/", api)`;
- 陷阱: `route()` 拷贝的是「当时已有」的路由，之后往子应用加路由不会同步；必须「先装配，最后挂载」，否则表现为 404 且不报错；排查 404 先用 `npx hono routes` 看实际路由表;

## 请求里的值怎么读？

```ts
app.get("/entry/:id", (c) => {
  const id = c.req.param("id");
  const q = c.req.query("q"); // 缺失是 undefined，不是 ""
  const tags = c.req.queries("tags"); // ?tags=A&tags=B → ["A","B"]
  const ua = c.req.header("user-agent"); // 大小写不敏感
  return c.json({ id, q, tags, ua, path: c.req.path });
});
```

- 类型: 查询值一律 `string`，数字自己转或交给校验器；`c.req.path` 只有路径，`c.req.url` 是完整 URL;
- 取全部请求头时键全是小写，`headers["X-Foo"]` 永远取不到;
- 请求体: `await c.req.json()` / `parseBody()` / `text()` / `formData()`，只能读一次；`json()` 遇非法 JSON 抛错变 500，要 400 就用校验器;
- 一次性流: 校验器读过后 `c.req.raw` 已耗尽，仍需原文用 `cloneRawRequest(c.req)`（`hono/request`）;
- 上传: `parseBody()` 里多文件必须带 `[]` 后缀（`body["photos[]"]`），`{ all: true }` 把同名多值收成数组；大文件要边读边写用 `c.req.raw.body`，对象存储直传则只发签名;
- 原始连接: Node 连接在 `c.env.incoming`，通用取 IP 用 `getConnInfo(c).remote.address`；反代后取真实 IP 见 [请求边界与来源可信](../../000-服务端知识/030-安全/050-请求边界与来源可信.md);
