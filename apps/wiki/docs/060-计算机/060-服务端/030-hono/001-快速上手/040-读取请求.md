# 读取请求

## c.req 里有什么？

- 入口: `HonoRequest`（`c.req`）读路径参数、查询、请求头与请求体;
- 原始对象: 标准 `Request` 在 `c.req.raw`，只有平台特性或流式转发才需要它;

## 路径参数和查询怎么读？

```ts
import { Hono } from "hono";

const app = new Hono();

app.get("/entry/:id", (c) => {
  const id = c.req.param("id"); // '/entry/123' → '123'
  const all = c.req.param(); // { id: '123' }
  const q = c.req.query("q"); // '?q=hono' → 'hono'
  const { limit, offset } = c.req.query(); // 全部查询值，均为 string
  const tags = c.req.queries("tags"); // '?tags=A&tags=B' → ['A','B']
  return c.json({ id, all, q, limit, offset, tags, path: c.req.path });
});
```

- 类型: 查询值一律 `string`，数字自己转或交给校验器，见 [参数校验](../002-服务端开发/020-参数校验.md);
- 缺失: 参数不存在返回 `undefined`，不是空字符串；`queries()` 只用于同名多值;
- 路径与废弃 API: `c.req.path` 只有路径，`c.req.url` 是完整 URL，`c.req.method` 是方法，日志用 `path`；`c.req.routePath` / `c.req.matchedRoutes` 已废弃，改用 `routePath(c)` / `matchedRoutes(c)`（`hono/route`）;

## 请求头怎么读？

```ts
app.get("/", (c) => {
  const ua = c.req.header("User-Agent"); // 大小写不敏感
  const headers = c.req.header(); // 键全是小写
  return c.json({ ua, hasAuth: !!headers["authorization"] });
});
```

- 大小写: `c.req.header()` 返回对象的键全是小写，`headers["X-Foo"]` 永远取不到；缺失值是 `undefined`;
- Cookie: 不要自己解析 `Cookie` 头，用 Cookie Helper；会话与 CSRF 规则见 [会话与 CSRF](../../000-服务端知识/030-安全/030-会话与CSRF.md);
- 一次性流: 原始 `Request` 的 body 是一次性流，校验器读过后 `c.req.raw` 已耗尽；`cloneRawRequest(c.req)`（`hono/request`）仍可读，适合转发、审计日志;
- 原始连接: Node 原始连接在 `c.env.incoming`，通用 IP 用 `getConnInfo(c).remote.address`；代理后取真实 IP 先看 [请求边界与来源可信](../../000-服务端知识/030-安全/050-请求边界与来源可信.md);

## 请求体怎么读？

```ts
app.post("/entry", async (c) => {
  const body = await c.req.json(); // application/json
  const form = await c.req.parseBody(); // multipart / urlencoded
  const files = form["photos[]"]; // 多文件必须带 [] 后缀
  return c.json({ body, files });
});
```

- 方法清单: `json()`、`text()`、`parseBody()`、`formData()`、`arrayBuffer()`、`blob()`;
- 只能读一次: `json()` 遇非法 JSON 会抛错并最终变成 500，要 400 就先校验 `Content-Type` 或用校验器;
- parseBody 选项: `{ all: true }` 同名多值统一成数组，`{ dot: true }` 把 `"a.b"` 还原成 `{ a: { b } }`；同名多文件不写 `[]` 只保留最后一个;
- 校验后取值: `c.req.valid(target)` 支持 `json` / `form` / `query` / `header` / `param` / `cookie`，前置条件是注册了对应校验器;
- 延伸: 请求体上限属于请求边界，见 [请求边界与来源可信](../../000-服务端知识/030-安全/050-请求边界与来源可信.md)；校验器两种写法见 [参数校验](../002-服务端开发/020-参数校验.md)；需要代理或流式转发原始请求见 [代理与内容协商](../090-按需查阅/030-代理与内容协商.md);
