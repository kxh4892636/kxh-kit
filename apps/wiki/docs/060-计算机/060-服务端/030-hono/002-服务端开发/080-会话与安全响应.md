# 会话与安全响应

## 安全响应头怎么一次性加齐？

- 一行 `app.use(secureHeaders())` 默认头全开，需要时按项覆盖;

```ts
import { Hono } from "hono";
import { secureHeaders } from "hono/secure-headers";

const app = new Hono();

app.use(secureHeaders()); // 默认头全开
app.use(
  "*",
  secureHeaders({
    xFrameOptions: false,
    strictTransportSecurity: "max-age=63072000; includeSubDomains; preload",
  }),
);
```

- 默认值: 删除 `X-Powered-By`；`Strict-Transport-Security: max-age=15552000; includeSubDomains`；`X-Content-Type-Options: nosniff`；`X-Frame-Options: SAMEORIGIN`；`Referrer-Policy: no-referrer`；`Cross-Origin-Resource-Policy: same-origin`；CSP 与 `Permissions-Policy` 默认不设;
- 覆盖规则: 用 `xFrameOptions` 等开关关闭，用 `strictTransportSecurity` 覆盖；与 `poweredBy()` 同名头后执行的赢；原理见 [安全响应头](../../000-服务端知识/030-安全/040-安全响应头.md);

## CSRF 怎么挡？

- 一行 `app.use(csrf())` 默认同源校验，按需换成显式来源;

```ts
import { csrf } from "hono/csrf";

app.use(csrf()); // 默认同源
app.use(csrf({ origin: ["https://app.example.com"] }));
app.use(csrf({ secFetchSite: ["same-origin", "none"] }));
```

- 检查范围: 只校验非安全方法（非 GET/HEAD/OPTIONS）+ 可被表单提交的 content-type;
- 判定与配置: 同时看 `Origin` 与 `Sec-Fetch-Site`，任一通过即放行；反代剥掉 `Origin` 时要显式配置；动态判断要校验协议与结尾，不能只做前向匹配；原理见 [会话与 CSRF](../../000-服务端知识/030-安全/030-会话与CSRF.md);

## Cookie 怎么读写与签名？

- 读写用 `hono/cookie`，签名用 HMAC-SHA256，读写都是 `async`;

```ts
import { setCookie, getCookie, deleteCookie, setSignedCookie, getSignedCookie } from "hono/cookie";

app.post("/login", async (c) => {
  setCookie(c, "session", "abc123", {
    path: "/",
    httpOnly: true,
    secure: true,
    sameSite: "Lax",
    maxAge: 3600,
  });
  await setSignedCookie(c, "uid", "42", "secret");
  return c.json({ ok: true });
});
app.post("/logout", (c) => {
  deleteCookie(c, "session", { path: "/" });
  return c.body(null, 204);
});
app.get("/me", async (c) =>
  c.json({
    session: getCookie(c, "session"),
    uid: await getSignedCookie(c, "secret", "uid"),
  }),
);
```

- 删除: 要带与原设置相同的 `path`/`domain`；`sameSite: "None"` 必须同时 `secure: true`;
- 前缀: `setCookie(c, "sid", "abc", { prefix: "host" })`（`__Host-`）或 `"secure"`（`__Secure-`），读取时也要声明前缀；违反前缀约束或 `maxAge` 超过 400 天会抛错;
- 签名返回值: 字符串=通过、`false`=被篡改、`undefined`=没有，`if (!value)` 可同时兜住;
- 只生成不写头: `generateCookie` / `generateSignedCookie` 只返回字符串，适合一次 Set 多个 Cookie;
- 会话存储: Hono 不自带，有状态方案 Cookie 只放不透明 sessionId、数据放 Redis；选型见 [会话与 CSRF](../../000-服务端知识/030-安全/030-会话与CSRF.md);
