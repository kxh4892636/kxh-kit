# 响应压缩

## Node 上压缩要手动挂吗？

- 要: Node 不会自动压缩，必须显式挂 `compress()`；Cloudflare Workers / Deno Deploy 会自动压缩;
- 目的: 给文本、JSON、HTML 响应加 gzip 压缩，减少传输体积;

## compress() 怎么挂到应用上？

- 一个中间件: `app.use(compress())`，默认 1KB 以上才压，gzip 优先;

```ts
import { Hono } from "hono";
import { compress } from "hono/compress";

const app = new Hono();

app.use(compress()); // 默认 1KB 以上才压，gzip 优先
app.get("/api/posts", (c) => c.json({ posts: Array.from({ length: 100 }, (_, id) => ({ id })) }));
```

## 哪些响应会被跳过？

- 已压缩内容: 图片、zip 等已压缩二进制类型在默认白名单里被排除;
- 流式响应: 带 `Transfer-Encoding` 的响应会被自动跳过，不会破坏 SSE;

## 阈值和类型怎么过滤？

- `threshold`: 默认 1024 字节;
- 小响应: 小于阈值的响应压了反而更大;
- `contentTypeFilter`: 限制压缩类型，如 `compress({ contentTypeFilter: /^application\/json/ })`;

## 压缩要付什么代价？

- 只压文本类内容，不要对已压缩内容再压;
- CPU: 压缩占 CPU，高吞吐服务先测量再决定，见 [性能与压测](../../000-服务端知识/060-观测与交付/050-性能与压测.md);
- 不属于压缩: 请求体大小、请求超时、IP 黑白名单见 [请求边界与来源可信](../../000-服务端知识/030-安全/050-请求边界与来源可信.md);
