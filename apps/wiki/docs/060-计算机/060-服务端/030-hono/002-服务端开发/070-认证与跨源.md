# 认证与跨源

## Bearer 与 Basic 认证怎么挂？

- 各挂一个中间件: `bearerAuth` 校验 Bearer token，`basicAuth` 校验用户名密码；认证结果只写进 `c.set("user", ...)`，业务 Handler 不再解析 token;

```ts
import { Hono } from "hono";
import { bearerAuth } from "hono/bearer-auth";

const app = new Hono();

app.use("/api/*", bearerAuth({ token: "honoiscool" }));
app.use("/v2/*", bearerAuth({ verifyToken: async (token) => token === "expected" }));
```

- token 写法: `bearerAuth({ token })` 固定 token，`verifyToken` 做动态校验；token 必须匹配 `/[A-Za-z0-9._~+/-]+=*/`，否则直接 400;
- 失败定制: 三个定制点 `noAuthenticationHeader`、`invalidAuthenticationHeader`、`invalidToken`，各可给 `message` 与 `wwwAuthenticateHeader`;
- Basic: 内部工具可用 `basicAuth({ username, password, verifyUser })`，失败 401 + `WWW-Authenticate`，realm 默认 `Secure Area`;
- 原理: 见 [认证与授权](../../000-服务端知识/030-安全/010-认证与授权.md);

## JWT 与 JWK 怎么验签？

- 验签中间件: `jwt()` 用共享密钥，`jwk()` 用远端公钥集；成功后 payload 在 `c.get("jwtPayload")`;

```ts
import { sign, verify, jwt, type JwtVariables } from "hono/jwt";
import { jwk } from "hono/jwk";
const token = await sign({ sub: "u1", exp: Math.floor(Date.now() / 1000) + 3600 }, "secret");
const payload = await verify(token, "secret", "HS256", "https://issuer", "my-api");
const jwtApp = new Hono<{ Variables: JwtVariables }>();
jwtApp.use("/auth/*", jwt({ secret: "secret", alg: "HS256" }));
jwtApp.use(
  "/api/*",
  jwk({ jwks_uri: "https://auth.example.com/.well-known/jwks.json", alg: ["RS256"] }),
);
```

- 算法与声明: 默认 `HS256`，支持 HS/RS/PS/ES 与 `EdDSA`；`exp`、`nbf`、`iat` 存在才校验，`iss`/`aud` 要显式传;
- 不能鉴权: `decode()` 不验签，不能用于鉴权;
- 密钥与位置: secret 来自环境变量时包一层 `(c, next) => jwt({ secret: c.env.JWT_SECRET, alg: "HS256" })(c, next)`；token 在 Cookie 里用 `jwt({ ..., cookie: "token" })`;
- `jwk()`: 要求 JWT 头带 `kid` 并拒绝 HS 系列，只接受不对称算法；原理见 [认证与授权](../../000-服务端知识/030-安全/010-认证与授权.md);

## CORS 怎么放行？

- 挂在路由前: `app.use("/api/*", cors({ origin: [...] }))`，只在一层配;

```ts
import { cors } from "hono/cors";

app.use(
  "/api/*",
  cors({
    origin: ["https://app.example.com"],
    allowMethods: ["GET", "POST"],
    allowHeaders: ["Content-Type", "Authorization"],
    credentials: true,
    maxAge: 600,
  }),
);
```

- 默认与凭据: 默认 `origin: "*"`，只适合公开接口；`credentials: true` 时不能是 `*`，必须回显具体来源;
- 位置冲突: 必须挂在路由之前，否则预检命不中；反向代理也加会出现重复 `Access-Control-Allow-Origin`;
- 动态来源: `(c, next) => cors({ origin: c.env.CORS_ORIGIN })(c, next)`；原理见 [跨源访问](../../000-服务端知识/030-安全/020-跨源访问.md);
