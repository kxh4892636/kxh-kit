# 用 app.request 测试

## app.request 是怎么测的？

- 不走网络: 不起端口、不经过网络，直接构造 `Request` 走完整链路并断言标准 `Response`；断言方式与测试框架无关（Vitest / Jest / `node:test` 都行）;

## 一次 app.request 测试长什么样？

- 造请求，拿响应，断言状态码、头与 JSON;

```ts
import { Hono } from "hono";

const app = new Hono()
  .get("/posts", (c) => c.text("Many posts"))
  .post("/posts", async (c) => {
    const body = await c.req.json();
    return c.json({ message: "Created", body }, 201, { "X-Custom": "Thank you" });
  });

const res = await app.request("/posts", {
  method: "POST",
  body: JSON.stringify({ message: "hello" }),
  headers: new Headers({ "Content-Type": "application/json" }),
});
console.log(res.status, res.headers.get("X-Custom"), await res.json());
```

- 表单与上传: `body: formData`（`FormData` 实例）；自定义 Request 可直接 `app.request(new Request("http://localhost/posts"))`;
- 注入 `c.env`: 用第三个参数 `app.request(path, init, MOCK_ENV)`；鉴权头放 `init.headers`;
- 坑: 校验 `json` / `form` 时必须带 `Content-Type`，否则 `c.req.valid()` 拿到 `{}`；HEAD 与 GET 要比对状态码、头一致、body 为 `null`;

## testClient 怎么用？

- 进程内直连: 参数写法与 `hc` 一致，但调用不经过网络;

```ts
import { testClient } from "hono/testing";

const app = new Hono().get("/search", (c) => c.json({ q: c.req.query("q"), results: ["a"] }));
const client = testClient(app);

const res = await client.search.$get({ query: { q: "hono" } });
const res2 = await client.search.$get(
  { query: { q: "x" } },
  { headers: { Authorization: "Bearer t" } },
);
```

- 硬性前提: 路由必须链式定义在 `new Hono()` 上，否则 `testClient` 推不出方法;
- 与 `hc` 的区别: `testClient` 进程内直连，参数写法与 `hc` 一致，见 [hc 客户端](../090-按需查阅/050-hc客户端.md);
- 依赖注入: 数据库、`fetch`、时间、消息队列在 `createFactory({ initApp })` 里注入，测试替换成内存实现；Handler 只读 `c.var`;
