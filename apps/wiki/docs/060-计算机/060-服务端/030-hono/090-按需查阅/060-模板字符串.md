# 模板字符串

## hono/html 适合什么页面、怎么写？

- 需要: 输出服务端渲染页面（后台、邮件模板、文档页）时，用 `hono/html` 零配置拼 HTML;
- 不需要: 纯 JSON API 不引入;
- 换 JSX: 需要组件、类型检查与深层嵌套时;

```ts
import { html } from "hono/html";

app.get("/:username", (c) => {
  const { username } = c.req.param();
  return c.html(
    html`<!doctype html>
      <h1>Hello! ${username}!</h1>`,
  );
});

// 组件就是返回字符串的函数
const Footer = () => html`<footer><address>My Address</address></footer>`;

const Layout = (props: { title: string; children: any }) => html`
  <html>
    <head>
      <title>${props.title}</title>
    </head>
    <body>
      ${props.children}${Footer()}
    </body>
  </html>
`;

app.get("/about", (c) => c.html(Layout({ title: "About", children: html`<p>about</p>` })));
```

## 插值为什么不会 XSS？

- 转义: `html` 自动转义插值;
- 例外: `raw()` 关闭转义，只用于插入可信 HTML;

## 组件函数怎么复用，开销与编辑体验如何？

- 复用: 返回值可直接嵌套组合，也可以作为「组件」函数复用;
- 开销: 不做虚拟 DOM，运行时开销比 JSX 小;
- 编辑: 编辑器高亮需装 lit-html 插件;

## hono/html 与 JSX 之间怎么选？

- 优先 `hono/html`: 邮件模板、纯拼接页面;
- 换 JSX: 需要循环、条件、组件层级时;
