# 页面布局

## 布局怎么避免每个页面重复写？

```tsx
import { jsxRenderer } from "hono/jsx-renderer";

app.use(
  "/page/*",
  jsxRenderer(({ children }) => (
    <html>
      <head>
        <meta charSet="utf-8" />
      </head>
      <body>
        <header>Menu</header>
        {children}
      </body>
    </html>
  )),
);

app.get("/page/a", (c) => c.render(<p>content</p>));
```

- `jsxRenderer` 是 `c.setRenderer()` 的语法糖，省掉自己挂中间件;
- 不用它时手写等价逻辑：

```ts
app.use(async (c, next) => {
  c.setRenderer((content) => c.html(<html><body>{content}</body></html>))
  await next()
})
```

- `c.render(jsx)` 的输出就是 `setRenderer` 里拼好的整页;

## 布局应该放在哪一层？

| 放法                                    | 适用                       |
| --------------------------------------- | -------------------------- |
| `app.use('*', jsxRenderer(...))`        | 整个应用都是页面           |
| `app.use('/admin/*', jsxRenderer(...))` | 只有某个区段是页面         |
| 每个路由自己 `c.render`                 | 页面风格差异大、只有两三页 |

- 布局中间件只挂在页面路径上，避免影响 JSON 接口;
- 多个区段不同布局时挂多个 `jsxRenderer`，路径不重叠即可;

## 布局参数怎么加？

- `c.render(content, args)` 的第二个参数需要先增强 `ContextRenderer` 类型;
- 增强方式、元数据提升规则见 [布局参数与元数据](./102-布局参数与元数据.md)。
