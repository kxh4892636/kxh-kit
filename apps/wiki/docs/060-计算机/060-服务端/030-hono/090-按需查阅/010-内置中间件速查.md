# 内置中间件速查

## 按需求查哪一行？

| 需求                | 导入路径                  | 函数                                                         |
| ------------------- | ------------------------- | ------------------------------------------------------------ |
| 基本认证            | `hono/basic-auth`         | `basicAuth({ username, password })`                          |
| API Token           | `hono/bearer-auth`        | `bearerAuth({ token })`                                      |
| JWT 校验            | `hono/jwt`                | `jwt({ secret, alg })`                                       |
| JWK 公钥校验        | `hono/jwk`                | `jwk({ keys })`                                              |
| 请求体大小限制      | `hono/body-limit`         | `bodyLimit({ maxSize })`                                     |
| 请求超时            | `hono/timeout`            | `timeout(ms)`                                                |
| 跨域                | `hono/cors`               | `cors({ origin })`                                           |
| CSRF                | `hono/csrf`               | `csrf()`                                                     |
| 安全响应头          | `hono/secure-headers`     | `secureHeaders()`                                            |
| 响应压缩            | `hono/compress`           | `compress()`                                                 |
| ETag / 304          | `hono/etag`               | `etag()`                                                     |
| 日志                | `hono/logger`             | `logger()`                                                   |
| 请求 ID             | `hono/request-id`         | `requestId()`                                                |
| Server-Timing       | `hono/timing`             | `timing()`                                                   |
| IP 限制             | `hono/ip-restriction`     | `ipRestriction(getConnInfo, {...})`                          |
| 上下文全局访问      | `hono/context-storage`    | `contextStorage()`                                           |
| 美化 JSON 输出      | `hono/pretty-json`        | `prettyJSON()`                                               |
| 尾斜杠重定向        | `hono/trailing-slash`     | `appendTrailingSlash()` / `trimTrailingSlash()`              |
| 表单模拟 PUT/DELETE | `hono/method-override`    | `methodOverride({ app })`                                    |
| 405 而非 404        | `hono/method-not-allowed` | `methodNotAllowed({ app })`                                  |
| 挂载其他框架        | `hono/mount`              | `mount(handler)`                                             |
| JSX 布局            | `hono/jsx-renderer`       | `jsxRenderer(...)`                                           |
| 语言/区域检测       | `hono/language`           | `languageDetector({ supportedLanguages, fallbackLanguage })` |
| 条件组合中间件      | `hono/combine`            | `some()` / `every()` / `except()`                            |
| 平台响应缓存        | `hono/cache`              | `cache({ cacheName })`                                       |

## 中间件之间的顺序怎么排？

```ts
app.use(secureHeaders()); // 安全头最先
app.use(requestId()); // 为后续日志提供 ID
app.use(logger()); // 记录完整耗时
app.use(compress()); // 在响应阶段压缩
app.use("/api/*", cors());
app.use("/api/*", timeout(10_000));
app.use("/api/*", bodyLimit({ maxSize: 1024 * 1024 }));
app.use("/api/*", authMiddleware); // 鉴权尽量靠后，减少无效开销
app.route("/api", apiRoutes);
```

- 同名响应头冲突时「后执行的覆盖先执行的」：`secureHeaders()` 之后再 `poweredBy()` 会把 `X-Powered-By` 加回来;
- 抛错发生在哪一层，只有外层中间件的 after 代码会继续执行（见 [中间件模型](../002-服务端开发/100-中间件模型.md)）;

## 哪些在 Node 上不可用或不适用？

| 中间件                 | Node 情况                                                  |
| ---------------------- | ---------------------------------------------------------- |
| `hono/cache`           | 需要全局 `Cache API`，Node 没有；改用 Redis 或反向代理缓存 |
| `hono/compress`        | Node 不会自动压缩，**必须显式挂**                          |
| `hono/context-storage` | 依赖 `AsyncLocalStorage`，Node 原生支持                    |
| `hono/ip-restriction`  | 需要 `getConnInfo` from `@hono/node-server/conninfo`       |
| `hono/mount`           | 可用，用于把 Express/itty-router 等挂进来                  |
| `hono/pretty-json`     | 开发环境用，生产会拖慢并放大响应体                         |
