# 内置中间件速查

## 需求对应哪条导入路径与函数？

| 需求                | 导入路径                  | 函数                                                         |
| ------------------- | ------------------------- | ------------------------------------------------------------ |

| API Token           | `hono/bearer-auth`        | `bearerAuth({ token })`                                      |
| JWT 校验            | `hono/jwt`                | `jwt({ secret, alg })`                                       |
| JWK 公钥校验        | `hono/jwk`                | `jwk({ keys })`                                              |
| 请求体大小限制      | `hono/body-limit`         | `bodyLimit({ maxSize })`                                     |
| 请求超时            | `hono/timeout`            | `timeout(ms)`                                                |
| 跨域                | `hono/cors`               | `cors({ origin })`                                           |
| CSRF                | `hono/csrf`               | `csrf()`                                                     |
| 安全响应头          | `hono/secure-headers`     | `secureHeaders()`                                            |
| 响应压缩            | `hono/compress`           | `compress()`                                                 |
| ETag / 304          | `hono/etag`               | `etag()`                                                     |
| 日志                | `hono/logger`             | `logger()`                                                   |

## 挂载顺序、覆盖与组合怎么定？

- 顺序: 安全头 → 请求 ID → 日志 → 压缩 → 跨域 → 超时 → 体积限制 → 鉴权 → 业务路由; 鉴权靠后，减少无效开销;
- 覆盖与组合: 同名响应头「后执行的覆盖先执行的」，抛错只外层中间件的 after 继续执行; `some` 任一通过、`every` 全部通过、`except(条件, ...mw)` 条件命中时跳过;

```ts
app.use(secureHeaders());
app.use(requestId());
app.use(logger((message, ...rest) => console.log(JSON.stringify({ message, rest })))); // PrintFunc
app.use(compress()); // Node 不自动压缩，threshold 默认 1024 字节
app.use("/api/*", cors());
app.use("/api/*", timeout(10_000));
app.use("/api/*", bodyLimit({ maxSize: 1024 * 1024 }));
app.use("/api/*", authMiddleware); // 鉴权靠后，减少无效开销
app.route("/api", apiRoutes);
```

## Node 上哪些中间件不能照搬？

- `hono/cache`: 依赖全局 `Cache API`，Node 没有; 改用 Redis 或反向代理缓存;
- `hono/ip-restriction`: `getConnInfo` 来自 `@hono/node-server/conninfo`; `hono/pretty-json`: 只用于开发;

## logger 和 requestId 的默认行为是什么？

- `logger()`: 默认输出方法、路径、状态码与耗时，`NO_COLOR` 关闭颜色; 换输出函数即可接结构化日志;
- `requestId({ headerName, limitLength, generator })`: 默认头名 `X-Request-Id`、长度上限 255，并自动写回同名响应头; `headerName: ""` 禁用复用与回写; 类型 `RequestIdVariables`;
