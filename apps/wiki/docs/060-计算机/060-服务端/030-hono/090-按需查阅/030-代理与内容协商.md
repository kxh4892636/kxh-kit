# 代理与内容协商

## proxy 转发时哪些头要改写、哪些要删？

- 改写: 替换 `Accept-Encoding`，清掉不该透传的响应头;
- 删头: `const res = await proxy(...); res.headers.delete("Set-Cookie")`;
- 转发: `proxy()` 把请求转给上游，返回可直接发出的 `Response`;

```ts
import { proxy } from "hono/proxy";

app.all("/proxy/:path", (c) =>
  proxy(`http://origin.internal/${c.req.param("path")}`, {
    ...c.req,
    headers: {
      ...c.req.header(),
      "X-Forwarded-Host": c.req.header("host"),
      Authorization: undefined, // 不外泄凭证
    },
  }),
);

app.get("/simple", (c) => proxy("https://example.com/"));
```

## proxy 的路径与逐跳头怎么处理？

- 路径: `proxy()` 不做路径重写，路径差异要在拼 URL 时处理;
- 逐跳头: `Connection` 默认忽略最安全; 只在可信内网且需要 RFC 9110 严格语义时开 `strictConnectionProcessing: true`;

## accepts 怎么保证返回值一定命中 supports？

- `accepts()`: 按 `Accept*` 头在多个表示里选一个，返回值一定是 `supports` 中的一项;
- 兜底: 都不匹配时由 `default` 决定;

```ts
import { accepts } from "hono/accepts";

app.get("/", (c) => {
  const lang = accepts(c, {
    header: "Accept-Language",
    supports: ["en", "ja", "zh"],
    default: "en",
  });
  return c.json({ lang });
});
```

- `header`: 可用 `Accept`、`Accept-Encoding`、`Accept-Language`、`Accept-Charset`;
- 场景: 按语言返回文案，或按 `Accept` 返回 JSON/HTML;
- 代理头与来源可信: [请求边界与来源可信](../../000-服务端知识/030-安全/050-请求边界与来源可信.md); 代理后真实 IP: [Helper 速查](./020-Helper速查.md);
