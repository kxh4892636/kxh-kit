# JSX 组件

## 启用 JSX 要改什么配置？

```json title="tsconfig.json"
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "hono/jsx"
  }
}
```

- 文件扩展名要改成 `.tsx`，`dev` 脚本里的入口路径同步改;
- 不想改 tsconfig 时用文件级注释：

```ts
/** @jsx jsx */
/** @jsxImportSource hono/jsx */
```

## 组件怎么写？

```tsx
import type { FC, PropsWithChildren } from "hono/jsx";

const Layout: FC = (props) => (
  <html>
    <body>{props.children}</body>
  </html>
);

function Card({ title, children }: PropsWithChildren<{ title: string }>) {
  return (
    <div>
      <h1>{title}</h1>
      {children}
    </div>
  );
}

app.get("/", (c) =>
  c.html(
    <Layout>
      <Card title="Hi">body</Card>
    </Layout>,
  ),
);
```

- `FC` 定义组件，`PropsWithChildren` 让 `children` 有正确类型;
- Fragment 用 `hono/jsx` 的 `<Fragment>` 或 `<>...</>`;
- 插入原始 HTML 用 `dangerouslySetInnerHTML={{ __html: '<b>x</b>' }}`;
- 静态子树可用 `memo()` 缓存，避免重复渲染;

## 组件里能做什么、不能做什么？

| 可以                                | 不可以                   |
| ----------------------------------- | ------------------------ |
| 接收 props、渲染子节点              | 直接查数据库             |
| 组合其他组件                        | 依赖请求外的全局可变状态 |
| 用 `useRequestContext()` 读请求数据 | 在组件里发网络请求       |

- 数据在 Handler 或中间件准备好，组件只负责渲染;
- 需要请求上下文时见 [SSR 实践与注意](./105-SSR实践与注意.md);
