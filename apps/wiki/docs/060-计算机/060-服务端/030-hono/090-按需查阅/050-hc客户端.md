# hc 客户端

## hc 怎么推出类型，参数又怎么传？

- 路径: 服务端导出 `AppType`，客户端 `hc<AppType>()` 直接得到路径、请求体、响应体的类型;
- 前提: 链式注册; 请求类型来自校验器（`zValidator` / `sValidator`）; 响应类型来自 `c.json(obj, status)` 的字面量;
- 适用范围: 同仓 TypeScript 项目; 跨语言调用改用 OpenAPI/IDL;

```ts
// server.ts —— 必须链式注册，类型才能从变量推导
import { Hono } from "hono";
import { zValidator } from "@hono/zod-validator";
import * as z from "zod";

const route = new Hono().post(
  "/posts",
  zValidator("form", z.object({ title: z.string(), body: z.string() })),
  (c) => c.json({ ok: true, data: c.req.valid("form") }, 201),
);

export type AppType = typeof route;
```

```ts
// client.ts
import { hc } from "hono/client";
import type { AppType } from "./server";

const client = hc<AppType>("http://localhost:3000/");
const res = await client.posts.$post({ form: { title: "Hello", body: "Hono" } });
if (res.ok) await res.json(); // 类型来自 201 返回体
```

- 大应用: 顶层链式挂载 `const routes = new Hono().route("/users", users).route("/posts", posts)`，再 `export type AppType = typeof routes`;
- 传参 key: 跟服务端数据来源一一对应，`param` / `query` / `json` / `form`; 路径参数写字符串，多参数多挂一层，参数值不做 URL 编码; 上传走 `form` + `File`，大文件改对象存储直传;

## 状态码不写进 c.json 会怎样？

- 收窄: 状态码必须显式写进 `c.json`，客户端才能按 `res.status` 收窄，不写只有 200 分支; 不要用 `c.notFound()`: 返回体类型推不出，`res.json()` 退化为 `unknown`，改用 `c.json({ ok: false, error: "not_found" }, 404)`;

## 类型为什么退化成 unknown 或 any？

- `Res.json()` 为 `unknown`: 用了 `c.notFound()` 或没写状态码; 请求体为 `any`: 没挂校验器，或路由不是链式注册;
- `Type instantiation is excessively deep`: 多是前后端 `hono` 版本不一致; IDE 卡顿就拆 app 或用 `hcWithType`;

## InferRequestType、$url 与类型工具怎么用？

- 推导: `InferRequestType` 取请求体类型，`InferResponseType` 取响应体类型;

```ts
import type { InferRequestType, InferResponseType } from "hono/client";

type Req = InferRequestType<typeof client.posts.$post>["form"];
type Res = InferResponseType<typeof client.posts.$post>; // 所有状态码并集；第二参 201 可只取 201
```

- `ApplyGlobalResponse<typeof app, { 500: { json: { ok: false; error: string } } }>`: 把 `onError` 的错误体并进类型，不会自动进;
- `$url()`: 需要绝对 base URL; `$path()` 不含 origin、适合做 SWR key; `$ws(0)` 取 WebSocket 端点;
- `parseResponse`: 直接返回解析后的 body，非 2xx 抛 `DetailedError`; `hcWithType` 在编译期算好类型，缓解类型实例化开销;
