# 构建与运行产物

## 从源码到线上产物要几步？

- 产物链: `tsx watch` 开发 → `tsc` 编译 → `node dist/index.js` → 反向代理 → 探针与日志;
- 入口只做 `serve`，端口与地址来自环境变量;

```ts
import { serve } from "@hono/node-server";
import { app } from "./app.js";

serve({
  fetch: app.fetch,
  port: Number(process.env.PORT ?? 3000),
  hostname: process.env.HOST ?? "0.0.0.0",
});
```

- `hostname` 写 `127.0.0.1`，容器外连不上；`PORT` 不写死;

## 产物为什么必须声明 ESM？

- `package.json` 缺 `"type": "module"`: `dist/*.js` 被当 CJS 执行，直接报错;
- `module` / `moduleResolution` 用 `NodeNext`: 相对导入要带扩展名，写 `./app.js`;
- `rootDir` / `outDir` 保证 `dist/index.js` 与源码同层级，`import.meta.url` 与静态文件不错位;

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ESNext",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "rootDir": "./src",
    "outDir": "./dist",
    "types": ["node"]
  }
}
```

## 镜像为什么要分两段？

- builder 里 `npm ci && npm run build && npm prune --production`；runner 只带 `dist`、`package.json` 与生产依赖，`tsx`/`typescript` 不进镜像;
- 非 root 运行；`.dockerignore` 排除 `node_modules`、`dist`、`.env`；日志写 stdout/stderr;

```dockerfile title="Dockerfile"
FROM node:22-alpine AS builder
WORKDIR /app
COPY . .
RUN npm ci && npm run build && npm prune --production

FROM node:22-alpine AS runner
WORKDIR /app
RUN addgroup --system --gid 1001 nodejs && adduser --system --uid 1001 hono
COPY --from=builder --chown=hono:nodejs /app/node_modules ./node_modules
COPY --from=builder --chown=hono:nodejs /app/dist ./dist
COPY --from=builder --chown=hono:nodejs /app/package.json ./
USER hono
CMD ["node", "dist/index.js"]
```

## 性能与 HTTP/2 要不要动？

- 适配器默认值已兼顾正确性与性能，没有压测证据不要改；`autoCleanupIncoming: false` 只在「请求方一定读完 body」时用;
- 优化顺序: 先测量 → 压缩 → 缓存 → 减少串行 `await` 与 N+1 → 最后才换路由器；默认 `SmartRouter(RegExp + Trie)` 对长驻 Node 进程够用;
- 压测: `npx hono benchmark --plain` 只测应用内部，`bombardier -d 10s http://localhost:3000/` 含 HTTP 栈；看 P99、内存与事件循环延迟;
- HTTP/2: 有网关时由网关终结、应用仍跑 HTTP/1.1；直连才用 `createServer: createSecureServer` + `serverOptions: { key, cert }`;
- 原理: [性能与压测](../000-服务端知识/060-观测与交付/050-性能与压测.md)、[HTTP2 与 TLS](../000-服务端知识/070-通信/030-HTTP2与TLS.md);
