# HTTP 报文与方法

## HTTP 报文由哪些部分组成？

- 请求报文: 客户端发送的报文;
- 响应报文: 服务端发送的报文;
- 结构: 报文首部 → 空行 → 报文主体;
- 报文首部:
  - 起始行: 请求行为 `方法 + URL + 版本`, 状态行为 `版本 + 状态码 + 原因短语`;
  - 首部字段: 通用首部 / 请求首部 / 响应首部 / 实体首部;

## HTTP 定义了哪些方法？

| 方法      | 语义               | 备注                    |
| --------- | ------------------ | ----------------------- |
| `GET`     | 请求资源           | 幂等, 可缓存            |
| `POST`    | 传输报文主体       | 非幂等                  |
| `PUT`     | 传输文件           | 不常用                  |
| `DELETE`  | 删除文件           | 不常用                  |
| `HEAD`    | 只取首部           | 不返回报文主体          |
| `OPTIONS` | 查询支持的方法     | 跨域预检会用到          |
| `TRACE`   | 查询请求的通讯路径 | 诊断用途                |
| `CONNECT` | 用通道协议连接代理 | 建立隧道, 如 HTTPS 代理 |

- 幂等: 同一请求执行多次与执行一次的效果相同;
