# DNS 概览与层次结构

## DNS 是什么, 为什么使用 UDP？

- DNS: 域名系统, 由 RFC 1034 与 RFC 1035 定义, 实现主机名到 IP 地址的转换;
- 本质: DNS 服务器实现的分布式数据库, 提供目录服务;
- 运输层: 基于 UDP, 端口 53;
- 使用 UDP 的原因: DNS 报文数据量小但数量多, UDP 速度快、首部开销小, 可减轻服务器负担;

## DNS 还能提供哪些服务？

- 主机别名: 为主机提供易记的别名;
- 邮件服务器别名: 让邮件服务器也能使用别名;
- 负载分配: 一个主机名对应多个 IP 地址, DNS 服务器在多个服务器间分散请求;

## DNS 的层次结构如何组织？

- 根 DNS 服务器: 层次结构的顶端;
- 顶级域 DNS 服务器 (TLD): 管理 `com`、`org` 等顶级域;
- 权威 DNS 服务器: 保存具体域名到 IP 的权威记录;

## 本地 DNS 服务器起什么作用？

- 位置: 不属于 DNS 层次结构, 每个 ISP 部署一台;
- 职责: 作为客户端的代理进行中转, 并缓存查询结果;
- 收益: 减少向上层 DNS 发出的查询流量;

## DNS 缓存如何减少查询流量？

- 机制: DNS 服务器收到回复报文后, 把记录缓存一段时间;
- 命中: 另一台主机发起相同查询时直接返回缓存结果;
- 过期: 缓存时间由资源记录的 TTL 字段决定;
