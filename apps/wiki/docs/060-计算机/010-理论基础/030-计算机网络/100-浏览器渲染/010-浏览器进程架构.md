# 浏览器进程架构

## 浏览器由哪些进程组成？

| 进程            | 职责                     |
| --------------- | ------------------------ |
| Browser         | 管理不同进程             |
| Render Process  | JS 引擎与渲染引擎        |
| Network Process | 负责网络协议             |
| GPU Process     | 负责页面渲染             |
| Plugins Process | 负责浏览器插件           |
| UI Process      | 地址栏、书签、跳转等界面 |
| Storage Process | 负责本地存储             |

- 通信方式: 进程之间通过 IPC 通信;
