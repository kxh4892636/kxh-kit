# 浏览器缓存位置

## 浏览器有哪些缓存位置？

| 位置           | 特点                             |
| -------------- | -------------------------------- |
| Service Worker | 独立线程中的缓存                 |
| Memory Cache   | 会话数据                         |
| Disk Cache     | 持久性数据, 用于强缓存与协商缓存 |
| Push Cache     | 会话数据, 存放 HTTP/2 推送的内容 |

## 强缓存与协商缓存落在哪一层？

- 强缓存与协商缓存都由 Disk Cache 承载;
- 判定字段、优先级与命中结果见 [HTTP 缓存机制](../060-HTTP/070-HTTP缓存机制.md);
