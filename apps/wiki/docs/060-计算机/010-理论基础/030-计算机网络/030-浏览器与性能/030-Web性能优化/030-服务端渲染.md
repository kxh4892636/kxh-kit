# 服务端渲染

## SSR 是什么, 有什么优缺点？

- SSR: 页面在服务器完成渲染后返回;
- 优点:
  - 首屏加载快: 服务端预先生成 HTML, 客户端在收到完整响应前即可显示部分页面;
  - 支持 SEO;
  - 用户体验更好;
- 缺点:
  - 服务器压力大;
  - 开发成本高: 需要额外维护服务端页面模板与数据获取流程;

## SSR 的实现流程是什么？

- 配置服务端环境: 在服务端搭建 Node 环境;
- 应用服务器: 监听 HTTP 请求并返回 HTML 文本;
- 路由: 按不同路径返回对应 HTML;
- 客户端脚本: 在 HTML 中插入客户端脚本, 用于交互与数据获取;
- SEO 优化: 补充 `meta` 标签;
