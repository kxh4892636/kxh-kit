# 路由器排队与分组调度

## 什么情况下发生丢包？

- 触发: 路由器的缓存空间耗尽;
- 结果: 到达的分组被路由器丢弃;

## 输入排队与队首阻塞有什么关系？

- 输入排队: 多个输入端口同时竞争同一输出端口时, 输入队列中的分组需要等待;
- 队首阻塞 (HOL): 队列前面的分组因目标输出端口繁忙而无法交换, 后面已可转发的分组也必须等待;

## 输出排队与主动队列管理是什么？

- 输出排队: 输出链路速率不足时分组在输出缓存中排队, 缓存满则丢弃;
- 主动队列管理 (AQM): 不等缓存耗尽, 按算法提前丢弃到达的分组或队列中的分组, 以提示发送方降速;

## 分组调度有哪些策略？

| 策略            | 规则                                                    |
| --------------- | ------------------------------------------------------- |
| 先进先出 (FIFO) | 严格按到达顺序依次处理                                  |
| 优先权排队      | 按首部信息划分优先级, 优先发送高优先级队列, 同级用 FIFO |
| 非抢占式优先权  | 分组一旦开始传输就不能被中断, 即使更高优先级分组到达    |
| 循环排队        | 不设严格优先级, 调度器在若干等待队列之间轮转            |
| 加权公平排队    | 不设严格优先级, 按队列权重的加权平均值分配带宽          |

## 加权公平排队如何分配带宽？

- 权重: 每个队列有一个基于分组数量的加权平均值;
- 保证: 每个队列至少能分配到与其加权平均值对应的带宽;
- 特点: 在保证各队列下限的同时仍能利用空闲带宽;
