# IPv4 编址与子网划分

## IPv4 地址如何表示？

- 长度: 32 bit;
- 记法: 点分十进制, 每个字节用十进制表示并以 `.` 分隔;

## 什么是子网？

- 子网: 若干主机与一台路由器共同构成的网络;
- 判定依据: 接口的 IP 地址与子网掩码按位与后得到相同的网络前缀;

## CIDR 如何定义子网地址？

- 记法: `a.b.c.d/x`;
- `x`: 网络前缀的比特数;
- 剩余 `32 - x` 位: 用于标识子网内的设备;

## 子网掩码如何算出网络地址与广播地址？

1. 把 IP 地址与子网掩码都写成二进制;
2. 掩码中连续的 1 对应网络地址部分, 其余位对应主机地址;
3. IP 与掩码按位与, 得到网络地址;
4. 网络地址不变, 主机位全部置 1, 得到广播地址;

## 什么是路由聚合？

- 现象: CIDR 定义的子网可在内部继续划分, 外部网络对此不可知;
- 效果: 对外只通告聚合后的一条前缀, 缩小转发表规模;
- 示例: `223.23.15.0/20` 内部划分 8 个 `223.23.15.0/23` 子网, 对外仍表现为 `/20`;

## 广播地址有什么作用？

- 全局广播地址: `255.255.255.255`;
- 效果: 发送到该地址的报文会交付给同一网络中的所有主机;

## 主机如何获得 IP 地址？

- 来源: 主机向 ISP 申请, 由 ISP 分配一块地址;
- 配置方式: 手工配置或由 DHCP 动态分配;

## DHCP 的交互流程是什么？

- 语义: 动态主机配置协议, 允许主机自动获取 IP 地址;
- 分配策略: 可配置为始终分配同一 IP, 也可分配临时 IP;
- 流程:
  1. 客户端广播 DHCP 发现报文 (基于 UDP 与 IP, 使用广播地址);
  2. 服务器广播 DHCP 提供报文;
  3. 客户端向选中的服务器发送 DHCP 请求报文;
  4. 服务器回送 DHCP ACK, 客户端在租期内使用该地址;
- 必要性: 四个步骤中后三个是实际必要的;
