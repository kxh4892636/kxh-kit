- 路径: 按自顶向下顺序学习: 因特网与网络核心 → 应用层 → 运输层 → 网络层 → 链路层;
- 使用方式: 先尝试回答每个 H2 问题, 再阅读正文, 需要前置概念时沿相对链接跳转;
- 边界: 只覆盖教材式的分层原理, HTTP 首部、TLS 与浏览器渲染等 Web 实践内容不在此范围;
- 篇幅: 单篇最多 144 行, 超出时按语义拆分。
