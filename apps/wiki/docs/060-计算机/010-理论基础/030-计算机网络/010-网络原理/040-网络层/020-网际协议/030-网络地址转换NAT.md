# 网络地址转换 NAT

## NAT 解决什么问题？

- 背景: IPv4 地址空间有限, 保留了一部分地址专供专用网络使用;
- 做法: 专用网络内的主机拥有唯一的专用 IP 地址, 对外共享一个公共 IP 地址;
- 转换: NAT 在出方向把专用地址映射为公共地址与端口, 在入方向反向还原;

![网络地址转换](../../../images/2023-09-06-16-55-31.png)

## NAT 如何完成地址与端口转换？

- 映射依据: 同时使用 IP 地址与端口号, 且映射是单射;
- 容量上限: 一个公共 IP 最多支持 65535 个内网主机同时对外通信;
- 前提: 内网主机主动发起连接, 外部才能建立回程映射;

## NAT 有什么优点？

- 节省 IP 地址, 缓解 IPv4 地址枯竭;
- 内网主机经 NAT 即可访问外网;
- 隐藏内网主机的 IP 地址, 提供简单的安全保护;
- 可用于负载均衡;

## NAT 有什么缺点？

- 网络延迟增大;
- 无法进行端到端的 IP 追踪;
- 部分应用层协议无法正确识别与穿透, 如 FTP 与 UDP 应用;

## 什么是中间盒？

- 中间盒: 在数据路径上执行 NAT、负载均衡、流量防火墙 (IDS) 等功能的中间组件;
- 特点: 不参与端到端协议语义, 但对路径上的分组做透明处理;
