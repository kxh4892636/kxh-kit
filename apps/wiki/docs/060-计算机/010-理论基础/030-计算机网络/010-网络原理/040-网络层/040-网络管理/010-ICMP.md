# ICMP

## ICMP 是什么？

- 名称: 因特网控制报文协议;
- 用途: 主机与路由器之间交换网络层的信息, 如差错与控制消息;
- 封装: 作为数据放在 IP 数据报的数据字段中传输;

## ICMP 报文有哪些类型？

- 典型类型: 目的不可达、超时、参数问题、回送请求与回送应答等;
- 用途: 回送类报文用于连通性探测, 差错类报文用于向源主机报告转发失败的原因;

## TTL 与 ICMP 如何配合？

- TTL: IP 数据报首部字段, 表示报文允许的最大转发次数;
- 配合: 转发次数用尽时, 路由器丢弃该数据报并向源主机回送 ICMP 超时报文;
- 应用: 这一机制是 traceroute 逐跳探测路径的基础;
