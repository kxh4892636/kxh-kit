# 自治系统内部路由 OSPF

## 自治系统是什么？

- 定义: 处于相同管理控制下、使用相同路由选择算法的一组路由器;
- 标识: 每个 AS 具有唯一的 AS 号;
- 边界: 对外隐藏内部网络信息, 对内使用自己的路由选择算法;
- 层级: 一个 ISP 可以包含一个或多个 AS, AS 之间按 ISP 的层级继续划分;
- 术语: 在 AS 内运行的路由选择算法称为 AS 内部路由选择协议;

## OSPF 如何工作？

- OSPF: 开放最短路优先, 属于链路状态协议;
- 机制: 泛洪链路状态信息, 各路由器用 Dijkstra 算法计算最短路径;
- 开销: 链路开销由人工设置, 不随负载变化;
- 通告时机: 链路状态变化时立即广播, 否则周期性广播;

## OSPF 有哪些优点？

- 安全: 支持报文鉴别;
- 多路径: 允许使用多条开销相同的路径;
- 多播支持: 可综合支持多播 OSPF (MOSPF) 与单播;
- 层次结构: 支持在单个 AS 内部再分层;
