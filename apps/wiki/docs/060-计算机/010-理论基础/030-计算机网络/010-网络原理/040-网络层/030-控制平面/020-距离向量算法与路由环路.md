# 距离向量算法与路由环路

## 距离向量算法如何工作？

- 基础: 每台路由器只知道自己到相邻节点的链路开销, 以及邻居通告的距离向量;
- 迭代: 通过与邻居交换距离向量并反复更新, 逐步收敛到最短路径;
- 特点: 无需全局拓扑信息;

## 为什么会出现路由选择环路？

- 根因: 只在局部区域交换信息, 邻居可能通告过时或错误的链路开销;
- 后果: 路由器根据错误开销选路, 形成环路;
- 恢复: 需要大量迭代才能得到准确开销;

## 无穷计数问题如何产生？

- 场景: 链路开销差异极大时, 坏消息传播很慢;
- 表现: 环路上的开销值每次迭代只缓慢增大, 迭代次数可能极大, 称为无穷计数问题;
- 影响: 收敛速度慢, 期间分组可能反复绕行或丢失;

## LS 与 DV 算法如何比较？

| 维度       | 链路状态 (LS)          | 距离向量 (DV)                |
| ---------- | ---------------------- | ---------------------------- |
| 所需信息   | 全网拓扑与开销         | 仅相邻节点的距离向量         |
| 报文复杂性 | 需要 N + E 个报文      | 取决于迭代次数               |
| 收敛速度   | $O(n^2)$               | 慢, 且存在无穷计数问题       |
| 健壮性     | 较强, 单点错误影响有限 | 局部节点错误会扩散到整个网络 |
