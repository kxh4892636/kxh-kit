# 自治系统间路由 BGP

## 自治系统之间使用什么协议？

- 前提: 所有 AS 必须使用同一种 AS 间路由选择协议;
- 协议: 边界网关协议 (BGP);

## BGP 的作用是什么？

- 可达性: 从相邻 AS 获取 IP 前缀的可达性信息;
- 选路: 在多个候选路径中确定到某个 IP 前缀的最好路由;

## 网关路由器与内部路由器有什么区别？

- 网关路由器: 位于 AS 边缘, 与其他 AS 的网关路由器相连;
- 内部路由器: 只连接 AS 内部的主机与路由器;

![内部路由器](../../../images/2023-09-08-11-08-20.png)

## BGP 如何通告路由信息？

- 传输: 使用 TCP 与 179 端口交换 BGP 报文;
- iBGP: 同一 AS 内部的 BGP 连接;
- eBGP: 跨越 AS 边界的 BGP 连接;

## IP 任播如何借助 BGP 实现？

- 做法: 多个物理服务器通告同一个 IP 前缀;
- 效果: BGP 按路由度量把请求导向最近的服务器;
