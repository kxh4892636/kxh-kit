# 信道划分协议

## 多路访问问题是什么？

- 点对点链路: 单个发送方对应单个接收方;
- 广播链路: 多个发送方与多个接收方共享同一信道;
- 多路访问问题: 如何协调多个节点对一个共享广播信道的访问;
- 多路访问协议: 规范节点在共享广播信道上的传输行为;

## TDM 如何划分信道？

- 做法: 把时间划分为固定长度的时间帧, 每帧包含 N 个时隙;
- 分配: 把一个时隙固定分配给一个节点;
- 缺点: 节点在其时隙之外无法发送, 空闲时隙被浪费;

## FDM 如何划分信道？

- 做法: 把信道按频率划分为不同频段;
- 分配: 把一个频段固定分配给一个节点;
- 缺点: 与 TDM 相同, 未使用的频段无法被其他节点利用;

## CDMA 如何划分信道？

- 做法: 给每个节点分配互不相同的编码;
- 发送: 节点用自己唯一的编码对数据编码后发送;
- 特点: 多个节点可同时发送, 接收方按编码分离出目标信号;
