# 数据中心网络

## 数据中心网络如何做负载均衡？

- 问题: 多台主机共同提供服务时, 请求需要分散到不同主机;
- 做法: 在数据中心网络内部部署负载均衡设备, 平衡各主机的工作负载;

## 等级体系结构是什么？

- 结构: 路由器与交换机按等级组织;
- 连接方式: 不同等级之间的设备采用一对多连接;
- 效果: 下层设备汇聚向上层, 上层设备成为共享瓶颈与聚合点;

## 数据中心网络有哪些发展趋势？

- 全连接拓扑: 不同等级的交换设备之间改为多对多连接, 提高对分带宽与容错;
- 模块化数据中心: 按模块单元复制部署, 便于扩容与维护;
