# 轮流协议

## 轮询协议如何工作？

- 主节点: 指定一个节点为主节点;
- 流程: 主节点轮流询问每个节点, 并告知其本轮最多可传输的帧数量;
- 特点: 无需竞争, 可保证公平与可控时延;

## 轮询协议有什么缺点？

- 轮询时延: 询问本身引入额外的往返等待;
- 单点故障: 主节点故障会导致整个信道瘫痪;

## 令牌传递协议如何工作？

- 令牌: 一个称为令牌的特殊帧, 在节点之间按固定次序传递;
- 发送: 节点收到令牌后, 若有数据待发就发送至多规定数量的帧, 然后把令牌转发给下一个节点;
- 空闲: 无数据待发时直接转发令牌;

## 令牌传递协议有什么缺点？

- 单点故障: 一个节点故障可能导致整个信道崩溃;
- 令牌丢失: 节点可能忘记释放令牌, 导致信道长期空闲;
