# 分组交换的时延与吞吐量

## 一个分组从源到目的经历哪些时延？

- 处理时延: 路由器解析首部、检查比特差错、决定输出链路的时间, 微秒量级;
- 排队时延: 分组在输出缓存中等待链路空闲的时间, 随拥塞程度变化;
- 传输时延: 把整个分组的比特推上链路的时间, 等于 分组长度 / 链路速率;
- 传播时延: 比特在物理媒介中传播的时间, 等于 链路长度 / 传播速率;
- 节点总时延: 上述四项之和;

## 传输时延和传播时延有什么区别？

- 传输时延: 取决于分组长度与链路速率, 与距离无关;
- 传播时延: 取决于距离与媒介中的传播速率, 与分组长度无关;
- 易错: 链路速率高只缩短传输时延, 不会缩短传播时延;

## 吞吐量如何定义与受限？

- 瞬时吞吐量: 接收方某时刻接收数据的速率;
- 平均吞吐量: 一段时间内接收数据的平均速率;
- 瓶颈链路: 端到端路径中各段链路吞吐量的最小值决定整体吞吐量;
- 结论: 提升非瓶颈链路的带宽对整体吞吐量没有帮助;
