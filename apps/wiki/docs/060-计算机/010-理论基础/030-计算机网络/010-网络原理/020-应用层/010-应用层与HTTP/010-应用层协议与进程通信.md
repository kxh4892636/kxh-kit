# 应用层协议与进程通信

## 应用层协议规定什么？

- 应用层: 负责不同应用程序之间如何传递报文, 该层分组称为报文;
- 应用层协议: 规定交换的报文类型、报文类型的语法、字段的语义, 以及发送与响应的规则;
- 边界: 只规定报文的交互规则, 不规定报文如何在网络上传输;

## 网络应用有哪些体系结构？

| 结构 | 服务端角色                       | 特征                               |
| ---- | -------------------------------- | ---------------------------------- |
| C/S  | 服务器处理请求, 具有固定 IP 地址 | 易管理, 需数据中心集群扩容         |
| P2P  | 服务器作用极小甚至没有           | 主机直接通信, 可扩展性好, 管理困难 |

## 进程之间如何通信与寻址？

- 客户进程: 发起通信的进程;
- 服务器进程: 等待被联系的进程;
- 套接字: 进程向计算机网络收发报文的接口;
- 寻址两要素: 目标主机的 IP 地址 + 目标进程的端口号;

## 为什么同一条报文需要同时给出 IP 与端口？

- IP 地址: 定位到目标主机;
- 端口号: 在目标主机内定位到具体进程, 因为一台主机同时运行多个网络进程;
