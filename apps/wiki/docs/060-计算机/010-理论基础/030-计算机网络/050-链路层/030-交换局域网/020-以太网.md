# 以太网

## 以太网的拓扑结构是什么？

- 拓扑: 星型拓扑;
- 中心设备: 位于中心的设备称为交换器, 各主机通过点对点链路与它相连;

## 以太网帧由哪些字段组成？

| 字段     | 作用                               |
| -------- | ---------------------------------- |
| 前同步码 | 唤醒并同步接收方适配器             |
| 目标地址 | 接收方 MAC 地址                    |
| 源地址   | 发送方 MAC 地址                    |
| 类型字段 | 指明上层协议                       |
| 数据字段 | 承载网络层数据报, MTU 为 1500 字节 |
| CRC      | 用作链路层的差错检测               |

## 以太网提供什么样的服务？

- 无连接: 发送前不建立握手;
- 不可靠: 收到出错帧时直接丢弃, 不返回确认, 也不请求重传;
- 无状态判别: 以太网无法分辨收到的数据报是全新数据报还是重传数据报;
