# 随机接入协议与 CSMA

## 随机接入协议的基本原则是什么？

- 发送: 节点以信道的全部速率发送帧;
- 冲突处理: 遭遇碰撞时等待一个随机时延后重发该帧;
- 特点: 无需集中协调, 但碰撞会浪费信道时间;

## ALOHA 与时隙 ALOHA 的效率如何？

- ALOHA: 帧一到达就立即发送; 发生碰撞后立刻以概率 `p` 重传, 否则等待; 之后每个时隙仍以概率 `p` 重传; 最大效率为 `1 / 2e`;
- 时隙 ALOHA: 时间划分为长度为 `L / R` 的时隙 (传输一帧的时间), 所有节点时隙起点一致; 帧只在时隙起点发送; 碰撞的节点在后续每个时隙以概率 `p` 重传直至成功; 最大效率为 `1 / e`;
- 结论: 统一时隙边界使时隙 ALOHA 的效率约为 ALOHA 的两倍;

## CSMA 为什么仍会碰撞？

- 载波侦听: 节点发送前先监听信道, 若检测到其他节点的帧在传输就等待;
- 仍会碰撞的原因: 信号在信道上有传播时延, 节点无法监听到整个链路上的全部传输;
- 后果: 两个节点可能同时判定信道空闲而同时开始发送;

## CSMA/CD 如何检测并处理碰撞？

- 检测: 传输过程中持续监听信道;
- 处理: 一旦检测到其他节点的帧就立刻停止传输, 避免继续浪费信道;
- 退避: 在重新"侦听—空闲时传播"之前等待一段随机时间;

## 二进制指数后退如何确定等待时间？

- 规则: 经历 `n` 次碰撞后, 从 `[0, 1, 2, ..., 2^n - 1]` 中随机选取一个整数 `K`;
- 等待时长:

$$\text{等待时间} = K \times \frac{512 \text{ bit}}{R}$$

- `R`: 信道传输速率;
- 效果: 碰撞次数越多, 可选的退避区间越大, 降低再次碰撞的概率;
