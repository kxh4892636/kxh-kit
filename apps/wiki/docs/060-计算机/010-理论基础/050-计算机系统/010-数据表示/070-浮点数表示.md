# 浮点数表示

## 二进制小数怎样表示？

- 形式: $b_m\cdots b_0.b_{-1}\cdots b_{-n}$;
- 数值:

$$b=\sum_{i=-n}^{m}2^i\times b_i$$

- 局限: 只能精确表示 $1/2$ 的幂的组合, 因此大量十进制小数无法精确表示;

## IEEE 754 用哪些字段表示一个浮点数？

- 编码形式:

$$V=(-1)^s\times M\times 2^E$$

- 符号位 $s$: 决定正负;
- 尾数 $M$: 一个二进制小数, 决定有效数字;
- 阶码 $E$: 对尾数加权, 决定数量级;

## 单精度和双精度如何划分字段？

| 格式   | 总位数 | 符号位 | 阶码位 | 尾数位 |
| ------ | ------ | ------ | ------ | ------ |
| 单精度 | 32     | 1      | 8      | 23     |
| 双精度 | 64     | 1      | 11     | 52     |

- 偏置量: 阶码有 $n$ 位时 $\text{Bias}=2^{n-1}-1$, 单精度为 127, 双精度为 1023;
- 阶码字段存放的是 $\text{Bias}$ 与真实阶码之和;

## 阶码和尾数的取值怎样决定数值含义？

| 阶码 | 尾数 | 含义                                 |
| ---- | ---- | ------------------------------------ |
| 全 0 | 全 0 | 零                                   |
| 全 0 | 非 0 | 非规格化数, $E=1-\text{Bias}$        |
| 其他 | 任意 | 规格化数, $E=e-\text{Bias}$, $M=1.f$ |
| 全 1 | 全 0 | 无穷大                               |
| 全 1 | 非 0 | NaN                                  |

- 规格化数: 尾数隐含前导 1, 即 $1.xxx$ 形式;
- 非规格化数: 尾数不带隐含的 1, 用于从最小规格化数平滑过渡到 0;

## 非负浮点数的取值边界是多少？

| 类型           | 值                           | 单精度              | 双精度               |
| -------------- | ---------------------------- | ------------------- | -------------------- |
| 零             | $0$                          | $0.0$               | $0.0$                |
| 最小非规格化数 | $2^{-23}\times2^{-126}$      | $1.4\times10^{-45}$ | $4.9\times10^{-324}$ |
| 最大非规格化数 | $(1-\epsilon)\times2^{-126}$ | $1.2\times10^{-38}$ | $2.2\times10^{-308}$ |
| 最小规格化数   | $1\times2^{-126}$            | $1.2\times10^{-38}$ | $2.2\times10^{-308}$ |
| 最大规格化数   | $(2-\epsilon)\times2^{127}$  | $3.4\times10^{38}$  | $1.8\times10^{308}$  |
| 无穷大         | $\infty$                     | —                   | —                    |
