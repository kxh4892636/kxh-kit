# 浮点转换与舍入

## 十进制浮点数怎样转成 IEEE 754 单精度？

1. 把十进制数转成二进制小数;
2. 规格化为 $1.xxx\times2^n$ 的形式;
3. 取小数部分左对齐并补 0, 得到 23 位尾数;
4. 阶码 $n$ 加上偏置量 127, 写成 8 位二进制;
5. 加上符号位;

```text
例: 176.0625 的单精度表示
1) 转二进制: 176.0625 = 10110000.0001
2) 规格化:   1.01100000001 × 2^7
3) 尾数:     01100000001000000000000
4) 阶码:     7 + 127 = 134 = 10000110
5) 符号位:   0
结果: 0 10000110 01100000001000000000000
```

## 浮点数怎样舍入？

- 前提: 尾数位有限, 多数实数无法精确表示;
- 目标: 在可表示的数里找最接近的一个;
- 结果: 误差无法消除, 只能控制量级;
- 后果: 舍入使浮点运算不再满足结合律, 改变运算顺序会改变结果;

## 为什么浮点运算不精确？

- 机制: 每次运算的结果都要舍入到可表示值;

$$x\odot y=\text{Round}(x\odot y)$$

- 解释: 运算结果是精确结果的舍入值, 误差会随运算次数累积;
