# 同步错误与信号量

## 同步错误是怎样产生的？

- 场景: 多个线程并发操作同一个共享变量;
- 原因: CPU 执行指令的先后顺序不确定, 交错方式不同会得到不同结果;
- 结果: 最终值不可预测;

## 进度图怎样判断并发是否正确？

- 构造: 把 n 个线程的执行过程表示为 n 维笛卡尔空间中的轨迹线;
- 安全轨迹线: 不会引起同步错误的轨迹线;
- 用途: 用轨迹线是否安全来判断某个同步方案是否可行;

## 信号量为什么能保证安全轨迹线？

- 信号量: 一种同步原语, 用于约束多个线程推进的顺序;
- 作用: 通过对临界区的互斥进入, 使轨迹线避开会引起错误交错的区域;
