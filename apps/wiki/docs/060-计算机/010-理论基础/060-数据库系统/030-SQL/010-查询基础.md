# 查询基础

## 一条 SQL 查询由哪些子句构成？

| 子句   | 作用               |
| ------ | ------------------ |
| FROM   | 确定要查询的表     |
| WHERE  | 约束元组的查询条件 |
| SELECT | 约束要返回的属性   |

```sql
SELECT *
FROM Movies
WHERE studioName = 'Disney';
```

## 投影操作用什么实现？

- 手段: 在 SELECT 子句中列出要保留的属性;
- 结果: 只返回这些属性, 元组按 WHERE 条件筛选;

```sql
SELECT title, length
FROM Movies
WHERE studioName = 'Disney';
```

## 怎样给结果属性改名？

- 手段: 用 `AS` 给属性起别名;
- 用途: 让结果列名可读, 或改名后供外层查询引用;

```sql
SELECT title AS name, length AS duration
FROM Movies
WHERE studioName = 'Disney';
```

## 选择操作用什么实现？

- 手段: 在 WHERE 子句中写条件表达式;
- 组合: 多个条件用 `AND`、`OR`、`NOT` 连接, 见 [排序与表达式](./020-排序与表达式.md);

```sql
SELECT title AS name, length AS duration
FROM Movies
WHERE studioName = 'Disney' AND year = 1990;
```
