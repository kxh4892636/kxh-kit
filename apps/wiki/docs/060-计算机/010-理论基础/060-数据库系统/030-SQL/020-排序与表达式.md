# 排序与表达式

## 怎样对查询结果排序？

- 手段: `ORDER BY` 子句;
- 顺序: `ASC` 升序、`DESC` 降序, 不写时默认为 `ASC`;
- 多列: 按列出的先后依次比较;
- 时机: 排序在所有其他操作之后执行;

```sql
SELECT title AS name, length AS duration
FROM Movies
WHERE title LIKE 'Star__'
ORDER BY length, title;
```

## 条件表达式支持哪些运算？

| 类别     | 运算                            |
| -------- | ------------------------------- |
| 比较运算 | `=`, `<>`, `<`, `>`, `<=`, `>=` |
| 布尔运算 | `AND`, `OR`, `NOT`              |
| 模式匹配 | `LIKE`                          |

## 字符串怎样比较与匹配？

- 比较: 直接用比较运算符, 按字母顺序判定大小;
- 模式匹配: 用 `LIKE` 加通配符;
- `%`: 匹配任意长度的字符;
- `_`: 匹配任意一个字符;

```sql
-- 匹配 Star 开头、总长恰好 6 个字符的标题
SELECT title
FROM Movies
WHERE title LIKE 'Star__';
```
