# 数据库更新

## 怎样插入元组？

- 语法: `INSERT INTO R(A1, ..., An) VALUES (U1, ..., Un)`;
- 语义: 向关系 R 插入一个元组, 属性的排列与括号中的值一一对应;
- 省略属性列表时按关系的属性顺序补全;

```sql
INSERT INTO StarsIn
VALUES ('The Maltese Falcon', 1942, 'Sydney Greenstreet');
```

## 怎样删除元组？

- 语法: `DELETE FROM R WHERE <条件>`;
- 语义: 删除满足条件的全部元组;
- 条件: 与查询中的 WHERE 写法相同, 可用子查询;

```sql
DELETE FROM MovieExec
WHERE netWorth < 10000000;
```

## 怎样修改元组？

- 语法: `UPDATE R SET <赋值列表> WHERE <条件>`;
- 语义: 对满足条件的每个元组执行赋值;

```sql
UPDATE MovieExec
SET name = 'Pres'
WHERE cert IN (
  SELECT presC FROM Studio
);
```
