# 索引

## 索引是什么？

- 定义: 建立在属性 (组) A 上的一种数据结构;
- 作用: 加快在 A 上的查询效率;
- 范围: 只对定义到的属性 (组) 生效;

## 怎样声明与删除索引？

- 声明: `CREATE INDEX <索引名> ON <表>(<属性列表>)`;

```sql
-- 单一属性
CREATE INDEX YearIndex ON Movies(year);
-- 多属性
CREATE INDEX KeyIndex ON Movies(title, year);
```

- 删除: `DROP INDEX <索引名>`;

```sql
DROP INDEX YearIndex;
```
