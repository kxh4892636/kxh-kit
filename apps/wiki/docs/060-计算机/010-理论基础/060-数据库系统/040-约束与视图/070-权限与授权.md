# 权限与授权

## 数据库中有哪些权限？

| 权限        | 作用对象             |
| ----------- | -------------------- |
| `SELECT`    | 关系                 |
| `INSERT`    | 关系                 |
| `DELETE`    | 关系                 |
| `UPDATE`    | 关系                 |
| `REFERENCE` | 完整性约束           |
| `USAGE`     | 关系与断言之外的模式 |
| `TRIGGER`   | 触发器               |
| `EXECUTE`   | 存储过程             |
| `UNDER`     | 创建子类型           |

## 创建者与所属用户一开始有哪些权限？

- 创建者: 对自己创建的数据库元素拥有权限;
- 所属用户: 由 `AUTHORIZATION` 子句指定;

```sql
AUTHORIZATION picard;
```

## GRANT 与 REVOKE 怎样授权和回收？

- 授权: `GRANT <权限列表> ON <数据库元素> TO <用户列表>`;

```sql
GRANT SELECT, INSERT ON Studio TO kirk, picard;
```

- 回收: `REVOKE <权限列表> ON <数据库元素> FROM <用户列表> <回收模式>`;
- 回收模式: `CASCADE` 逐层回收该用户转授出去的权限, `RESTRICT` 只回收第一层;

```sql
REVOKE SELECT, INSERT ON Studio FROM picard CASCADE;
```
