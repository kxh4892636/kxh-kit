# 修改表约束

## 怎样给已有的表添加约束？

- 语法: `ALTER TABLE <表> ADD CONSTRAINT <约束名> <约束定义>`;
- 约束名: 由用户指定, 后续删除时用它定位;
- 用途: 表已建好后再补主键、检查等约束;

```sql
ALTER TABLE MovieStar ADD CONSTRAINT NameIsKey
PRIMARY KEY (name);

ALTER TABLE MovieStar ADD CONSTRAINT GenderIsValid
CHECK (gender IN ('F', 'M'));
```

## 怎样删除约束？

- 语法: `ALTER TABLE <表> DROP CONSTRAINT <约束名>`;
- 依据: 用添加时声明的约束名;

```sql
ALTER TABLE MovieStar DROP CONSTRAINT NameIsKey;
```
