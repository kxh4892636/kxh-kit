# BCNF

## BCNF 要求什么？

- 要求: 对 R 中的任意非平凡函数依赖 $A_1A_2\cdots A_n \rightarrow B_1B_2\cdots B_m$, 属性组 $A$ 必须是 R 的超键;
- 一句话: 任何非平凡函数依赖的左边都必须是超键;
- 定位: BCNF 是修正后更严格的 3NF;

## BCNF 比第三范式严格在哪？

| 范式 | 对非平凡依赖 $A \rightarrow B$ 的要求 |
| ---- | ------------------------------------- |
| 3NF  | $A$ 是超键, 或 $B$ 是某个键的子集     |
| BCNF | $A$ 必须是超键, 没有例外              |

- 差异来源: 当 $A$ 不是超键但 $B$ 属于某个键时, 3NF 放行, BCNF 拒绝;

## BCNF 分解的代价是什么？

- 收益: 消除函数依赖带来的冗余;
- 代价: 分解后可能不再保持原有的函数依赖;
- 权衡: 与 3NF 的对比见 [范式概览](./020-范式概览.md);
- 分解步骤: 见 [分解方法](./070-分解方法.md);
