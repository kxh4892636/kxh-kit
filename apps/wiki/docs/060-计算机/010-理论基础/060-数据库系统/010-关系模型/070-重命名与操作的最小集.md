# 重命名与操作的最小集

## 重命名 $\rho$ 解决什么问题？

- 定义: 修改关系的名字或属性的名字, 不改变元组内容;
- 用途一: 让结果关系的属性名可被外层运算引用;
- 用途二: 同一关系参与自连接时, 用不同别名区分两侧的同名属性;

## 哪些运算是关系代数不可再分解的基本运算？

- 基本运算: 并, 差, 选择 $\sigma$, 投影 $\pi$, 笛卡尔积 $\times$, 重命名 $\rho$;
- 依据: 这六个运算无法用其余运算表示;
- 结论: 它们构成关系代数的最小完备集;

## 交、$\theta$ 连接、自然连接如何用基本运算表示？

$$R \cap S = R - (R - S)$$

$$R \Join_C S = \sigma_C(R \times S)$$

$$R \Join S = \pi_L(\sigma_C(R \times S))$$

- 含义: 交依赖差, 三种连接依赖笛卡尔积与选择, 自然连接还需要投影去掉重复的共有属性;
- 作用: 说明 SQL 的多种连接写法最终都落到同一组基本运算上;
