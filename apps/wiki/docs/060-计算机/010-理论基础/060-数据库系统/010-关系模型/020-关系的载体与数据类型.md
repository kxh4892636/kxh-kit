# 关系的载体与数据类型

## 关系在 SQL 中由什么承载？

| 关系模型 | SQL 对象 | 特点                                                         |
| -------- | -------- | ------------------------------------------------------------ |
| 关系     | 表       | 直接存储, 可查询可更新                                       |
| 导出关系 | 视图     | 由计算定义, 见 [虚拟视图](../040-约束与视图/080-虚拟视图.md) |
| 临时关系 | 临时表   | 执行 SQL 时临时构造                                          |

## SQL 支持哪些数据类型？

| 类别   | 类型                           |
| ------ | ------------------------------ |
| 字符串 | 可变长度字符串, 固定长度字符串 |
| 位串   | 可变长度位串, 固定长度位串     |
| 布尔   | 布尔值                         |
| 数值   | 整数类型, 浮点类型             |
| 时间   | 日期, 时间                     |

## PRIMARY KEY 与 UNIQUE 声明键时有什么区别？

- 共同点: 都要求键上的属性值唯一;
- PRIMARY KEY: 属性值不能为 NULL;
- UNIQUE: 属性值可以为 NULL;
