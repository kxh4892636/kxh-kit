# 可选控件

## checkbox 如何进行多选？

- 分组: `name` 相同的多个 checkbox 视为同一组, 组内可多选;
- `value`: 选中时提交的值;
- `checked`: 声明默认选中;

```html
<input type="checkbox" id="questionOne" name="subscribe" value="yes" checked />
```

## 提交时 checkbox 会发送什么？

- 被选中: 发送该控件的 `name=value`;
- 选中但没有 `value`: 发送 `name=on`;
- 一个都没选: 控件处于未知状态, 不发送任何值;

## radio 与 checkbox 有什么区别？

- 选择数量: radio 同组内只能选中一个;
- 取消: radio 一旦选中, 除重置表单外无法取消;
- 分组: 同样以相同的 `name` 归为一组;

```html
<input type="radio" id="soup" name="meal" value="soup" />
```

## 如何给同组选项写说明文字？

- 做法: 每个控件配一个 `label`, 用 `for`/`id` 关联;
- 示例: 见 [表单元素](./040-表单元素.md) 的 `fieldset` 一节;
