# 文档基本结构

## 一个 HTML5 文档由哪些部分组成？

- `<!DOCTYPE html>`: 表明文档使用 HTML5;
- `<html>`: 根元素, 其余元素都写在其中;
- `<head>`: 网页头部, 存放元数据;
- `<body>`: 网页内容, 渲染可见部分;

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="utf-8" />
    <title>My test page</title>
  </head>
  <body>
    <p>This is my page</p>
  </body>
</html>
```

## DOCTYPE 声明有什么作用？

- 作用: 声明文档的 HTML 版本为 HTML5;
- 位置: 文档最前, 在 `<html>` 之前;
- 写入 `head` 的元数据见 [文档头部](./020-文档头部.md);

## html 元素如何声明网页语言？

- 属性: 根元素上的 `lang`;
- 取值: 语言-地区格式, 如 `zh-CN`、`en-US`;
- 作用: 声明网页内容使用的语言, 供用户代理按该语言处理文本;

```html
<html lang="zh-CN"></html>
<html lang="en-US"></html>
```
