# 引用与信息元素

## blockquote 与 q 元素如何表示引用？

- `blockquote`: 块级引用, 独占一段;
- `q`: 行内引用, 引号由浏览器补;
- `cite` 属性: 两者都可用它给出引用来源的 URL, 该属性不影响渲染;
- 写法: 标签内照常写被引用的文本;

```html
<blockquote cite="https://datatracker.ietf.org/doc/html/rfc1149">
  <p>Standard for the transmission of IP datagrams on avian carriers.</p>
</blockquote>
<p>
  According to Mozilla's website,
  <q cite="https://www.mozilla.org/en-US/about/history/details/"
    >Firefox 1.0 was released in 2004 and became a big success.</q
  >
</p>
```

## cite 元素表示什么？

- 语义: 引用作品或文档的名称, 如标准号、书名、影片名;
- 与 `cite` 属性的区别: 元素是可见的出处名称, 属性是机器可读的来源 URL;

```html
<p>More information can be found in <cite>[ISO-0000]</cite>.</p>
```

## abbr 元素如何标注缩写？

- 做法: 用 `abbr` 包裹缩写;
- `title`: 给出全称, 鼠标悬停时显示;

```html
<p>Using <abbr title="html">HTML</abbr> is fun and easy!</p>
```

## address 元素要求怎样的内容结构？

- 语义: 声明联系信息, 如邮箱、电话、通信地址;
- 内容限制: 内部只使用 `a` 元素;
- 换行: 用 `br` 分隔多行联系信息, 见 [非语义容器](./040-非语义容器.md);

```html
<p>Contact the author of this page:</p>
<address>
  <a href="mailto:jim@rock.com">jim@rock.com</a><br />
  <a href="tel:+13115552368">(311) 555-2368</a>
</address>
```

## time 元素如何表达机器可读时间？

- 分工: 标签内写给人看的文本, `datetime` 属性写机器可读值;
- 格式: `datetime` 使用 ISO8601 标准;

```html
<p>
  The Cure will be celebrating their 40th anniversary on
  <time datetime="2018-07-07">July 7</time> in London's Hyde Park.
</p>
```
