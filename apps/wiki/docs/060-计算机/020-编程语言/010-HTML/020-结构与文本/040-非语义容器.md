# 非语义容器

## div 元素如何使用？

- 定位: 无语义的块级容器;
- 用途: 需要一块可挂 `class`/`id` 的区域做布局或装饰时使用;

```html
<div class="shadowbox">
  <p>Here's a very interesting note displayed in a lovely shadowed box.</p>
</div>
```

## span 元素如何使用？

- 定位: 无语义的行内容器;
- 用途: 为一段文字中的局部片段挂样式或脚本钩子;

```html
<p><span>Some text</span></p>
```

## div 与 span 有什么区别？

| 元素   | 显示类型 | 换行       | 典型用途     |
| ------ | -------- | ---------- | ------------ |
| `div`  | 块级     | 独占一行   | 区块级布局   |
| `span` | 行内     | 与文本同行 | 行内局部标记 |

- 显示类型与嵌套规则见 [块级与行内元素](../010-基础/020-块级与行内元素.md);

## br 与 hr 元素有什么作用？

- `br`: 在文本中插入换行, 如地址分行;
- `hr`: 插入一条水平线, 表示主题转换;
- 边界: 两者都是空元素, 不承载内容;

```html
Mozilla<br />
331 E. Evelyn Avenue<br />
Mountain View, CA<br />
<hr />
<p>This is the second paragraph of text.</p>
```
