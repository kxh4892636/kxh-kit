# 文本标记

## strong 与 b 有什么区别？

- `strong`: 语义加粗, 表示内容的重要性;
- `b`: 形式加粗, 只改变外观, 不表达重要性;

```html
<p>Before proceeding, <strong>make sure you put on your safety goggles</strong>.</p>
<p>Before proceeding, <b>make sure you put on your safety goggles</b>.</p>
```

## em 与 i 有什么区别？

- `em`: 语义倾斜, 表示需要强调;
- `i`: 形式倾斜, 只改变外观;
- 选择: 语气重音用 `em`, 外语词、术语、分类名等用 `i`;

```html
<p>This is <em>not</em> a drill!</p>
<p>This is <i>not</i> a drill!</p>
```

## u 元素为什么不推荐使用？

- 作用: 给文本加下划线;
- 问题: 网页中下划线通常表示可点击的链接, 容易造成误解;
- 替代: 用 CSS 控制下划线;

```html
<p>This paragraph includes a <u class="spelling">wrnogly</u> spelled word.</p>
```

## sup 与 sub 元素如何表示上下标？

- `sup`: 上标, 如指数;
- `sub`: 下标, 如化学式;

```html
<p>
  One of the most common equations in physics is <var>E</var>=<var>m</var><var>c</var><sup>2</sup>.
</p>
<p>
  Almost every developer's favorite molecule is
  C<sub>8</sub>H<sub>10</sub>N<sub>4</sub>O<sub>2</sub>.
</p>
```

- `var` 元素见 [计算机代码元素](./090-计算机代码元素.md);
