# 约束

## any 约束是什么？ 有哪些操作限制？

- 约束入口: `any` 允许任意类型实参，空接口与别名含义见[interface 值](../../008-接口与动态类型/020-interface值.md);
- 操作限制: 只可使用所有类型都支持的操作;

```go
func Identity[T any](v T) T { // any 允许任意类型作为类型实参
	return v
}
```

## comparable 约束是什么？ 哪些类型不满足？

- `comparable`: 允许相等比较的类型约束;
- 不包含类型: slice, map, function;

```go
func Equal[T comparable](a, b T) bool { // comparable 允许 == 和 !=
	return a == b
}
```

- 接口实参: Go 1.20 起，`any` 等可比较接口也可满足 `comparable` 约束；若实际比较的动态值不可比较，仍会 panic;

- 动态值反例: 下例的类型实参 any 可以通过约束检查，但两个接口中装的都是不可比较的切片;

```go
var a any = []int{1}
var b any = []int{1}
// Equal[any](a, b) // 编译允许，执行 == 时 panic
_, _ = a, b
```

## 自定义约束如何声明？ union 与类型集合如何表达？

- constraint interface: 可在接口中写类型集合;
- union: `|` 表示允许多个类型;
- 类型集合: 约束允许的所有类型;

```go
type Integer interface {
	~int | ~int8 | ~int16 | ~int32 | ~int64 // ~T 允许底层类型为 T 的自定义类型
}

func Max[T Integer](a, b T) T {
	if a > b { // 只有类型集合中所有类型都支持的操作可用
		return a
	}
	return b
}
```

## 类型元素是什么？ 基本接口与非基本接口有何区别？

- 接口元素: 只有方法元素与类型元素两类;
- 方法元素: 如 `String() string`，只说明“具备这些方法的类型”，不直接点名类型;
- 类型元素: 如 `~int`、`int`，或用 `|` 连接的并集，直接圈定类型集合;
- 基本接口: 类型集合能完全由方法列表定义，可作为普通值类型;
- 非基本接口: 含类型元素（并集、`~T`、`comparable`）或内嵌了非基本接口，只能作为约束;

```go
type Number interface {
	~int | ~int64 | ~float64 // 整行是一个类型元素
}
```

- 无法作为值类型: 接口值运行时只是 `(动态类型, 动态值)` 并靠方法表派发；非基本接口的类型集合里各类型布局不同、也可能没有共同方法，接口值无法表示;

```go
func Sum[T Number](xs []T) T { // 合法：只出现在约束位置
	var s T
	for _, x := range xs {
		s += x // 类型集合中所有类型都支持 +
	}
	return s
}
```

```go
var n Number              // 非法：cannot use type Number outside a type constraint
var _ = []Number{}        // 非法：同上，不能作切片元素
type S struct{ v Number } // 非法：同上，不能作字段
var _ = Number(1)         // 非法：cannot use interface Number in conversion
```
