# 内置函数

## 如何按任务找到内置函数的学习入口？

- `len(ch)`: 只表示缓冲区里尚未接收的元素数;
- 不代表: 等待中的 goroutine 数量;
- 不能判断: 通信是否已经完成;

| 函数                | 描述                                         |
| ------------------- | -------------------------------------------- |
| `len`               | 返回 string, array, slice, map, channel 长度 |
| `cap`               | 返回 array, slice, channel 容量              |
| `make`              | 创建 slice, map, channel                     |
| `new`               | `new(T)` 创建 T 的零值并返回指针             |
| `append`            | 追加 slice 元素                              |
| `copy`              | 复制 slice 元素                              |
| `delete`            | 删除 map key                                 |
| `close`             | 关闭 channel                                 |
| `clear`             | 清空 map 或将 slice 元素置零                 |
| `complex`           | 根据实部和虚部构造复数                       |
| `real`              | 返回复数实部                                 |
| `imag`              | 返回复数虚部                                 |
| `min`               | 返回一组有序值中的最小值                     |
| `max`               | 返回一组有序值中的最大值                     |
| `panic`             | 触发 panic                                   |
| `recover`           | 捕获正在传播的 panic                         |
| `print` / `println` | 输出实现相关调试信息                         |

- 容器操作: 见[切片](../003-类型系统/003-复合与间接类型/030-slice操作.md)与[map](../003-类型系统/003-复合与间接类型/040-map.md);
- 复数操作: 见[复数](../003-类型系统/002-基础类型/040-复数.md);
- 异常流程: 见[panic](../009-错误与异常控制/030-panic.md)与[recover](../009-错误与异常控制/040-recover.md);

## 如何组合使用内置函数？

- 组合顺序: 先初始化容器, 再操作, 最后读结果;
- 分工: `make` 预留容量, `append` 增加长度;
- 观察: `len` 与 `cap` 分别看两种边界;

```go
func main() {
	s := make([]int, 0, 4) // make 创建 slice
	s = append(s, 1)       // append 返回新 slice
	println(len(s), cap(s))
}
```

## clear 如何清理 slice 与 map 的内容？

- clear 对 slice: 保留长度, 元素归零;
- clear 对 map: 删除全部键;
- 边界: nil slice 与 nil map 也能调用;

```go
s := []int{1, 2}
m := map[string]int{"go": 1}
clear(s)
clear(m)
println(len(s), s[0], len(m)) // 2 0 0
```
