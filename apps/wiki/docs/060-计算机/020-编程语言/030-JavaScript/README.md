## 如何阅读这组笔记？

- 路径: 先学语言核心 (语言基础 → 数据类型 → 运算符与语句 → 引用类型 → 函数 → 对象模型 → 执行上下文 → 迭代 → 异步), 再学宿主能力 (BOM → DOM → 事件 → 网络与存储 → 模块化 → 工作者线程 → 浏览器 API → 错误处理);
- 使用方式: 先尝试回答每个 H2 问题再读正文, 需要前置概念时沿相对链接跳转;
- 边界: 宿主能力以浏览器为口径, Node.js 专有 API 不在此范围;
- 篇幅: 普通笔记最多 144 行, 超出时按语义拆分。

## 这组笔记从哪里来？

- 来源: 本仓库 `apps/wiki/docs/000-中转/30-JavaScript` 的个人学习笔记, 主体沿用《JavaScript 高级程序设计 (第 4 版)》与 MDN 的讲解顺序;
- 取舍: 保留语言语义、边界行为与可复现示例, 去掉重复的原子 API 清单与过时实现细节;
