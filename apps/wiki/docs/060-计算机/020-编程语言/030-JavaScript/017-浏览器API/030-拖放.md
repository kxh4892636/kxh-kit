# 拖放

## 拖动源元素会触发哪些事件？

- 顺序: `dragstart` → `drag` → `dragend`;
- `dragstart`: 开始移动鼠标的瞬间触发;
- `drag`: 拖动过程中持续触发;
- `dragend`: 停止移动时触发;

## 放置目标会触发哪些事件？

- 顺序: `dragenter` → `dragover` → `drop` 或 `dragleave`;
- `dragenter`: 拖动元素进入放置目标时触发;
- `dragover`: 只要仍在放置范围内就持续触发;
- `dragleave`: 离开放置范围时触发;
- `drop`: 放置到目标上时触发;

## DataTransfer 如何传递数据？

- 来源: 拖放回调的 `event.dataTransfer`;
- 作用: 由被拖动元素向放置目标传递字符串数据;

| 成员                              | 作用                                  |
| --------------------------------- | ------------------------------------- |
| `dropEffect`                      | 放置效果: `none`/`copy`/`link`/`move` |
| `effectAllowed`                   | 允许的拖动效果                        |
| `files` / `items` / `types`       | 文件列表 / 数据项列表 / 类型列表      |
| `setData(format, data)`           | 写入指定格式的数据                    |
| `getData(format)` / `clearData()` | 读取 / 清除数据                       |
| `setDragImage(image, x, y)`       | 自定义拖动图像                        |

## 哪些元素默认可拖动, 如何自定义？

- 默认: 图片、链接和文本可以被拖动;
- 自定义: 用 `draggable` 属性控制任意元素;

```html
<img src="smile.gif" draggable="false" alt="Smiley face" />
<div draggable="true">...</div>
```

- 强制放置: 部分元素默认不接受放置, 在 `dragover` 与 `dragenter` 中调用 `event.preventDefault()` 即可让任意元素成为放置目标;

```js
droptarget.addEventListener("dragover", (event) => event.preventDefault());
droptarget.addEventListener("dragenter", (event) => event.preventDefault());
```
