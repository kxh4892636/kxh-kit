# 声明文件

## 声明文件有什么用, 后缀是什么？

- 用途: 声明第三方库的类型、变量、方法的类型信息, 让 TypeScript 认识没有类型的 JavaScript;
- 后缀: `.d.ts`;
- 内容: 只描述类型, 不产生运行时代码;

## 如何声明自定义类型？

- 写法: 在声明文件或普通模块中用 `type` 导出类型别名, 供其他文件 `import`;

```typescript
export type CaseListData = {
  key: string;
  title: string;
  data: string[];
};
```

- 效果: 业务数据结构可以在多个文件间共享同一份类型定义;
