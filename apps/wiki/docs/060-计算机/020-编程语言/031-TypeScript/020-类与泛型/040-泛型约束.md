# 泛型约束

## 为什么需要泛型约束？

- 问题: 泛型参数在函数内部仍是未知类型, 不能访问任何属性或方法;
- 目标: 在保持泛化的同时, 声明类型参数至少具备哪些成员;

## 如何用 extends 声明泛型约束？

```typescript
interface Lengthwise {
  length: number;
}

const loggingIdentity = <T extends Lengthwise>(arg: T): T => {
  console.log(arg.length);
  return arg;
};
```

- 语法: `<T extends 约束类型>`;
- 效果: 实参必须满足约束; 函数体内可以安全访问约束中声明的成员 `length`;
- 返回值: `T` 仍是调用时的具体类型, 不会退化为约束类型;
