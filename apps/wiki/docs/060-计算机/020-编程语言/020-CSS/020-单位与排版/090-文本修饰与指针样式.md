# 文本修饰与指针样式

## text-decoration 简写如何使用？

- 属性: `text-decoration`;
- 语法: 组合 `line`、`style`、`color` 等成分;

```css
.over {
  text-decoration: wavy overline lime;
}
```

## 文本修饰的成分属性有哪些？

| 成分属性                | 作用       |
| ----------------------- | ---------- |
| `text-decoration-line`  | 修饰线位置 |
| `text-decoration-style` | 修饰线样式 |
| `text-decoration-color` | 修饰线颜色 |

```css
.both {
  text-decoration-line: underline overline; /* 可叠加 */
  text-decoration-style: wavy;
}
```

## 超链接默认有哪些状态样式？

- link: 下划线;
- unvisited: 蓝色;
- visited: 紫色;
- hover: 鼠标显示为小手图标;
- focus: 方框包裹;
- active: 红色;

## cursor 如何设置鼠标样式？

- 属性: `cursor`;

```css
.bar {
  cursor: auto;
  cursor: none;
  cursor: pointer;
  cursor: text;
  cursor: move;
  cursor: wait;
  cursor: not-allowed;
  cursor: grab;
  cursor: zoom-in;
}
```
