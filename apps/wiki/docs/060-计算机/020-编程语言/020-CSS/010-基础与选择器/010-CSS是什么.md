# CSS 是什么

## CSS 是什么？

- CSS: 层叠样式表 (Cascading Style Sheets);
- 作用: 描述 HTML 文档的呈现方式;
- 关系: HTML 定义结构, CSS 定义样式;

## CSS 规则由哪些部分组成？

- 规则: 选择器 + 声明块;
- 选择器: 指定规则作用的元素;
- 声明块: 一对 `{}` 包裹的若干声明;
- 声明: `属性: 值;` 形式;

![css rule 结构](../images/2022-05-30-19-09-54.png)

```css
h1 {
  color: blue;
  background-color: yellow;
  border: 1px solid black;
}
```

## 如何把样式表接入 HTML？

| 方式     | 写法                      | 特点                 |
| -------- | ------------------------- | -------------------- |
| 外部样式 | `<link rel="stylesheet">` | 可复用、可缓存, 推荐 |
| 内部样式 | `<style>` 标签            | 仅作用于当前文档     |
| 内联样式 | `style` 属性              | 可维护性差, 避免使用 |

```html
<link rel="stylesheet" href="styles.css" />
```

```html
<style>
  p {
    color: red;
  }
</style>
```

```html
<p style="color: red;">内联样式</p>
```

## CSS 的空白与注释如何处理？

- 空白: 空格、换行符、制表符;
- 作用: 分隔属性值, 提高可读性;
- 忽略: 多余空白被浏览器忽略;
- 注释: `/* ... */` 形式, 不产生样式;

```css
/* comment */
```

## 浏览器如何解析 CSS？

- 成功解析: 应用该规则;
- 解析失败: 忽略该部分, 不报错阻塞;
- 后果: 拼写或语法错误会静默失效;
