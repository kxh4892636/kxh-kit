# 继承与特殊值

## 继承是什么？

- 继承: 子元素未声明某属性时, 使用父元素的计算值;
- 传递方向: 沿 DOM 树向下;

## 哪些属性可继承, 哪些不可继承？

| 类别         | 可继承性 | 典型属性                         |
| ------------ | -------- | -------------------------------- |
| 样式类       | 可继承   | font、color、text、list 相关     |
| 布局与尺寸类 | 不可继承 | 盒模型、position、float、display |

## 继承与层叠的覆盖关系是什么？

- 继承值: 优先级最低, 任何直接命中的声明都覆盖它;
- 显式继承: 用 `inherit` 强制子元素取父值;

## 全局特殊值如何强制取值来源？

- `inherit`: 取父元素计算值;
- `initial`: 取属性初始值 (浏览器默认);
- `unset`: 可继承属性按 inherit, 否则按 initial;
- `revert`: 回退到上一个 origin 的样式;
- `all`: 一次性把所有属性设为同一来源值;

```css
.reset {
  all: unset;
}
```
