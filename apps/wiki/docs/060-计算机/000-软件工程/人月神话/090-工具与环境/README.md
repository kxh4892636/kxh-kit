## 这组笔记的前提是什么？

- 前提: 个性化的工具集妨碍沟通, 而沟通正是项目的关键问题;
- 因此: 项目经理应制订工具策略, 为通用工具开发分配资源, 同时不吝啬专业工具的投入;
