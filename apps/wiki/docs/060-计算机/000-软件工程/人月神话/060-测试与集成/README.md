# 测试与集成

- [010-构件单元调试的演进](./010-构件单元调试的演进.md)

## 这组笔记回答什么问题？

- 调试技术为什么在二十年间反复演进, 甚至回到起点;
- 系统集成调试为什么比单元调试更难, 以及如何把它变成可计划的流程;

## 这组笔记的前提是什么？

- 前提: 系统调试（相对于单元测试）花费的时间会比预料的更长;
- 因此: 它需要完备、系统化、可计划的方法, 而不是靠临时凑合;
