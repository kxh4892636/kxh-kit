## 这组笔记回答什么问题？

- 为什么"概念完整性"是系统设计最重要的考虑因素;
- 怎样在多人开发的大型项目中保住概念完整性;
- 设计者最容易犯什么系统性错误, 以及如何用机制约束;

## 为什么这组是原著的中心论点？

- 原著前言自述: 中心论点是"由于人员的分工, 大型项目碰到的管理问题和小项目区别很大, 关键需要是维持产品自身的概念完整性";
- 第 4-7 章是围绕这个论点的展开;
