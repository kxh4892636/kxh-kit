## 这组笔记回答什么问题？

- 为什么第一个系统通常必须被丢掉;
- 软件为什么必然退化, 维护为什么永远做不完;
- 什么样的开发模型和设计策略才经得起持续变更;

## 为什么这组要区分原著与修正？

- 原著: 第11章主张"为舍弃而计划, 无论如何你一定要这样做";
- 修正: 20 年后作者指出第 11 章隐含假设了瀑布模型, 并明确"瀑布模型是错误的";
- 阅读提示: 不要把第 11 章当作可独立执行的方案, 要和第 19 章的增量开发一起读;
