## 这组笔记回答什么问题？

- 一个团队应该由多少人组成、按什么方式分工;
- 人数多了以后, 靠什么机制维持交流和组织;
- 组织架构如何为变更和授权做准备;

## 这组笔记的前提是什么？

- 前提: 人月不可互换, 沟通成本随人数非线性增长（见 020-人月与进度）;
- 因此: 团队规模、分工方式和交流机制不是行政问题, 而是决定进度能否成立的工程问题;
