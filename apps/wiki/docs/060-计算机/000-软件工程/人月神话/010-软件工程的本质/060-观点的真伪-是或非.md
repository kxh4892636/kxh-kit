# 观点的真伪：是或非

## 1995 年作者如何复盘 1975 年的全部论断？

- 做法: 抽取 1975 年版《人月神话》的全部论断;
  - 按章节编号列成命题清单, 以方括号评论标出 20 年后的变化;
- 复盘动机: 哪些观点得到数据和经验支持? 哪些被证明不正确? 哪些显得陈旧过时?
- 命题性质: 全部是作者当年认为将会正确的客观事实与经验法则;
  - 都可操作验证; 写成刻板形式是为引发读者的思考、判断与讨论;
- 清单规模: 只是 177 页原书内容的摘要, 详细论证仍在各章;
- 计数: 编号命题 202 条 (1.1 至 15.15) 加原著结束语 2 条, 共 204 条;

| 判定口径 | 含义                                   |

| 部分真   | 方向成立, 但需补充条件或被后续数据修正 |
| 过时     | 原书方括号标注因技术或市场变化而失效   |
| 伪       | 022 明确自我否认                       |
