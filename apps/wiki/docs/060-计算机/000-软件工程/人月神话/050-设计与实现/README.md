## 这组笔记回答什么问题？

- 程序规模为什么是成本问题, 怎样把它当作预算来控制;
- 什么样的技术手段能真正减小规模或提高性能;
- 如何在写代码之前就把 bug 的数量降下来;

- 前提: 软件的根本困难是概念结构的复杂度（见 010-软件工程的本质）;
