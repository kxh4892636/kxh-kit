## 这组笔记回答什么问题？

- 一个项目最少需要哪些关键文档;
- 面向用户、面向验证、面向维护的文档各写什么;
- 怎样把文档负担降到最小;

## 这组笔记的前提是什么？

- 前提: 文档不是行政负担, 而是项目经理的主要个人工具;
- 理由: 只有书面计划是精确和可以沟通的, 书写过程本身迫使上百次细小决定浮出水面;
