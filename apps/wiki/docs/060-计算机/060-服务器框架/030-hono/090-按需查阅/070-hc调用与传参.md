# hc 调用与传参

## 客户端怎么调用？

```ts
import type { AppType } from "./server";
import { hc } from "hono/client";

const client = hc<AppType>("http://localhost:3000/");

const res = await client.posts.$post({ form: { title: "Hello", body: "Hono" } });
if (res.ok) {
  const data = await res.json(); // 类型来自 201 的返回体
}
```

| 服务端数据来源  | 客户端传参 key         |
| --------------- | ---------------------- |
| `param` / `:id` | `param: { id: '123' }` |
| `query`         | `query: { page: '1' }` |
| `json` 校验     | `json: {...}`          |
| `form` 校验     | `form: {...}`          |

- 路径参数必须写字符串；带 `:id` 的路由用 `client.posts[':id'].$get({ param: { id } })`;
- 多个路径参数就多挂一层：`client.posts[':postId'][':authorId']`;
- 参数值不会被 URL 编码，需要带斜杠时服务端用 `:id{.+}` 匹配，客户端自己 `encodeURIComponent`;

## 请求头与 fetch 选项怎么传？

```ts
// 全局：所有请求都带
const client = hc<AppType>(url, { headers: { Authorization: "Bearer x" } });

// 带 Cookie
const withCookie = hc<AppType>(url, { init: { credentials: "include" } });

// 单次覆盖
await client.search.$get(
  { query: { q: "x" } },
  {
    headers: { "X-Custom": "1" },
    init: { signal: controller.signal },
  },
);
```

- `init` 是标准 `RequestInit`，优先级最高，可覆盖 body/method/headers;
- 自定义 fetch（如内部服务直连）：`hc<AppType>(url, { fetch: customFetch })`;
- 自定义查询序列化：`buildSearchParams: (query) => URLSearchParams`;

## 上传文件怎么写？

```ts
const res = await client.user.picture.$put({
  form: { file: new File([bytes], "a.png", { type: "image/png" }) },
});
```

- 服务端用 `zValidator('form', z.object({ file: z.instanceof(File) }))` 接收;
- 大文件别走 RPC 客户端，改用直传对象存储 + 签名接口;
