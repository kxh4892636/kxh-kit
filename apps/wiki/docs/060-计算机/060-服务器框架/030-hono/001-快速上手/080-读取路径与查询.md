# 读取路径与查询

## `c.req` 是什么？

- `HonoRequest`：对标准 `Request` 的封装，负责路径参数、查询、头、请求体解析;
- 原始对象在 `c.req.raw`，需要平台特性（如 Cloudflare 的 `cf`）时才用它;

## 如何读取路径参数与查询？

```ts
app.get("/entry/:id", (c) => {
  const id = c.req.param("id"); // '/entry/123' → '123'
  const all = c.req.param(); // { id: '123' }

  const q = c.req.query("q"); // '?q=hono' → 'hono'
  const { limit, offset } = c.req.query(); // 全部查询值，均为 string
  const tags = c.req.queries("tags"); // '?tags=A&tags=B' → ['A','B']

  return c.json({ id, all, q, limit, offset, tags });
});
```

- 查询参数一律是 `string`，数字要自己转或交给校验器（见 [手写参数校验](../002-服务端开发/030-手写参数校验.md)）;
- 参数不存在时返回 `undefined`，不是空字符串;
- `queries()` 用于同名多值，单值场景不要用它;

## 路径相关的属性有哪些？

| 属性                  | 含义                                        |
| --------------------- | ------------------------------------------- |
| `c.req.path`          | 仅路径，如 `/about/me`                      |
| `c.req.url`           | 完整 URL 字符串                             |
| `c.req.method`        | `GET`、`POST`…                              |
| `c.req.routePath`     | 已废弃，改用 `routePath(c)`（`hono/route`） |
| `c.req.matchedRoutes` | 已废弃，改用 `matchedRoutes(c)`             |

```ts
app.get("/about/me", (c) => c.json({ path: c.req.path, url: c.req.url, method: c.req.method }));
```

- 记录日志用 `path`，避免把 query 里的大量参数写进日志;
