# 读取请求体

## 该用哪个方法读请求体？

| 方法                             | 适用 Content-Type                              | 返回                             |
| -------------------------------- | ---------------------------------------------- | -------------------------------- |
| `c.req.json()`                   | `application/json`                             | 解析后的对象                     |
| `c.req.text()`                   | `text/plain`                                   | 字符串                           |
| `c.req.parseBody()`              | `multipart/form-data`、`x-www-form-urlencoded` | `Record<string, string \| File>` |
| `c.req.formData()`               | 同上                                           | 标准 `FormData`                  |
| `c.req.arrayBuffer()` / `blob()` | 二进制                                         | `ArrayBuffer` / `Blob`           |

```ts
app.post("/entry", async (c) => {
  const body = await c.req.json();
  return c.json({ received: body });
});
```

- 请求体只能读一次，重复读会抛错;
- `json()` 遇到非法 JSON 会抛错，最终变成 500；要返回 400 就先校验 `Content-Type` 或用校验器;

## 表单与文件上传怎么取值？

```ts
const body = await c.req.parseBody();
body["name"]; // string | File
body["file[]"]; // (string | File)[]  ← 多文件必须带 [] 后缀

const all = await c.req.parseBody({ all: true }); // 同名多值统一成数组
const dotted = await c.req.parseBody({ dot: true }); // 'a.b' → { a: { b } }
```

- 同名多文件不写 `[]` 时只会保留最后一个;
- `all: true` 时同名多值一律变数组，单值仍是标量;
- 上传大小限制用 `bodyLimit` 中间件，见 [压缩体积与超时](../002-服务端开发/120-压缩体积与超时.md);
- 完整的文件校验写法见 [文件上传](../002-服务端开发/150-文件上传.md);

## 读完之后怎么用校验后的数据？

```ts
app.post("/posts", zValidator("json", schema), (c) => {
  const data = c.req.valid("json"); // 类型已收窄
  return c.json(data);
});
```

- 可用目标: `json`、`form`、`query`、`header`、`param`、`cookie`;
- 前置条件是注册了对应校验器，否则 `valid()` 拿不到值;
- 校验器的两种用法见 [手写参数校验](../002-服务端开发/030-手写参数校验.md) 与 [Schema 校验与 Zod](../002-服务端开发/040-Schema校验与Zod.md);
