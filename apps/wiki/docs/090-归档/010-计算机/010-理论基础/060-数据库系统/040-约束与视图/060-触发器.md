# 触发器

## 触发器的工作模式是什么？

- 三段式: 事件 - 条件 - 动作;
- 激活: 发生对应事件时, 触发器被激活;
- 判定: 触发器测试触发条件;
- 执行: 触发条件成立时执行对应动作;

## 怎样创建触发器？

- 语句: 使用 `CREATE TRIGGER`;
- 内容: 声明触发事件, 触发条件与要执行的动作;
- 与断言的区别: 断言只做检查并拒绝更新, 触发器还能主动执行动作;

```sql
CREATE TRIGGER <触发器名>
  AFTER INSERT ON StarsIn
  WHEN (<条件>)
  <动作>;
```
