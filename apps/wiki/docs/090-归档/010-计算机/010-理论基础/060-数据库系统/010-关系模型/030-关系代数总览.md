# 关系代数总览

## 关系代数为什么被称为查询语言的基础？

- 定位: 以关系为输入、以关系为输出的运算集合;
- 用途: 描述"要什么"而不是"怎么算", 是 SQL 查询的语义基础;
- 特点: 运算可嵌套, 前一个运算的结果可直接作为后一个运算的输入;

## 关系代数分哪几类运算？

| 类别        | 运算                      | 作用                 |
| ----------- | ------------------------- | -------------------- |
| 集合运算    | 并, 交, 差                | 基于集合的元组合并   |
| 去行 / 去列 | 选择 $\sigma$, 投影 $\pi$ | 筛选元组或属性       |
| 组合元组    | 笛卡尔积 $\times$, 连接   | 把多个关系的元组配对 |
| 重命名      | 重命名 $\rho$             | 修改关系名或属性名   |

## 关系代数中哪些运算无法由其他运算表示？

- 基本运算: 并, 差, 选择, 投影, 笛卡尔积, 重命名;
- 作用: 这六个运算构成关系代数的最小完备集, 其他运算都可由它们导出;
- 导出关系: 交, $\theta$ 连接, 自然连接都能用基本运算表示, 见 [重命名与操作的最小集](./070-重命名与操作的最小集.md);
