# SNMP 与网络管理框架

## 网络管理框架由哪些部分组成？

- 管理服务器: 运行管理程序, 采集与控制被管设备;
- 被管设备: 需要被监控的网络设备;
- 管理信息库: 保存被管设备可被查询与设置的状态数据;
- 网络管理代理: 运行在被管设备上的进程, 负责与管理服务器通信;
- 网络管理协议: 规定管理服务器如何查询状态并通过代理采取行动;

## SNMP 如何传递管理信息？

- SNMP: 简单网络管理协议;
- 位置: 运行在管理服务器与网络管理代理之间;
- 请求响应模式: 管理服务器发送请求, 代理执行动作并回送响应;

## 陷阱报文有什么用？

- 类型: 非请求报文, 由代理主动发出;
- 用途: 被管设备出现异常情况时主动通知管理服务器, 无需等待轮询;
