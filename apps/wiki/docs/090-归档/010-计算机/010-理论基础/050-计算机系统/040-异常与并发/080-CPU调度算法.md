# CPU 调度算法

## 常见的 CPU 调度算法有哪些？

| 算法         | 规则                                            |
| ------------ | ----------------------------------------------- |
| 先到先服务   | 按到达顺序依次执行                              |
| 最短作业优先 | 优先执行预计运行时间最短的进程                  |
| 优先级调度   | 优先执行优先级最高的进程                        |
| 轮转法       | 把 CPU 时间划分为若干片段, 每个进程分配一个片段 |

## 轮转法怎样工作？

- 划分: 把 CPU 时间划分为若干时间片;
- 分配: 每个进程分到一个时间片, 用完就让出 CPU;
- 类比: 类似多路访问中的时分划分;
