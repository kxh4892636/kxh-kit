# 指令集体系结构

## 指令集体系结构是什么？

- 指令: 一个或多个字节组成的二进制序列, 用于控制处理器行为;
- 指令集体系结构 (ISA): 处理器支持的指令集合, 以及每条指令的字节级编码;
- 作用: 定义软件与硬件之间的契约, 编译器按 ISA 生成目标代码;

## 处理器中可见的状态有哪些？

| 状态          | 内容                             |
| ------------- | -------------------------------- |
| 程序寄存器    | 若干存储 64 位字的寄存器         |
| 条件码 CC     | 最近一次算术或逻辑运算的状态信息 |
| 程序计数器 PC | 当前正在执行指令的地址           |
| 内存          | 程序、数据与运行栈               |
| 状态码 Stat   | 程序执行的总体状态信息           |
