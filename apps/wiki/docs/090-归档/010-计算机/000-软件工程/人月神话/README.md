# 人月神话

## 这组笔记是什么？

- 来源: 《人月神话（二十周年纪念版）》, Frederick P. Brooks, Jr. 著, 中文电子版;
- 内容: 原书 15 章 + 1995 年增补 5 篇 (《没有银弹》《再论》《观点: 是或非?》《20年后的人月神话》《结束语》);
- 体例: 按概念重组, 每篇一个概念; H2 提问, 正文电报体;
- 出处: 每篇末尾 source 行标注原书章节;

## 按什么顺序读？

- 抓主干: 先读 [010](./010-软件工程的本质/README.md) 与 [020](./020-人月与进度/README.md);
- 抓中心论点: 软件的根本困难 + 人月不可互换;
- 组织问题: 读 [030](./030-概念完整性/README.md) 与 [040](./040-团队与组织/README.md);
- 工程实践: 读 [050](./050-设计与实现/README.md) 到 [090](./090-工具与环境/README.md);
- 看 20 年后的结论: 读 [010](./010-软件工程的本质/README.md) 的观点判定、[100](./100-人与产品/README.md) 与 [110](./110-附录/010-注解补充的数据与来源.md);
