# 请求绑定与校验

## 绑定和校验怎么一步做完？

- 一个调用: `c.BindAndValidate(&req)`;
- 顺序: 先按 tag 绑定, 再跑 `vd` 校验;

```go
type CreateArticleRequest struct {
	Title   string   `json:"title" vd:"len($)>0 && len($)<=100"`
	Content string   `json:"content" vd:"len($)>0"`
	Tags    []string `json:"tags"`
}

func createArticle(ctx context.Context, c *app.RequestContext) {
	var req CreateArticleRequest
	if err := c.BindAndValidate(&req); err != nil {
		c.JSON(consts.StatusBadRequest, map[string]string{
			"code": "INVALID_ARGUMENT", "message": "invalid request",
		})
		return
	}
	// 调 Service。
}
```

- 参数必须是结构体指针;

## vd 规则怎么写？

- `vd` 里的 `$`: 指字段本身;
- 例: `len($)>0` 表非空, `len($)<=100` 表上限;
- 校验失败的映射: 见 [错误分层与响应](../000-服务端知识/020-契约与错误/020-错误分层与响应.md);

## 参数从 path、query、header、body、form 各怎么绑定？

| 来源   | tag                          | 放什么                 |
| ------ | ---------------------------- | ---------------------- |
| path   | `path:"id"`                  | 资源标识               |
| query  | `query:"page"`               | 分页、过滤、排序       |
| header | `header:"X-Idempotency-Key"` | 认证、幂等键、内容协商 |
| json   | `json:"title"`               | JSON 请求体            |
| form   | `form:"name"`                | 表单或上传元数据       |

- 来源: 由 IDL 的 `api.path/query/header/body/form` 决定;
- 详见: [007-hz与IDL](./007-hz与IDL.md);

## vd 表达式写到什么程度为止？

- 只写字段级约束: 空值与长度、数值范围;
- 数值范围: `$>0`、`$>=1 && $<=100`;
- 长度写法: `len($)>0 && len($)<=100`;

## 长度校验按字节还是按字符？

- 注意: Go 的 `len` 对字符串按字节算;
- 中文按字符限: 在 Service 里转 `[]rune` 再判;
- 所有权、状态机、跨字段一致性属于业务规则, 放 Service;
