# 建表与增删改查

## crud 语法

```ts title="src/main.ts"
import { db } from "./db";

await db.schema
  .createTable("person")
  .ifNotExists()
  .addColumn("id", "integer", (col) => col.primaryKey().autoIncrement())
  .addColumn("first_name", "text", (col) => col.notNull())
  .execute();

const person = await db
  .insertInto("person")
  .values({ first_name: "Jennifer" })
  .returningAll()
  .executeTakeFirstOrThrow();
const rows = await db.selectFrom("person").select(["id", "first_name as fn"]).execute();
const updated = await db
  .updateTable("person")
  .set({ first_name: "Jen" })
  .where("id", "=", person.id)
  .executeTakeFirst();
const deleted = await db.deleteFrom("person").where("id", "=", person.id).executeTakeFirst();

console.log(rows); // [ { id: 1, fn: 'Jennifer' } ]
console.log(Number(updated.numUpdatedRows), Number(deleted.numDeletedRows)); // 1 1
```

- 建表最后一定要 `.execute()`; 漏了它什么也不会发生;
- 漏 `.where()` 就是全表改或清库, Kysely 不拦;
- `.values()` 调两次是覆盖, 不是追加;
- `no such table`: 建表没跑, 或连错了库;

## 列约束和索引怎么写？

| 约束   | 写法                                                        |
| ------ | ----------------------------------------------------------- |
| 非空   | `col.notNull()`                                             |
| 唯一   | `col.unique()`（做 upsert 的前提）                          |
| 主键   | `col.primaryKey()`, SQLite 配 `integer` + `autoIncrement()` |
| 默认值 | `col.defaultTo(v)` / `defaultTo(sql\`...\`)`                |
| 外键   | `col.references('person.id').onDelete('cascade')`           |

```ts
await db.schema
  .createTable("pet")
  .addColumn("id", "integer", (col) => col.primaryKey().autoIncrement())
  .addColumn("owner_id", "integer", (col) => col.references("person.id").onDelete("cascade"))
  .addColumn("name", "text", (col) => col.notNull().unique())
  .execute();

await db.schema.createIndex("pet_owner_id_index").on("pet").column("owner_id").execute();
```

- 建索引: `on(表).column(列)`, 多列继续 `.column()`;
- 唯一索引: 加 `.unique()`;
- 删除: 用 `dropIndex("名").ifExists()`;
- 命名约定 `<表>_<列>_index`;
