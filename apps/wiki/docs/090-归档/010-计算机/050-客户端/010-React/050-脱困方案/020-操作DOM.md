# 使用 ref 操作 DOM

## 如何拿到 React 管理的 DOM 节点？

- 绑定节点: 把 ref 对象传给标签的 `ref` 属性;
- 时机: React 在提交阶段关联, 清理时解除;
- 调用时机: 在事件处理器或合适的 Effect 里调 `focus`、`scrollIntoView`;
- 原因: 渲染时节点可能还不存在;

```jsx
import { useRef } from "react";

function Search() {
  const inputRef = useRef(null);
  return (
    <>
      <input ref={inputRef} />
      <button onClick={() => inputRef.current?.focus()}>聚焦</button>
    </>
  );
}
```

## 如何为动态列表保存多个 DOM 节点？

- 回调 ref: 每项给一个接收节点的函数;
- 提交时: 记录到 Map, 返回清理函数在解除时删除;
- Hooks 限制: 不在 `map` 循环里调 `useRef`;

## 循环里怎样管理多个节点 ref？

- 做法: 用 Map 容器, 或提取列表项组件;
- 回调身份: 每次新建 ref 回调会让 React 先清理旧回调再设新的;
- 要求: 清理与注册必须对称;

```jsx
const nodes = useRef(new Map());
const list = items.map((item) => (
  <li
    key={item.id}
    ref={(node) => {
      nodes.current.set(item.id, node);
      return () => {
        nodes.current.delete(item.id);
      };
    }}
  >
    {item.name}
  </li>
));
```

## 如何访问子组件内部的 DOM？

- Ref 输入: React 19 的函数组件可直接收 `ref` prop, 再传给内部标签;
- 收益: 不必展开旧的转发 API;
- 能力限制: 不想暴露整个 DOM 时用 `useImperativeHandle`, 只给允许的操作;
- 详见: Context 与 Ref 参考;

```jsx
function MyInput({ ref, ...props }) {
  return <input {...props} ref={ref} />;
}
```

## 更新 state 后立刻操作新节点时需要注意什么？

- 提交延迟: setter 之后 DOM 可能仍对应旧状态, 立即滚动可能滚到旧条目;
- 同步桥接: 只有必须在回调返回前看到新 DOM 的浏览器集成才考虑 `flushSync`;
- 契约: 见 ReactDOM 概览;
- 所有权: 焦点、滚动与测量通常安全;
- 禁止: 手动删改 React 正在管理的子节点, 否则双方状态失配;
