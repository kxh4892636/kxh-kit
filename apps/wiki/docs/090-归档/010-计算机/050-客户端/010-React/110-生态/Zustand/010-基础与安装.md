# Zustand 状态与订阅

## Zustand 怎样组织组件外的共享状态？

- Store: 用 `create` 定义状态与操作;
- 用法: 组件通过返回的 Hook 选择片段, 同一 store 可供多处订阅;
- 选择边界: 只放确实需要跨组件共享的数据;
- 反例: 局部输入或短暂的 UI 状态不必都提到 store;

```bash
npm install zustand
```

## 如何在 action 中更新当前状态？

- Set: 用 set 提交新片段, 基于旧值计算时传更新函数; 嵌套对象仍需不可变更新;
- `get`: 在 action 执行时读 store 的最新状态;
- 适用: 需要结合多个现有值的操作, 也不会改到 React 的闭包变量;

```js
import { create } from "zustand";

export const useCounter = create((set, get) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
  readCount: () => get().count,
}));
```

## 组件怎样只订阅需要的片段？

- Selector: 用选择函数只取需要的值;
- 避免: 直接订阅整个 store, 让不相关变化也触发更新;
- 相等判断: 选择结果相等时, 该订阅不会引起重渲染;
- 但父组件、Context 或本地 state 仍可能让它重跑;

```jsx
function Counter() {
  const count = useCounter((state) => state.count);
  const increment = useCounter((state) => state.increment);
  return <button onClick={increment}>{count}</button>;
}
```
