# 导航与链接

## 用户主动点击导航时为什么优先使用 Link？

- 链接语义: `Link` 提供真实 href 与客户端导航;
- 保留: 键盘、复制链接与新标签打开等习惯;
- 目标表达: to 可包含路径、查询和 hash, 相对路由解析与相对路径解析要按意图选择;

```jsx
import { Link } from "react-router";

const link = <Link to="/users">用户列表</Link>;
```

## 如何给当前导航项显示激活样式？

- `NavLink`: 在 Link 之上提供激活状态;
- 定制: 用 `className` 或 children 回调调整展示;
- 模式限制: pending、视图过渡等状态取决于所用路由模式;
- 反例: 任意 BrowserRouter 环境都没有完整数据导航状态;

```jsx
import { NavLink } from "react-router";

const item = (
  <NavLink to="/messages" className={({ isActive }) => (isActive ? "active" : "")}>
    消息
  </NavLink>
);
```

## 如何在业务操作之后执行导航？

- `useNavigate`: 用于登录成功、流程完成等事件里的编程式导航;
- 反例: 页面上本该是链接的元素不要换成它;
- 替换历史: replace 适合不希望后退回到中间页的场景, 普通导航则新增历史记录;

```jsx
function LoginButton({ login }) {
  const navigate = useNavigate();
  return (
    <button
      onClick={async () => {
        await login();
        navigate("/account", { replace: true });
      }}
    >
      登录
    </button>
  );
}
```
