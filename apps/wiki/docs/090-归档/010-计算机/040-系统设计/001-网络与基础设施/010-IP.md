# IP 地址

## IP 地址如何让数据找到目标？

- IP 地址: 标识网络接口在网络中的位置;
- 用途: 路由器依据目标地址转发数据包, 可比作邮寄地址;
- 地址与设备: 一台设备可有多个接口与多个地址;

## IP 会变，还能当设备身份证吗？

- 可变性: 地址也会变化;
- 结论: IP 不是永久的设备身份证;
- 寻址边界: IP 负责把包送往目标网络和接口, 具体交给哪个应用还需要传输层端口;

## IPv4 与 IPv6 怎样表示地址？

| 版本 | 位数 | 地址空间      | 示例           |
| ---- | ---- | ------------- | -------------- |
| IPv4 | 32   | 约 43 亿      | `192.0.2.10`   |
| IPv6 | 128  | 约 3.4 × 10³⁸ | `2001:db8::10` |

- IPv4: 常见表示由四段十进制数构成, 地址空间有限是部署 IPv6 的主要动机;
- IPv6: 用十六进制与冒号表示, 连续零段可按规则压缩;
- 前提: 地址长度增加需网络设备与应用共同支持;
- 版本迁移: 两种协议可以并存, 地址空间更大不等于某个服务自动支持 IPv6;

## 公网与私网地址的区别是什么？

- 公网地址: 用于公共互联网路由, 其可达性仍取决于路由、防火墙和服务监听;
- 私网地址: 在组织或家庭网络内部使用;
- 特点: 不同独立网络可重复使用;
- 边界: 不能当作全球唯一的公网目标;
- NAT: 把内部连接映射到公网连接;
- 效果: 多个家庭设备可共享一个出口公网地址;
- 原文修正: 共享公网地址只是常见的 NAT 部署方式;
- 澄清: 它不是公网地址的定义, 也不是所有网络必须如此;

## 静态与动态地址适合什么场景？

| 分配方式 | 工作方式                             | 典型场景           | 代价                   |
| -------- | ------------------------------------ | ------------------ | ---------------------- |
| 静态     | 地址保持稳定, 由管理员或分配策略固定 | 服务托管、远程访问 | 维护地址分配, 避免冲突 |
| 动态     | DHCP 等机制按租约分配                | 终端接入、地址复用 | 不能假设地址永久不变   |

- 分类维度: 公私网描述使用范围, 静动态描述分配方式, 二者可以组合;
- 设计影响: 如果客户端依赖长期稳定入口, 应通过域名等机制隔离底层地址变化;
