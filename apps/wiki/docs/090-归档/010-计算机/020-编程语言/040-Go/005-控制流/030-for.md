# for

## 三段式循环的 init、condition、post 如何书写？

- 三段式: init 只执行一次;
- 每轮: 先查 condition, 跑循环体, 再运行 post;

```go
func main() {
	for i := 0; i < 3; i++ { // init; condition; post
		println(i)
	}
}
```

## 条件循环如何书写, 如何表达 while 语义？

- 条件循环: 只留 bool 条件, 每轮开始前检查;
- 要求: 循环体自行推进状态, 否则条件可能一直成立;

```go
func main() {
	n := 3
	for n > 0 { // condition-only for; 表达类似 while 的循环
		println(n)
		n--
	}
}
```

## 无限循环如何书写, 如何退出？

- 无限循环: 省略全部控制部分, 一直执行;
- 结束方式: `break`、`return` 或取消信号;
- 边界: `break` 只退出它针对的循环;

```go
func main() {
	for { // 无限循环
		println("once")
		break // 退出当前循环
	}
}
```
