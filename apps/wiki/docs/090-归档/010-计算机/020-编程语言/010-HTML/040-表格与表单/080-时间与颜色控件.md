# 时间与颜色控件

## 日期与时间类型有哪些？

| type             | 选择粒度     | `value` 格式示例   |
| ---------------- | ------------ | ------------------ |
| `date`           | 年-月-日     | `2018-07-22`       |
| `month`          | 年-月        | `2018-05`          |
| `week`           | 年-周        | `2018-W18`         |
| `time`           | 时-分        | `18:00`            |
| `datetime-local` | 本地日期时间 | `2018-06-12T19:30` |

```html
<input
  type="date"
  id="start"
  name="trip-start"
  value="2018-07-22"
  min="2018-01-01"
  max="2018-12-31"
/>
<input type="month" id="start" name="start" min="2018-03" value="2018-05" />
<input type="time" id="appt" name="appt" min="09:00" max="18:00" required />
<input type="week" name="week" id="camp-week" min="2018-W18" max="2018-W26" required />
<input
  type="datetime-local"
  id="meeting-time"
  name="meeting-time"
  value="2018-06-12T19:30"
  min="2018-06-07T00:00"
  max="2018-06-14T00:00"
/>
```

## min、max 与 required 如何约束输入？

- `min`/`max`: 取值下界与上界, 用同类型的时间格式书写;
- `required`: 提交前必须填写;
- 效果: 越界或缺失时浏览器校验不通过;

## color 类型有什么特别的行为？

- 形态: 提供一个颜色选择器控件;
- 取值: 返回小写十六进制颜色值;

```html
<input type="color" name="color" id="color" />
```
