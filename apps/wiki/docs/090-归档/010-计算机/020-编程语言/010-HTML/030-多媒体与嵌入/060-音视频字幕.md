# 音视频字幕

## track 元素如何添加字幕？

- 位置: 嵌套在 `audio` 或 `video` 内部;
- 数量: 多个 `track` 表示多条字幕轨道, 可同时提供多语言;
- 资源: 字幕文件由 `src` 指向;

```html
<video controls poster="/images/sample.gif">
  <source src="sample.mp4" type="video/mp4" />
  <source src="sample.ogv" type="video/ogv" />
  <track kind="captions" src="sampleCaptions.vtt" srclang="en" />
  <track kind="descriptions" src="sampleDescriptions.vtt" srclang="en" />
  <track kind="chapters" src="sampleChapters.vtt" srclang="en" />
  <track default kind="subtitles" src="sampleSubtitles_en.vtt" srclang="en" />
</video>
```

## track 的属性分别控制什么？

| 属性      | 作用                                    |
| --------- | --------------------------------------- |
| `src`     | 字幕文件 URL                            |
| `kind`    | 字幕类型                                |
| `srclang` | 字幕语言; `kind="subtitles"` 时必须提供 |
| `label`   | 字幕菜单中显示给用户的名称              |
| `default` | 声明默认开启的轨道                      |

## kind 有哪些取值？

| 取值           | 含义                                               |
| -------------- | -------------------------------------------------- |
| `subtitles`    | 面向非母语观众的翻译字幕, 默认值                   |
| `captions`     | 面向母语观众的字幕, 含音效说明, 适合听障或静音场合 |
| `descriptions` | 场景描述字幕, 供看不到画面时了解画面               |
| `chapters`     | 章节字幕, 用于剧集/影片章节导航                    |
| `metadata`     | 电影元数据字幕, 不可见, 供脚本读取                 |
