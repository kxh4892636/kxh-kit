# 超链接

## a 元素的核心属性有哪些？

| 属性     | 作用                           |
| -------- | ------------------------------ |
| `href`   | 链接目标的 URL                 |
| `target` | 跳转形式, 如 `_blank` 新标签页 |
| `rel`    | 与目标资源关系的描述信息       |

```html
<a rel="page" href="https://www.mozilla.com" target="_blank">Mozilla</a>
```

- `href` 与 `src` 的差别见 [src 与 href 的区别](../010-基础/040-src与href的区别.md);

## 链接到非 HTML 资源时会发生什么？

- 可预览类型: 浏览器能渲染的资源直接在页面中打开;
- 不可预览类型: 触发下载该文件;
- 依赖环境: 下载或打开文件所需的环境缺失时, 链接无法正常使用;

## 如何创建邮件链接？

- 写法: `mailto:邮件地址` 后接查询参数;
- 参数: `cc` 抄送人、`bcc` 密件抄送人、`subject` 邮件题目、`body` 邮件内容;
- 边界: 参数值需做 URL 编码, 空格写作 `%20`;

```html
<a
  href="mailto:nowhere@mozilla.org?cc=name1@mail.com,name2@mail.com&bcc=name3@rapidtables.com&subject=The%20subject%20of%20the%20email&body=The%20body%20of%20the%20email"
>
  Send mail with cc, bcc, subject and body
</a>
```
