# HTML 语法基础

## HTML 元素由哪些语法部分构成？

- 标签: 尖括号包围的名字, 如 `<p>`;
- 元素: 开始标签 + 内容 + 结束标签, 如 `<p>text</p>`;
- 属性: 写在开始标签内的键值对, 见 [元素属性](./030-元素属性.md);
- 空元素: 只有一个标签, 没有内容与结束标签, 如 `<img />`;

```html
<p class="note">My cat is very grumpy</p>
```

## 注释如何书写？

- 语法: `<!-- 注释内容 -->`;
- 用途: 说明代码意图, 浏览器不渲染;
- 边界: 注释不能嵌套;

```html
<!-- commentary -->
```

## 引号中如何表示引号？

- 方案一: 嵌套不同种类的引号, 外层双引号内写单引号, 反之亦然;
- 方案二: 用转义字符 `&quot;`、`&apos;`;

```html
<p id="''">test</p>
<p id='""'>test</p>
```

## 连续空格在浏览器中如何渲染？

- 折叠规则: 无论多少个空格、制表符或换行, 都渲染为一个空格;
- 例外: `<pre>` 元素内的空白原样保留, 见 [计算机代码元素](../020-结构与文本/090-计算机代码元素.md);

## 特殊符号的转义字符有哪些？

| 特殊符号 | 转义字符 |
| -------- | -------- |
| `<`      | `&lt;`   |
| `>`      | `&gt;`   |
| `"`      | `&quot;` |
| `'`      | `&apos;` |
| `&`      | `&amp;`  |

- 原因: 这些字符与标签语法、实体语法冲突, 需转义后才能作为文本显示;
