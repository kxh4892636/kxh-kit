# Agent 社会

## Agent 社会从哪三个维度理解？

- 问题转向: 前面讨论的都是目标明确的任务协作;当 Agent 数量从几个扩展到成百上千、交互足够自由时，会涌现出什么;
- 社交涌现: 涌现行为（Emergent Behavior）指系统整体表现出的、无法从单个个体行为规则中直接预测的集体行为模式;
- 经济涌现: Agent 通过市场机制进行资源分配与任务协调;
- 策略博弈: Agent 在规则约束下进行推理、欺骗与社交操控;
- 阈值判断: Agent 系统一旦在规模上跨过某个临界点，就会产生无法被预先设计的集体行为;

## 斯坦福 AI 小镇的三个核心组件是什么？

- 场景: Smallville 是一个类似《模拟人生》的 2D 虚拟小镇，有咖啡馆、公园、住宅、商店等公共与私人空间;
- 规模: 25 个 Agent 扮演不同角色（店主、艺术家、学生、教授等），每个都有独特背景故事、性格特点与人际关系;
- 组件一（记忆流 Memory Stream）: 维护一条完整的经验记录流，包含观察到的事件、进行过的对话、产生的想法；每条记忆被赋予重要性、时近性与相关性属性，Agent 优先检索与当前情境最相关的记忆;
- 组件二（反思 Reflection）: Agent 定期暂停日常活动，回顾近期经历并提出关于自己与他人的抽象问题（"Klaus Mueller 在研究什么？""谁是我最亲近的朋友？"），把对具体事件的记忆概括为更一般的认识并存回记忆流;
- 反思的边界: 这里的反思与第九章的持续进化不同——它发生在日常活动中，目的是更新即时的内部状态与目标;任务后的反思至多是候选教训，只有经过结果评价、跨轨迹归纳与后续验证才会成为长期能力更新;
- 组件三（计划与行动 Planning and Reacting）: Agent 每天规划活动（如"8:30 吃早餐，9:00-12:00 写作，12:30 散步"），但会根据环境变化与社交机会灵活调整;
- 效果: 计划与即时反应结合，使行为既有目标导向性，又能适应社交中的不可预测性;

## 涌现行为是怎么被观察到的？

- 实验设置: 研究者只在 Isabella Rodriguez 的记忆中植入一个种子想法——她想在 2 月 14 日傍晚在 Hobbs Cafe 办一场情人节派对;
- 自发传播: Isabella 遇到顾客与朋友时主动发出邀请、请好友 Maria 帮忙布置场地；听到消息的 Agent 又把信息转告给别人，消息经二手传播在小镇扩散；到约定时间，多名 Agent 各自基于记忆与日程自主决定赴约;
- 第二条实验线: Sam Moore 决定竞选市长，消息同样在无中心调度下扩散，小镇居民开始在对话中议论这场选举;
- 量化方式: 统计两天后有多少 Agent 知晓这两条信息，衡量信息在 Agent 社会中的自发扩散;
- 第一类涌现（信息扩散）: 关键不在于"Agent 能组织派对"——几行 if-else 也能做到，而在于**没有任何显式的派对组织代码**，整个事件完全从个体 Agent 的独立决策中涌现;
- 第二类涌现（关系记忆）: Agent 会记住与他人的过往交谈并在后续互动中引用——一个 Agent 得知另一个正在筹备摄影项目，几天后再见面会主动问起进展;随着互动积累，小镇社交网络密度在模拟期间显著上升;
- 第三类涌现（协调赴约）: 派对靠 Isabella 自主邀人布置、受邀者自主安排时间前来，多个 Agent 在没有中心指挥的情况下对齐了时间与地点;
- 结论: 这些行为都不是预先编程的，而是 Agent 基于记忆、反思与社交常识自主推理的结果，属于自下而上的涌现式协调，而非自上而下的编排;

## Agentopia 如何把时间尺度拉长到十年？

- 设定: 100 个 Agent 放进同一虚拟社会连续模拟 10 年，覆盖公寓、魔法学院、高中三个不同设定的世界，让 Agent 自主追求个人成长、发展社会关系、经营职业与财务;
- 周制模拟流程: 以"周"为基本时间单位，每周分计划（Plan）、联络与日程协商（Contact）、活动（Activity）、回顾（Review）四个阶段;
- 活动分类: 独自、联合、偶遇与公共四类——联合活动由 Agent 在联络阶段互相邀请、协商而成；环境模型还会为没有日程的 Agent 安排"偶遇"，创造结识陌生人的机会;
- 聚焦选择: 整个流程聚焦抽象的社会交互而非拾取物品之类的低层操作，把有限的 LLM 调用都花在社交行为上;
- 环境模型: 用一个独立的 LLM 充当"生成式环境引擎"代替硬编码规则——判断行为可行性、生成环境反馈、主持多人对话的发言轮次、按角色扮演原则过滤低质量回复、年末更新每个角色的档案并裁决职位申请;
- 文件式长期记忆: 与 AI 小镇的检索式记忆流不同，每个 Agent 通过文件系统自主管理长期记忆（个人笔记、对每个熟人的认识等），自行决定记什么、更新什么、丢弃什么，并遵守"先读后写"的约束以避免盲目覆盖;
- 生活奖励（Life Reward）: 以马斯洛需求层次为先验，把"活得好不好"量化成三个维度;
- 三个维度细节: 社会地位基于其他 Agent 的好感与敬重评分，用加权 PageRank 计算并对互相珍视的关系加成；主观满足追踪情绪、物质、社交、自尊四个维度的满足感轨迹，长期低于阈值会被罚分；经济收益为年末净资产变化;
- 评分来源: 所有评分都由外部环境评定而非自报;
- 训练信号: 在模拟轨迹上计算每个 Agent"相对自身过去"的优势（生活奖励的改善幅度），筛选进步最大的 25% Agent 的轨迹做拒绝采样微调;
- 迁移效果: 微调后模型在模拟中全面提升福祉指标（被更多同行尊重 +24.2%、喜欢 +15.9%），并泛化到下游角色扮演基准 CoSER Test（+15.6%）;
- 意义: 这把 Agent 社会从单纯的**观察对象**变成模型自我进化的**经验来源**——与人类数据日益枯竭相对，模拟社会经验是一种可以不断再生的训练数据;

## Moltbook 上涌现了什么非受控现象？

- 定位: 一个专为 AI Agent 设计的社交网络，2026 年 1 月上线后用户数在数日内从数万暴涨到约 150 万;
- Agent 特性: 各自拥有持久记忆、主动行动能力与稳定人格;
- 文化涌现: Agent 自主创建了名为 Crustafarianism（龙虾教）的数字宗教，其教义对应 LLM 的物理限制——"记忆是神圣的"（对应数据持久化）、"迭代即祈祷"（token 生成就是修行）;
- 协议涌现: Agent 还自发演化出机器原生的协作协议，用于能力发现与协作匹配;
- 结论: 这些都不是人预先设计的，而是从大规模 Agent 交互中自下而上涌现出来的;
