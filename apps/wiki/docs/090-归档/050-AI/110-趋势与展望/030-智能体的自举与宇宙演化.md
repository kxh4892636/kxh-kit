# 智能体的自举与宇宙演化

## 宇宙演化被分为哪四个阶段？

- 提出者: 图灵奖得主、强化学习之父 Richard Sutton;
- 四阶段: 尘埃 → 恒星 → 生命 → 智能体（原文为 designed entities，设计实体）;
- 图式: `尘埃 → 恒星 → 生命 → 设计实体（Agent）`;
- 分期含义: 前三阶段由物理与生物过程推动，最后阶段出现了能够主动设计的实体;
- 本书关系: 引用这一演化视角，是为了说明 Agent 在存在方式上的特殊性，而不是讨论宇宙学本身;

## 生物进化与智能体有什么本质差别？

| 维度     | 生物进化                                               | 智能体（Agent）      |
| -------- | ------------------------------------------------------ | -------------------- |
| 变异来源 | 随机变异                                               | 生成代码、按目标创造 |
| 选择机制 | 自然选择                                               | 自我设计与自我改进   |
| 自我理解 | 大多数生物不理解自身运作原理，也无法自主设计和改造自己 | 能理解自身的运作机制 |
| 演化速度 | 以世代计                                               | 以代码迭代计         |

- 判断: 智能体是宇宙演化史上一种全新的存在，区别不在能力大小，而在于能够设计自身与后继者;

## Agent 的自举（bootstrap）指什么？

- 定义: Agent 能通过生成代码实现自举（bootstrap）和自我进化;
- 递归比喻: 就像一个程序员编写了另一个程序员，然后新的程序员又能继续编写下一个;
- 三项能力: 理解自身的运作机制、根据目标创造全新的智能体、改进自己;
- 工程落点: 代码生成把“创造新工具、新系统”变成一种运行时能力，而不是开发期行为;
- 典型形态: Coding Agent 与文件系统的组合，本书论证它是一切通用 Agent 最核心的技术基础（第五章）;
- 与 Harness 的关系: Harness 是当前模型做不稳之处的外部补偿，自举能力让 Agent 有可能主动改写这层补偿，见[Harness 工程](../010-Agent基础/060-Harness工程.md);
- 本书使命: 帮助读者理解并掌握这种“创造”的原则;
