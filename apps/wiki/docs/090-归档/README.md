## 为什么归档

本目录下归档了 2026-11-12 之前的所有笔记;

之前我很喜欢系统化的学习, 经常啃大头书, 技术文档, 并做各种各样的笔记;

然后使用 anki 进行记忆, 很享受学习的过程, 但随着 AI 的来临, 这一切有些不一样了.

以往我的学习, 往往只是术的层面, 而不是道的层面, 而且因为系统学习, 所以往往都是以知识体系划分, 相对来说是层次结构且细碎的. 但无论是日常工作, 或者功利的面试八股, 往往都是 case 为主, 串联起若干知识;

而且随着 AI 的发展, 他已经在方方面面超过了我, 这时候, 感觉不能把自己当作一个硬盘, 而应该是一个内存, 把 AI 当作第二大脑, 而自己只是一个索引;

因此, 我决定, 后续不在系统学习一门知识了, 一方面自己时间不够, 另一方面功利来讲, case 为主或者背诵一些八股文, 往往具有更高的 ROI;

同时这种方式还可以站在巨人的肩上, 现在互联网已经有大量梳理好的 case, 我只需要在 AI 的帮助下, 把他内化为自己的内容, 正所谓干中学, 用不到的知识不是好知识;
