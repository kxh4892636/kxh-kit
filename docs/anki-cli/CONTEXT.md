# Anki CLI

Anki CLI（`anki-cli`）是一个命令行工具：通过 AnkiConnect 插件控制本机 Anki，覆盖笔记、卡片、牌组、标签、媒体、模板、统计与 GUI 的全部操作。

## Language

### 通道

**AnkiConnect**：
Anki 的本地 HTTP 插件（FooSoft 出品，Anki 插件码 2055492159，默认 `http://localhost:8765`）。`anki-cli` 与 Anki 之间的唯一通道，所有操作都经其 action 完成。
_避免使用_：add-on、插件（在本域内指代该通道时）

**action**：
AnkiConnect 暴露的单次操作单元（如 `deckNames`、`addNote`、`answerCards`）。每条 CLI 子命令在内部映射到一个或多个 action。
_避免使用_：接口、API

### 数据模型

**笔记**：
一张笔记 = 一个笔记类型 + 一组字段值 + 标签；按笔记类型的卡片模板可生成多张卡片。
_避免使用_：条目、记录

**卡片**：
由笔记按卡片模板生成的最小复习单元，携带调度状态（到期、间隔、难度系数）与复习历史。
_避免使用_：卡（口语化）、笔记

**牌组**：
卡片的归属容器，支持 `父::子` 层级（最多 2 层）。
_避免使用_：分类、分组

**笔记类型**：
定义字段列表、卡片模板与 CSS 的模板类型（Anki 的 note type）。
_避免使用_：model、模板（与卡片模板冲突）、type

**卡片模板**：
笔记类型内定义卡片正反面 HTML（Front/Back）的模板（Anki 的 card template）。
_避免使用_：模板（与笔记类型冲突）

**字段**：
笔记类型声明的命名槽位，笔记为其填充值；第一个字段是排序字段，不可为空。
_避免使用_：属性、列

### 复习

**到期**：
卡片的调度状态：已到达应复习的时间。
_避免使用_：过期、待复习

**评分**：
复习时对记忆表现的 4 级评价：Again(1)/Hard(2)/Good(3)/Easy(4)，提交后更新卡片调度。
_避免使用_：评级、打分、grade

**复习会话**：
「拉取到期卡片 → 逐张呈现 → 评分」的完整闭环；CLI 中以 `review` 命令承载。
_避免使用_：学习会话、study session

### CLI

**子命令**：
CLI 的接口单元，按 `资源 动词` 分组（如 `notes add`）；每条子命令对应上游 anki-mcp-server 的一个 MCP 工具，行为与校验一致。
_避免使用_：工具、tool、命令（不区分层级时）

**只读模式**：
全局开关（`--read-only` / `READ_ONLY`）：阻止一切写操作，复习与同步除外。
_避免使用_：safe mode、保护模式
