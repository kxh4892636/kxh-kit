# 卡片复习命令组

## 交付

4 条卡片子命令，行为与上游工具一致：

- `anki-cli cards due [--deck <n>] [--limit <n>] [--no-learning] [--include-new]` ← get_due_cards（`-is:suspended` + 状态组合查询、deck 名转义、new/due 诚实计数）；
- `anki-cli cards list [--deck <n>] [--state due|new|learning|suspended|buried] [--limit <n>]` ← getCards（单一状态过滤，默认 due；`-is:suspended` 除外规则与上游一致）；
- `anki-cli cards present <id> [--answer]` ← present_card（渲染内容提取 `extractRenderedCardContent`，reversed/cloze 按模板方向渲染）；
- `anki-cli cards rate <id> <1-4>` ← rate_card（评分前 cardsInfo 存在性预检、评分后返回 nextReview）。

## 范围

做：以上 4 条命令 + 单测（假 AnkiConnect 服务器）。
不做：交互式 `review` 命令（issue 10）；其他分组命令。
