# 牌组命令组

## 交付

4 条牌组子命令，行为与上游工具一致：

- `anki-cli decks list [--stats]` ← listDecks（含每牌组 study-queue 统计、根牌组汇总语义）；
- `anki-cli decks stats <deck>` ← deckStats（study-queue + true card-state counts 两族统计）；
- `anki-cli decks create <name>` ← createDeck（`父::子` 最多 2 层）；
- `anki-cli decks move <deck> <cardIds...>` ← changeDeck（牌组不存在则创建）。

## 范围

做：以上 4 条命令 + 单测（假 AnkiConnect 服务器）。
不做：其他分组命令。
