## 交付

11 条笔记类型子命令，行为与上游工具一致：

- `anki-cli models list` ← modelNames；
- `anki-cli models fields <name>` ← modelFieldNames；
- `anki-cli models styling <name>` ← modelStyling；
- `anki-cli models templates <name>` ← modelTemplates；
- `anki-cli models create <name> --field <n>... --templates <json> [--css <file|->] [--cloze]` ← createModel（卡片模板经 JSON 输入，形如 `[{Name,Front,Back}]`）；
- `anki-cli models update-styling <name> --css <file|->` ← updateModelStyling；
- `anki-cli models update-templates <name> --templates <json>` ← updateModelTemplates；
- `anki-cli models field-add <name> <field> [--index <n>]` ← addModelField；
- `anki-cli models field-remove <name> <field> --yes` ← removeModelField；
- `anki-cli models field-rename <name> <old> <new>` ← renameModelField（提示模板引用需单独更新）；
- `anki-cli models field-reposition <name> <field> <index>` ← repositionModelField。
