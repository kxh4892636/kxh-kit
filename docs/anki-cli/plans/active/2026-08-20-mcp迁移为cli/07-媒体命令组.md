# 媒体命令组

## 交付

4 条媒体子命令，行为与上游工具一致，安全校验完整保留：

- `anki-cli media list [--pattern <p>]` ← getMediaFilesNames；
- `anki-cli media get <filename> [--out <path>]` ← retrieveMediaFile（默认输出 base64 + 文件名到 stdout JSON）；
- `anki-cli media store (--file <path> | --url <url> | --data <base64>) [--filename <n>] [--delete-original]` ← storeMediaFile（文件路径限媒体 MIME 类型、URL 防 SSRF、文件名防路径穿越）；
- `anki-cli media delete <filename> --yes` ← deleteMediaFile。

## 范围

做：以上 4 条命令 + 单测（假 AnkiConnect 服务器）+ 安全校验单测（MIME 白名单、SSRF 阻止 10.x/172.16.x/192.168.x/127.x/169.254.x、`../` 清洗）。
不做：其他分组命令。
