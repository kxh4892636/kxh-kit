# 本地包全链路验收

## 交付

一个可从本地 `.tgz` 安装的完整 `loopx` 产物，使用者可从安装后的 bin 发现命令、管理两个受管 skill、预演写操作并通过假 AnkiConnect 运行 Anki 操作。

## 范围

- 完成 `packages/loopx/README.md`，覆盖本地打包/全局安装、AnkiConnect 配置、命令发现、全 options、JSON、预演、skill 生命周期、self-update 和不保留 `anki-cli` 的迁移提示。
- 将 [Anki 冒烟检查清单](../../../anki冒烟检查清单.md) 的命令全部更新为 `loopx anki` 与命名 options，保留专用测试牌组和验收后清理约束。
- 建立分发产物端到端测试：生成 `.tgz`，安装到临时 npm prefix，只通过安装后 bin 与包内 assets 验收。
- self-update 只使用 scripted adapter 验收；真实 npm 发布/更新冒烟留待首次发布。真实 Anki 验收以更新后的手工清单为交付证据，不在自动化中改动用户集合。

## 直接依赖

- 04: 最终包必须包含经 scripted adapter 验证的 CLI self-update；消费其 PackageManagerPort、回滚和 skill 同步契约。
- 11: 分发产物必须只含收口后的命令、包和 skill；消费其已删除旧 Anki 形态的 contract 结果。

## 验收

- [ ] 临时 npm prefix 中只有 `loopx` bin；`loopx --help`、`self --help`、`self skill --help`、`anki` 各组/leaf `--help` 从已安装产物成功运行。
- [ ] 从已安装产物对临时工作区执行 `skill list`、`install --all`、`check`、预演更新/卸载与真实 `uninstall --all`，`loop-x` / `loop-x-cli` 状态与文件效果全部正确。
- [ ] 已安装 `loopx anki` 通过假 AnkiConnect 完成至少一个 query 和一个 mutation 的真实/预演验收，预演零写，JSON shape 与退出码正确。
- [ ] README 命令可复现本地打包/安装，Anki 冒烟清单不含旧 bin 或 positional input。
- [ ] `node .agents/skills/loop-x/script/check-domain.mjs .`、`vp run @kxh4892636/loopx#test`、`vp run @kxh4892636/loopx#build`、分发产物端到端测试和 `vp check` 全部通过。
