# 拉取与物化

## 交付

`loopx workspace pull [--name <name>...] [--path <path>] [--worktree-branch <branch>]` 把配置中的子仓物化为本机可用状态并更新到基准分支最新：克隆缺失则浅克隆到克隆存储、worktree 缺失则创建工作分支检出，然后 fetch 并 fast-forward。未指定 `--name` 时处理全部子仓。

## 范围

- 克隆存储路径解析：`workspace.local.yaml` 已记录的 `clone_path` 优先，否则默认 `~/workspaces/<name>`；物化成功后把实际路径写回 `workspace.local.yaml`。
- 克隆缺失：`git clone --depth 1 --branch <branch> <url> <clone_path>`（普通浅克隆，非 bare）。
- worktree 缺失：`git -C <clone_path> worktree add -b <工作分支> <检出路径> <branch>`；目标 worktree 由 `--path` 指定（相对工作区根，默认配置 path），工作分支由 `--worktree-branch` 指定（默认 `worktree/<name>-<yyyymmddhhmmss>`）；worktree 已存在时忽略 `--worktree-branch`，改分支用 `worktree switch`；目标路径已存在且非本命令创建的 worktree 时报 JSON 错误并跳过该子仓。
- `--path` 与 `--worktree-branch`：仅在指定单个 `--name` 时可用；与多个 `--name` 或未指定 `--name` 同用时输出用法错误（退出码 2）。
- 更新：`git -C <clone_path> fetch --depth 1 origin <branch>`，再对 worktree 执行 `git -C <worktree> merge --ff-only <branch>`；脏 worktree 或不可快进时该子仓报告 skipped 并带原因，其余子仓继续。
- `--name` 可重复指定若干子仓；指定不存在的 name 时报 JSON 错误。
- Mutation，支持 `--dry-run` 返回每个子仓将执行的动作计划。
- git 调用通过 shell（`node:child_process`），不引入 git 库；集成测试使用临时目录中的真实 git 仓库与 `file://` 远程。
- 不做：worktree/克隆删除、并发物化、进度渲染。
