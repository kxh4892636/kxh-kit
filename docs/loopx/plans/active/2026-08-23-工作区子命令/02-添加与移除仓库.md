# 添加与移除仓库

## 交付

`loopx workspace add --name --url --path --branch` 以 upsert 语义写入子仓条目（name 不存在则追加，已存在则更新其 url/path/branch）；`loopx workspace remove --name` 移除条目。二者只改配置文件，不触碰仓库、worktree 或本机克隆。

## 范围

- `add`：四个选项均必填；name 已存在时更新该条目而非报错；path 被其他子仓占用时输出 JSON 错误；写回保持 YAML 可读格式。
- `remove`：name 不存在时输出 JSON 错误。
- 二者均为 Mutation，支持 `--dry-run` 预览配置变更。
- 不做：`workspace.local.yaml` 的清理（remove 后残留 clone_path 记录由 pull 忽略未知 name 处理）、任何 git 副作用。
