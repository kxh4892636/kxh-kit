# 配置模型与定位

## 交付

`loopx workspace init` 在 cwd 创建含空 `repositories` 的 `workspace.yaml`；配置加载模块能从任意子目录向上定位工作区根，解析并用 zod 校验 `workspace.yaml` 与 `workspace.local.yaml`，供后续所有 workspace 命令复用。

## 范围

- 新增 `yaml` 依赖；定义 workspace.yaml / workspace.local.yaml 的 TypeScript 类型与 zod schema。
- 从 cwd 向上查找 `workspace.yaml` 的定位逻辑；找不到时输出 JSON 错误并提示先运行 `init`。
- name 唯一、path 不重复、url 为 ssh 或 http(s)、path 为相对路径且不含 `..` 的校验。
- `loopx workspace init` 命令（Mutation，支持 `--dry-run`）：cwd 已存在 `workspace.yaml` 时报错。
- `src/builtins/workspace/` 骨架与命令组注册。
- 不做：add/remove/pull/list/status。
