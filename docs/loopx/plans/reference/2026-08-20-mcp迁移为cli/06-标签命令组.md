## 交付

5 条标签子命令，行为与上游工具一致：

- `anki-cli tags list` ← getTags；
- `anki-cli tags add <noteIds...> --tag <t>...` ← addTags；
- `anki-cli tags remove <noteIds...> --tag <t>...` ← removeTags；
- `anki-cli tags replace <noteIds...> --from <t> --to <t>` ← replaceTags；
- `anki-cli tags clear-unused --yes` ← clearUnusedTags。
