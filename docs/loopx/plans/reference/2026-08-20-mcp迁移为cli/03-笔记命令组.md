## 交付

6 条笔记子命令，行为与上游工具一致：

- `anki-cli notes add --deck <n> --model <n> --field k=v... [--tag ...] [--allow-duplicate] [--duplicate-scope deck|collection] [--dup-scope-deck <n>] [--dup-check-children] [--dup-check-all-models]` ← addNote（含排序字段非空校验、duplicate/model/deck/field 分类错误提示）；
- `anki-cli notes add-batch --deck <n> --model <n> [--tag ...] [--allow-duplicate] [--duplicate-scope ...]`，笔记数组经 stdin JSON ← addNotes（≤100，逐条部分成功，duplicate 跳过）；
- `anki-cli notes find <query>` ← findNotes；
- `anki-cli notes info <noteIds...>` ← notesInfo；
- `anki-cli notes update <id> --field k=v...` ← updateNoteFields（HTML 支持、audio/picture 参数对齐、浏览器打开时的上游坑提示）；
- `anki-cli notes delete <noteIds...> --yes` ← deleteNotes（无 `--yes` 拒绝执行）。
