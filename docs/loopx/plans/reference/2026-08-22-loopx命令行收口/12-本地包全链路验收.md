## 交付

## 范围

- 完成 `packages/loopx/README.md`，覆盖本地打包/全局安装、AnkiConnect 配置、命令发现、全 options、JSON、预演、skill 生命周期、self-update 和不保留 `anki-cli` 的迁移提示。
- 将 [Anki 冒烟检查清单](../../../anki冒烟检查清单.md) 的命令全部更新为 `loopx anki` 与命名 options，保留专用测试牌组和验收后清理约束。
- 建立分发产物端到端测试：生成 `.tgz`，安装到临时 npm prefix，只通过安装后 bin 与包内 assets 验收。
- self-update 只使用 scripted adapter 验收；真实 npm 发布/更新冒烟留待首次发布。真实 Anki 验收以更新后的手工清单为交付证据，不在自动化中改动用户集合。
