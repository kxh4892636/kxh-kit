# 日线查询与缓存刷新

## 交付

调用日线 API 获得前复权日线和明确缓存元信息；已有缓存可重复读取，需要更新时从红色火箭刷新。

## 范围

实现行情用例、Zod 日期与上游验证、红色火箭 adapter、日线/交易日历 migrations 和 Drizzle store。接入现有服务路由，扩展 AppType；证券目录的最新缓存日期连接真实存储。此项拥有日期裁剪、缓存策略、事务批量写入、取消/超时/大小限制和失败语义；不修改图表。

## 直接依赖

- 01：消费可运行 Node 服务、配置、HTTP 错误契约、SQLite migration 入口与证券目录。

## 验收

- [x] 受控上游首次查询返回 refreshed 和正确日线，再次查询返回 cache 且不再次拉取；目录最新缓存日期随之更新。
- [x] 缺省 qfq、严格日期、起止顺序、未知证券、空有效区间、上海时间跨日、未完成日过滤、周末及已记录闭市日均有可判定结果。
- [x] 真实临时 SQLite 验证日线幂等 upsert、日期范围升序、最新日期、迁移重复执行与写入失败回滚。
- [x] 上游合法响应排序及可选数值、非法字段、HTTP 失败、超时、响应过大、取消均有回归证据；错误不留下部分行情写入。
- [x] Node 构建、类型检查和服务测试通过，真实上游冒烟结果与受控测试分开报告。
