## 决策与证据

### 2026-11-01 用户定稿

1. **不用数据库**：放弃 SQLite/Kysely，曲目索引以静态 `tracks.json` 维护，且该文件由**后端**持有（2026-11-01 追加指定）。
2. **状态全部在前端**：播放历史（近 13 条）与洗牌袋逻辑放在前端，进页面先请求后端索引接口 `GET /api/tracks`。
3. 其余按推荐：Node 22 + TS 栈、Hono、React 19、TanStack Router/Query、Tailwind 4 + shadcn/ui、原生 `<audio>`、vitest browser + Playwright。

### 为什么无数据库是自洽的

- 曲目索引是**派生物**：145 首、37 作品，全部来自文件与 IA 元数据，`build_index.py` 几秒重建，168 KB JSON 可被静态缓存。
- 历史是**单用户、单浏览器**的 13 条记录，`localStorage` + `zustand/persist` 足够；跨设备同步不在范围内。
- 洗牌袋是**会话内临时状态**，刷新重洗即可，无需持久化。
- 结论：唯一值得入库的「历史」在本机单用户场景下用本地存储即可，引入 SQLite 只增加迁移与进程状态，不换来任何能力。

### 定稿技术栈

| 层            | 选择                                                                                                |
| ------------- | --------------------------------------------------------------------------------------------------- |
| 运行时 / 语言 | Node 22.12+；TS 7 原生 `tsc`；dev 用 `node --watch --experimental-strip-types`                      |
| 后端          | Hono 4.13.7 + `@hono/node-server` 2.1.1，只监听 `127.0.0.1`                                         |
| 音频交付      | `@hono/node-server/serve-static`（已验证 `Accept-Ranges`/`Content-Range`/206 + `createReadStream`） |
| 索引          | 后端持有 `server/data/tracks.json`，`GET /api/tracks` 提供（带 ETag/304），前端不打包索引           |
| 状态          | zustand 5 + `persist`（localStorage，13 条上限）；洗牌袋为内存数组                                  |
| 参数校验      | zod 4.5（`.env`：端口、曲库根）                                                                     |
| 契约          | `hono/client`（hc）+ `shared/api.ts`（仅健康检查等少量接口）                                        |
| 前端          | React 19.2 + TanStack Router + TanStack Query                                                       |
| 样式          | Tailwind 4 + shadcn/ui（Radix，组件源码入仓）                                                       |
| 播放器        | 原生 `<audio>`，`preload="metadata"`                                                                |
| 测试          | vitest 5（browser mode）+ Playwright                                                                |
| 质量          | `vp check`（lint/format/类型）                                                                      |
| 启动          | `node dist/server/main.js`，`127.0.0.1`，无反向代理                                                 |

### 参照片事实（`apps/etf`）

`client/` + `server/` + `shared/` 三分层；`vite.config.ts` 以 `client` 为 root、`build.outDir` 为 `../dist/client`；服务端 `serve({ fetch: app.fetch, port, hostname: "127.0.0.1" })`；`.env` 用 zod 解析；类型化接口用 `hono/client` 的 `ApplyGlobalResponse`。
