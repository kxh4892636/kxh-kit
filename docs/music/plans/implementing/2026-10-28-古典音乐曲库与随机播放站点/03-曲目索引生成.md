# 曲目索引生成

## 交付

`tracks.json` 与生成脚本：每首曲目一条记录，含作曲家、作品、乐章/段落、时长、格式、体积、封面、相对路径、来源链接与许可，供站点直接消费。关联 [US-003](../story.md#us-003-曲目信息来自索引而非文件名)。

## 范围

- 做：从 IA 元数据 + 曲库目录派生索引；校验曲目数与文件存在性；把索引写到站点可读的位置。
- 不做：改写音频文件、写入 ID3、调用 MusicBrainz 在线接口（元数据里已有 MBID，离线可用）。

## 直接依赖

- **01**：需要曲库文件真实在位，才能校验 `path` 与 `bytes`/`md5`。

## 决策与证据

- **曲目单元 = 一个 `.flac`**：每个曲目在元数据中有四种同名格式（`.flac`/`.mp3`/`.ogg`/`.png`），以 FLAC 为主音频，MP3/OGG 作为兜底候选，PNG 为封面。
- **字段来源**：`composer` 取 `title` 首段（`Johann Sebastian Bach`）并以目录前缀交叉校验；`work` 取目录名（`Beethoven_SymphonyNo.3Eroica` → 可读化）；`movement` 取 `title` 末段；`seconds` 取 `length`（秒，浮点）；`path`/`cover` 为曲库内相对路径。
- **离线优先**：`external-identifier` 里的 AcoustID / MusicBrainz recording id 直接带入索引，供未来补全信息，不在生成期联网。
- **许可字段**：固定写入 `CC PD Mark 1.0` 与条目 URL，页面据此渲染署名。
