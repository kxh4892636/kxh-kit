# 随机播放站点实现

## 交付

一个能在本机跑起来的随机播放站点：打开即播、下一首按洗牌袋抽取、显示作曲家/作品/乐章、页脚标注来源与许可；构建通过并可在浏览器实际操作。关联 [US-002](../story.md#us-002-打开即随机播放)。

## 决策与证据

- **随机用洗牌袋**：对曲目 id 数组做 Fisher–Yates，逐个弹出；弹空后重洗，可选「与上一首同作曲家则重抽一次」。直接 `Math.random()` 抽取会频繁连续重复，体验差且不可解释。
- **播放用 `<audio>` 而非 Web Audio**：需要拖动进度与省电，`<audio src>` + 静态 Range 即可；Web Audio 只在需要交叉淡入时才值得。
- **索引与音频分离**：页面只 fetch `tracks.json`，音频按需请求，避免首屏加载几十 MB。
- **许可展示不可省**：PD Mark 允许自由使用，但站点仍应标注来源，方便日后追溯。
