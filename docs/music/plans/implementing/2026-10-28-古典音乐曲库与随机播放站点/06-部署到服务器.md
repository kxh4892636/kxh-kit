## 上下文

- 主机：`ali` → `123.57.92.26:22`，Debian 13（trixie），1 vCPU / 1.6 GB 内存 / 40 GB 磁盘（部署后剩余约 22 GB）

- 曲库：`/srv/music-library`（145 个 FLAC + 同名 mp3/ogg/png，共 9.0 GB）
- 服务：`/etc/systemd/system/music.service`，监听 `127.0.0.1:5210`，环境变量来自 `/srv/music-app/.env`（`BASE_PATH=/music`）
- 站点：`/etc/nginx/sites-available/music`；限流与超时在 `/etc/nginx/conf.d/00-music-limits.conf`；分片日志格式在 `/etc/nginx/conf.d/10-media-log.conf`
- 截图：`docs/music/design/shots/deployed-1440.png`

## 决策与证据

- **子路径不靠 rewrite**：应用自己支持 `BASE_PATH=/music`——Hono 用 `root.route("/music", app)` 把页面、API、音频、波形一起挂在前缀下，处理器内部用 `stripBase` 还原路径；前端 `vite base=/music/`、TanStack Router `basepath`、索引里的 `media/…`/`waves/…` 都是相对路径，由 `appUrl()` 拼前缀。这样 nginx 只需 `proxy_pass http://127.0.0.1:5210;`（不剥前缀、不重写）。
- **静态产物与索引同源**：`dist/client` 由应用自己托管（含 SPA 回落），无需 nginx `root`；`tracks.json` 与波形留在 `server/data`，改曲库只重启服务。
- **曲库只读**：systemd 里 `ReadOnlyPaths=/srv/music-library`，服务用户对目录只有读权限；上传完成后 `chown -R music:music` 并 `chmod` 收紧（scp 以 root 落盘时目录是 0700，导致首次 404，已修）。
- **媒体路径守卫**：`resolveMediaPath` 拒绝 `..` 逃逸与点文件（曲库里的 `.done` 标记不会被下载），越界 Range 回 416。
- **分片证据**：`/var/log/nginx/music-media.log` 记录每条响应的 `Content-Range` 与字节数，实测每条都是 `bytes N-(N+524287)/SIZE`、`bytes=524288`；浏览器 DevTools 里偶尔出现的“整段”区间是 Chrome 媒体缓存的合并显示，服务端并未发出大包。

## 安全措施

| 层    | 措施                                                                                                                                                                                                                            |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 网络  | ufw 默认拒绝入站，仅放行 22/80/443；应用只监听 `127.0.0.1:5210`，不对公网暴露                                                                                                                                                   |
| SSH   | 仅密钥登录（`PasswordAuthentication no`，部署前已如此）；fail2ban `sshd` jail（`maxretry=5`、`bantime=1h`、`backend=systemd`）                                                                                                  |
| nginx | 仅暴露 `/music/`，其余路径 404；`server_tokens off`；`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`；API `limit_req 20r/s burst=30`、连接数限制、`client_max_body_size 2m`、代理超时 300s |
| 进程  | systemd 加固：`NoNewPrivileges`、`ProtectSystem=strict`、`ProtectHome`、`PrivateTmp`、`ProtectKernelTunables`、`RestrictSUIDSGID`、`MemoryMax=512M`、非登录用户 `music`                                                         |
| 应用  | 索引 zod 校验、ETag/304、Range 上限 512 KB、路径穿越与点文件拦截、`/api/*` 未命中回 JSON 404                                                                                                                                    |
