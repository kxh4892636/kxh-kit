## 决策与证据

- **主题 Bloom（deal 1/3）**：音乐、暖纸、赭石与 19 世纪录音的气质相符；Ink 的 teal 更像目录，Ultraviolet 的紫会与封面色打架。
- **签名是波形，不是封面**：Internet Archive 给的 PNG 是 800×200 的波形挖空图（黑色矩形 + 透出波形的 alpha 洞），没有方形唱片封套。直接用它当封面会糊；因此把 alpha 反相成白色剪影（`make_wave_mask.py`），再用 `mask-image` 以 `--wave-ink` 着色——波形因此是「录音自己的形状」，随播放走动的地形线，而不是装饰。
- **网格只出现在波形那一块并向右淡出**：Bloom 的规矩是网格不铺满整屏；`mask-image` 的横向渐隐同时处理了网格与波形，避免「装饰性网格背景 + 上面什么都没有」。
- **强调色只落在四处**：播放/暂停的橡胶帽、正在播放行的底色、波形的走过区与被走过的进度线。表格里的「播放」平时是 muted，行悬停或聚焦才变赭石，避免四行红字抢戏。
- **App 口径的密度**：控制件 44px、标签 14px muted、sentence case 不加字距；打印式的小标题（如「正在播放」）一律不用，改用 byline 与作品名承担层级。
- **只有一件事在屏上**（2026-11-01 用户两次修正）：删掉试听列表，页面只保留「当前曲目 + 最近听过」；播放/下一首与键位提示都下移到波形下方，排成一条控制台，读的顺序变成「是什么 → 它的形状 → 怎么放」。
- **曲库规模只说一次**：145 首 / 37 部作品的数字移进页脚，与许可同处一行，避免在正文里重复。
- **移动端把表格降级为堆叠**：≤40rem 时表头移出视觉流（仍留给读屏），每行变成「作品 / 乐章 / 作曲家 + 右上时长 + 右下播放」，390px 下不再出现四个字的换行。
- **单乐章作品**：索引里 `movement` 为空（源标题只有两段），界面显示「单乐章」，不把整串标题重复两遍。
- **字体自托管**：Ranade 只有 300/400/500/700，没有 600，显示字重取 700；woff2 从 fontshare 取回自托管，生产不依赖 CDN。
