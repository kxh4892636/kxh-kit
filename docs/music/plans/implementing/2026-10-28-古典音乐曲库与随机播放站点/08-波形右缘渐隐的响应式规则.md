# 波形右缘渐隐的响应式规则

## 交付

波形那条「向右淡出」的遮罩只在双列布局里出现；单列（≤ 960px）时波形铺满整列、右缘不再模糊，网格与剪影都顶到边缘。关联 [US-002](../story.md#us-002-打开即随机播放)。

## 范围

- 做：把 `.wave` 的 `mask-image` 渐隐与列数绑定，验证 1440 / 1024 / 900 / 390 四档。
- 不做：改波形本身的数据或绘制；改 60rem 断点位置。

## 直接依赖

- **04**：`WaveSeek` 组件与 `.wave` 样式。

## 验收

- [x] 1440px：`mask-image` 为 `linear-gradient(to right, …62%, …92%)`，双列，波形右缘渐隐
- [x] 1024px：仍为双列，渐隐保留（列宽 576px 时淡出起点随比例走）
- [x] 900px：单列，`mask-image: none`，波形宽度 852px 顶到内容区右缘
- [x] 390px：单列，`mask-image: none`
- [x] `vp check` 通过，54 个单测不受影响
- [x] 线上复验：1440 为 `linear-gradient(…)` 且双列；900 为 `mask-image: none` 且单列

## 决策与证据

- **用「列数」而不是「视口宽」当条件**：渐隐的用意是让波形在双列里向右“化开”，避免与右列硬碰；单列时右边就是内容边界，渐隐反而像没画满。列数由同一个 60rem 断点决定，所以规则直接写进那段媒体查询里，不新增断点。
- **只关 `.wave` 的渐变遮罩，不动 `.wave__ink`**：后者是每首曲子的剪影遮罩（`--wave-src`），关掉会让波形整块消失。
- **实测值**：`getComputedStyle('.wave').maskImage` 在 1440/1024 返回渐变、900/390 返回 `none`；`.stage` 的 `grid-template-columns` 分别为两列/一列，与预期一致。
