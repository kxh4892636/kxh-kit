# 标签管理

## 交付

`anki-cli tag` 子命令组可用：列出、添加、移除、重命名标签，清理未使用标签。

## 范围

做：getTags、addTags、removeTags、replaceTags、clearUnusedTags（需 `--yes`）。

不做：笔记字段操作。
