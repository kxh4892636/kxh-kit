# 媒体管理

## 交付

`anki-cli media` 子命令组可用：列出、下载、上传（base64 / 文件路径 / URL）、删除 collection.media 中的媒体文件，安全校验与上游对等。

## 范围

做：getMediaFilesNames（pattern 过滤）、retrieveMediaFile（base64）、storeMediaFile（三种来源）、deleteMediaFile（需 `--yes`）；安全校验原样移植——MIME 白名单（`MEDIA_ALLOWED_TYPES`）、`MEDIA_IMPORT_DIR` 路径限制、URL 私网/回环拦截（`MEDIA_ALLOWED_HOSTS`）、文件名净化。

不做：把媒体插入笔记字段（属 updateNoteFields）。
