# 笔记管理

## 交付

`anki-cli note` 子命令组可用：创建（单个/批量）、查询、查看详情、更新字段、删除笔记。

## 范围

做：addNote、addNotes（批量 ≤100，部分成功）、findNotes（Anki 查询语法）、notesInfo（含 CSS）、updateNoteFields（CSS-aware，支持 HTML）、deleteNotes（需 `--yes`）。

不做：标签、媒体、模型操作（各自 issue）。
