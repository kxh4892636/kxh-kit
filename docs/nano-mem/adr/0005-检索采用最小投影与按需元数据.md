# 检索采用最小投影与按需元数据

`nnm search` 默认只返回采用记忆及准确重放 selector 所需的 `id`、`content`、`scope`，并只为 project 记忆返回 `project`。来源与时间元数据通过可重复的 `--include` 显式加入；search 恒定的生命周期字段不返回。这样能减少 agent 上下文中的无效信息，同时保留检索 → 使用闭环与按需追溯能力。

## Considered Options

- 默认返回完整记忆 DTO：兼容维护读取的 shape，但持续输出 search 场景不需要的生命周期与时间字段。
- 使用 `--metadata` 一次返回全部元数据：接口简单，但无法让调用方只承担所需信息的上下文成本。
- 使用 `--fields` 自定义完整投影：最灵活，但会允许移除采用闭环必需字段，并扩大公共契约。

## Consequences

- `search` 与 `get/list` 使用不同投影；调用方不能把 search 结果当作完整记忆。
- project/global 结果以 `scope` 区分，global 结果不携带无意义的 `project: null`。
- 新增可选元数据必须显式进入 `--include` 的封闭字段集合，不能退化为任意 metadata 或字段 DSL。
