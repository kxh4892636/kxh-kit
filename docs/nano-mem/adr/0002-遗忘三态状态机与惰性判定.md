# 遗忘三态状态机与惰性判定，无后台任务

记忆按「活跃(active) → 休眠(dormant) → 已删(trashed)」三态状态机遗忘：可检索性 R 低于 0.35 进入休眠（默认隐藏），R 低于 0.10 或休眠超过 180 天由 `nm gc` 标为已删并清除超期（默认 30 天）记录。状态判定在查询与 `nm gc` 时基于 FSRS 即时计算，不运行任何后台调度任务。

**Considered Options**:

- 硬删除（被拒绝——丢失可恢复性与统计，用户无法查看"忘掉了什么"）。
- 后台定时任务清理（被拒绝——为单用户工具引入进程常驻/调度复杂度）。
- 纯时间衰减（被拒绝——无法表达"使用频率越高越不易忘"，这正是 FSRS 的价值）。

**Consequences**:

- 阈值（R 0.35/0.10、180 天、30 天保留）为可调常量，判定规则分布在 `search`/`list`/`gc` 各命令，由 spec 收口。
- 「搜不到不代表没有」：休眠记忆经 `--include-dormant` 可查，已删记录在保留期内仍存在但默认不出任何结果。
