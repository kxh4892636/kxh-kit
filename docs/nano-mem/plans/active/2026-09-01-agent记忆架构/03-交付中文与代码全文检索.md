# 交付中文与代码全文检索

## 交付

agent 可以用中文自然短语、英文、文件路径和代码标识符检索当前 project 与 global 的相关活跃记忆，且任何用户文本都不能改变 FTS/SQL 语法。

## 范围

- 实现共享的 content/query tokenizer：CJK 1–3 gram、NFKC lowercase、camel/snake/kebab/path/extension 分段。
- 实现 FTS5 external-content 索引、参数化 MATCH、BM25 over-fetch、scope gate、limit 和空结果。
- 实现只对最终返回结果累计 retrieval-count 的原子事务；先建立 lexical score，生命周期 boost 由 04 接入。
- 提供索引重建 seam 与 tokenizer 版本测试，不加入向量或外部分词依赖。

## 直接依赖

- 02：需要真实 memories schema、scope 解析和事务 repository；消费其 FTS 同步字段、rowid 关联和公开 DTO。

## 验收

- [x] 两字及更长中文短语、英文关键词、camelCase 部分、snake_case 部分、kebab 文件名、路径段和扩展名均命中相关记忆。
- [x] query 中的引号、连字符、冒号、括号、MATCH 操作符和 SQL 字符不会报语法错、扩大 scope 或执行注入。
- [x] 默认 search 只组合当前 project + global；显式 scope/project 行为与 spec 一致，其他 project 永不成为候选。
- [x] FTS 是候选唯一入口，无候选时稳定返回空数组；默认 limit 10、最大 50、over-fetch 50。
- [x] 只有最终返回项增加 retrieval-count，get/list 和未返回候选不增加，事务失败时计数不部分提交。

- 交付物：版本化共享 tokenizer、SQLite v2 search-term migration/重建 seam、参数化 FTS5 BM25 search repository 与 `nm search` CLI。

- 查询语法/SQL 注入文本稳定返回字面候选或空数组；scope 测试证明默认 current project + global、显式 project/global 与 project override 不泄漏其他项目。
