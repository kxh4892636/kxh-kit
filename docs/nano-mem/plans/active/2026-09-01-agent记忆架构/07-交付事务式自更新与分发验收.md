# 交付事务式自更新与分发验收

## 交付

用户可以预演或执行 `nm self update`，把全局 CLI 更新到最新稳定版或指定版本，并使已安装的 `nano-mem` skill 同步到同一包版本；任何失败都恢复更新前现场。

## 范围

- 实现 npm 版本/tag 解析、默认稳定版选择、全局包更新计划、已安装 skill 同步与补偿事务。
- modified skill 在计划阶段拒绝，除非 `--force`；未安装 skill 不因 CLI 更新而隐式安装。
- 使用可注入 package executor 与临时 prefix/target 覆盖成功、CLI 失败、skill 失败和回滚失败证据。
- 完成 tarball、本地临时安装、`nm --help`、记忆 smoke、self skill 与 self update dry-run 的分发验收。

## 直接依赖

- 06：需要可查询和可回滚的受管 skill 操作；消费其状态、backup/restore 与 manifest 契约。

## 验收

- [ ] 不带版本选择最新稳定版，`--version` 接受有效 semver 或 npm tag 并拒绝无效/不可用目标；dry-run 不改变 CLI 或 skill。
- [ ] 成功更新后 CLI 和已安装 skill 版本一致；skill 未安装时只更新 CLI。
- [ ] CLI 更新失败、skill 同步失败或 post-check 失败都恢复旧 CLI 与旧 skill，返回可复核的失败阶段和 recovery 结果。
- [ ] modified skill 无 `--force` 时在任何包变更前失败；使用 `--force` 时计划明确展示会覆盖的目标。
- [ ] 从 `pnpm pack` 产物安装到临时 prefix 后，只有 `nm` bin，数据库 smoke、全部 help、skill 生命周期和 self update dry-run 均通过。
- [ ] 包级 check/test/build/coverage、changed-scope 格式检查、全仓串行 build/test 通过，发布内容与许可证/第三方声明完整；clean-main 的既有全仓格式失败保留为基线证据。
- [ ] Plan 合入 main 后，从同一已验证 tarball 全局安装 `nm`，并以已安装 CLI 将包内 `nano-mem` skill 强制同步到仓库 `.agents/skills`；真实命令 smoke 通过且安装副作用进入最终 commit。
