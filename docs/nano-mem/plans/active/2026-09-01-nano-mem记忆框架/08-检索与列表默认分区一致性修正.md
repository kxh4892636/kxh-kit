# 检索与列表默认分区一致性修正

## 交付

`search`/`list` 默认限定当前 agent 分区（全局 `--agent` 的默认值 = 当前工作目录名），显式 `--agent <name>` 覆盖，跨分区检索用 `--agent *`；README 相应陈述与 `--help` 一致（消除对照已确认设计「检索默认限定当前分区」的偏差）。

## 范围

- `src/cli.ts`：`search`/`list` 的分区过滤从「仅显式 --agent 时过滤」改为「默认 ctx.agent（cwd basename），显式 --agent 覆盖，`--agent *` 表示全分区」；`--run` 语义保持不变（显式才过滤）。
- 单测补充：不带 `--agent` 时 search/list 只返回当前分区；`--agent <other>` 返回该分区；`--agent *` 跨分区。
- README.md：勘正「仅显式过滤」陈述为默认限定当前分区 + `--agent *` 跨区说明。
- 不做：run 分区默认值不变；其他行为不变。
