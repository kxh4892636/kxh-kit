# 交付多词组合全文检索

## 交付

agent 使用 `nnm search` 输入多个空白分隔词组时，可以优先得到完整命中更多词组的活跃记忆；高覆盖层不足 `limit` 时自动由下一层补足，填满后不返回或排名更低覆盖层。

例如查询 `Pi subagent domain glossary ADR` 时，只包含 `Pi` 与 `subagent` 的记忆属于二词命中层；在更高命中层未填满 `limit` 时，它能够进入结果，而不会因缺少其余三个词返回空数组。

## 范围

- 在共享搜索 tokenizer 边界建立空白词组解析和派生 token 集去重。
- 在 memory repository 实现完整词组匹配计数、覆盖层回填、完整边界层排序及 flat OR BM25。
- 移除旧 BM25 前 50 候选预截断，同时保持作用域、遗忘过滤、层内生命周期排序、final limit 和事务式检索计数。
- 保持现有最小检索投影、`--include` 参数和 maintenance `MemoryRecord` DTO；更新 README 搜索语义。
- 不实现语义检索、同义词、翻译、公开评分、schema 变更或查询词数上限。

## 直接依赖

- 无；直接消费现有 tokenizer、FTS5 external-content 索引、lifecycle ranking、scope predicate、search DTO 与事务边界。

## 验收

- [x] 查询五个词组时，分别完整命中 5、4、3、2、1 个词组的记忆按命中数降序逐层回填；相同记忆跨词组只出现一次，边界层填满 `limit` 后不返回低层记忆。
- [x] 组内仍要求全部派生 token 命中：中文词组不会降级为单字召回，camelCase、snake/kebab、路径、扩展名及普通英文的既有能力保持有效。
- [x] 连续 Unicode 空白正确切组；无 token 组被忽略，派生 token 集相同的重复组不重复计数，全部无效时返回空数组且不更新 retrieval count。
- [x] 每个覆盖层使用该层全部合格记录独立执行现有 BM25/lifecycle 排序；层内最终顺序为组合分数、BM25、`id ASC`，且超过 50 个单组候选时不存在旧预截断遗漏。
- [x] scope、project/global 组合、显式或自然软遗忘过滤保持正确；flat OR 的部分 token 命中记录不能越过完整词组资格门槛。
- [x] 引号、连字符、冒号、括号、MATCH 操作符及 SQL 文本继续按普通查询文本处理，不改变 FTS/SQL 语法或扩大作用域。
- [x] 仅最终返回的去重记忆各增加一次 `retrieval_count`；未返回层、边界层被截记录和部分 token 命中记录不增加，故障时计数整体回滚。
- [x] `nnm search` 的参数、`--limit` 校验、最小检索投影、`--include` 与 maintenance DTO 无变化；实现不枚举非空词组组合，也不新增公开词数上限。
- [x] `pnpm --filter @kxh4892636/nano-mem check`、`test`、`build` 全部通过，并有 CLI 级示例覆盖 `Pi subagent domain glossary ADR` 的二词层召回。
