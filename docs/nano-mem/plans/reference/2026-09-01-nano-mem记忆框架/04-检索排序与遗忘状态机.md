# 检索排序与遗忘状态机

## 交付

`nm search` 全文检索与三态遗忘状态机落地：检索按 `0.65×rel + 0.35×R` 排序、默认阈值与过滤器可用；高频使用的记忆排名随使用上升；R 低于阈值的记忆自动休眠隐藏、久未使用的被 `nm gc` 标已删并清除——「使用越频繁越靠前、长期不用被遗忘」的用户结果成立。

## 范围

- `src/search.ts`：FTS 查询（CJK 归一化同构）、bm25 取分、`rel = 1/(1+exp(bm25))`、`score = w_rel×rel + w_strength×R`（默认 0.65/0.35，`--score-weights` 支持覆盖）、`--min-score`（默认 0.35）、`--limit`（默认 10）、`--agent`/`--run`/`--tag` 过滤。
- 自动弱使用：search 命中返回的记忆默认记一次 Hard（`--no-touch` 关闭）；实现为一次 `recordUse`。
- 状态机：有效状态惰性判定（查询时按 R 计算休眠；state=trashed 直接视为已删）；`--include-dormant` 可见休眠；`list --state` 支持 active/dormant/trashed/all。
- `nm gc [--dry-run] [--retention-days 30]`：R<0.10 或休眠超 180 天 → 标 trashed（dry-run 只预览计划）；清除 trashed 超保留期记录（物理删除 + FTS 同步）。
- 单测：首条未使用记忆 R 高；重复 search/use 后排名比对（排名上升或不降）；时间推进后 R 衰减 → 休眠 → gc 标删/清除；阈值参数可调验证。
- 不做：skill/README（05）、self（06）、LLM/向量（非范围）。
