# Nano Mem

Nano Mem 管理 agent 记忆从形成、作用域隔离、检索和实际使用，到软遗忘、恢复与删除的完整生命周期。`nano-mem` skill 负责 agent 策略，`nm` CLI 负责确定性的本地机制与受管 skill 自管理。

## Language

**记忆**：
带记忆作用域与生命周期、可被独立存储和复用的原子知识。
_Avoid_：知识、记忆记录、条目、事实、笔记

**记忆作用域**：
记忆的可见性边界，取 `project` 或 `global`；默认检索组合当前 project 与 global。
_Avoid_：workspace scope、session scope

**项目标识**：
标识一个 project 记忆空间的值；它不是项目的完整路径或持久化记录 ID。
_Avoid_：项目路径、workspace ID

**全文相关性**：
FTS 判断记忆内容与查询是否词法匹配的候选资格，是进入检索结果的内容门槛。
_Avoid_：可检索性、检索热度、优先级

**记忆稳定性**：
使用事件能够增强的 FSRS 生命周期状态，决定可检索性随未使用时间衰减的速度；它不等于使用次数。
_Avoid_：使用次数、检索次数

**可检索性**：
记忆稳定性结合连续经过时间得到的动态生命周期信号，用于表达记忆随时间保留的程度。
_Avoid_：全文相关性、检索热度、使用频率

**检索事件**：
一条记忆被 `search` 作为结果返回一次；`get` 和 `list` 等维护读取不产生检索事件。
_Avoid_：访问事件、使用事件

**检索热度**：
检索事件累积形成的有界排序信号，只在具有全文相关性的候选内调整次序，不增强记忆稳定性。
_Avoid_：可检索性、全文相关性、使用频率

**使用事件**：
一条活跃记忆被实际采用后，通过显式 `use` 记录的事件；它增强记忆稳定性并更新使用统计。
_Avoid_：检索事件、访问事件

**活跃记忆**：
尚未软遗忘、具备进入默认检索候选资格的记忆；它仍须通过记忆作用域与全文相关性门槛。
_Avoid_：已恢复、未删除记忆

**软遗忘**：
从默认 `search` 隐藏但持久数据仍存在、可以恢复的生命周期状态；自然衰减与显式 `forget` 是不同触发原因。
_Avoid_：删除、物理删除、过期

**恢复**：
把软遗忘记忆按新记忆的初始生命周期转为活跃记忆，同时保留记忆身份与知识本体且不伪造使用事件。
_Avoid_：使用、重新新增

**删除**：
经显式确认后不可恢复地物理移除记忆；删除不属于软遗忘生命周期状态。
_Avoid_：软遗忘、forget、隐藏

### Skill 管理

**受管 skill** 与 **skill 安装状态** 为 [Common](../common/CONTEXT.md) 共享术语。Nano Mem 使用它们表达由 `nm self skill` 安装、检查、更新或卸载的 `nano-mem` skill 及其四态。
