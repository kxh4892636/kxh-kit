# 状态事件自动续跑

## 交付

当当前 Herdr session 任一 workspace 的任一已识别 agent 进入 `idle`、`blocked` 或 `done` 时，插件无需人工调用即可立即检查并自动续跑满足限流证据的停顿。

## 范围

- 在 manifest 声明 `pane.agent_status_changed` event hook，并以 `handle-event` 入口消费 `HERDR_PLUGIN_EVENT_JSON`。
- 将事件只作为唤醒信号；解析 `.data` 后调用单目标处理接口并再次取得 authoritative agent 状态与读取修订。
- 复用 01/02 的候选、233 字符匹配、两种发送、指纹和诊断契约；`idle`/`done` 共用 `agent.prompt` 路径。
- 增加按 session/terminal 分片的跨进程文件锁，覆盖重复、乱序、并发与 occupant 被替换的事件。
- 不实现补偿 worker。

## 直接依赖

- 02：事件 handler 需要消费已经覆盖 `idle`、`done` 与 `blocked` 的单目标处理接口、Herdr socket 端口、发送策略、指纹与诊断契约。

## 验收

- [x] event envelope 测试证明只有进入 `idle`/`blocked`/`done` 的事件会触发检查；`working`/`unknown` 只更新去重资格而不发送。
- [x] 事件缺字段、状态已变化、terminal 已替换、read revision 已变化、重复或并发投递时安全跳过或至多发送一次。
- [x] matching `idle`/`done` 与所有类型的 matching `blocked` 分别沿 01/02 的既定发送路径成功，事件 payload 中的非权威旧值不能绕过二次确认。
- [x] 两个独立 handler 进程并发命中同一目标时，假 Herdr 只收到一次输入；遗留锁按明确 lease 过期策略恢复。
- [x] `corepack pnpm --filter @kxh4892636/herdr-limit-resume check`、`test`、`build` 通过。
- [x] disabled link 的 Herdr plugin list 不含 unknown event 或其他 manifest warning。
- [x] `node .agents/skills/nano-flow/script/check-domain.mjs .` 通过。
