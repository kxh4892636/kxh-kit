# 补偿扫描与插件生命周期

## 交付

插件在 Herdr restore 或 live handoff 后自动恢复，并以 30 秒 best-effort 补偿扫描覆盖漏失的状态事件；禁用或卸载后 worker 自行退出，操作者可按文档安装、诊断并理解非监督限制。

## 范围

- 在 manifest 声明 `[[startup]]` worker；按 socket/session 分片保证每个 server 至多一个 worker。
- worker 启动时立即执行全量扫描，之后每 30 秒复用 01/02 的扫描纵切。
- 每轮用 `plugin.list` 检查 enabled/installed 状态；disable、unlink 或 uninstall 后停止后续检查和输入。
- 处理终止信号、单轮错误隔离、遗留 worker lease 和结构化日志轮换；明确 Herdr 不监督意外退出的 worker。
- 编写本地 link、GitHub subdir install、Herdr restart/handoff、日志/state 目录、禁用与卸载说明。
- 增加分发与隔离 runtime smoke，不修改或重启当前工作的 Herdr session。

## 直接依赖

- 03：startup worker 与事件 hook 共同组成最终 manifest 和生命周期，并消费已稳定的自动续跑、跨进程锁、去重及诊断契约。

- [ ] 假时钟/假 socket 集成测试证明 worker 启动立即扫描，随后严格按 30 秒节拍扫描；单轮失败不终止后续轮次，同一 session 不能并存两个 worker。
- [ ] disabled、unlinked 或 missing plugin 响应使 worker 在发送任何新输入前退出；终止信号清理自己持有的 worker lease。
- [ ] Herdr restore/live-handoff startup 重复启动、遗留 lease 过期与进程重建场景不会破坏跨重启去重，也不会让不同 socket session 互相抑制。
