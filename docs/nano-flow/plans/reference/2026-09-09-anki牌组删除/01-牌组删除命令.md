# 牌组删除命令

## 交付

`nnf anki decks delete --name <deck> --yes` 删除指定牌组及其全部卡片与子牌组，并返回删除范围与卡片数；缺 `--yes` 为用法错误，目标不存在报错，`--read-only` 拦截，`--dry-run` 只返回计划。路由文档与分发 help 同步，本地打包重装后 `nnf` 可用该命令。

## 范围

`packages/nano-flow/src/builtins/anki/decks/decks.ts`（新增 `deleteDeck`）、`anki-command.ts`（注册 `delete`）、`decks/deck-operation-boundaries.spec.ts`、`anki-command.spec.ts`、`parser-contracts.spec.ts`、`test/distribution.spec.ts`、两份 `nano-flow-cli/references/anki.md`。不含 registry 发布与其他 `decks` 子命令。
