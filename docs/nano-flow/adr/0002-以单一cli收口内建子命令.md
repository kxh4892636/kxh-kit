# 以单一 CLI 收口内建子命令

Nano Flow 使用单一 `nf` bin 收口仓库内建的 CLI 能力，Anki 作为 `nf anki` 迁入后删除原 `anki-cli` 包、bin 和独立业务域，不保留兼容入口。相较为每项能力持续发布独立 CLI，单一命令树降低了安装、发现和路由成本；代价是子命令共用包版本与核心执行契约。MVP 的扩展 interface 仅面向内建子命令，不引入第三方运行时插件。

**Considered Options**: 保留各独立 CLI 并提供薄包装层（被拒绝——仍然要维护多个包、bin 和兼容契约）；运行时插件系统（被拒绝——MVP 只需低耦合接入仓库内建子命令）。
