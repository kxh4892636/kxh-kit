# 行级虚拟列表

## 交付

打开含数万行变更的单个文件 (lockfile 重写、大型新增/删除文件), 首屏与滚动不再卡死: 只有视口附近的行挂载到 DOM, unified 与 split 两种布局同样受界。

## 范围

做:

- 引入 `@tanstack/react-virtual` (已批准的新依赖), 在文本 diff 渲染链路 (TextDiffViewer / DiffChunk / SideBySideDiffChunk) 实现行级 windowing; 评论行、展开按钮等变高行由虚拟器动态测量。
- 新增/删除文件的全量行 (现 `useExpandedLines.ts:411` 强制全渲染处) 同样纳入 windowing。
- 保留导航契约: 键盘光标、评论跳转、文件树点击依赖行 DOM id (`file-{fileIndex}-chunk-{chunkIndex}-line-{lineIndex}`, domHelpers.ts:8-9), 虚拟化后以"先确保目标行挂载再滚动"编排维持可用 (先例: useLazyDiffRendering 的 ensureFilesRenderedUpTo + rAF 重试)。

不做: 文件级卸载 (04 的范围); Markdown/Notebook/Image 专用 viewer 的虚拟化; 语法高亮机制本身改造。
