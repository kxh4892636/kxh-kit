# 默认对比与三点对比

## 交付

打开仓库即呈现有意义的默认 diff：当前分支与远程默认分支的三点对比，无需手工选择 base/target。

## 范围

做：

- 默认对比 = 当前分支 vs 远程默认分支的三点对比；远程默认分支判定顺序：`origin/HEAD` symref → `origin/main` → `origin/master` → 第一个远程分支。
- 降级链：无远程或 detached HEAD 时，默认对比降级为未提交改动 vs HEAD。
- branch 间对比的三点（默认）/ 两点切换选项。

不做：对比矩阵的其他形态（branch/commit/staged/working-tree 选择能力由 fork 自带，01 已落地）。

## 直接依赖

- 01：消费其 GitDiffParser 数据层与 fork 自带的对比选择 UI。

## 验收

- [ ] 处于 feature 分支的仓库打开后，默认展示当前分支与远程默认分支的三点 diff。
- [ ] 无远程的仓库打开后，默认展示未提交改动 vs HEAD。
