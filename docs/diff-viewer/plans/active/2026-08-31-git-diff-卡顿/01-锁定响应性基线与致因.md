# 锁定响应性基线与致因

## 交付

卡顿会话能够在真实 Electron 中稳定复现并量化；健康基线、失败预算和 layer/commit 对照把 causal hotspot 收窄到可实施的模块，使后续修复不依赖猜测。

## 范围

- 记录实际失败会话的对比选择、输入规模、文件类型、显示模式、运行形态与卡顿阶段；不能复用原仓库时构造等形 fixture。
- 建立同机健康小对比与失败 fixture 的首次稳定、静止期收敛、按钮响应、滚动响应和 long task 基线。
- 在真实 Electron、真实布局和真实 `ResizeObserver` 下提供可重复的 failing responsiveness 用例或等价诊断 harness。
- 分别关闭文件、chunk、行虚拟层并执行关键 commit 对照，结合 renderer profile 定位 causal hotspot。
- 只增加测试/开发诊断设施并记录结论，不修改生产行为来掩盖卡顿。

## 直接依赖

- 无。

## 验收

- [x] 真实或等形失败 fixture 在当前 fixed point 稳定越过同机响应性预算，而健康小对比保持在预算内。
- [x] 性能证据覆盖首次稳定、静止期收敛、代表性按钮响应、滚动响应和 long task，且使用真实 Electron 与真实 `ResizeObserver`。
- [x] layer/option A/B 对照与 CDP profile 给出可证伪的 causal hotspot、最小修复边界和 Issue 02 可直接消费的预算。
- [x] 诊断开关与详细埋点不进入生产 UI 或长期产品遥测。

## 诊断证据

- fixed point `41855c6`、Windows 同机、真实 Electron/CDP：健康 1×20 行 fixture 的 24 次同步 scroll burst 为 0.1–0.4ms；多轮中，单巨型 chunk 的行虚拟层（1×1000 行）为 277–389ms，多 hunk 的 chunk 虚拟层（1×1000 行）为 387–563ms，多小文件的文件虚拟层（100×20 行）为 465–766ms，文件+行嵌套（12×1000 行）为 851–1242ms。
- 同轮浏览器真实 wheel 输入（12 次、交替方向）的派发耗时范围为健康 191–202ms、行 531–554ms、chunk 554–569ms、文件 565–680ms、嵌套 464–544ms；虚拟化 fixture 是同机健康基线的 2.4–3.4 倍。CDP profile 在四种超预算形状都采到密集 DOM 提交与 `getBoundingClientRect`，而静止期连续三个 250ms 窗口均能收敛且无 long task，说明回归集中在滚动更新路径，不是后台死循环。
- 只设置 `useFlushSync: false` 的 A/B 构建：健康/行/chunk/文件/嵌套的同步 burst 为 0.1/0.9/0.3/0.6/1.0ms；真实 wheel 派发为 193/329/380/467/295ms，相对 fixed point 的四个虚拟化形状分别下降 40%/31%/17%/36%；连续滚动最长帧全部为 16.8–17.2ms。只减少额外 layout-effect 触发没有稳定收益。
- commit 对照与 layer 对照一致：`65c0deb` 引入行/chunk 虚拟化及共享主滚动容器上的默认同步通知，`b6fc7a2` 又把文件 windowing 接到同一滚动链；当前五形状矩阵分别隔离无虚拟化、行、chunk、文件和文件+行嵌套路径。`useFlushSync` 单 option A/B 在保留全部虚拟层、动态测量和导航契约时消除了同步事件处理放大。
- causal hotspot：`@tanstack/react-virtual` React wrapper 的默认同步通知在文件级与行级 virtualizer 共用主滚动容器时放大为连续同步 renderer commit。Issue 02 的最小修复边界是关闭该同步通知；保留所有虚拟层、动态测量与导航契约。
- 锁定预算：每个虚拟化 fixture 的 24 次同步 scroll burst 必须低于 `max(20ms, 同轮健康基线 × 10)`；真实 wheel 派发低于同轮健康基线的 2.75 倍；静止 task ratio 低于 10%，无 long task；工具栏响应低于 150ms；连续滚动最长帧低于 50ms；可见后 5 秒内取得连续三个 task ratio 低于 10% 的 250ms 窗口。首次可见只记录同机回归，不设跨机器绝对阈值。

## 交付记录

- 交付物：真实 Electron 等形 fixture、CDP task/layout/style 指标、Long Task 观察、真实 wheel 与合成 burst、CPU profile、工具栏与滚动响应采样，以及健康/行/chunk/文件/嵌套五层矩阵。
- 证据：fixed point 多轮同步 burst 的行/chunk/文件/嵌套层稳定达到 277–389/387–551/465–766/860–1242ms；真实 wheel 也稳定区分健康与虚拟化路径。`useFlushSync: false` A/B 把全部虚拟化形状的同步 burst 降至 1ms 以内，并显著降低真实 wheel 派发等待；Issue 02 负责把五层矩阵转为长期预算断言。
