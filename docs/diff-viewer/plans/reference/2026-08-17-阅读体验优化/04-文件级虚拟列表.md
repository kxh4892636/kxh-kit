# 文件级虚拟列表

## 交付

浏览含数百个文件的 diff 时, 远离视口的文件块被卸载, DOM 总量不随滚动/跳转累积; 文件树点击与键盘导航仍可跳转任意文件。

## 范围

做:

- 将现 `useLazyDiffRendering` 的"只挂不卸"改为 windowing: 远离视口的文件块卸载, 回到附近时重新挂载; 每文件粘性头部 (DiffViewerHeader) 行为保持。
- 文件树点击/键盘跨文件导航的"先确保挂载再滚动"编排保持可用 (现有 ensureFilesRenderedUpTo + rAF 重试语义保留)。
- 复用 03 建立的 react-virtual 集成与滚动容器接线, 不引入第二套虚拟化机制。

不做: 行级 windowing (03 已完成); 文件树本身 (FileList) 的虚拟化。
