# 默认浅色主题

## 交付

无用户偏好时应用以 light 主题启动: 首屏 bootstrap 即 light (不闪 dark), 默认语法高亮主题为 light 族; Settings 的 light/dark/auto 三选项保留, `auto` 仍跟随系统; 已存有偏好的用户不受影响。

## 范围

做:

- `SettingsModal.tsx` DEFAULT_SETTINGS: `theme` dark → light, `syntaxTheme` 切到对应 light 族主题。
- `appearanceTheme.ts` bootstrap: 无存储偏好时解析为 light (不再跟随系统); `auto` 语义不变。

不做: 色板/配色本身调整; 删除 dark 或 auto 选项; 色弱模式 (deuteranopia) 改动。
