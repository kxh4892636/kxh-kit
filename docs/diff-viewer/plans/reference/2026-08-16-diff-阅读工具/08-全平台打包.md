# 全平台打包

## 交付

electron-builder 产出 Windows / macOS / Linux 三平台安装包；Windows 产物实际构建、安装并启动验证。

## 范围

做：

- electron-builder 配置：Windows（nsis）、macOS（dmg）、Linux（AppImage + deb）三类 target 与应用元数据。
- 打包脚本（如 `pnpm --filter @kxh4892636/diff-viewer pack`），并接入构建产物布局。
- Windows 安装包实际构建、安装、启动验证。

不做：代码签名、自动更新、CI 发布流水线；macOS / Linux 实机构建验证（mac 产物需 macOS 构建环境，本 issue 只保证 target 配置就绪）。

## 直接依赖

- 01：消费其应用骨架与 main / preload / renderer 构建产物布局。

## 验收

- [x] Windows 安装包构建成功，安装后启动可渲染 diff。
- [x] macOS / Linux target 配置就绪（构建命令存在且配置可解析）。
