# Diff Viewer

Diff Viewer 是一个 Electron 桌面工具：打开本地或远程目录，自动识别其中（含嵌套）的 git 仓库，以仓库分组阅读和评审 diff。

## Language

### 对比

**对比**：
一个仓库内 base 与 target 两个 commitish（或 working tree / staged）构成的 diff 视图配置；每个仓库同一时刻只有一个激活对比，可切换。
_避免使用_：diff 配置、比较

**三点对比**：
以两个 branch 的 merge-base 为 base 的对比，呈现"目标分叉后的改动"；branch 间对比的默认方式。两点对比为可切换选项。
_避免使用_：三叉对比

**默认对比**：
打开仓库时的初始对比：当前分支与远程默认分支的三点对比。
_避免使用_：初始 diff

### 仓库与视图

**嵌套仓库**：
打开目录后递归扫描发现的 git 仓库；在仓库内部发现的独立仓库（含 submodule）识别为父子条目。
_避免使用_：子目录仓库

**远程视图**：
通过 SSH 打开远程主机上的目录：git 命令在远端执行，diff 数据传回本地渲染。
_避免使用_：远程仓库（与 git remote 冲突）

### 评论

**评论锚点**：
评论的定位坐标：仓库 + 文件路径 + 行号 + side（new 为主，支持 old）+ 可选代码片段快照。
_避免使用_：评论位置
