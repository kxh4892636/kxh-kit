# 安装配置与真机验证

## 交付

`@kxh4892636/pi-deepseek-web` 已安装进本机 pi；`~/.pi/agent/pi-deepseek-web.json` 写入用户提供的 DeepSeek key 与默认限额；本机 pi 能用 `web_search` 与 `web_fetch` 完成一次真实检索与抓取，并留下证据。

## 范围

- 在 workspace 执行 `pnpm install`，使 `turndown`、`@joplin/turndown-plugin-gfm` 落位到包内 `node_modules`。
- 执行 `pi install <abs path>/packages/pi-deepseek-web`，确认 `~/.pi/agent/settings.json` 的 `packages` 包含该本地路径。
- 写入配置文件：`apiKey` = 用户提供的 key，其余字段用默认值；仓库内只保留 `.example`，确认密钥不进入任何被跟踪文件。
- 真机冒烟：用 `pi -p` 分别驱动 `web_search` 与 `web_fetch`，从会话 jsonl 核对工具调用、结果与来源。
- 记录安装与卸载方式（README / 交付记录），不改 pi 上游。
