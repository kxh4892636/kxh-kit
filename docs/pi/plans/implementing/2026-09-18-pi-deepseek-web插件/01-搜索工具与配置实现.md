# 搜索工具与配置实现

## 交付

安装 `@kxh4892636/pi-deepseek-web` 后，模型可调用 `web_search` 工具，经 DeepSeek 的 `web_search_20250305` 服务端工具得到可选搜索问答与去重来源列表；端点、模型、凭据与限额来自配置文件。

## 范围

- 包脚手架：`package.json`（`pi.extensions` 指向 `./src/index.ts`、peer/dev 依赖）、`tsconfig.json`、`vite.config.ts`、`.gitignore`、`README.md` 与配置文件 `.example`。
- `src/config.ts`：路径优先级（`PI_DEEPSEEK_WEB_CONFIG` > 项目 `.pi/` > `getAgentDir()`）、字段默认值、凭据回退与缺失错误。
- `src/search.ts`：DeepSeek 请求构造、请求头、`citationSnippets`、`mapAnthropicResponse`、错误分类。
- `src/format.ts`：`web_search` 的模型可见文本投影。
- `src/index.ts`：扩展工厂，注册 `web_search` 工具。
- vitest 单测覆盖上述纯逻辑（含错误分支）。
- 不包含 `web_fetch`（Issue 02）与安装/落盘（Issue 03）。
