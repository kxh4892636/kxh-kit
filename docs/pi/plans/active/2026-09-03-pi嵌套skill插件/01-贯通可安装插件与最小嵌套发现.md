# 贯通可安装插件与最小嵌套发现

## 交付

用户可以把 `pi-nested-skill` 作为 Pi package 加载；启动资源发现时，插件能从一个已载入原生 skill 的路径找到其后代 `SKILL.md` 并交回 Pi。

## 范围

- 创建 package manifest、README、TypeScript 配置和 extension entry。
- 建立 discovery 的最小接口与 extension `resources_discover` 编排。
- 贯通“原生 skill command 路径 → 一个后代 `SKILL.md` → 补充路径”的最小闭环。
- 建立 package 级测试入口与宿主 API test double。
- 不在本 issue 完成 ignore、symlink、排序、冲突矩阵或 input 原位展开。

## 直接依赖

- 无。

## 验收

- [x] package 可由 Pi 的 `package.json#pi.extensions` 入口加载，测试证明 startup/reload 的资源事件能返回父 skill 内的后代 `SKILL.md`，且不返回父 `SKILL.md` 自身。
