# 交付网页抓取模型工具

## 交付

Pi 模型可以调用 `web_fetch` 匿名读取一个公共 HTTP(S) 文本页面，获得带最终 URL、状态码、不可信提示和引用指引的有界文本或安全 Markdown。

## 范围

在安全 transport 上实现 HTML/text/JSON/XML 结果、非 2xx 数据语义、活动/隐藏 HTML 移除、Turndown + GFM 转换、转换失败省略、最终 50KB/2,000 行上限与 Pi tool 注册。覆盖 content-type、charset、binary/missing type、HTML sanitizer、Markdown escaping、截断和 fake `ExtensionAPI` round trip。不执行公开网络 smoke。

## 直接依赖

- 01：需要 package entry、fetch 配置与 extension 组合入口；消费其 config snapshot 与 package test seam。
- 03：需要安全匿名 transport；消费其 bounded fetch result、final URL/status/body kind 和稳定错误。

## 验收

- [x] fake Pi tool call 能把受控公共 HTML 转为不含活动/隐藏内容的 GFM Markdown，并保留状态、外部不可信提示与引用指引；binary、非法 charset、跨源 redirect 与大小超限均形成稳定 error tool result。
