# 建立公共网页抓取安全传输

## 交付

package 获得一个匿名、有界、可取消的公共 HTTP(S) 抓取模块；它在连接前证明目标地址公开并把连接固定到该地址，重定向不能逃出原 origin。

## 范围

实现 URL/长度/credential policy、IPv4/IPv6 公共单播分类、DNS64 映射防护、resolver 与 `undici` pinned connector、同源逐跳重定向、byte/char/timeout/redirect 上限、Content-Type/charset 分类和稳定错误。通过注入 resolver/connector/transport 构造 deterministic tests。暂不注册 `web_fetch`，不做 HTML→Markdown。

## 直接依赖

- 01：需要 package dependency、fetch 配置与测试 seam；消费其 resolved fetch snapshot 和错误脱敏约定。

## 验收

- [ ] controlled resolver/connector tests 证明公共地址才会被 dial，mixed/private/DNS64-private 解析均在连接前拒绝，同源每跳重新验证、跨源拒绝，所有 body/timeout/cancel 上限可独立判定且不发送搜索 credential。
