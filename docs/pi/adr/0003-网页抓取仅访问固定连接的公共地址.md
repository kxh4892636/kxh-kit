# 网页抓取仅访问固定连接的公共地址

`web_fetch` 只访问公共 HTTP(S) 文本资源：请求前验证全部 DNS 结果为公共地址，把连接固定到已验证地址，并只跟随同源重定向且在每一跳重新解析与固定。HTML 删除活动与隐藏内容后转换为 GFM Markdown；二进制或缺失 Content-Type 的响应拒绝进入模型上下文。

## Considered Options

- **公共地址验证与连接固定（选定）**：同时阻止直接 SSRF、DNS rebinding 与重定向逃逸。
- **校验 URL 后使用普通 fetch**：连接时会再次解析主机，攻击者可在校验后改变 DNS 结果；被拒绝。
- **允许内网与 localhost**：便于本地服务访问，但把模型工具变成内网探测与数据发送通道；被用户明确拒绝。

## Consequences

- 跨源重定向要求模型使用新的 `web_fetch` 调用，使每个新 origin 都显式可见。
- PDF 等二进制内容、浏览器执行与正文抽取不在本能力范围内。
- 安全策略不可由配置放宽；配置只调整时间、字节、字符、输出与同源跳数上限。
