# 插件采用全局分区配置

`pi-deepseek-web` 从 Pi `getAgentDir()` 下的 `pi-deepseek-web.json` 读取 strict `{ search, fetch }` 全局插件配置，并在每次工具调用开始时形成一次不可变 snapshot。该配置及搜索凭据供用户的所有 Pi 项目共享；search section 必须存在，fetch section 可省略并使用安全默认上限。

## Considered Options

- **全局分区配置（选定）**：凭据只配置一次，search 与 fetch 的不同责任仍由 section 隔离。
- **项目级配置**：凭据作用域较窄，但每个项目都要复制或引用同一 DeepSeek credential；被用户明确拒绝。
- **package-local 配置**：local path 可用，但 npm/git 更新可能覆盖或清理配置，且把用户 secret 放进安装存储。

## Consequences

- 全局 credential 不经过项目 trust；用户必须把配置文件视为跨项目共享的私有数据。
- literal `apiKey` 只存在于未跟踪的实际配置；也可用 `apiKeyEnv` 引用环境变量。
- 配置修改在下一次工具调用生效，同一批查询或抓取不会混用两次读取结果。
