# 开发验证

在仓库根目录运行 `pnpm run ready`，依次执行全仓格式、lint 与类型检查、各包测试和构建。

文本文件检出使用 LF，以 `.gitattributes` 为准；Windows 批处理文件保留 CRLF。不要依赖个人的 `core.autocrlf` 设置来满足格式门禁。

测试阶段使用 `vp run -r --no-cache test`，保留默认并发。Windows 上，缓存任务的执行跟踪与 Git/MSYS 子进程存在冲突；串行运行仍会出现 `MapViewOfFileEx 'shared.5'`、错误码 487，关闭任务缓存后通过。构建阶段保留缓存。更新工具链后，如需恢复测试缓存，必须重新进行有缓存和无缓存的 Git 集成对照。

Workspace 的 CLI 契约位于 `packages/nano-flow/src/builtins/workspace/testing/`，使用可读 JSON 快照。辅助代码递归解码嵌套 JSON，规范化工作区路径、临时 fixture URL、随机目录和 Git SHA；命令参数、退出码和业务输出仍参与比较。修改快照前核对原业务断言与预期差异，不收录机器路径或仅为消除失败而更新期望。
