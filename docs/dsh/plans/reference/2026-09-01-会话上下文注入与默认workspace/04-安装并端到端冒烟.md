# 安装并端到端冒烟

## 交付

改动后的插件安装到 web profile 并重启生效；冒烟验证两项行为：①未给 workspace 时新会话与调用方同 workspace；②`context` 作为系统消息注入、创建不触发调用、首调用由用户消息驱动后（`session_read` 可读到注入上下文与回复）。

## 范围

- `vp pack` 重建 dist → **同步 dist 到 profile 快照**（经验：`dsh plugin add` 是快照复制）→ 用户手动重启 web 进程。
- 冒烟（一次模型请求）：`session_spawn`（带 `context`、不带 workspaceId/cwd）→ 验证新会话 workspace 与调用方一致 → 确认创建后未触发调用（`session_wait` 前 `session_read` 无回复；或等待观察）→ `session_prompt` 首条用户消息 → `session_wait` → `session_read` 看见注入上下文（系统段）与回复 → `session_archive` 清理。
- 不包含：任何其他功能变更。

## 直接依赖

- 02：消费默认 workspace 行为。
- 03：消费 context 注入行为。

## 验收

- [ ] 安装成功 + 重启后工具可用
- [ ] 冒烟：同 workspace 验证通过；注入上下文出现在系统视图中；创建后无模型调用（**零调用证据**：创建到首条用户消息之间无 assistant 回复）
- [ ] 首条用户消息触发模型调用并产生回复；`session_read` 可读
- [ ] 冒烟会话已归档；`vp check`/`test` 全绿（合并后）
