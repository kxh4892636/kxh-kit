# 重装重启与真机冒烟

## 交付

两个插件在重启后的 `0.1.2-rc.1` 宿主上端到端正确：profile 装入 `0.1.2-rc.1` 版上游工具包，9 个自有工具与 5 个上游搜索工具可用，已存在子会话的 `session_read` 成功，任意深度 skill 发现仍生效。

## 范围

- `vp pack` 重建两个包的 `dist`；`dsh plugin --profile web add file:<包路径>` 重装快照（`file:` 为快照复制，不跟随源码）。
- 重启 3080 受管实例（`dsh-alive`），使新快照生效；重启会中断当时正在执行的会话，交付时最后执行并请用户刷新页面。
- 真机冒烟（零成本优先）：工具目录含 9 个自有 `session_*` 与 5 个上游搜索工具；`session_list`；`session_read`（带 `parentSessionId` 读已存在子会话，验证 inject 与 `stateOf` 修复）；`session_read`（普通会话，验证 `chunkrow/*` 展开仍在）；嵌套 skill 仍在技能目录。
- 端到端冒烟（一次模型请求）：`session_spawn` → `session_prompt` → `session_wait` → `session_read` → `session_rename` → `session_archive`。
- 不包含：代码逻辑变更（冒烟暴露的新缺陷按新 issue 处理）、`alpha` 发布通道验证、GUI 与上游改动。

## 直接依赖

- 01：消费其 peer/依赖范围（重装时解析出 `0.1.2-rc.1` 版上游工具包）。
- 02：消费其 `ctx.get` 服务组装与 `stateOf` 顺序修复（子会话读取能否成功取决于此）。

## 验收

- [ ] 两个包 `dist/main.mjs` 重建成功；profile 快照与工作区 `dist` 哈希一致

- [ ] 重启后工具目录含 9 个自有 `session_*` 与 5 个上游搜索工具（`session_search`/`session_trace`/`session_event_search`/`session_event_trace`/`session_event_read`）
- [ ] `session_read`（带 `parentSessionId`）成功返回消息，无 `cannot get property "…" without inject`
- [ ] `session_read`（普通会话）仍把 `chunkrow/*` 打包行展开为 assistant 文本；`session_list` 返回正常
