# 会话管理工具实现与单元测试

## 交付

用户可在会话中通过 9 个模型工具完成 session/model CRUD：`session_list` / `session_read` / `session_spawn` / `session_prompt` / `session_model_list` / `session_model_select` / `session_rename` / `session_archive` / `session_wait`，均直调 Host 服务并携带可读错误映射。

## 范围

- 包脚手架：`package.json`（`dsh.bundle.patch` 声明、peer/deps）、`cordis.patch.yml`（至少含 `session-manager` 插入行）、`tsconfig.json`、`vite.config.ts`、`README.md`。
- 9 个工具的实现（`defineTool` + 参数校验 + `execute` + `presentCall`）：参数/输出契约按 spec「实施决策」表。
- Host 调用封装：`sessionController` / `workspaceRegistry` 注入、`RemoteError` → 可读错误映射、subagent 子会话寻址（`parentSessionId` + 投影 mode 自动解析）。
- vitest 单元测试（fake ctx/服务驱动）：参数校验、正常路径、错误映射、归档过滤与 workspace 归属、子会话寻址失败路径。
- 不包含：上游搜索挂载（Issue 02）、安装与冒烟（Issue 03）。
