# 使用 Fyne 重写管理界面

2026-09-06，用户在原生 Win32 版本交付并合入 main 后，明确选择 Fyne 重写 GUI，并要求先拆分任务。

Fyne 替代 ADR 0001 的“Win32 系统控件”选择，用维护中的 Go GUI 框架承载主题、自适应布局和界面交互；原生在此指桌面窗口与本机运行，不表示控件由 Windows 系统绘制。外部 Node.js/npm、单 exe、私有版本安装、用户数据隔离和管理核心行为保持原决策。

重写集中于 GUI 及必要 Windows 集成。首次可操作构建即验证工具链、中文字体、图形依赖和性能；框架选择不自动放宽已确认的性能预算。完整依赖图及交付基线仍待本轮 Plan 确认。
