# 原生管理器与外部运行环境分离

管理器采用 Go 与 Win32 系统控件，作为单个 exe 分发；使用本机 Node.js，缺失时提示安装，不内嵌或自动升级 Node.js。用户明确要求高性能 Windows 原生 GUI，接受运行依赖与配置写入用户数据目录，因此不采用浏览器运行时承载管理窗口，也不将完整 DSH 与 Node.js 打包进 exe。

官方 DSH 通过 npm 的发布渠道安装到管理器私有版本目录，更新时准备新目录再切换；保留原全局安装与默认用户 profile。这样可避免 Windows 文件占用导致原地升级失败，并让程序版本回退独立于用户的 Node.js 与全局工具管理；回退不撤销上游数据迁移。
