# 托盘保活与登录自启

## 交付

用户关闭窗口后，托盘中的管理器保持 DSH 运行，崩溃自动恢复，并可选择登录时自动启动。

## 范围

US-004：托盘操作、用户意图驱动的保活、退避与稳定重置、低频可达状态提示、登录自启、完整退出及注销清理。保活恢复固定运行版本；自动版本切换由 03 负责。

## 直接依赖

01：消费可运行 GUI、启动/停止及受管 Job 契约，才能观察受管实例退出、恢复和清理。

## 验收

- [ ] 关闭窗口进入托盘，DSH 继续可访问，双击托盘可恢复窗口。
- [ ] 受管服务异常退出按 1/2/4/8/16/30 秒恢复，稳定运行 60 秒重置退避。
- [ ] 主动停止取消定时恢复；HTTP 暂不可达只显示异常，不直接终止进程。
- [ ] 明确退出与注销清理受管 Job，其他 Node.js 进程不受影响。
- [ ] 登录自启可开关，默认关闭；恢复配置正确。本 issue 测试和原生集成门禁通过。
