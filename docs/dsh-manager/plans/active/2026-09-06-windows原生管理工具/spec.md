# Windows 原生 DSH 管理工具

## 问题

Windows 本机使用者需要轻量 GUI 完成 DSH 安装更新、指定端口启动和保活，减少手工维护。管理器使用 Go 和 Win32，交付单 exe。Node.js 使用系统安装版本，不内嵌。

## 方案

以单个 Windows 原生进程集中管理单个 DSH 实例。默认本机 3080 端口，可保存工作目录与端口；后台完成安装、更新与进程操作，窗口显示版本、状态和有界日志。关闭窗口进入托盘，可选登录自启；主动停止不触发保活。

从官方 npm latest 发布渠道解析固定版本，安装到 LocalAppData 的私有版本目录。首次使用自动准备 DSH；之后启动检查更新，每 6 小时自动检查下载，下次显式启动应用。用户可关闭自动更新或立即更新重启。新版本首次就绪失败时回退一次到先前成功版本。

## 已排除的备选

- 内嵌 Node.js：用户明确不需要，使用系统环境。
- WebView/Electron 管理窗口：原生系统控件更符合本工具的性能与平台目标。
- GitHub master 源码构建或覆盖全局 npm 安装：增加工具链、干扰现有环境，且源码版本不等于已发布版本。
- 无响应即强制重启：DSH 可能正在长任务中；首版以进程退出为保活触发。
- Windows 服务与多实例：超出确认的单用户、单实例、托盘使用边界。

## 实施决策

### 平台与模块

- 独立 Go module 位于 apps/dsh-manager，目标 Windows 10/11 x64，中文系统控件，嵌入 manifest，适配 DPI。
- 管理核心拥有启动/停止/更新命令与状态快照，集中串行化状态变化、退避和版本事务。
- Windows adapter 隐藏 Job Object、进程创建、端口所有权、托盘、命名互斥及登录自启。
- 版本仓库隐藏 npm 渠道查询、超时安装、版本目录、当前/上次成功/待应用/失败版本记录。
- 测试通过可替换进程、时间与版本来源验证使用行为。GUI 只接受快照和发出意图，异步工作通过窗口事件通知。

### 环境与持久化

- 检测 PATH 上的 Node.js，支持选择 node.exe；检测相应 npm 入口。缺失或不兼容时提示安装，不自动安装或升级 Node.js。
- Node.js 兼容要求依据官方发布包依赖及实际运行验证；源码当前要求仅作为检查依据，不能把源码版本当成发布包版本。
- 使用 node.exe 与官方包 bin 路径及独立参数启动，工作目录为用户配置；绑定 127.0.0.1，传入 --port 与 --no-open。
- 配置原子写入用户 LocalAppData。受管 DSH 使用默认用户 profile 与数据目录，保持已有模型和会话配置。
- 私有安装目录不改动全局 DSH；不接管其他方式启动的服务。端口冲突明确提示。

### 窗口与进程

- 单窗口包含当前/最新版本、服务状态、端口、工作目录、Node.js 路径和有界日志；支持启动/停止/重启、检查更新、更新并重启、打开 Web UI。
- 提供自动更新、保活和登录自启复选框；登录自启默认关闭，用户主动开启后才注册。
- 用户级命名互斥保证单管理器；重复打开激活原窗口。
- 启动使用挂起创建、加入 Job Object 后恢复执行，避免未归属的派生子进程；失败要清理所创建进程。
- 就绪判断结合进程存活、监听端口属于受管 Job 与 HTTP 可达；启动超时 120 秒。
- 异常退出后按 1/2/4/8/16/30 秒退避，稳定 60 秒后重置。保活重启保持原运行版本，不自动消费待应用版本。
- 运行中周期性低频检查 HTTP，仅提示可达异常，不据此强制重启。
- 主动停止先取消待重启，再尝试经过验证的优雅退出；超时清理受管 Job，记录无法优雅退出的情况。
- 关闭窗口隐藏到托盘；“退出并停止服务”及注销清理受管实例。管理器崩溃通过 Job 句柄关闭清理受管进程，首版不提供管理器退出后的后台守护。

### 更新事务

- 查询 npm latest dist-tag，可指向 rc/alpha，按真实版本号展示；不比较 GitHub master。
- 解析一次具体版本后固定安装；网络与安装有超时、错误反馈及取消清理。
- 安装完整成功后才设置待应用版本，部分安装不作为成功版本。
- 下次显式启动或管理器重新启动尝试待应用版本；运行中只下载准备，手动立即更新才重启服务。
- 新版首次就绪失败回退一次旧版本，标记失败版本，避免保活重启反复升级；用户手动操作可重试。
- 保留当前与上一个成功版本，另保留尚待应用的版本；清理只针对本工具拥有且未使用的目录，删除前验证绝对路径。
- 只承诺程序版本回退，不承诺撤销 DSH 已执行的数据迁移。
