# 自动更新回退与最终交付

## 交付

用户得到自动准备更新、失败可回退的轻量管理器，以及可直接运行的最终单文件 exe。

## 范围

US-003 与全故事最终验收：定时与手动检查、npm latest 解析、固定版本安装、待应用版本、更新重启、失败回退、失败版本抑制、目录清理；最终构建、使用说明、全部门禁与性能实测。

## 直接依赖

02：消费已完成的单实例 GUI、保活与用户停止意图契约，保证更新重启不与崩溃恢复竞争；01 的安装能力通过 02 的完整管理器继承。

## 验收

- [ ] 启动和每 6 小时检查官方 npm latest，支持关闭自动检查与手动检查，超时失败可见。
- [ ] 运行时准备版本不打断服务；下次显式启动或立即更新重启才应用，保活恢复不偷偷升级。
- [ ] 半途安装不记录为成功；新版就绪失败回退一次旧版并标记失败版本，用户可重试。
- [ ] 版本清理只处理已验证归属且未使用的目录，保留当前、上次成功和待应用版本。
- [ ] 全部故事对应的测试、至少 80% statement coverage、静态检查、真实 DSH 与 GUI 冒烟通过。
- [ ] 窗口启动、空闲内存及 CPU 满足 spec 预算；记录实测环境及未验证平台。
- [ ] 最终单 exe、构建方法、说明与门禁证据可定位；双轴审查无阻塞，提交成功后登记交付。
