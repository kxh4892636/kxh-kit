# 原生窗口与首次安装启动

## 交付

用户双击单 exe，通过原生窗口自动安装官方 DSH，设置端口与目录并启动、访问、停止服务。

## 范围

US-001 与 US-002：Go module、Win32 窗口、DPI manifest、Node.js/npm 检测、独立版本安装、原子配置、有界日志、就绪检测、Job 进程清理及命名互斥。窗口尚不提供后台保活与自动更新；后续在同一管理核心扩展。

## 直接依赖

无；根 issue，建立后续消费的启动/停止、快照、安装版本与受管 Job 契约。
