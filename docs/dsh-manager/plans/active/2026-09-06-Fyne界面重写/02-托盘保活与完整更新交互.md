# 托盘保活与完整更新交互

## 交付

用户可关闭窗口进入托盘，保持后台运行；通过 Fyne 窗口完成保活、登录自启与自动/手动更新，继续使用全部既有管理能力。

## 范围

接通托盘恢复与菜单、关闭隐藏、退出/注销清理、后台登录入口、三个选项、当前/最新/待应用版本和更新状态、检查更新、更新并重启。管理核心保持既有事务语义；仅按必要边界调整接口。

## 直接依赖

- 01：消费可操作的 Fyne 窗口、UI 调度与快照桥接、单实例/激活契约和基础服务操作，以同一生命周期承载后台能力。

## 验收

- [ ] 关闭入托盘不中断服务，恢复仍显示正确状态；退出和注销取消安装/恢复并清理受管进程，托盘不可用时窗口保持可访问。
- [ ] 登录项与 `--background` 保持兼容，只有单实例归属成功后启动后台检查或受管实例。
- [ ] 保活、登录自启、自动更新可保存并恢复；快速操作末次意图生效，失败后显示真实持久配置。
- [ ] 运行中准备更新不打断服务；显式启动/更新重启应用待应用版本，崩溃保活保持原版本。
- [ ] 新版失败回退及抑制、手动重试、下载期间停止、检查失败不破坏保活均可从 GUI 验证。
- [ ] 新控件测试与既有核心回归通过，隐藏时无持续无效刷新，输出阶段交付证据。
