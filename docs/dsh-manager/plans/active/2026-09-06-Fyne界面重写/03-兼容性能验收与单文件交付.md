# 兼容性能验收与单文件交付

## 交付

用户得到正式替代旧版的 Fyne 单文件 exe，所有既有能力保留，并有可复核的兼容性、界面和性能证据。

## 范围

将 Fyne 切为唯一正式入口，移除旧 Win32 控件/托盘代码及不再需要的 lxn/win 直接依赖；保留必要 Windows adapter。完成明暗主题、中文、DPI 和旧配置升级验证，替换原生子控件 ID 测量方法，优化性能，更新构建、许可、说明与验证记录。

## 直接依赖

- 02：消费已完整接通的 Fyne 生命周期、后台保活及更新能力，才能移除旧 GUI 并对最终替代版作完整验收；01 的基础交互经 02 继承。

## 验收

- [ ] 正式入口只使用 Fyne GUI，构建与运行不存在对旧 GUI 的隐式依赖，必要系统集成仍有效。
- [ ] 明暗主题、100%/150%/200% DPI、最小尺寸、长路径/错误、中文输入和日志滚动通过实际截图与交互检查；未验证环境明确列出。
- [ ] 旧配置、版本目录、登录项可复用；真实 DSH 使用隔离 profile/端口完成安装与启动停止冒烟。
- [ ] gofmt、go vet、全部测试、自有生产代码整体覆盖率至少 80% 和双轴审查通过。
- [ ] 最终可交互启动 <1 秒、空闲工作集 <40 MiB、60 秒 CPU <0.6 秒；分别记录可见与托盘状态，同条件提供旧版对照，预算冲突有明确解决结论。
- [ ] 单文件 exe、大小/SHA256、可复现构建入口、工具链/图形依赖、许可、使用说明和门禁证据齐备。
