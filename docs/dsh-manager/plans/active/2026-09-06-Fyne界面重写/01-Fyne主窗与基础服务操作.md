# Fyne 主窗与基础服务操作

## 交付

用户可在现代中文 Fyne 窗口中读取旧配置、修改设置、首次安装并启动 DSH、停止或重启、打开 Web UI，并查看状态及日志。

## 范围

固定依赖和可复现构建工具链；建立自适应主题布局与中文字体方案；将必要单实例/窗口激活边界从旧 GUI 提取；接通配置、服务操作、快照与有界日志。交付可单独运行的 Fyne 开发构建及初步性能结果。正式托盘和自动更新入口由 02 负责，最终旧 GUI 移除由 03 负责；本阶段关闭 Fyne 开发窗口明确退出并停止，不能宣称完整替代版。

## 直接依赖

无。消费基准提交已验证的 Manager 命令、快照、持久化与进程管理契约；必要 prefactoring 与第一个用户结果一同交付。

## 验收

- [ ] 指定版本工具链可构建并运行单个 Fyne exe，列明非系统 DLL 依赖检查结果；未要求最终用户安装编译器。
- [ ] 旧配置/有效安装直接可用；首次安装、启动/停止/重启、认证浏览器地址正常，端口冲突可见且不接管外部实例。
- [ ] 中文显示/输入/粘贴、路径选择、错误提示、状态按钮及有界日志可操作；后台操作不冻结窗口。
- [ ] 重复打开激活已有管理器，不创建第二个受管实例；开发窗口退出清理受管进程。
- [ ] 控件与核心回归通过；记录初始单 exe 大小、首帧/可交互时间、可见/隐藏资源占用，对照 spec 预算及 frontier。
