# 分发包采用选择性覆盖安装

`@kxh4892636/loop-kit` 在发布时从当前工作区生成资源快照，并通过必填的 `--target` 安装到已存在的目标根目录。`DOMAIN.md` 与 `.agents/skills/loop-kit` 采用覆盖式合并，保留目标中的额外文件；`AGENTS.md` 只同步 `GENERAL RULES` 和 `LOOP KIT` 两个受管标记块，保留其他内容。安装会预先校验标记结构，重复执行时跳过未变化内容，任一步骤失败则回滚整次写入。该边界优先保证用户自有内容不被误删，同时让包内同路径内容随版本更新。
