# Loop Kit

Loop Kit 业务域。本仓库维护可分发的工程协作规则与技能集合。

## Language

**受管标记块**：
源 `AGENTS.md` 中由同名起止注释界定、由分发包负责同步的内容区域，固定为 `GENERAL RULES` 和 `LOOP KIT`。安装时替换目标文件中的同名块，追加缺失块，并保留其他内容；目标文件不存在时，只按源文件顺序创建这两个块。
_避免使用_：配置段、托管片段

**目标根目录**：
用户通过必填的 `--target <path>` 参数指定的已存在目录；所有分发内容均按其在本仓库中的相对路径写入该目录，安装过程只创建其内部缺失的子目录。
_避免使用_：输出目录、安装路径

**分发包**：
发布到 npm 的 `@kxh4892636/loop-kit`，包含发布时本仓库中受分发内容的快照，并将其安装到目标根目录。
_避免使用_：安装器、同步包

**事务性整目录替换**：
先完整准备并校验分发包中的目录，再整体替换目标中的同路径目录；成功后目标目录与分发包一致，失败时恢复原目录。
_避免使用_：覆盖式合并、先删后拷

**已删除 skill 数**：
更新后从 `.agents/skills/loop-kit` 消失的 skill 数量；每个包含 `SKILL.md` 的目录计为一个 skill，随整目录替换移除的其他内容不计数。
_避免使用_：删除文件数、删除项数
