# Branching Template

用于不同可观察条件会进入不同过程或生成不同产物的 skill。主 `SKILL.md` 只负责选择分支和执行共同规则；每个分支的完整行为放在自己的文件中。

主文件骨架：

```markdown
# <Skill Title>

<所有分支共享的目标。>

## 选择分支

- **当 `<可观察条件 A>`**：读取 [BRANCH-A.md](references/BRANCH-A.md)，生成 `<产物 A>`。
- **当 `<可观察条件 B>`**：读取 [BRANCH-B.md](references/BRANCH-B.md)，执行 `<行为 B>`。

现有事实足以确定分支时直接选择；只有选择会实质改变目标且无法检索时才询问用户。

## 共同规则

- <每个分支都需要的规则。>

## 共同完成标准

每次只执行命中的分支；该分支的完成标准和共同规则全部满足后才算完成。
```

分支文件骨架：

```markdown
# <Branch Name>

当 `<精确条件>` 成立时使用本分支。

## 流程

### 1. <动作>

<说明。>

**完成标准：** <本步骤证据。>

### 2. <动作>

<说明。>

**完成标准：** <本步骤证据。>

## 分支产物

- **产物：** <文件、外部对象或结论>
- **验证：** <成功信号>
- **交接：** <下一步>
```

分支指针必须同时表达触发条件和目标行为；仅写“详情见某文件”不构成可靠指针。
