# Workflow Template

用于存在必要执行顺序的 skill。先写 steps，再写只在执行中按需查阅的 reference。

```markdown
# <Skill Title>

<用一两句话定义行为，并用一个引导词说明整个过程如何保持一致。>

## 流程

### 1. <动词开头的步骤名>

<动作、需要读取的事实和允许的决策。>

**完成标准：** <能够明确判定完成或未完成的条件；必要时列出必须全部覆盖的对象。>

### 2. <动词开头的步骤名>

<只执行当前阶段需要的动作。>

**完成标准：** <当前阶段的证据。>

### 3. <验证或交接>

<运行验证、处理失败并准备交付。>

**完成标准：** <验证结果、失败分支和交付状态均已明确。>

## 共享规则

- <每次运行都会用到、且会改变默认行为的规则。>

## 产物契约

- **位置：** `<路径、外部系统或回复位置>`
- **必需结构：** <章节、字段或文件>
- **验证：** <可执行检查与成功信号>
- **交接：** <下一阶段的输入和责任方>
```

用真实内容替换所有占位符；没有共享规则或持久产物时删除对应章节。
