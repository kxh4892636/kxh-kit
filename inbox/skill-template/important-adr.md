# seed-domain

调用 `grill-with-docs` skill, 初始化/更新业务域的 _ADR_ 文档。
关注于业务域*多仓库全栈开发*。
根据代码库现状，用尽可能少但足够的问题，使其覆盖下列实际存在的主题。
以下主题为重大架构决策，只要存在，必须创建为 ADR 文档。

## common

- 工作区概述；
- 代码开发约束；
- 多仓依赖关系；
- 如何联调/验收；

## fe

- 前端架构；
- 如何启动和调试前端应用；
- 如何开发一个组件；
- 如何接入一个接口；
- 如何 Mock 后端接口；
- 如何埋点/日志；
- 如何测试；

## be

- 后端架构；
- 如何启动和调试后端应用；
- 如何创建一个 API/RPC 接口；
- 如何接入数据库；
- 如何设计一个数据模型/数据表
- 如何开发/消费异步任务；
- 如何 Mock 外部数据；
- 如何记录日志/指标与 Trace；
- 如何测试；
